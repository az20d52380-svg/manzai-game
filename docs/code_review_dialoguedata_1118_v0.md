## 問題なしと確認した所
- 空の山・範囲外：pick/banter/reaction/indexAvoidingUsed は空配列ガードと負数対応の剰余あり。banterPools は6帯とも存在。強制アンラップ（!）・as! は無し。
- 描画ごとの変化：DialogueData は乱数 API を使わない。独白は session.picker(key: 年×131+週)（stablePicks で同じ週は同じ番号）。行動の一言は選んだ瞬間にだけ引く（WeekMainView.swift:866・body 内ではない）。salt の年×131+週は週が48以内で衝突しない。
