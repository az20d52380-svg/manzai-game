# 10年遊んだ時の「週の声」（掛け合い＋独白）の読み返し率の実測 v0

**材料・コード不変**（2026-10-25・懸念の台帳 L40「日常雑談の無口化」の材料）。GameCore・アプリ・テスト・tools は1行も変えていない。判断はオーナー。

## 要点3行
1. 10年で**週頭の声を約320〜360本読み、そのうち約60〜64%は「前に読んだのと同じ文」**（異なる文は約130）。1〜3年目は約8〜12%、4〜6年目は約63〜72%、**7〜10年目はほぼ全部（96〜98%）が読み返し**。1つの文の最多は1キャリア内で6〜9回。
2. 掛け合い（俺⇄谷口）は10年で約130〜145本読み、読み返し約62〜66%（69本のうち約50本を使う）。**帯別では「空白帯(lull)」が最悪（80%）**、平常・通過後・大会前が44〜55%。独白側は「体力低下」「通過後」「空白帯」「平常」が51〜75%。
3. 掛け合いは週の30〜55%で抽選されるだけで、残りの週は独白が出る。**どちらも足りていない**：声の数は1年あたり約32本に対し、在庫は掛け合い69本＋独白（帯ごと5〜32本）。無口化は「文が尽きて同じ文に戻る」形で、4年目あたりから起き始める。

## 材料（方法・仮定）
- 実測コード：scratchpad `banter/` の Swift 実行パッケージ（GameCore にパス依存・コミットしない）。`DialogueData.swift`（アプリ本物）をリンクして、**アプリと同じ呼び方**で `DialogueData.banter` と `DialogueData.innerVoice` を呼ぶ。`WeekRunner` を実際に10年回し、自由週ごとに声を1つ出す。
- GameSession／WeekMainView から写した式（行番号）：
  - 掛け合いの抽選：`rollWeekBanter`（GameSession.swift:607-617）＝本番まで6週以上先か次の本番なしなら55%・それ以外30%、当たれば `banter(band:, salt: 年*131+週, picker:)`。
  - 帯の決め方：`banterBand`（:619-627）＝連敗2以上 > 所持金5万未満 > 通過直後 > 大会1〜2週前 > 6週以上先 > 平常。
  - 直近避け：`pickIndex`（:117-125）＝使用済み番号を避け、尽きたら最も古く使った番号から使い回す（`usedPicks` はキャリア通算、`stablePicks` は年替わりで消す=:1081）。
  - 独白：`WeekMainView.monoBox`（:597-603）＝掛け合いが出ない週に `innerVoice(...)`（同じ picker、key=年*131+週）。弱点能力の判定は :1606-1610。
  - 次の本番：`upcomingStages`（:661-691）。自由週は今週を含めない。連敗・通過の更新は pump の :1255-1264、行動で失効は :345-347。
- **写せなかった所（近似）**：選択肢イベントが立った週は掛け合いも独白も出ない（:608）。確定発火の条件は多いので、**独立に12%の週を「声なし」にする近似**を置いた（0%の感度試験も実施、下に併記）。オファー帯が出る週は独白が隠れる（WeekMainView:388-393）、Beat1 発話が出る週も省略していない＝実際はここがやや少なく読まれる可能性。
- ボット3種×各30キャリア（シード違い）：全て大会は夜行バス・ネタは1本作って稽古/ライブで磨く。
  - **steady**：8手の稽古・バイト・休みの周期。所持金12万未満ならバイト、体力30未満は完全休養。各年頭に全能力を下限35へ（B型）。
  - **strong**：steady と同じ行動。1〜3年目は下限35、4年目から60（C型）。
  - **poor**：バイト（キツい・標準）中心、稽古は3週に1回。能力注入なし（A型。約6年で夜逃げ＝6.2年で終了）。
  - strong と steady の差が小さいのは、声の帯を決めるのが「連敗・所持金・通過直後・本番までの週数」で、能力の大小では動かないため（強い方が通過直後帯が少し多い程度）。
- 「読み返し率」＝（読んだ本数−異なる文数）／読んだ本数。掛け合いは1本＝2〜3行をまとめて1つの文として数える。同じ文が別の帯・別の場面にあれば同じ文として数える。

## 読み方（材料。判断はオーナー）
- 読み返しは**在庫の少なさと、1年に出る声の数（約32本）が主因**。直近避けは効いているが（1〜3年目は8%）、プールを一巡した後（掛け合い帯の在庫は11〜12本）は必ず戻る。
- 本数の多い帯が先に枯れる：**空白帯（掛け合い11本・独白14本）**、**独白の平常（32本）**、**通過後（掛け合い11・独白8）**。逆に連敗・金欠帯は在庫に余裕（出番が少ない）。
- 掛け合いは平均で10年に約130本読み、帯別の使用本数は 56（lull）・26・25・20 …。**増産の優先順（目安）**：①掛け合いの lull、②独白の passed と lowStamina（体力低下は8〜10本）、③掛け合いの plain/afterPass/eve、④独白 midseason。
- 在庫の目安：lull の掛け合いは10年で約56本読まれる（毎年約5.6本）。在庫11本では1年で半分近くを使い切る。台帳 L40 の「長期滞在帯を優先増産」はこの測定と向きが合う（具体の本数はオーナー判断）。
- 増やすかどうか、増やす場合の優先度、読み返し率の許容線（例：10年で3割以下）はオーナー判断。実プレイは戦い方・オファーや発話の出方・イベント頻度が違うので、絶対値は目安。
