# お笑い・漫才・芸人題材ゲーム 先行作リサーチ v0（2026-10-15）

目的：漫才コンビ育成SLG（48週×最大10年・稽古/バイト/休む・大会・ネタ帳・審査員講評）の作者が、先行作から「楽しさの作り方」と「避けるべき失敗」を学ぶ。
注意：実在作品名はこの調査文書の中だけ。ゲーム本体には出さない。
調査の限界：WebSearch 9回＋ページ取得。ストアの個別レビュー本文までは取れず、「評価」は記事・ストア表示の要約。確度は各項に（高/中/低）で付記。発売年が取れなかったものは「不明」。

## 作品一覧

### 1. 『THE 芸人』（スーパー野田ゲーWORLD 収録）
- 年・機種：2022年（11月の追加アップデート）／Nintendo Switch。素材協力はカイロソフト。
- 遊びの芯：お笑い事務所を立ち上げ、フリー芸人を雇って育成。週単位でネタ作り・オーディション・バイトを割り振り、毎月の賞レース（オンライン対戦）に出す。能力は「ネタ力」「平場力」「社交性」＋知名度・所持金・モチベーション。
- 評価（確度：中・Inside Games の体験記事1本）：褒め＝バイト漬けや社交性など「芸人の苦労」がシステムに出ている／売れる難しさに手応え／実在・架空芸人が混在して愛着が湧く。叩き＝知名度が低いと仕事が来ず、能力が上がっても収入に結びつかない／モチベーションが下がると立て直しにくく引退者続出／生活費で金が溶ける／事務所ライブでの資金稼ぎなど抜け道。
- 取り入れる：「バイトしないと食えない・知名度が無いと仕事が来ない」という芸人らしい制約を、稽古/バイト/休むの選択の重みにする。避ける：低迷から這い上がる手段が無い詰み（救済と抜け道の両方に注意）。

### 2. 『相声模拟器』（Steam・中国語系）
- 年・機種：2024年2月5日／Steam（PC）。350円。日本語非対応。
- 遊びの芯：相方と組み、セリフの選択肢でやり取りしながら芸を身につけていく漫才シミュレーション。自由な発想のステージもある。
- 評価（確度：低・紹介記事のみ。内容評価の記述なし）：Game*Spark が「ちょっと珍しい」として紹介。レビュー100件超が掲載条件。
- 取り入れる：漫才をセリフ選択の積み重ねで見せる軽さ。避ける：言語・文化の壁で笑いが伝わらないこと（ボケの面白さは文章力に依存）。

### 3. 『ともだち芸能舎』
- 年・機種：不明（最新更新2024年7月）／iOS（Kairosoft）。無料・課金あり。
- 遊びの芯：芸人・俳優・歌手など芸能人を育成し、友達キャラとタッグも組む。街で他プレイヤーと出会う通信要素。
- 評価（確度：中・App Store 表示）：5段階中2.7（53件）。好意＝カイロ好きにはやり込み要素が多い。不満＝ランク5超が厳しすぎる／終盤は他プレイヤーと出会わないと伸びずプレイヤーが少ないと詰む／不具合／データ引き継ぎ不可／序盤に日付が急に進み仲間が去る。
- 取り入れる：育成のやり込み余地。避ける：通信相手に依存する終盤、引き継ぎ不可、終盤の難度の急な壁。

### 4. 『キミは漫才師』（モバゲー）
- 年・機種：不明（2月24日サービス開始）／ガラケー向けソーシャル（DeNA モバゲータウン、開発パクレゼルヴ）。
- 遊びの芯：養成学校を出て地方の舞台を回り、ボケ/ツッコミを選んでコンビを組み、ファンを集めて日本一を目指す。「オモロカード」を集めてテレビ出演、他プレイヤーと漫才バトルでカードを奪い合う。
- 評価（確度：低・プレスリリースのみ）：評価記事は見つからず。
- 取り入れる：ファン数が増えて出番の格が上がる段階構造。避ける：カードの奪い合い等、コレクション/課金型に寄ると「漫才の面白さ」が消える。

### 5. 『タッチで漫才！ メガミの笑壺DL』
- 年・機種：2013年前後（記事は2013年5月）／ニンテンドーDS（DSiウェア）。COLLAVIER。
- 遊びの芯：ネタが自動進行し、ツッコミどころでコマンドが出たら最適なツッコミ（セリフ／表情／イメージ）を瞬時に選ぶ。「たとえツッコミ」「ノリツッコミ」は瞬発ミニゲーム。客の期待値を超えればクリア。
- 評価（確度：中・Inside Games 記事）：褒め＝的確なツッコミが決まる爽快感／チュートリアルが親切／テキストスキップ／後半ほど面白い。叩き＝タッチとボタンの使い分けが中途半端／声が無く文章を読むのでテンポが悪い／入力待ちでテンポ低下／漫才のバリエーションが少ない。
- 取り入れる：「最適な一手を選んだ時の気持ちよさ」と難度の尻上がり。避ける：ネタの種類不足、入力待ちのテンポ悪化、文字だらけの舞台。

### 6. 『よしもと芸人人生ゲーム』
- 年・機種：2012年8月／ボードゲーム（タカラトミー）。吉本創業100周年企画。
- 遊びの芯：人生ゲームの形で「笑いポイント」を稼ぎ、大御所を目指す。
- 評価（確度：低・発売情報のみ。レビューは取れず）。
- 取り入れる：ランダムイベントで人生の浮き沈みを見せる軽さ（ライブ・営業・事件）。避ける：運だけで勝敗が決まり、芸の成長が関係しない作り。

### 7. 『お笑いサッカー【育成シミュレーション】』
- 年・機種：不明（最終更新2023年1月）／iOS（Ginga Games）。Android 版は配信停止の表記。
- 遊びの芯：芸人そっくりの顔の選手を練習で育て、試合に出す。練習後の妙なイベントや、トラックで妨害など騒がしい展開。全国対戦。
- 評価（確度：低・ストア説明のみ）：編集部は「本格シミュレーションとカジュアルの併存」と紹介。ユーザー評は取れず。
- 取り入れる：練習後のバカバカしい突発イベントで育成の単調さを割る。避ける：題材とゲーム本体が噛み合わない（芸人なのに笑いの要素が薄い）こと。

### 8. 『Comedy Night』（スタンドアップ演者体験）
- 年・機種：2017年／Steam（PC）。Lighthouse Games。
- 遊びの芯：本物のマイクで自分のジョークを喋り、ネット上の本物の観客がヤジったり投票で降ろしたりする。キャラの見た目や声のピッチを変えられる。
- 評価（確度：中・gg.deals/Steamのまとめ）：Steamは「やや好評」（約74%、約9千件）。褒め＝安く、笑い転げる体験になる。叩き＝マイク必須／内容は一緒に遊ぶ相手の質に左右される（品のない部屋が多い）／Steam Deck は操作の制限あり。
- 取り入れる：観客の反応が即時に返ってくる緊張感。避ける：他人依存で体験の質が運任せになる設計。

### 9. 『Frowntown』
- 年・機種：2024年4月／Nintendo Switch（Elushis）。
- 遊びの芯：スタンドアップ芸人を目指すライフシム+RPG。クラブごとの観客の好みに自分の「WIT」を合わせて受ける。ステージ外の行動が能力と進路に影響し、装備を整えて最終大会へ。
- 評価（確度：低・Metacritic にレビュー0件。ストア説明のみ）。
- 取り入れる：「客層（会場）に合わせてネタを選ぶ」構造（寄席/ライブ/テレビで効くネタが違う）。避ける：不明（評価未取得）。

### 10. 小粒の経営系：『Chuckle Tycoon』『Idle Comedy Empire Tycoon』
- 年・機種：2024年／itch.io（Global Game Jam 作品）、iOS 放置系。
- 遊びの芯：コメディクラブ経営。変わり者の芸人と交渉し、飲み物や広告、価格を最適化。放置系は小さなクラブから帝国まで拡大。
- 評価（確度：低）：放置系は App Store 4.8（469件）だが、内容評は取れず。
- 取り入れる：数字が伸びる快感は放置系が強い＝成長の見える化。避ける：芸人が数字の駒になり、ネタの個性が消えること。

## まとめ

### 取り入れたい仕組み5つ
1. 「食えない芸人の制約」を選択の重みにする（稽古/バイト/休むの三択が毎週効く。出典：THE 芸人）。
2. 的確な選択が決まった時の爽快感と、尻上がりの難度（出典：メガミの笑壺）。
3. 会場・客層ごとに効くネタが違う（出典：Frowntown、Comedy Night の観客反応）。
4. 練習・稽古の合間に入るバカバカしい突発イベントで単調さを割る（出典：お笑いサッカー、人生ゲーム）。
5. 知名度・ファン数が上がると出番の格が変わる段階構造（出典：キミは漫才師、THE 芸人）。

### 避けたい失敗5つ
1. 一度低迷すると這い上がれない詰み（モチベーション低下・知名度ゼロ。出典：THE 芸人）と、その逆の資金稼ぎの抜け道。
2. 終盤の急な難度の壁や、他プレイヤー依存の進行（出典：ともだち芸能舎）。
3. 舞台がテキストだらけ・入力待ちでテンポが悪い（出典：メガミの笑壺）。
4. ネタ/漫才のバリエーション不足で飽きる（出典：メガミの笑壺）。
5. カード収集・課金・対戦に寄って、漫才そのものの面白さが薄れる（出典：キミは漫才師、ともだち芸能舎）。
