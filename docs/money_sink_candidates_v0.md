# 能力に変わらない吸い込み口の案 実測 v0（決定はオーナー）

要点
1. 能力・経験点に変えない出費だけを足すと、帯（決勝到達・初優勝・解散・夜逃げ）は4ボットとも全案で base と完全一致（動かない＝効きすぎの案なし）。10年目所持金だけが減る。
2. ローテ・必要充足のドーム割合は base 95〜97% → A2段階買い 48〜51%（所持金中央 約800万）／A単独ライブ年1 70〜72%／B仕送り 86〜90%／D全部 19〜21%。
3. どの案も のんびり改・やり込みのドームが 16〜18% → 0〜5% に潰す（残金が元々少ない人にも効く）。決めない：選択肢は §3。

節：§1 案と値段／§2 表／§3 所見と選択肢

## §1 案と値段（効果は一切なし＝出費のみ。年の頭に判定）
- A 単独ライブ年1：年1回 120万。残金 400万以上なら買う（最大10回）。
- A2 段階買い：小箱100万→中250万→大ホール500万を順に1回ずつ（計850万）。残金が価格+300万以上なら次を買う。
- B 仕送り・おごり：年 56万（後輩におごる年4回×5万＋仕送り月3万）。残金 300万以上なら毎年。
- C 衣装・小道具（見た目）：年 150万。残金 600万以上なら毎年。単独では測らず D に含む。
- D A2＋B＋C の同時。
- money_sink_research_v0 §3 の A（単独ライブ段階買い）を優先し、B は③C（後輩・寄付）の軽い形、C は B（見た目）に相当。
- 条件：`tools/exp_money_after_merge_v0.py` の one() をそのまま使用（全部入り・ネタ込み・同4ボット）。スクリプト `tools/exp_money_sink_candidates_v0.py`。n=300 で当たり→5案を n=1000。生出力 `docs/measure_raw/money_sink_candidates_n1000.txt`。

## §3 所見と選択肢（決めない）
- 帯：出費が能力に返らず、買う条件も残金だけなので、解散・夜逃げ（残金が減る側）も含め帯は不変。効きすぎの案は無し。出費で残金が減っても、買う条件が高い残金なので赤字側には近づかない。
- 副作用：のんびり改・やり込み（base でドーム16〜18%・300〜800万 77%）も、どの案でもドームがほぼ消え、全員が300〜800万の段に集まる。買う条件の残金を上げれば抑えられる（例 A2 を価格+600万以上にする、など）。
- 選択肢：
  1. A2 段階買い（推奨）。理由：ローテ・必要充足のドームが半分（約50%）になり、段が「稼ぎ方と使い方」で分かれ始める。1回きりで「買ったか」が語りに出せ、research §3-A とも一致。
  2. A単独ライブ年1。理由：毎年の定例にできるが、削りが A2 より浅くドーム70%台。
  3. D 全部入り。理由：ドームを約20%まで落とすが、300〜800万の段に8割が集まり、段が1つしか働かない。
  4. B 仕送りは単独では弱い（86〜90%）。後輩の物語出口として A2 に足す補助向き。
- 次の確認（決めない）：A2 の買う余裕（+300万）を +600万 にした時の のんびり改・やり込みの段、会場の閾値の上げ（B案）との組み合わせ。
