# M-1決勝「番組感」調査と改善案 v0（2026-10-15）

目的：オーナー指摘「決勝の演出がM-1っぽくない」への材料。コード変更なし。決めるのはオーナー（選択肢＋推奨の形で並べる）。
重複回避：進行表の時系列は `docs/comedy_research_v2/r1_m1_grandprix.md` §2-1（24行）、MC進行は `r6c_m1_mc_flow.md`、大会構造は `research_m1_deep_v0.md`。本書は「画と音の質感」と「足りない場面」に絞る。

## §0 要点3行
- 今のゲームの決勝は「籤（lot）」から始まる＝番組が始まった感（オープニングV・タイトルコール・審査員席の紹介・進出組の紹介）が丸ごと無い。ここが「らしくない」の最大原因。
- Web で裏が取れたのは骨格のみ（下の出典）。照明・スモーク・音・テロップ書体・採点の灯り方などの質感は検索では確認できず【慣例・要録画確認】。断定せず「らしさの方向」として扱う。
- 効き目の大きい順に、①オープニング ②審査員席の紹介 ③進出組紹介＋登場の扉 ④籤の演出強化 ⑤合計点の溜め…と15案（§3）。予選用の番組感は §4。

## §2 現状の決勝（FinalsPresentationView の beat 一覧）
preceding（先の組が順に出る）→ lot（自組の籤）→ perform（ネタ・歓声）→ open（7審査員の点が1人ずつ）→ comments（講評2人）→ board（暫定席・入れ替え・1本目確定）→ duel（最終決戦・票めくり）→ result（優勝発表）。
既にある番組要素：黒×金の番組タイトル（broadcastTitle）、下三分（lowerThird）、暫定席の入れ替え、票めくり。
無い物：オープニング、MC登場、審査員席の紹介、進出組の紹介、登場の扉、敗者復活組の合流、エンディング。

## §3 足す・変える場面（効き目の大きい順・13案）
各：場面／M-1での見え方／ゲームでの架空化／秒数／飛ばせるか。固有名・曲・コピーは使わない（架空）。

1. **オープニング煽りV**／黒地に白い大きな語り、歴代の名場面の断片、最後に決めの1行。／黒地＋金文字で「今年の一年」を3〜4行（例：架空の語り「ひと組だけ、日本一」）、自組の一年（ここまでの戦績・結成年・相方）をカットで差し込む。音は低い太鼓→弦の盛り上がり。／12〜15秒／初回のみ全長、2回目以降は1タップで飛ばせる（長押しで全スキップ）。
2. **タイトルコール＋スタジオ全景＋MC登場**／照明が落ちて一気に点灯、番組ロゴが出て、MCが定位置に立つ。／broadcastTitle を全画面で出して金の粒と光芒、MCシルエットが下手から登場し一言。／6〜8秒／ネタ前の演出は飛ばせる。
3. **審査員席の紹介（7人を端から順に）**／席ごとにカメラが寄り、名前＋肩書のテロップ、人によってMCが一言。／既存7審査員（JudgeData）のバストアップを左から順に点灯、名前＋肩書の下三分、新任・復帰には「今年から」の小タグ。／10〜14秒／飛ばせる。後の採点の席順とつなげる（同じ並び＝端から灯る）。
4. **進出組の紹介（10組の顔見せ）**／組ごとの紹介Vや楽屋の様子。／10組の名札が縦に並び、1組ずつ点灯。自組は金枠。結成年・「初／再・ラストイヤー」タグ（架空の上限年に対して）。／8秒／飛ばせる。
5. **敗者復活組の合流**／別会場の中継から勝者を発表し、駆け込んで合流。／「11組目」でなく「最後の1枠」として名札が後から入り、中継ワイプ風の枠で歓声。敗者復活ルートの年のみ（自組が復活組なら主役の場面）。／5〜8秒／飛ばせる。
6. **籤の演出強化（ゲストが引く）**／ゲストが箱から1枚、名前が読まれ、待機中の全組の顔が順に抜かれる。／架空ゲスト（スポーツ選手風の肩書だけ）が箱から札を引く。札がめくられる前に待機組の名札が震える→自組のとき心拍音。／5秒×自組の回のみ（NPC組は短縮1秒）／飛ばせる。
7. **コンビ紹介V＋キャッチコピー（登場前）**／名前の大テロップ・経歴・予選の様子・コピー。／自組は「ここまでの戦績」から自動生成した1行コピー（架空）＋結成年。NPC組は名前＋1行。黒背景→金のコピー。／自組6秒・NPC2秒／飛ばせる。
8. **登場の扉・せり上がり**／扉が開く前の暗がり→飛び出し→センターマイクへ。出囃子。／黒から縦に光の筋→扉が左右に割れる（既存の舞台像を使う）→二人が歩き出す。音は短い架空の出囃子（既存SEの合成）。待機中は暗がりで相方の呼吸音だけ。／4秒／飛ばせる（ネタ直前なので短く）。
9. **ネタ中の画づくり（ワイプ・テロップ・審査員の顔）**／二人のショット中心に審査員の笑い顔・客席の抜き。／現状の波形＋歓声に、審査員の顔の小窓（笑い度でアイコン切替）、残り時間バー（4分）を足す。ネタ名は出さない（ネタ本文を書かない方針に合致）。／ネタ尺そのまま（自動）／既存の自動進行。
10. **採点の溜め（点が灯る順番・合計の大表示）**／審査員の点が端から1人ずつ、最後に合計が大きく出て一瞬の間。／openBeat の7枠を席順の横一列に固定し、点は「？」→数字で反転。最後に合計がスケールアップし、金の粒、無音0.5秒→歓声。2回目以降は点灯間隔を短縮。／1人0.7秒×7＋合計2秒＝約7秒／長押し・タップで飛ばせる（既存の fastForward と整合）。
11. **暫定順位ボードの「暫定○位」表示と席**／合計の直後に暫定順位、3位以内は暫定席へ、4位以下は即退場。／現状の board を「暫定1〜3位の3席」中心に見せ、押し出された組が立ち上がって退場、MCの一言。／5〜8秒／飛ばせる。
12. **最終決戦の入り（3組の並び・出順決め）**／上位3組が並ぶ。1位通過から出順を選ぶ（CM中）。／3組を並べた金枠のカードに「最終決戦」と大テロップ、1位から順に出順カードを選ぶ（自組が1位なら自分で選ぶ選択肢で能動感）。／6秒／出順選択は自動に切替可。
13. **票の開き（審査員ごとに1票）と優勝の瞬間**／審査員が順に票を入れ、最後に王者が宣言される。金テープ・紙吹雪、崩れ落ち、賞金ボード、トロフィー。／既存 duel の票めくりに、開票前の暗転と1拍の無音を足す。優勝は金の紙吹雪＋トロフィー＋賞金ボードの順（金額は架空）。敗者2組には拍手。／優勝演出は8〜10秒／票めくりは飛ばせる、優勝の瞬間だけ飛ばせない。
14. **エンディング（全景・エンドロール）**／出演者全体の引き、余韻のまま終わる。／result のあと、全員が並ぶ全景→暗転→一年の結果を1行（「第◯回決勝・◯位」）。次の週へ進むボタン。／5秒／飛ばせる。
（予備）15. **CMまたぎの「ここで一旦」演出**／最終決戦の前や敗者復活の前でCM入り。／黒に「しばらくお待ちください」風の1枚（架空）を2秒挟み、続きから再開。やりすぎるとテンポが落ちるので任意。／2秒／飛ばせる。

優先して着手するなら 1・3・6・10・13（番組の入口と山場）。入口3点（1・2・3）だけで印象はかなり変わる。

## §4 予選（通常の大会結果）にも効く番組感 4案
1. **大会タイトルカード**：結果画面の頭に「◯◯杯 第N回」の黒金カードを1.5秒（既存の broadcastTitle の小型版）。
2. **出場組数と自組の位置を最初に見せる**：「◯組が参加／あなたは第N試合」を下三分で。
3. **結果発表の溜め**：順位を「？」から反転、合格ラインを越える瞬間は金の点灯、落ちる時は無音1拍。※％表示は出さない（オーナー判断）。
4. **審査員の一言を1人だけ付ける**：紙講評とは別に、顔付きの短い一言1つ（既存 verdict の使い回し）。
5. **番組の質感の統一**：全大会で同じ下三分・同じ効果音の系統（規模で金→銀→銅を変える）で「同じ番組世界」を作る。

## §5 要確認・未調査
- 実際の放送の質感（照明の色味、スモーク、票の開き方、暫定席の位置）は録画の目視が必要。オーナーが見たい場面を挙げてもらえれば確認項目を絞れる。
- 実装時は表示側（FinalsData のUI専用RNG と View）で完結＝規律A外。音は既存SEの合成か新規の架空SE（実在曲は使わない）。
