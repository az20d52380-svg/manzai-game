## 所見
- **L1（低）disband AX3：台詞ログ3行が折返して画面下端まで伸び、台詞ボックスが下端ぎりぎり。切れず押せる。** 直し案：大きい文字では場面イラスト高を縮める（前回 dynamic_type_audit_1025_v0 L1 と同じ・未対応）。
- **L2（低）netaentry AX3：「大阪遠征」看板の右の「優勝／無双」札が看板に重なり気味、出発ボタン説明が2行。** 読める。直し案：札を看板の外か下へ。ファイル未特定（FinalsPresentation系ではなく大会前画面。`grep -n '見送る' Sources`で特定）。
- **L3（低）netaentry ダーク（通常文字）：持ちネタ名が「商店街の…」と省略表示**（AX3では全文出るので、幅の取り合いで通常サイズのほうが切れる逆転）。直し案：ネタ名に lineLimit(2)／minimumScaleFactor、または完成度の行を折返し可に。
- **L4（低）yearend AX3：見出しカードの「頂グランプリ 到達段階」が2行になり右の「優勝／無双」札と重なる。出来事の一覧は1行ぶんしか見えず、灰「観戦」札の行（第48週）は見えない。** 直し案：札を見出しカードの外へ／一覧を可変高に（前回 L2 と同じ・未対応）。
- **L5（低）yearend ダーク：「優勝／無双」札（灰）が見出しカード右端とレーダー表の上にはみ出して重なる（通常文字でも）。** 文字は読める。直し案：札の位置をカード内へ収める。灰「観戦」札は第48週の行で表示OK（文字は沈まない）。
- 補足：アプリは色が固定でダークモードに追従しない（背景クリーム・文字濃色のまま、変わるのは状態バーのみ）。YoseCatalog.swift:122 のみ `.preferredColorScheme(.light)`。文字が背景に沈む箇所は無し。ダーク対応が方針なら別途設計判断。

高0／中0／低5。押せなくなるボタン・読めない文字は無し。
