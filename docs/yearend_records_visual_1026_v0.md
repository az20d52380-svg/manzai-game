## 食い違いの見当
- 軽微(1) 年表の賞金表示：NotebookView.swift の logEntries / 年表（yearHistory の prize / 10000）。YearRecord.prize は「その年の賞金の合計」で、頂GPの判の同じ行に「+185万」と並ぶ。ラベルか注記（「年の賞金」）を足すと誤解が減る。数字自体は合っている。
- 軽微(2) 下が切れる：画面の問題でなく目視手段の欠如。MZ_SCROLL のようなフックを足せば10年目の表全体を確認できる（コードは今回は触らない）。
- 参考：判や戦績は log 文字列を contains で拾う（「優勝」かつ「客席」なし→優勝、「客席」→観戦、「通過」「敗退」→…、他は休）。「休」が既定に落ちるので、将来 log に新しい文言が増えると「休」札に誤分類されうる（今は該当なし）。
