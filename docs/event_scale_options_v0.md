## 結論
1. やり込みの優勝は①13.2% → ②10.3% → ③12.4% → ④4.7%。③（成長の鈍りだけ）は①とほぼ同じで、甘さの主因は「鈍り」ではない。④との差（13.2→4.7）は、B.add に入っている年の予算・知名度の鈍化・相性の凍結のほうが大きいと見られる（今回は分解していない）。
2. ②（半減）は必要充足を8.8→4.6%、決勝75→58%に下げ、効きが大きい。ただしやり込み優勝は10.3%でまだ目安（3〜5%）より上。④に近づけるなら、予算・知名度の鈍化を通す案を別に測る必要がある。
3. 推奨に近いのは②（効果の大きさで素直に締められる）。③は締まらないので単独では不採用寄り。④水準まで締めるなら「年の予算を通す」案を追加実測するのがよい（判断はオーナー）。

## 体感への影響の見立て
- ①今：変化なし（イベントは強く効く）。
- ②×0.5：イベントの得は半分になり「イベントで一気に伸びる」実感が薄れる。減る方は据え置きなのでやや辛口。
- ③鈍りのみ：序盤の体感は変わらず、能力が高い終盤だけ少し効きが落ちる。ほぼ気づかない。
- ④B.add：イベントがアプリより弱い旧実測。年の予算で頭打ちになり、イベントを重ねても伸びない感じが出る。

## § 原因の切り分け（キュー115・tools/exp_event_scale_v1.py）
素の加減算（EVENTS_APP=True）に B.add の部品を「1つだけ」通した。n=300（※は n=1000）。優勝／決勝（%）。
B.add の分解：鈍り（GROWTH_DECAY_D）＋年の予算（YEAR_GROWTH_CAP）＋知名度の鈍化（FAME_OTHER_MULT/CAP・愛され芸人）＋相性の凍結。

| 案 | 必要充足 | やり込み |
|---|---|---|
| 素の加減算（今） | 7.7／76.7（※8.8／75.5） | 13.7／89.3（※13.2／87.3） |
| ⑤年の予算だけ | 2.0／48.0（※2.3／48.2） | 4.7／70.3（※4.0／69.5） |
| ⑥知名度の鈍化だけ | 8.3／74.7 | 13.0／89.7 |
| ⑦相性の凍結だけ | 7.7／76.7 | 13.7／89.3 |
| ⑧知名度だけ素・他は B.add | 2.3／49.0（※2.1／51.5） | 4.3／66.3（※4.4／68.0） |
| B.add 全部（参考） | 2.3／53.7（※3.3／52.2） | 5.7／76.0（※4.7／73.5） |

結論：
1. 差の主因は「年の予算」ひとつ。年の予算だけでやり込み13.2→4.0%、必要充足8.8→2.3%とほぼ B.add 全部（4.7%／3.3%）まで落ち、逆向き⑧（知名度だけ素）でも4.4%でほぼ変わらない。
2. 知名度の鈍化・相性の凍結はほぼ効かない（イベント経由では優勝への寄与が誤差内。相性の凍結はイベントで凍結中の相性増加が起きず差ゼロ）。締めるなら年の予算をイベントの能力増分に通す案が最有力（判断はオーナー）。
