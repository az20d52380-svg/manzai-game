## §1 指摘

### 1. 下の部屋の行が「家賃はいまのまま」と出る（実際は家賃が減る）　【低〜中・確信度 高】
- 場所：ShopView.swift:75 `roomRentText`（rent==0 → 「家賃はいまのまま」）、:100〜 の `if i > 0`（合計は i>0 だけ）。
- 手順：マンション／タワーで暮らす→お店を開く→「ボロアパート」の行を見る。
- 見えること：「家賃はいまのまま」。タワーから戻るなら実際は4週ごとの上乗せ15万が0になる。同様にタワー在住の「マンション」行は「家賃 +¥50,000」と出て、増えるように読める（実際は15万→5万に減る）。合計行（「生活費と合わせると…」）もボロアパートには出ない＝下げる側の得が見えない。
- 実際に起きること：表示だけの誤解（数値は GameEngine 側が正しい）。
- 最小の直し：rent==0 の文言を「家賃の上乗せなし」に、いま上の部屋にいる時は各行に「いまより −¥◯」を足す／合計行を i==0 にも出す（`totalDue` は i==0 でも動く）。
- 既出：いいえ。

### 2. 年限定の品（喉のケア用品・新幹線回数券）を年末の週に買うと、ほぼ使えずに年初で消える　【低・確信度 中】

- 見えること：買えて「今年あと0回」になる。残りの週数や「今年はもう効果が小さい」の警告は無い。

- 最小の直し：年の残り週が少ない時は値札の下に一言（または買えなくする）。判断はオーナー（規律A不要・表示のみ）。

### 3. 体力が満タン近くでも回復ドリンクが買える（買った分の回復が捨てられる）　【低・確信度 高】

### 4. 買えない理由が品にだけ出ない（部屋には「あと¥◯」が出る）　【低・確信度 高】
- 場所：ShopView.swift:~137 `row`（`ok` が偽の時は名前と帯の色を薄くするだけ）。部屋の行は :112 で「あと ¥◯ あれば引っ越せる」を出す。
- 手順：所持金が値段未満（または借金中）でお店を開く。
- 見えること：品の札が灰色になるだけ。回数の上限は「今年あと0回」の札で分かるが、お金不足は理由が出ない。

### 5. 所持金ぴったりまで使えるので、次の4週ごとの支払い前に借金になる　【低・確信度 中・設計判断】
- 場所：Item.swift:31 `canBuy`（money >= price のみ）。支払いは GameEngine.applyWeekEnd:335。
- 手順：所持金が少ない月に高い品を買い、次の4週目の支払いを迎える。
- 見えること：買えるし警告は無い。部屋の引っ越しの行は「生活費と合わせると4週で¥◯」を出すが、品の購入では支払いまでの余裕を出さない。
- 実際に起きること：支払いで所持金が負→生活苦（体力 −10 ほか）。意図どおり（借金は救済あり）だが、買う時に気づきにくい。
- 最小の直し：現状維持、または次の支払い額を下回る買い物に確認の一言（オーナー判断）。
- 既出：近い話は「お金が足りない選択肢の見せ方」（AUTOPILOT・money-short-choice-candidate）だが、お店の購入は別。

## §2 問題なしと確かめた主な所
- **週をまたいだ後の「戻す」**：起きない。お店は週画面の fullScreenCover（WeekMainView:195）で「買い物・週は進まない」（:1002）。購入中に週は進まず、閉じれば `visitStart`／`purchases`（@State）は捨てられる。再入店は新しい起点なので、週の効果の二重取りは不可。
- **「戻す」の全復元**：`replayItemPurchases` は起点の GameState を丸ごと戻して残りを `buy` で買い直す。購入は乱数なし・体力は clamp のみ・他の状態へ波及する効果（能力・年上限・銭湯のチケット・hasRecorder・新幹線）も起点から再計算されるので、波及後に戻しても残りの買い物と整合する。残りの買い物が買い直しで失敗する場合（返すと所持金が増えるだけ）も無い。
- **年上限／一度だけの品**：`canBuy` と `limitText` は同じ itemCounts を読む。戻すと回数も戻る（買い直しで再計算）。銭湯は tickets>0 で不可・表示は「のこり◯回」。ICレコーダーは店の品書き外（shopLineup に無い）で `canBuy` が false。
- **部屋の戻し**：引っ越しは無料で money を変えず、`visitStart?.room` を同期（:130）。起点の room と現在の room が一致するので、戻すで部屋は戻らない（ShopUndoRoomTests が session で確認）。
- **表示の値段と判定の一致**：値札は `config.items[...]price`、判定も同じ spec。引っ越しの「あと¥◯」は `roomRents[i]−money` で `canMoveRoom`（上げる時 money≥roomRents[target]）と一致。「生活費と合わせると4週で」は `livingCostDue`（やりくり上手込み）で実際の引き落としと同じ式。
- **借金中の購入**：money<価格で `canBuy` 偽（負の所持金は全品不可）。下の部屋へは借金中でも戻れる（:176 の仕様どおり）。
- **ガチャ・ログイン**：GachaView は GameState の money に触らない（別の状態）。お店を開いている間に session.state を書き換える経路は見つからず、起点への丸ごと巻き戻しで他の変更を消す事故は今は無い（将来、店の中に別の状態変更を足す時は注意＝逆操作でなく丸ごと復元のため）。
- **保存**：購入・引っ越し・戻すは毎回 `saveNow`。店を開いたまま落ちても購入は確定のまま（「戻す」は失うが損はない）。
