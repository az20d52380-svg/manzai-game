## §3 測り方
- スクリプト `tools/exp_old_questions_1108_v0.py`（新規・既存の式・GameCore・golden・tools は不変）。生データ `docs/measure_raw/old_questions_1108_n300.{txt,json}`（n=300・約1分）と `old_questions_1108_n1000.{txt,json}`（n=1000・約4分）。結論の数字は全て n=1000。
- 条件：YEARS=15・較正A・周回の式は sim_career の今の既定のまま（周回の点 0）。ネタ込み（NETA_ON=NETA_V2=True）。ボット4種＝帯の組（exp_balance_snapshot_v0.make2：のんびり改／ローテ／必要充足／やり込み）。全部入り（部屋＋アイテム＋特技＝exp_money_after_merge_v0.one の "all"）。`C.EVENTS_APP` False/True。
- 並列は `Pool(maxtasksperchild=1)`＋`map(..., chunksize=1)`。上書き（EVENTS_APP・記録の差し込み）は各プロセス内だけ。
- 詰まりは exp_ability_stall_v0 の `stalled`（週末に経験点 5以上・伸び余地あり・押せる＋が0）を使用。auto＝今の pour_all、hand＝人の手配り近似（旧 q93_r2m_current と同じ測り方）。

- 会場の段は 0/300万/800万の閾値（venueTier1/2Money）を前提に <0／0〜300／300〜800／800以上で数えた（GameConfig の現在値は未照合）。
