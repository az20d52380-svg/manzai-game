# 決勝のモブ組の重なり 実測 v0（懸念の台帳 L58 の材料・2026-10-25 夜・定期の回）

## §1 要点
- 名簿50組から毎年9組（観戦の年は10組）。10年で42組が登場し、最多の組は10年で6回出る（4回以上が5組）。前年との重なりは 0〜4組（平均 約2組）。
- 顔ぶれは**年だけ**で決まる（`FinalsData.yearRoster(year:selfName:count:)`・種＝year*7919+0x2A6D）＝**何周しても N 年目の決勝は同じ9組**。周回で目に付くのはこちら。
- 決めるのはオーナー（①今のまま ②周ごとに変える：種にキャリアの種を混ぜる＝表示だけ・GameCore 不変 ③名簿を増やす／名前の生成器 AUTOPILOT 46）。

## §2 手法
- `FinalsPresentationView.swift` の SeededRng と yearRoster を scratchpad の Swift スクリプトに写して 1〜15年目を列挙（自組名は空・9組）。
- 15年では47組が登場・最多7回。前年との重なり（2〜15年目）：4,3,1,3,3,1,1,2,1,3,0,3,1,1。

## §3 注意
- ②を選ぶ場合、準決勝後の「決勝進出者の発表」（同じ yearRoster を使う）と決勝の画面が同じ種を使い続ける必要がある（今は年だけで一致させている）。
