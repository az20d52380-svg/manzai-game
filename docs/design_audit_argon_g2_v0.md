# 漫才コンビ育成ゲーム 実機画面デザイン監査レポート（画面17〜31）

正本デザインシステム『寄席と計器（Yose & Gauge）』v2.0（`@docs/design_system_argon_v1.md`）に基づき、商業リリース基準（パワプロ・ウマ娘級）で15画面の監査と改修設計図を提示します。

## 17_ネタ帳_一覧

### ① 点数
**56 / 100点**

### ② デザインシステムから外れている所
* **禁則事項#1・#2・#3の三重違反**：
  * タグ（「長め」「見飽きられた」「自信作」「まだ人前でやっていない」）がすべて禁止されている `Capsule()`（丸ピル型）になっている（§5-⑤ `YoseTag` 違反）。
  * 各カードの右上に禁止されているシェブロン `>` が配置されている（§8-3違反）。
  * 「型を変える」「しまう」ボタンに `2pt` の墨枠（`yoseSumi`）とハードシャドウがなく、角丸の大きい枠なしベージュボタンになっている（§8-2違反）。
* **ゲージの仕様違反**：完成度・客の反応のバーに `1.5pt` の墨枠と25%刻みの目盛りスリットがない（§5-⑧ `YoseGauge` 違反）。
* **ヘッダーとタブの仕様違反**：ヘッダーのタイトルが左寄せ（「ネタ帳 あなたのコンビ」）になっており、§5-① `YoseHeaderBar`（中央金文字＋左右の金菱形飾り線）を使っていない。上部タブの非選択背景も `yoseKi`（木札色）ではなく背景と同化している。
* **勝負ネタカードの強調不足**：1枚目の「商店街の福引」に `.yoseHarigami(isFeatured: true)`（朱枠2.5pt＋内金枠1pt＋左端6pt臙脂帯）が適用されておらず、他のカードと枠が同じ。

### ③ AIっぽい所・UXの分かりにくさ（初めての人が迷う所）
* **操作の二重導線で迷う**：カード右上に `>` があり、下部にも「勝負ネタにする」「型を変える」「しまう」のボタンが並んでいるため、「カード全体を押すのか、下のボタンを押すのか」が初見で分からない。
* **Web管理画面（SaaS）のようなAI臭**：丸いピル型タグと枠なしグレーボタン、細いフラットバーの組み合わせが典型的なAI生成のWebダッシュボードに見える。

### ④ 直す設計図（優先順）
1. **カード骨格と勝負ネタ強調の適用（§5-④ `YoseHarigamiModifier` / §7-型C）**
   * **部品・配置**：全カードに `.yoseHarigami(isFeatured: isShobuNeta)` を適用。右上の `>` は完全削除。1枚目の勝負ネタは左端に幅 `6pt` の `yoseEnji` 帯、外枠 `yoseShu`（`2.5pt`）＋内枠 `yoseKin`（`1pt`）で特別感を出す。
   * **余白**：画面左右マージン `14pt`、カード間 `VStack(spacing: 12)`、カード内パディング上下 `10pt`・左右 `12pt`。
2. **丸カプセルタグの全廃と角札化（§5-⑤ `YoseTag`）**
   * **部品・色トークン**：すべての丸タグを角丸 `0pt` の `YoseTag` に置換。流派（「伏線回収」「畳みかけ」）は `.solidEnji`、警告（「見飽きられた」）は `.outlineShu`、肯定（「自信作」）は `.outlineKin`、尺・回数補足は `.outlineSumi`。
3. **アクションボタンの物理ボタン化（§5-② `YoseButtonStyle`）**
   * **部品・文字段階**：「勝負ネタにする」は `YoseButtonStyle(.primary)`（背景 `yoseShu`・文字 `yoseKinari` 15pt Heavy）、横の「型を変える」「しまう」は `YoseButtonStyle(.secondary)`（背景 `yoseWashi`・墨枠 `2pt`・下影 `2pt`）。高さはすべて `34pt`、横間隔 `8pt`。
   * **動き**：押下時 `0.06秒 .easeOut` で `y: +2pt` 沈み込み＋ `.rigid` ハプティクス。「勝負ネタにする」押下時は朱印 `YoseHankoStamp("真剣勝負")` が `scaleEffect(2.2 -> 1.0)`（`0.22秒 .spring`）で叩きつけられ、上部に `YoseToast` を出す。
4. **計器ゲージの適用（§5-⑧ `YoseGauge`）**
   * **部品・色トークン**：完成度は `fill: YoseColor.shu`、客の反応は `fill: YoseColor.kinBright` の `YoseGauge(height: 12, showTicks: true)` に置換。右端の数値は `numLarge`（`22pt .heavy .monospacedDigit()`、色 `yoseSumi`）。
5. **ヘッダーと上部タブの正規化（§5-① `YoseHeaderBar` / §5-⑩ `YoseTopTabBar`）**
   * **部品**：最上部を `YoseHeaderBar(title: "ネタ帳", subtitle: "あなたのコンビ", closeAction: ...)` に差し替え、直下に高さ `42pt` の `YoseTopTabBar`（非選択タブ背景 `yoseKi`、選択タブ下線 `yoseShu` 4pt）を隙間 `0pt` で結合。

### ③ AIっぽい所・UXの分かりにくさ（初めての人が迷う所）

* **プロトタイプ感の強いスカスカ画面**：標準スライダー2本とテキストクレジットだけが浮いており、商業ゲームのオプション画面としての密度がない。

### ④ 直す設計図（優先順）
1. **丸ノブSliderの廃止と「木札ステップ計器」への置換（§5-⑧ `YoseGauge` 応用＋§5-② `YoseButtonStyle`）**
   * **部品・配置**：OS標準 `Slider` を廃止。左からラベル `BGM`（`bodyBold` 14pt・幅48pt）、`[-]` 物理ボタン（`32×32pt` `.secondary`）、10段階目盛り入り `YoseGauge(value: bgm, total: 100, fill: YoseColor.shu, height: 14)`、`[+]` 物理ボタン（`32×32pt` `.secondary`）、右端に `numMedium`（`16pt .heavy` 等幅数字）を配置（ゲージ直接ドラッグも可）。
   * **動き**：1目盛り（10単位）変更ごとに `0.06秒` で数値が跳ね、SEスライダー変更時は確認用の小太鼓SEを鳴らす。
2. **「このキャリア（育成データ管理）」セクションの常設表示（§5-④ `YoseHarigamiModifier`）**
   * **部品・配置**：音量カードの下 `20pt` にセクション見出し `このキャリア`（`sectionTitle` 17pt Heavy）を置き、`.yoseHarigami()` カード内に現在の進行状況（「1年目 第11週 / コンビ名」）と、「最初からやり直す」ボタン（`YoseButtonStyle(.secondary)`、文字色 `yoseShu`、高さ `44pt`）を常設する。
3. **クレジット・権利表記の木札枠格納（§5-③ `YoseKifudaModifier`）**
   * **部品・配置**：宙に浮いている「音楽: 魔王魂…」とバージョン表記を、画面下部の `.yoseKifuda()`（背景 `yoseKi`・内枠 `yoseKiDark`）の奥付札（高さ `64pt`、パディング `12pt`）に収め、寄席の千社札・番組表の佇まいにする。
4. **ヘッダーの統一（§5-① `YoseHeaderBar`）**
   * **部品**：`YoseHeaderBar(title: "設定", closeAction: ...)` を使用し、右ボタン表記を「とじる」に統一、左右の菱形金飾り線を入れる。

## 19_設定_やめる確認

### ① 点数
**38 / 100点**

### ② デザインシステムから外れている所
* **§5-⑪ `YoseModal` の完全不使用**：重大なデータ削除確認（「最初からやり直しますか？ 今のコンビの記録は消えます。」）であるにもかかわらず、画面暗転モーダル（`YoseModal`）を使わず、設定画面のインラインカードとして突然出現している。
* **ボタンの下影欠落**：「やめる」「やり直す」ボタンに `2pt` のハードシャドウ（`yoseSumi`）がなく、平面的な四角になっている（§5-② `YoseButtonStyle` 違反）。

### ③ AIっぽい所・UXの分かりにくさ（初めての人が迷う所）
* **「やめる」という言葉の致命的な二重意味バグ**：
  * 「キャリアを**やめる**（＝引退・リセットする）」と思って左の「やめる」を押すのか、「やり直すのを**やめる**（＝キャンセルして元の画面に戻る）」のか、日本語として完全に紛らわしい。データ消失事故を起こす最悪のUXアンチパターン。

### ④ 直す設計図（優先順）
1. **インライン表示を廃止し、専用モーダル `YoseModal` に変更（§5-⑪ `YoseModal`）**
   * **部品・配置**：18番で「最初からやり直す」を押した際、画面全体を `Color.black.opacity(0.65)` で暗転させ、中央（左右マージン `24pt`）に `YoseModal`（上部 `40pt` の `yoseEnji` 見出し帯に金文字「キャリアのやり直し」、本体背景 `yoseWashi`、外枠 `yoseSumi` 2.5pt、下影 `4pt`）を表示する。
   * **動き**：`0.18秒 .spring(response: 0.25, dampingFraction: 0.8)` でモーダルが `scaleEffect(0.95 -> 1.0)` で出現。
2. **ボタン文言の明確化（「やめる」の排除）**
   * **文字・部品**：左のキャンセルボタン（`YoseButtonStyle(.secondary)` 高さ `44pt`）のラベルを **「もどる」**（または「キャンセル」）に変更。右の実行ボタン（`YoseButtonStyle(.primary)` 背景 `yoseShu` 高さ `44pt`）を **「記録を消してやり直す」** に変更し、誤操作を完全に防ぐ。
3. **消えるデータの明示（UX安全装置）**
   * **部品・色トークン**：モーダル本文（`bodyBold` 14pt）の下に、`yoseKi.opacity(0.45)` 背景・`yoseSumi` 1pt枠の小箱を置き、消去される「現在のコンビ名・年数・所持金」を明示してからボタンを押させる。
