# 周回のごほうび：他の作品の例 v0（2026-10-25・調べ物・決定ではなく材料）

Web 検索は5回。検索で確かめられた事と、一般的に知られている事（要確認）を分けて書く。ゲーム内に持ち込む名前は架空にする前提（作品名は出典のみ）。

## 要点3行
- 例は6つ。型2（選んで持っていく装備・継承）に近い例が4（パワプロ継承／ウマ娘因子／学マス サポカ／Dead Cells）、型1（自動で数値が増える）に近い例が1（Hades の鏡は「自分で振る」数値強化なので型1寄りの混合）、どちらでもない解放型が1（Slay the Spire）。
- 強さの上限は「枠の数を絞る」「重ねを禁止する」「入手を確率にする」の3種が多い。数値をそのまま積む型は、難度側のつまみを同時に持つ例（Dead Cells・Hades の誓約系）が多い。
- 受け止めは「選ぶ・育てる」は手応え、「全部取り終えたら作業」は作業感、の二分。解放が早く尽きると「宿題」と言われる例がある。

## §2 型1・型2 に近い例
### 型1（点に応じて経験点と所持金が自動で増える）に近い例
- Hades の鏡（#4）：貯めた通貨で数値が恒久的に上がる。ただし「自分で何を買うか選ぶ」点で、完全自動の型1とは違う。
- ウマ娘の因子の青（#2）：能力ボーナスが開始時に足される。選ぶ要素が付く。
- 良い所：仕組みが単純。どの遊び方にも効く。「前より楽になった」が毎回分かる。投資の回収が見える（#4）。
- つまずき所：上げ続けると最初の数週の緊張が消える（本ゲームの実測でも点5で最初の昇格が1〜2週目）。Hades は初心者向けには楽にしすぎる懸念が批評に出ている。難度側のつまみを別に持たないと、慣れた人には作業になる。

### 型2（点で解放される初期装備を選んで持っていく）に近い例
- パワプロ継承（#1）、ウマ娘の継承枠（#2）、学マスの編成（#3）、Dead Cells の初期装備（#6）。
- 良い所：「今回は何を持っていくか」を考える楽しみがある。周ごとに違いが出る。枠数を絞ることで強さの上限を自然にかけられる。
- つまずき所：最強の組み合わせが固定されると選ぶ意味が薄れる（本ゲームの実測でも同じ指摘）。ウマ娘では良い因子を集める周回が作業化しやすい。解放の数が少なすぎると選択肢が見えない。

### どちらでもない
- Slay the Spire（#5）：数値を強くせず、幅と難度だけを広げる。強さの上限問題が起きにくい代わりに、「周回で楽になる」手応えは弱い。

## §3 このゲーム（15年・初優勝が1〜2%の帯）に当てはめた材料（決定はしない）
- 実測（meta_start_bonus_1020_v0 §0）では、初期の経験点・所持金は優勝をほとんど動かさず、決勝進出と序盤の安定を上げる。他作品でも「開始時の底上げ」は序盤の楽さに効く役目であり、勝敗は難度や別の要素で決めている例が多い。
- 上限のかけ方の型：①枠数を絞る（型2、点15で2つ・点30で3つの案と同じ）、②重ねを禁止する（実測の前提と同じ）、③難度側に自分で上げるつまみを足す（Dead Cells・Slay the Spire 型）。③は今の文書には無い案で、優勝まで届かせたい時の候補になる。
- 作業感の対策の例：「同じ最強装備」に収束するなら、装備ごとの得意な遊び方を分ける（実測 §4 の指摘と一致）。解放が早く尽きるなら、解放の数を点の後半に厚くする。
- 推奨（材料として1行）：型2の「少数の枠で選ぶ」形が他作品で最も一般的で、手応えの報告も多い。ただし最強固定を避ける調整が前提。型1は単純で土台に向くが、慣れた人向けの別のつまみが要る。決めるのはオーナー。
