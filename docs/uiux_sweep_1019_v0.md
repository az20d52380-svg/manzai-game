## 所見
| 画面 | 何が起きた | 重さ | 直し方の案 |
|---|---|---|---|
| 全体（グローバル） | 11pt 未満の文字が残っていた（購入タグ10・知名度ラベル10・ヘッダ副題10・出演者「あなた」札9/10・LIVE札10・オファー注記9） | 中 | 11ptへ引き上げ（済・ce370a3） |
| 年間香盤 | 大会名10pt・「今週」札9pt。「今週」札が大会名に被る。11ptにすると被りが悪化するので9のまま据え置き | 中 | 「今週」を枠線の強調だけにする／札をセルの右上へ寄せる（セル幅の設計が要る） |
| 能力アップ | 注釈「数字＝その能力を…」「特技」ボタンが小さく、押せる所と分かりにくい。経験点アイコン内の字が10pt | 低 | 注釈を2行に分けて12pt、「特技」を主ボタンの大きさへ |
| 能力アップ | 下の「特技」一覧がフッターボタンと近く窮屈（最下部が切れて見える） | 低 | 一覧の下に余白を足す |
| 通知（qual_notice/qual_line） | 「既読」10pt・薄い（装飾） | 低 | 触らない（意図的な演出） |
| 設定 | 「権利表記」箱の上に大きな空白（中身が上に偏る） | 低 | 余白を均す程度。後回しで可 |
| ネタ/コンビ画面 | 能力の行は崩れ無し。数字の右端が枠に寄っている | 低 | 右余白+4pt |
| 舞台直前（stage） | 「優勝/無双」の目標札が小さく、舞台の人物と重なる | 低 | 札を12ptに、位置を上へ |
| 年間香盤・図鑑・用語集・店・設定 | 崩れ（切れ・重なり）は見えず | - | - |

## 判断が要る（Gemini とデザインする時に）
- 週メイン画面の雰囲気：舞台イラストとコマンドボタンの比重（舞台が主か、ボタンが主か）。
- エンディング図鑑の「？？？」灰色カードの見せ方（ロック状態の雰囲気）。
- 通知画面（ロック画面風）と本編画面の色の差。
