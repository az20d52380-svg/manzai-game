# 面白さとUI/UXの作り直し v0 — 実プレイ27週・他社23本・3方向比較

## 0. 結論

> **オーナー判断（2026-10-07）：A「削る」で進める。％（通過見込み）は「冷める」ので出さない。** 本書の推奨（混合案）と見込み％表示は不採用。スライス1の指示は `proposals/PROMPT_slice1-cut-A_v0.md`。

- **つまらなさの正体は「押しても何も動かない・勝敗が育成とつながっていない」の2点に集約される。** 27週遊んで、本番の数字（実力＋相性）の伸び 15→30（W1→W27）のうち **73%は相性（数字1つ）から**来た。経験点5通貨×5能力という一番複雑な仕組みが運んだのは残り27%で、しかも本番はブレ±18【仮・机上】のサイコロが支配している（ライン未満で2勝・1敗）。
- 他社23本から抜いた共通原理8つのうち、本作は **「押した瞬間に世界が動く」「育成の着地を"観る"」「題材を動詞にする」** の3つを特に満たしていない。逆に、イベントの文章と「慣れの外し方」のような**本作でしか作れない選択**は、手本と比べても強い資産。
- 推奨は **混合案「削って、舞台を主役にする」**：経験点・のばす・能力ピルを消して1週1タップにし（A）、週の山場を「舞台に立つ→客席が動く」に置き換え（Cの芯）、本番の見込みと負けの距離を見せる（B）。**最初のスライスは GameCore 無改変・golden 不変**で作れる。

節構成：§1 実プレイ記録／§2 現状の裏取り／§3 リサーチ（表・原理・仕分け）／§4 診断／§5 3方向比較と推奨／§6 UI/UX（主要3画面）／§7 ロードマップ／§8 出典

## 4. 診断 — 本作のどこが"圧倒的につまらない"のか（5つ）

### D1. 押しても何も動かない（P1違反）

- **言い切り**：1週の結果が「閃き+1」のような小さい・読めない数字で、しかも本番の数字に届くまで**2回の乗り換え**（稽古→経験点→のばす→能力→実力値）がある。
- **現物の根拠**：W2「閃き+1・体力−20」のチップ2枚だけ。W3 のばすで2段注いで**「いまの実力 17→17」**。W19 で5段注いで能力+5、**実力は+1**。経験点は `0.48` 倍で発行され（`GameConfig.swift:135`）、能力はさらに加重平均で実力値になる（`GameEngine.swift:60-63`）。
- **補足**：等級も1年中動かない（初のG→FがW22・メンタル）。監査C-01の「等級帯バー」は入っているが、帯の中で少し満ちるだけ。

### D2. 1週の判断が判断になっていない（P2・P7違反）

- **言い切り**：選択肢は多い（カテゴリ5×変種11）のに、**最適解が自明か、差が無い**。
- **現物の根拠**：「相方と過ごす（相性+1・体力+20）」が「ネタ合わせ（相性+1・体力−20）」の上位互換に見える（W4）。バイト3種は体力1あたり収入が全部4,000円（`GameConfig.swift:195-199`）。オファーは毎回「お金重視」1枚（W7・W17）で、W18に所持金58万になってから**お金の判断が消えた**。稽古カード5枚の中身と数字はW1とW20で完全に同じ。
- **補足**：11種のうち実際に使ったのは6種。迷ったのは「どれを選ぶか」ではなく「経験点をどう使うか」（W3・W10）＝**判断の中身が"週の行動"から"表計算"に移っている**。

### D3. 勝敗が育成とつながっていない（P3・P5違反）

- **言い切り**：本番はブレ±18【仮】のサイコロが支配し、それが**画面に一切出ない**ので、勝っても負けても理由が分からない。
- **現物の根拠**：ライン30／実力21で敗退（W12・机上見込み約28%）、ライン28／23で優勝（W15・約40%）、ライン33／30で優勝（W27・約45%）。入口は「ライン30／実力21」だけを見せる＝プレイヤーは「9足りない＝無理」と読むが、実際は3〜4回に1回通る。星3つは勝っても負けても★1〜2で情報を持たない。講評「床を見ていた」は"メンタル"を指すが、メンタルを上げる行動（自宅で休む+2）との対応は画面に無い。
- **数字**：1年で手で動かせる能力分は実力値+6が上限（器）、相性は+15まで。27週の伸びの73%が相性。**一番複雑な仕組み（5通貨×5能力）が一番効いていない。**

### D4. 山場が見えない（P4違反）

- **言い切り**：12週かけた準備の着地が、ネタも客も相方も映らない**2秒の一本線**。
- **現物の根拠**：W12 の本番画面（`TournamentResultView` の WaveformView）。勝ちの波形は1種類でW15とW27が同じ形。決勝演出（7審査員・票札・最終決戦）は作り込まれているが、1年目は観客版でしか見られない（監査H-01）。
- **補足**：ダビスタ・ウマ娘は「育てたものが走るのを観る」が着地。本作は「育てたものが漫才するのを観る」場面が1つも無い。

### D5. 「漫才コンビの成り上がり」が遊びの中心にない（P6・P8違反）

- **言い切り**：本作でしか作れない面白さは**イベントの文章と一部の選択**にだけあり、毎週の操作はどの育成ゲームとも同じ「数値の行動を選ぶ」。
- **現物の根拠**：W23「慣れの外し方」（相性15到達で発火・「崩す/固める」）は、題材と状態と選択が噛み合った唯一の瞬間だった。一方、ネタは型7種・尺3種・完成度・手応え・戦績まで実装済み（`Neta.swift`）なのに、週メインでは「完成度54」の1行と大会入口のプルダウンにしか出ない。週次イベントはやっていないライブを前提に始まる（W17・W20）。

### 5-2. 推奨：混合案「削って、舞台を主役にする」（A＋Cの芯＋Bの見込み表示）

**理由**
1. D1・D2（押しても動かない・判断が無い）は **Aでしか根治しない**。経験点を残したまま見せ方を磨いても（B）、2回の乗り換えは消えない。
2. A単独では D4・D5（山場が無い・題材が皮）が残る。**週ごとの小さな山場＝「舞台に立つ→客席が動く」**を入れると、ゲーム発展国++の「1本ごとの評価」（P7）と、ダビスタ/ウマ娘の「観る」（P4）を同時に満たせる。ネタの型・完成度・手応えは実装済みなので素材の新設は少ない。
3. D3（勝敗が見えない）は **Bの見込み表示**が最安。式から計算するだけで乱数を引かない。
4. 最初のスライスは**GameCore 無改変・golden 不変**で作れる。舞台の反応は既存の決定論 `Neta.liveBuzz` を表示し、演出の揺れだけUI乱数で付ける。勝敗への寄与を上げる判断（ルール5・規律A）は、**触って面白いと分かってから**行う（規律B-5「体感の問題を数値で直さない」と同じ順番）。

**スライス1（W1〜W8）の中身**

| 変更 | 実装の当て先 | golden |
|---|---|---|

**モックで分かったリスク（先に書いておく）**：見込みを見せると、**今の数値では育成が見込みをほとんど動かさない**ことも見えてしまう（モックの机上再現で W1→W11 の見込みは 13%→24%【仮】、「舞台に立つ」は見込み±0、休むとブレが縮んで見込みが僅かに下がる）。これは D3 そのもので、表示が悪いのではなく数値の関係が原因。スライス1の試遊で「伸びても見込みが動かない」が不満の中心になったら、その時点で **ブレ幅の縮小（規律A発動・golden全再測）か、ネタ補正の拡大（ルール5・sim同期）** を数値側の次の一手として判断する（体感→演出→数値の順＝規律B-5）。

**新設と転用の代案**：3拍の舞台View は新設（約200行【仮】）。転用案は決勝演出 `FinalsPresentationView` の「暫定ボード」の部品流用だが、決勝の格（黒×金）が週の小舞台に降りると決勝の特別感が薄れるので、別Viewを推す。

### 5-3. 既決への異議（2件）【設計上の懸念】

1. **「週メインで通過ラインを出さない」（v8確定・START_HERE:69）を覆す提案**。理由：ブレ±18の本作でラインを隠すと、勝敗が「理由の無い運」に見える（D3）。見込みは「4割」「五分」のような粗い語＋帯で出し、細かい数字は出さない。決めるのはオーナー。
2. **パワプロ式の手動割り振り（経験点5通貨・2026-08のオーナー指示で導入）を撤去する提案**。理由：sim/golden は導入後もずっと「自動全量注ぎ」で測っていて、手動にしたのは実ゲームだけ（`GameConfig.swift:146-150`）。手動の自由度が勝敗に効く余地は器（+6/年）の中だけで、その代償が迷い3回（W3・W10・W19）と画面1枚（702行）。**撤去しても経済は同じ**で、後から戻すことも git でできる（★★）。決めるのはオーナー。
