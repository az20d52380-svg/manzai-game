### 低-2 部屋の「戻る」行：「家賃はいまのまま」が誤読を招く（重さ 低・表示のみ）
- 場所：ShopView.swift:81-84（i==0 は常に「家賃はいまのまま」）。

### 低-3 買えない理由が出ない品がある（重さ 低・表示のみ／VoiceOver 含む）
- 場所：ShopView.swift:166・:173-175・:182。

## 見て問題なしの所
- 買えるか：row の `ok` は GameEngine.canBuy そのもの。canBuy が見る所持金・年の回数・持ち越し中の回数券・稼働中フラグは、押した時の buy も同じ canBuy を通るので、有効なのに失敗／無効なのに成功は起きない。連打しても2回目は弾かれる。
- 値札：¥表示は config.items の price、購入で引く額も同じ spec.price。
- 回数の札：「今年あと◯回」は yearlyLimit − itemCounts、年替わりで itemCounts は消える（Item.swift:88-92）ので札と canBuy が一致。「持っている」「のこりN回」も canBuy と同じ条件。
- 効果の文：栄養ドリンク／回復ドリンク大（体力 +8／+20）、喉のケア用品（体調ダウン確率が下がる）、新幹線（大阪遠征の交通費0・体力0：WeekRunner.swift:209）は説明と一致。部屋の文：家で休む回復 +10/+20 の「よく／とても」は roomHeals と一致、「あと ¥」は canMoveRoom が false の時だけで負にならない。
- 「戻す」：店に入った時の状態から残りを順に買い直す方式で、お金が増える方向の戻しでは買い直しが失敗する並びは作れない（今の品揃えは全て所持金を減らすだけ）。
- 動き：ShopView 自体にアニメ無し。フェードイン（WeekMainView.swift:1746-1751 FadeInOnAppear）は Theme.Motion.r 経由で減らす動きに対応済み。
- 触覚：購入・戻す・引っ越しは成功時のみ1回。ボタンスタイル側の二重発火は確認していない（YoseButtonStyle に触覚の記述は見つからず）。
