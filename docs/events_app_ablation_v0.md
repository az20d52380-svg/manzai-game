# EVENTS_APP アブレーション v0（どのイベントが決勝到達・所持金を押し上げたか）

- 要点1：差のほぼ全部は「確定発火」の効果（序盤の相性+2・つっこみ後の表現+2・相性+1・パス後の知名度+3・谷口の+15万など）。これだけ外すと ローテ決勝 33.6→19.6%（従来 19.8%）、10年目所持金 1682→1457万（従来 1337）＝ほぼ従来に戻る。固有9種を外しても −4.8pt、25種を1種ずつ外した差は n=300 の誤差内。
- 要点2：見立て（知名度20未満の期間が短くなる）は「当たり」。知名度20に届く通算週の中央値 ローテ 156→87（約1.4年早い）、必要充足 126→87。確定発火を外すと 131/125 に戻る。
- 要点3：アプリのイベントは「底上げが効きすぎ」ではなく「確定発火が下積み期の抜け道になっている」可能性。決めない。推奨は §4。

節構成：§1 外し方／§2 表／§3 原因／§4 所見

## §1 外し方
スクリプト `tools/exp_events_app_ablation_v0.py`（式・既定値は不変。差し替えはプロセス内のみ・1ジョブ=1プロセス）。全部入り・ネタ込み、ボットはローテ・必要充足。基準 base＝EVENTS_APP=True。
- `-<key>`：週次抽選のプール(25種)から1種外す（抽選の母数も変わる）。
- `-UNIQUE`：固有9種をまとめてプールから外す。
- `-CONFIRM`：確定発火7種（justlost・styletalk・passfork・eve・early・tsuuka・tani）の**効果だけ**無効化（発火判定・消費は残す。nameless は元々効果なし）。`-C:<key>` は1種だけ。
- 知名度20到達週：毎週末に fame>=20 を初めて見た通算週（48週/年）。到達率は全条件 100%。
- 注意：ジョブを同一プロセスで連続実行するとパッチが持ち越される（最初の実行で発覚・修正済）。生出力は修正後。

## §3 原因（どのイベントの何の効果か）
- 主因＝確定発火の群。ローテで −14pt、所持金 −225万、f20 +44週。7種のうち単独で効くのは early（−4.4pt）・styletalk（−7.6pt）・tani（−5.2pt）・passfork（−4.8pt）で、単独の和(約22pt)が群(14pt)より大きい＝効果は重なっていて、どれか1つを外しても他が穴を埋める。
  - early（1年目3〜14週・相性7以下で相性+2）、styletalk（3連敗後 表現+2/相性+1）：下積みで能力と相性を底上げ。
  - tani（所持金10万未満・相性8以上で+15万）：所持金の下支えが10年目所持金に直結（−1644 vs 1682）。
  - passfork（通過後 知名度+3）：唯一の直接の知名度加点だが、f20 への寄与は約8週。
- 固有9種・汎用16種は1種ずつ外しても誤差内（最大でも meishi −5pt、n=1000 で −5.0pt／f20 +5週）。群として −4.8pt。確定発火のように「必ず・早く」起きないため効きが薄い。
- 知名度20未満の罠への効き：確定発火が立つ週は週次抽選と関係なく起き、体力50以上なら能力+2系の加点が入る。能力が上がる→回戦通過が早い→知名度20に早く届く、の経路（直接の知名度加点は passfork +3 のみ）。従来プールは1イベント/20週程度の確率抽選で、これが無かった。
- ボット差：必要充足は元から知名度が早く伸びる(f20=126週)ので差が小さい(+7pt)。ローテは能力の伸びが遅く、確定発火の底上げが罠の脱出を直接早める(+13.8pt)。
- 未検証：どの経路(能力か相性か所持金か)が一番効くかの分解は未実施（`-C:` を能力/相性/金の項目別に無効化する実験が次の一手）。

## §4 所見（決めない・推奨のみ）
- アプリ側をこのまま正とするか：差は「アプリのイベント内容が強い」というより「確定発火が1周目の下積みに必ず効く」ことが原因。ゲームとして正しい挙動(つっこみ後・パス後・序盤の声かけ)なので、アプリを正とするのが自然。**推奨：アプリ側を正とし、sim 側の基準を EVENTS_APP=True に切り替える**（旧プールの測定値は帯がずれるため、今後のバランス判断は True で取り直す）。
- 効きすぎ候補：styletalk（ローテ −7.6pt）が単独最大。3連敗した人への救済なので意図通りだが、下積み期の連敗で毎回発火するなら、能力+2を+1にする余地あり。early の相性+2（1年目限定）も同様。ただしどれも単独 ±5〜8pt で、帯を壊す大きさではない。
- tani の +15万：所持金下支えとして効く（−1644 vs 1682 のうち一部）。10年目所持金を気にするなら金額か条件（所持金10万未満）が調整点。
- 優勝率は全条件で0〜4%（ほぼ不変）＝イベントは決勝止まりまでの底上げで、優勝の壁は動かさない。
