## 15_コンビ画面_ちから

* **① 点数**：**82点**（あと一歩で合格。基礎コンポーネントは高い精度で入っているが、名札カードと上部木札のバランスで減点）
* **② まだ設計どおりでない所**
  * 上部の「実力 115」と「相性 19」の高さ・文字サイズが非対称（`YosePowerBadge` は数字30ptで高さ約46pt、隣の相性バッジは数字20pt程度で高さ約38pt）で、上揃えのまま段差ができている。また右半分が空白になっている。
  * 下部の「コンビの名札」カードの見出し帯（臙脂）の直下に `yoseKin`（消金）の飾り罫線がなく、項目ラベル（「コンビ名」「相方」「いま」）が `yoseHaiSumi` の細字で左端、値が明朝体で右端に離れすぎており、禁則事項9「カードの真ん中に `Spacer()` で巨大な空白を空けることの禁止」に抵触している。
* **③ 崩れ・AIっぽさ・初めての人が迷う所**
  * 「相 方」だけ不自然なスペースが空き、「いま」というひらがなラベルと右端の「1年目 第1週」の間が約180ptも空いているため、視線が左右に往復して読みづらい。
  * 5能力すべてのゲージが `115` なのに、「センス〜華」はバーが8割程度で止まり、「メンタル」だけ100%満タンになっている（上限値の違いが視覚的に分からず、バグに見える）。
* **④ 85点に届くための直す指示（優先順3個）**
  1. **上部木札2連の等高・2カラム均等化（`YosePowerBadge` ＆ 相性 `yoseKifuda`）**：`HStack(spacing: 10)` で左右均等幅（各幅 `177.5pt`、高さ `48pt` 固定）に揃え、「相性」の数値も `YoseFont.number(26, weight: .black)` に引き上げてベースラインを一致させる。右側に `YoseGauge(value: 19, total: 100, height: 8)` を添えて「相性の上限」を直感化させる。
  2. **「コンビの名札」カードの2列グリッド化（`YoseHarigamiModifier` 内部）**：臙脂ヘッダー（高さ `28pt`）の下辺に `Rectangle().fill(YoseColor.kin).frame(height: 1.5)` を追加。内部の3行は `Spacer()` で左右端に飛ばすのをやめ、左ラベル幅を `84pt` 固定（`YoseFont.gothic(12, weight: .bold)`・背景 `YoseColor.ki.opacity(0.35)` の小見出し箱）＋右側に値（`YoseFont.mincho(16)`）を左寄せで配置し、行間に `1pt` の `YoseColor.kiDark.opacity(0.5)` 区切り線を引く。
  3. **能力行（`YoseHarigamiModifier` 5行）のゲージ最大値基準の統一**：`YoseGauge` の `total` 引数を全能力共通の最大値（例：`120` または `100`）に統一し、同じ `115` なら同じゲージ長になるように修正する。

## 16_コンビ画面_記録

* **① 点数**：**83点**（一覧性と木札・朱印の骨格は良好だが、3列サマリーの単位表記とテキスト折り返しで減点）
* **② まだ設計どおりでない所**
  * 「大会の記録」のセクション見出しに、仕様書3章 `sectionTitle` で規定された「下に2ptの墨線または左に朱の縦帯」がない（#17には下線があり、#18には左縦帯があるのに、この画面だけ裸の文字になっている）。
  * 上部サマリー木札（`yoseKifuda`）の「3回」「1回」「500万」の単位文字（「回」「万」）が `yoseHaiSumi` で小さく、特に「獲得賞金 500万」が `YoseColor.kin` や `shu` ではなく黒文字のため、賞金獲得の達成感が薄い。
* **③ 崩れ・AIっぽさ・初めての人が迷う所**
  * 44週の行が「44週｜頂GP決勝 優勝『ひだまり座』（客席から）［観戦］」と「44週｜頂GP決勝 優勝 +¥500万［優勝］」の2行に分かれており、同じ週に客席観戦と自身の優勝が同時発生したような矛盾した記録に見えて混乱する。また1つ目の44週の行だけ2行折り返しで行高が膨らんでいる。
* **④ 85点に届くための直す指示（優先順3個）**
  1. **セクション見出し「大会の記録」の装飾統一（`sectionTitle`）**：見出し左に `Rectangle().fill(YoseColor.shu).frame(width: 4, height: 18)` を置くか、下辺に `Rectangle().fill(YoseColor.sumi).frame(height: 2)` を引き、#17・#18とデザインを揃える。
  2. **上部3列サマリー木札（`yoseKifuda`）の数値・単位強化**：高さを `68pt` に固定し、ラベル（「大会出場」「優勝」「獲得賞金」）を `YoseFont.gothic(11, weight: .bold)`（色：`YoseColor.haiSumi`）、数値を `YoseFont.number(24, weight: .black)`、単位（「回」「万」）を `YoseFont.gothic(13, weight: .heavy)`（色：`YoseColor.sumi`）に引き上げる。「獲得賞金」の数値は `YoseColor.shu` または `Color(hex: 0x9A7B1C)` で強調する。
  3. **戦績リスト行（`yoseHarigami`）のレイアウト整理**：週数カラムを幅 `52pt` 固定（`YoseFont.number(14, weight: .heavy)`）にし、縦区切り線を `YoseColor.kiDark` `1.5pt`（高さ `24pt`）に統一。2行になる場合は行間 `lineSpacing(2)`、カード上下パディングを `10pt` に統一して窮屈さを消す。

  3. **下部「権利表記・バージョン」木札（`yoseKifuda`）の配置見直し**：`Spacer()` で画面最下部に突き放すのではなく、「このキャリア」の下 `24pt` に配置するか、木札の上部中央に `showNail: true`（釘穴ドット）を付けて「楽屋の定位置に打ち付けられた木札」の意匠にする。
