# イベント会話・場面背景（全22画面：11か所×昼/夜）実機デザイン監査レポート（Round 3）

『寄席と計器（Yose & Gauge）』v2.0（`@docs/design_system_argon_v1.md`）およびイベント会話背景仕様書（`@docs/event_backgrounds_argon_v1.md`）に基づき、実機スクリーンショット全22画面（11場所×昼/夜）を商業リリース基準（85点合格）で厳格に採点・監査しました。

## bg_apartment_day.png

1. **点数**：**78点**（不合格・あと7点）
2. **まだ設計どおりでない所**
   * 仕様書「4-3. 部屋」で定義されている「押し入れ横のカレンダー貼り紙」と「ちゃぶ台の上のみかん」が省略されており、四畳半の生活感が薄い。
   * 天井から下がる裸電球の傘が、`Path`（台形）に対して `.overlay(Rectangle().stroke(...))` を掛けているため、**台形の外側に四角い黒枠（長方形のバウンディングボックス）が浮き出てしまっている**。
   * ステージ左上に常設すべき「場所・時間帯の木札バッジ（`安アパート ・ 昼`）」が描画されていない。
3. **崩れ・AIっぽさ・初めての人が迷う所**
   * **描画崩れ（最優先）**：天井の照明傘の周りに不自然な長方形の黒枠が重なっており、図形プリミティブの実装ミスが一目でバレる。
   * ちゃぶ台の2本の脚（`offset(y: 12)`）に墨枠（`yoseSumi`）がなく、天板（墨枠2ptあり）と質感が分離して見える。
   * 障子の桟（格子線）が外枠と同じ太さ・色調に見え、奥行きがない。
4. **85点に届くための直す指示（優先順・3個）**
   1. **`ApartmentBackdrop` の照明傘シェイプ**：`.overlay(Rectangle().stroke(YoseColor.sumi, lineWidth: 1.5))` を廃止し、同じ台形 `Path` に対して `.stroke(YoseColor.sumi, lineWidth: 1.5)` を重ねて四角い外枠ゴミを消す。
   2. **`ApartmentBackdrop` のちゃぶ台脚＆みかん**：脚2本（`width: 12, height: 22`）に `.overlay(Rectangle().stroke(YoseColor.sumi, lineWidth: 1.5))` を追加し、天板中央（`offset(x: 0, y: -11)`）にみかん（`Circle().fill(Color(hex: 0xE57C23)).frame(width: 10, height: 10)`＋墨枠1.5pt）を配置する。
   3. **`EventStageBackdropView` 左上木札**：ステージ左上（`x: 14, y: 10`）に `安アパート | 昼` の `.yoseKifuda()` バッジを重畳表示し、初見で場所が100%伝わるようにする。

## bg_apartment_night.png

1. **点数**：**74点**（不合格・あと11点）
2. **まだ設計どおりでない所**
   * `EventTimeTintModifier`（`.night`）の減光（`brightness(-0.18)` + 乗算グラデーション）が照明器具自体にもそのまま掛かっており、**夜なのに裸電球（`yoseKinBright`）が暗い黄土色にくすんで消灯しているように見える**。
   * 昼の障子窓（`yoseWashi`）がただグレーに濁るだけで、「外の夜空（濃紺）」と「室内の電球の暖色」の対比が出ていない。
3. **崩れ・AIっぽさ・初めての人が迷う所**
   * 昼画面と同じく、照明傘の周囲に長方形の黒枠バウンディングボックスが残っている。
   * 画面全体にグレーの막（幕）を掛けただけの「単調な暗転」に見え、夜の安アパート特有の侘しさ・白熱電球の温かみが弱い。
4. **85点に届くための直す指示（優先順・3個）**
   1. **`ApartmentBackdrop` の裸電球＆ハロー効果**：夜（`time == .night`）の時は電球（`width: 12, height: 12`）を減光フィルターの上に置くか、電球中心（`x: w * 0.48, y: 36`）に `RadialGradient(colors: [YoseColor.kinBright.opacity(0.45), .clear], center: .center, startRadius: 6, endRadius: 90)` を `.blendMode(.screen)` で重ねて電球を明確に発光させる。
   2. **`ApartmentBackdrop` の障子窓（夜間）**：夜間は障子の面色を `Color(hex: 0x3A4659)`（夜の青み）に切り替え、室内の暖色光との色温度差を作る。
   3. **照明傘のバウンディング枠修正**：昼と同様に `Rectangle().stroke` を台形 `Path.stroke` に差し替える。

## この群（全22画面）の共通の問題と、画面同士で揃っていない所

### 1. 全画面共通の4大問題（最優先で一括修正すべき事項）

1. **「全画面表示（852pt）の中央に220ptの背景帯だけを置いたプレビュー状態」になっており、仕様書「第5章」のイベント会話UIと結合されていない**
   * 今回の22枚はすべて上下（`y: 0〜316pt`、`y: 536〜852pt`）が生成り（`yoseKinari`）の空白になっており、背景ステージ左上に常設すべき**「場所・時間帯の木札バッジ（`稽古場 | 昼` 等）」**も、上部の `YoseHeaderBar`、下部の会話板・選択肢・`YoseVitalMoneyBar` も表示されていません。
   * **会話文字の可読性についての判定**：仕様書どおり「背景ステージ（220pt）の下に生成り＋白和紙の会話板を分離配置する」設計であれば、本文のコントラスト比（`13.8:1`）は全22画面で100%保証されます。ただし、背景ステージ左上に重ねる木札バッジ（`.yoseKifuda()`）は早急に実機表示へ組み込んでください。
2. **`EventTimeTintModifier`（夜 `.night`）が「照明器具や内照看板」まで一緒に黒く潰してしまっている**
   * 11か所すべてに一律で `.brightness(-0.18)` と濃紺の乗算フィルターを掛け、かつ画面ど真ん中（`center: .center`）に1つだけ `RadialGradient` を置いているため、以下の破綻が全夜画面で発生しています：
     * **本来光るべき光源が暗い**：アパートの裸電球、楽屋のハリウッドミラー電球、公園の街灯、ファミレス・喫茶店のペンダントランプ、なんば駅の駅名標、劇場の提灯がすべて泥色に沈んで消灯して見える。
     * **光源がない場所が光っている**：特に `bg_park_night`（左に街灯があるのに中央の草むらが光る）や `bg_sento_night`（富士山の胴体だけがぼんやり光る）で顕著。
   * **解決策**：各背景ビューで「発光パーツ（電球・窓の夜空・内照看板）」を分岐させるか、夜フィルターの後に発光レイヤーを重ねてください。
3. **非矩形 `Path`（台形・三角形）に対する `.background()` / `.overlay(Rectangle())` の誤用による四角いゴミ枠**
   * `bg_train_day/night` の吊り革（三角形の周りに白い四角が出る）と、`bg_apartment_day/night` の照明傘（台形の周りに四角い黒枠が出る）で、SwiftUIのビュー矩形に対するモディファイア誤用が起きています。非矩形の `Shape / Path` には必ず同じ `Path` で `.fill()` と `.stroke()` を掛けてください。
4. **夜の窓ガラス（室内から見た外の景色）が「昼の水色を灰色に濁らせただけ」になっている**
   * `bg_famires_day`（昼なのに窓が夜色）の逆転をはじめ、`bg_keikoba_night`、`bg_apartment_night`、`bg_office_night`、`bg_train_night` のすべてで、夜の窓が「濃紺の夜空」ではなく「くすんだグレー水色」になっています。室内背景の窓ガラス色は、`time == .night` の時に濃紺（`#1B263B`）へ明示的に切り替えると、昼夜の差が一気に劇的になります。
