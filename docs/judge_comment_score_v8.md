## §3 直し案（△・文字列だけ。式・乱数消費・GameConfig は不変）
1. `Paper.passMentalLow` に2本足す（例「{入り}で目線が泳いだ。{中}から客の顔を見られた。」「{一言}の前に一拍の迷い。中身が助けた。」）※行数を変えると salt からの選び方は変わるが golden 外。
2. `Paper.failNear` に1〜2本（例「{中}までは同じ線。{締め}の一押しで差がついた。」）。
3. `Paper.passBurst` に1本（「この夜の形」の重なりを3→2回以下に）。
4. 型なし語彙の {締め}「振り出しの締め」→「話を戻す締め」（要素数そのまま）。3か所（83・107・125行）のうち 125 行目が現行の型なし語彙。
5. #41 の行「{中}、二人の関係がネタに乗っていない。」に処方を足す：「…乗っていない。一度、相方の言葉を拾ってから返すこと。」
6. 「間の幅」系（pass と fail に各1本ずつ似た行）は片方の言い方を変える（例 fail 側「{入り}は速く{締め}は遅い。速度を一つに。」）。
