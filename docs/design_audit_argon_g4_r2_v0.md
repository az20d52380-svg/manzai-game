## 47_0011_イベント会話_0011.png（月末の飲み会）

### ① 新しい点数
**前回：24点 ➔ 今回：58 / 100点**（+34点・基礎骨格は入ったが商業リリース基準には未達）

### ② 設計図どおりでない所
* **下部ステータス帯（`YoseVitalMoneyBar`）の欠落（前回指示③未実装）**：`[756-792pt]` に常時表示すべき `YoseVitalMoneyBar`（体力・所持金）が実装されておらず、「飲み会に行く／自炊する」の判断基準となる現在の所持金・体力が画面上で一切確認できない。
* **ヘッダーとイベント題名看板の統合による週数・種別の消失（前回指示①違反）**：`YoseHeaderBar` にイベント名「月末の飲み会」を直接入れてしまったため、本来ヘッダーが持つべき「何年目の第何週か」「日常イベントか交流イベントか」の情報が消えている。
* **背景イラストの未改修（前回指示④未実装）**：「月末の飲み会（夜道・居酒屋）」にもかかわらず、ピンク〜オレンジのグラデーション壁に謎のベージュの角丸四角が3つ並んだ元の背景のままで、夜道の黒漆トーン（`yoseKuroUrushi`）や赤提灯・暖簾のシルエットが入っていない。
* **選択肢ボタンがすべて副ボタン色（`.secondary`）で主従がない**：2つの選択肢がどちらも同じ白和紙（`yoseWashi`）のフラットな文字中央揃えボタンになっており、押した際の手応えや選択肢としての視覚的フックが弱い。

### ③ 新しく出た崩れ・AIっぽさ・初めての人が迷う所
* **既読（過去行）のグレーアウトによる「押せないボタン（Disabled）」への誤認**：ト書きと1行目の谷口のセリフ枠の背景が `yoseGinNezu`（`#D4CFC4` 付近の濃いグレー）で塗りつぶされている。デザインシステムにおいてグレー背景＋薄文字は「押せない無効ボタン」のトークンであるため、会話ログが「無効化されたUIパーツ」に見えて画面全体が濁っている。
* **全セリフ一括表示による視線誘導の破綻と中段の空白**：1画面にト書き＋セリフ3行＋選択肢2個をすべて同時展開したことで、どこを今読めばいいのか視線が散るうえ、セリフ群の下（`y: 560〜700pt` 付近）に依然として約 `140pt` の中途半端な空白地帯が残っている。
* **話者名札（`谷口` / `俺`）に役職小見出し（`roleLabel`）がない**：`YoseSpeechBox` 規定の黒漆小見出し（`相方` など）が省かれており、赤い小箱だけが浮いている。

### ④ 次に直す指示（優先順3個）
1. **画面最下部に `YoseVitalMoneyBar` を固定連結し、選択肢との間にステータス判断軸を入れる**
   * **部品・数値**：画面最下部（SafeArea上端、`y: 782〜818pt`、高さ `36pt`）に `YoseVitalMoneyBar(stamina: ..., maxStamina: ..., money: ..., fame: ...)` を配置。選択肢ボタン2つは `y: 650〜766pt`（各高さ `52pt`、縦間隔 `10pt`、左右マージン `14pt`）に引き上げ、中段の空きスペースを `24pt` 以内に圧縮する。
2. **過去セリフのグレー塗りつぶし（`yoseGinNezu`）を廃止し、和紙背景の濃淡と左端インジケーターで現在行を示す**
   * **部品・数値**：既読セリフ枠の背景をグレーにするのをやめ、既読行は `yoseKinari`（`#F5F0E1`、枠線 `yoseHaiSumi` `1.5pt`、下影 `0pt`）、現在フォーカス行（最新の2行）は `.yoseHarigami(isFeatured: true)` または `yoseWashi`（`#FBF8F1`、枠線 `yoseSumi` `2pt`、ハードシャドウ `y: 2pt`）にする。ト書き枠は左端の金線を `yoseEnji`（幅 `6pt`）に変え、背景を `yoseKi.opacity(0.45)` の木札調にしてセリフと明確に区別する。
3. **夜道・赤提灯の背景ディテール実装と後ろ姿シルエットの引き締め**
   * **部品・数値**：舞台領域（高さ `240pt` に圧縮）の背景を夜道色（上端 `#1E1916` ➔ 下端 `#2C221E`）に変更し、謎のベージュ四角3つを「居酒屋の障子窓（内枠格子 `1pt` 入り `#F5D799`）＋右端に朱色の長提灯（`yoseShu` 幅 `28pt`×高さ `48pt`、上下に黒漆枠 `4pt`）」に差し替える。青・赤のこけし図形には `yoseSumi` `2pt` のアウトラインを付与して背景からパキッと分離させる。

## 47_0012_イベント会話_0012.png（短期バイトの話）

### ① 新しい点数
**前回：23点 ➔ 今回：55 / 100点**（+32点・タイトル被りは解消したが背景矛盾とステータス欠落が残存）

### ② 設計図どおりでない所
* **「稽古場」なのに本番の「寄席」背景のまま（前回指示②未実装）**：ト書きは「稽古場。月末の昼。」であるにもかかわらず、「寄席」の額縁とセンターマイク、本番用スポットライトがそのまま残っている。
* **センターマイクの頭が「寄席」の額縁の「席」の文字を隠している**：前回のカプセルタイトル被りはなくなったが、センターマイクの丸いグリル部分が「寄席」額縁の「席」の字の右半分に重なっており、オブジェクト同士の衝突が解消されていない。
* **`YoseVitalMoneyBar` の欠落（前回指示④未実装）**：「短期バイトに入る／断る」という金銭と体力のトレードオフを選ぶイベントなのに、現在の所持金と体力が見えない。

### ③ 新しく出た崩れ・AIっぽさ・初めての人が迷う所
* **「夜勤で稼ぐか、今の暮らしを続けるか」の判断材料がゼロ**：初めてのプレイヤーは、自分が今お金に困っているのか（家賃や大会エントリー費が足りるのか）、体力が満タンなのか瀕死なのかが分からず、勘で選択肢を押すしかない。
* **1行目の谷口のセリフだけが暗いグレー箱に沈んでいる違和感**：まだ会話を読み始めたばかりなのに、最初のセリフ「これ見て。倉庫の短期バイト〜」がグレーアウトしており、視線が3行目へ飛んでしまう。

### ④ 次に直す指示（優先順3個）
1. **本番「寄席」額縁とマイクを撤去し、昼の「稽古場」専用背景へ差し替え**
   * **部品・数値**：背景の「寄席」額縁・サンパチマイク・床の丸いスポットライトを非表示にする。代わりに壁面中央（`y: 96pt`）に「稽古場ホワイトボード」（幅 `160pt`×高さ `76pt`、背景 `yoseWashi`、外枠 `yoseSumi` `2pt`、下辺に `yoseKiDark` `4pt` の粉受けトレイ）と、右奥にパイプ椅子2脚の幾何学シルエット（`yoseHaiSumi`）を配置する。
2. **`YoseVitalMoneyBar` の最下部常設と選択肢ボタンの主従化**
   * **部品・数値**：最下部（高さ `36pt`）に `YoseVitalMoneyBar` を固定表示する。2つの選択肢ボタン（左右マージン `14pt`、高さ `50pt`）は `YoseButtonStyle(.secondary)` をベースにしつつ、左端に朱色の菱形印（`8×8pt` `yoseShu`）を入れて「選択肢であること」の視認性を高める。
3. **会話ボックスのグレーアウト廃止と `YoseSpeechBox` の完全適用**
   * **部品・数値**：全セリフ枠の背景を `yoseWashi`（`#FBF8F1`、外枠 `yoseSumi` `2pt`、角丸 `2pt`、下影 `y: 2pt`）に統一し、話者名札（幅 `62pt` 固定）の上部に `roleLabel`（「相方」「自分」、`9pt Heavy`、`yoseKuroUrushi` 背景＋`yoseKin` 文字）を付与する。

## 47_0013_イベント会話_0013.png（先輩のおごり）

### ① 新しい点数
**前回：25点 ➔ 今回：60 / 100点**（+35点・上端提灯の見切れは直ったが、テーブルの前後破綻とグレー箱問題あり）

### ② 設計図どおりでない所
* **焼肉ロースター（網）のレイヤー順序が未修正（前回指示③未実装）**：相変わらず2人の背中よりも手前（画面下端の黒い帯の上）にオレンジ色の楕円形ロースターが浮いており、2人が肉を背にして壁を向いている構図のままになっている。さらに壁の短冊も無地の赤とベージュの四角のままで、メニューの擬似文字線が入っていない。
* **最下部の `YoseVitalMoneyBar` 欠落（前回指示④未実装）**：焼肉で体力が回復するイベントなのに体力ゲージが表示されていない。

### ③ 新しく出た崩れ・AIっぽさ・初めての人が迷う所
* **4行のセリフ＋ト書き＋2選択肢で詰め込まれた画面の窮屈さとグレー箱の汚さ**：セリフが4行あるため、上2行（先輩・俺）が濃いグレー（`yoseGinNezu`）、下2行（先輩・谷口）が白和紙に分断されており、白黒の縞模様のように見えて非常に読みづらい。
* **話者「先輩」の名札が「谷口」「俺」と全く同じ赤色（`yoseShu`）**：3人の登場人物（先輩・俺・谷口）が全員同じ `yoseShu` の名札になっているため、誰が喋っているかの瞬間判別がしづらい。

### ④ 次に直す指示（優先順3個）
1. **話者名札（`YoseSpeechBox` 左札）の役割別カラーリングと固定幅化**
   * **部品・数値**：話者名札の幅を全行 `64pt` に統一し、話者ごとに背景色を分ける。「谷口（相方）」＝ `yoseShu`（`#BD3C28`）、「俺（自分）」＝ `yoseKuroUrushi`（`#1E1916`）、「先輩・マネージャー（ゲスト）」＝ `yoseEnji`（`#7D221E`）または `yoseTokiwa`（`#2E583C`）とし、一目で会話の掛け合いリズムが分かるようにする。
2. **焼肉テーブルとロースターを「2人の間（テーブル上）」へ移動し、短冊に縦線を追加**
   * **部品・数値**：手前の黒い床帯にある楕円ロースターを削除し、2人のシルエットの間（`y: 230pt` 付近、茶色いカウンター天板の上）に七輪/ロースター（幅 `80pt`×高さ `18pt`）を配置する。背後の5枚の短冊（赤・生成り）にはそれぞれ中央に `yoseSumi.opacity(0.35)`（赤短冊には `yoseKinari.opacity(0.4)`）の幅 `2pt`×長さ `24pt` の縦線を2本ずつ描き込む。
3. **グレーアウト廃止＋`YoseVitalMoneyBar` 追加による縦レイアウトの再配分**
   * **部品・数値**：舞台領域の高さを `260pt` ➔ `210pt` に50pt縮小し、浮いたスペースを使って最下部に `YoseVitalMoneyBar`（高さ `36pt`）を配置する。全セリフ枠はグレー塗りを廃止し、`yoseWashi` 背景＋明朝体 `15pt`（上下パディング `8pt`）でスッキリ揃える。

## 全体（全59画面）を通して残る統一感の問題

今回の改修で「丸カプセル（`Capsule`）の廃止」「ヘッダー帯（`YoseHeaderBar`）の導入」「明朝体セリフとハードシャドウの適用」「丸顔こけしアイコンの廃止（めくり名札化）」が大きく前進しましたが、**全59画面を1本の商業ゲームとして通して見たとき、以下の5つの重大な不統一・未完成箇所**が残っています。

### 1. イベント会話画面（47系）における「既読セリフのグレー塗りつぶし（`yoseGinNezu`）」の誤用
* 今回新しく発生した最大の問題です。イベント会話画面で過去のセリフ（上1〜3行）を `yoseGinNezu`（`#D4CFC4`）で塗りつぶしたため、デザインシステムで定義した **「`yoseGinNezu` ＝ 押せない無効ボタン（Disabled）」のルールと正面衝突** しています。
* 特に4行会話の画面（`0013` / `0025` / `0027` / `0028` / `0029`）では画面中央の大部分が暗い鼠色の箱で埋め尽くされ、和紙（`yoseKinari` / `yoseWashi`）の明るく粋なトーンが失われています。セリフ枠は全行 `yoseWashi`（または既読のみ `yoseKinari`）に統一し、グレー塗りは即刻廃止してください。

### 2. 話者名札（めくり）の横幅不統一によるセリフ枠のガタつきと、話者別の色分け欠如
* `48`/`49`（週メイン画面）では `YoseSpeechBox` の名札の上に黒漆の `相方` ラベルがついていますが、`47`（イベント会話画面）ではそれが省略されています。

### 3. 下部ステータス黒帯（`YoseVitalMoneyBar`）の「画面による有無」と「緑ブロックの残存」
