### 低-1 相性14.6が「15」と見えるのに「近くにいない」終わりになる
- 場所：NotebookView.swift:133（`Int(s.compat.rounded())`）／Endings.swift:90・93・95（`compat >= 15`）
- 手順：相性が小数（GP 予選落ちの −0.5 などや周回ボーナスで小数になる）で 14.6 の状態で最後の年末を迎える。手帳の相性札は「15」。終わりは「近くにいた」側（#4・#6・#8）ではなく #3・#5・#7 に分岐する。
- 既出か：partner_audit_1115_v0.md §2-2 が「表示は四捨五入・ゲートは生の値」を指摘済み。ただしそこにはエンディング判定（Endings.swift）が入っていない＝影響先が最終分岐だと追記が要る。
- 直し方の案：①今のまま（式を触らない）。②judge の比較だけ `compat.rounded() >= 15` にして表示とそろえる（表示専用の層・乱数なし・golden 非経路だが、終わりの分岐の境界が動く＝オーナー決定）。③手帳の相性を切り捨て表示にする（他画面と食い違う）。推奨②（見た数字と結果が合う方が納得が早い）。ただし決めるのはオーナー。

### 低-2 手帳の「経験点を使う」と「もう伸びにくい」が同時に出る
- 場所：NotebookView.swift:74-76（経験点 N 未使用／週の画面の能力アップで使う）と :83（今年はもう、能力が伸びにくい）
- 手順：成長の器が98%以上満ちた年に、経験点が残っている（自動注ぎが無効の設定）状態で手帳の能力タブを開く。上は「使え」、下は「伸びにくい」と言う。使っても伸びない（Allocation.swift:62 で器を超える分は縮む）ので、前者が空約束に読める（未確認：縮む量がどれだけかは実測していない）。
- 既出か：grep で既出なし。
- 直し方の案：①`full` の時は上の「週の画面の能力アップで使う」の行を出さず「年が明けると使える」にする。②下の文を「経験点は年が明けてから使うと伸びる」に変える。推奨①（1画面で言うことが1つになる）。

### 低-3 勇退（#7）以外の S6b 付きの終わりで、最初の1フレームだけ場面カードが出る（未確認）
- 場所：EndingViews.swift:19（`stage` 初期値 `.cards`）と :36-42（onAppear で `.s6b` に替える）
- 手順：#5・#8 の終わりに入る。初期値が `.cards` なので onAppear が走るまでの 1 描画で場面カード1枚目（結末の最初の台詞）が映り、すぐ S6b に切り替わる。#7 は cards が空なので Color.clear で守られている。

### 低-4 「決勝を知らないまま」の文言と、観戦で決勝を観た年の食い違い
- 場所：Endings.swift:56-62（hint #3・#4・#5・#6）・:94（`reachedFinal` だけ数える）／GameSession.swift:1127（`watchedFinal`）
- 手順：決勝に出られなかった年に第47週で決勝を客席から観る（観戦）。15年そのまま終わると #3/#4 が出る。図鑑のヒントは「決勝を知らないまま十五年」だが、プレイヤーは決勝を観ている。
- 既出か：grep で既出なし。
- 直し方の案：①ヒントを「決勝の舞台に立たないまま十五年」「決勝の舞台に立って」に直す（逐語の仕様 endings_spec_v1.md の文なので正典側の更新が要る）。②観戦も「決勝を知る」に数える（判定の変更＝オーナー決定）。推奨①（判定を動かさない）。

### 低-5 名前入力：空白だけだと無反応・結成を押した後の 0.45 秒の窓
- 場所：IntroFlow.swift:675-694（decide）・:556-560（おまかせボタン）
- 手順：①コンビ名を空白だけにして「結成する」→ trim で空になり `guard` で黙って戻る（エラーの表示なし。ボタンが壊れて見える）。②結成を押す（decided=true）→ 0.45 秒以内に「おまかせで考える」を押す。名前の State が変わり、onDecide は 0.45 秒後に読んだ `name` を渡す＝画面の札と違う名前で決まる可能性（未確認：State 読み出しのタイミング）。
- 既出か：①は未。②の遅延コールバック全般は delayed_callback_audit_1108_v0.md の IntroFlow:687 の行（閉じても取り消せない）だけで、おまかせとの競合は書かれていない。
- 直し方の案：①空なら札を揺らす・「名前を入れてね」を1行出す。②decide の冒頭で `name` を値で取り（`let n = name`）、decided 中はおまかせボタンを `.disabled(decided)` にする。推奨：両方（どちらも数行・表示専用）。

### 低-6 手帳：改名の編集中に別の札の改名を押す・手帳を閉じると入力が捨てられる
- 場所：NotebookView.swift:344・398（`renameDraft = neta.name` で上書き）・:408（commitRename は確定ボタン／Return だけ）
- 手順：ネタAの題名を直している途中でネタBの「改名」を押す → A の入力はコミットされず消える（renamingID が B に移る）。手帳を閉じても同じ。
- 既出か：grep で既出なし。
- 直し方の案：①別の札を押した時、先に今の編集を commit する。②今のまま（題名の変更は軽い）。推奨②（二度手間が出るだけで状態は壊れない）。

### 低-7 旧セーブで過去の年の道中大会の優勝が通算に入らない

- 直し方の案：①今のまま。②出荷前の旧セーブが無ければ何もしない。推奨①。
