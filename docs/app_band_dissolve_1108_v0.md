# やり込みボットの解散約40%の原因（2026-11-08・調べるだけ・式と数値は変更なし）

## 要点3行
- 結論は①（ボットの作り）が主因。解散の式と各定数は GameCore と Python で一致しており、②の同期漏れは見つからなかった。ボットが相性を上げる行動（ネタ合わせ・相方と過ごす）をほぼ選ばず、相性が 5→2〜9 に張り付いて、すれ違いゲージが約 10〜15 年目で 100 に届く。
- 「rift が 30 以上なら ネタ合わせ（体力40未満は相方と過ごす）」を足すだけで、解散 45%→0%、決勝到達 30%→72%、15年内初優勝 0%→6%（どちらも n=100・seed 1000〜1099）。
- ③（普通の遊び方）：相性を一度も上げずに15年放置するプレイは、人間でも解散する設計。ただし「毎週最適化して相方を放置する人」がどれだけいるかは測れていない。予告イベント（rift 50 到達）の選択肢 A（−30）は先頭選びで毎回押しているのに、それでも解散した。

## 結論
- ①が主因（確認済み）：相性を上げる行動をボットが取らないと解散する。守りを1行足すだけで解散 0%・決勝 72% になり、アプリ本体の解散の式は設計どおりに動いている。
- ②（本物のバグ・同期漏れ）は、式・定数・順序・二人の週の印・相性の源の全てで見つからなかった。
- ③は部分的：相性を長く上げない放置プレイは解散する、という設計の結果。ただし実際のプレイヤーがそうなる割合は、このボットでは言えない。

確かめられなかった事
- Python の 11.7%（APP=1）／26%（APP=0）との差の原因。Python 側は今回回しておらず、Cafe/Spa ラッパー・週イベントの相性効果（イベントで相性が上がる回数）の差が候補。切り分けていない。
- 週イベントの有無（B）での解散は今回再測定していない（前回 n=300 で A 39.7%・B 38.0%、差なし）。
- n=100 のため、解散率 45% の信頼幅は約 ±10pt。方向（守りで 0%）は明確。
