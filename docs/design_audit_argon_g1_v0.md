# 実機画面 全16枚 厳格監査レポート（基準：『寄席と計器』v2.0）

パワプロ（サクセス）・ウマ娘級の商業リリース基準（100点満点・合格ライン85点）に照らし、`@docs/design_system_argon_v1.md`（以下「正本」）に対する全16画面の監査結果と修正設計図を以下に示す。

---

## 01_タイトル

### ① 点数：**48 / 100点**

### ② デザインシステムから外れている所
* **禁則§8-4違反（こけし人間と等間隔の丸頭観客）**：中央の青・赤の角丸矩形＋半円頭の「こけし漫才師」と、下部の同サイズ・等間隔に並んだ黒い雪だるま型観客シルエットが正本の禁則事項に直撃している。
* **禁則§8-10違反（ぼかしグロー・ドロップシャドウ）**：タイトル文字『四分の夜』の背後に白いぼかし発光（Blur）がかかっており、サンパチマイクの球体にも3D風のグラデーションが入っている。
* **ボタン仕様違反（§5-②）**：「はじめる」ボタンがくすんだ黄土色＋白細枠＋ぼかし下影になっており、`YoseButtonStyle(.primary)`（背景 `yoseShu`・墨枠 `2pt`・ハードシャドウ `y: 3pt`）に準拠していない。

### ③ AIっぽい所・UXの分かりにくさ
* SwiftUIの `Circle` と `RoundedRectangle` だけで無理やり人間と観客席を描いた「AI生成プロトタイプ臭」が最も強く出ている。
* 初見プレイヤーが起動した瞬間、「商業ゲーム」ではなく「個人開発の習作」と感じてしまう最大のボトルネック。セーブデータがある場合の「つづきから」と「はじめから」の階層分けも見えない。

### ④ 直す設計図（優先順）
1. **舞台中央の「こけし人間・丸頭観客」を撤去し、寄席の『めくり台＋サンパチマイク＋定式幕』の象徴構図に置換**
   * **部品・配置**：中央（`y: 280〜540pt`）のこけし2体を削除。代わりに舞台上手・下手に寄席の「めくり台（縦長の木枠＋`yoseWashi` の紙札・墨2pt枠・高さ `180pt` × 幅 `68pt`）」と中央にソリッドな黒漆（`yoseKuroUrushi`）＋金差し色のサンパチマイクを配置。下部の観客席は等間隔の丸を廃止し、`#181210` 単色で高さ・幅をランダムにずらしたシルエット帯（高さ `56pt`）にする。
2. **タイトルロゴを『寄席大看板（額縁木札）』＋ `YoseOutlinedText` で組む**
   * **部品・配置**：上部 `y: 140pt`、左右マージン `24pt`。背景 `yoseKuroUrushi`、外枠 `yoseKin`（`3pt`）＋内枠 `yoseShu`（`1.5pt`）、ハードシャドウ `yoseSumi`（`y: 4pt`）の看板額縁を配置。
   * **文字・色**：中央に `YoseOutlinedText`（44pt Black・塗り `yoseKinari`・縁取り `yoseSumi` 2pt・下影 `y: 3pt`）で『四分の夜』。副題「―漫才師、育成。―」は `YoseFont.mincho(16)`・色 `yoseKin` で看板下部に配置（ぼかし発光は全廃）。
3. **「はじめる」ボタンの `YoseButtonStyle(.primary)` 化**
   * **部品・配置**：下部 `y: 660pt`、左右マージン `32pt`（幅 `329pt` × 高さ `58pt`）。
   * **色・文字・動き**：背景 `yoseShu`（`#BD3C28`）、外枠 `yoseSumi` `2pt`、上辺ハイライト白22% `2pt`、下影 `yoseSumi` `y: 3pt`。文字は `buttonMain`（角ゴ 20pt Heavy・`yoseKinari`）。押下時 `0.06秒 .easeOut` で `y: +3pt` 沈み込み＋`.rigid` ハプティクス。
4. **右上「設定」ボタンの木札化**
   * **部品・配置**：右上（`top: 64pt, trailing: 14pt`）の裸の白ギアアイコンを廃止し、`40×40pt` の `YoseKifudaCard`（背景 `yoseKi`・墨枠 `2pt`・下影 `2pt`・ギアは `yoseSumi`）に格納する。

## 02_導入回想カード

### ① 点数：**45 / 100点**

### ② デザインシステムから外れている所
* **禁則§8-4違反**：画面中央に巨大な青・赤の「こけし人間」が鎮座している。
* **禁則§8-1違反**：下部会話ログの「谷口」「俺」の話者ラベルが角丸（`cornerRadius(4〜6)`）のピル型になっており、青色（`#3B66D6`）などパレット外のWebカラーが使われている。
* **部品未適用（§5-⑨）**：会話エリアが「3行同時に並ぶチャット風リスト」になっており、正本の `YoseSpeechBox`（めくり名札＋貼り紙セリフ枠）が使われていない。

### ③ AIっぽい所・UXの分かりにくさ
* 上部背景の3つの白い縦長枠（教室の窓のつもり）が「中身が空のプレースホルダー枠（画像読み込みエラー）」にしか見えない。
* 下部に3行のセリフが最初から並んでおり、最下段の右端にだけ小さな `▼` があるため、「1行ずつ読ませるノベルなのか、3行まとめて1ページなのか、どこをタップすれば進むのか」が直感的に分からない。

### ④ 直す設計図（優先順）
1. **下部会話エリアを『ノベル進行型の `YoseSpeechBox`（§5-⑨）』または『貼り紙台本ビュー』に統一**
   * **部品・配置**：下部 `y: 600〜810pt`、左右マージン `14pt`。3行同時表示をやめるか、現在の発話行を `YoseSpeechBox`（左に幅 `58pt` の朱色めくり札 `yoseShu`＋墨枠 `2pt`、右に `.yoseHarigami()` の白和紙箱）で大きく見せ、過去2行はその上に透過度70%の台本行として積む。俺のラベル色もWeb青を廃止し `yoseKuroUrushi`（黒漆）＋ `yoseKinari` 文字に統一。
2. **場所見出し札と進行インジケーターの統合（上部ヘッダー化）**
   * **部品・配置**：左上（`x: 14pt, y: 64pt`）の「高校の教室。休み時間。」は角丸を `0pt` にし、背景 `yoseEnji`・外枠 `yoseSumi` `2pt`・左端に `yoseKin` `4pt` 縦帯・下影 `y: 2pt` の木札看板にする。右上の進行ドット（`■□□`）は `10×10pt` の直角正方形（現在地 `yoseShu`、未読 `yoseGinNezu`、すべて墨枠 `1.5pt`）にする。
3. **背景の「空っぽの3窓フレーム」と「こけし」の刷新**
   * **部品・配置**：空の白枠3つとこけし2体を廃止。回想シーンは中央に `.yoseHarigami()` の「挿絵額縁（幅 `335pt` × 高さ `320pt`・二重墨枠）」を置き、その中に夕暮れグラデーション（`yoseKi` → `yoseKinari`）と校舎の格子シルエット・桜びら等をハードエッジ図形で描く。
4. **ページ送りモーションの明確化（§6-4）**
   * **動き**：画面タップで次のセリフが `offset(y: 8 -> 0)`（`0.18秒 .spring`）でせり上がり、右下の `▼`（`yoseShu`）が `0.6秒` 周期で上下 `2pt` バウンスしてタップを促す。

## 03_名前決め

### ① 点数：**52 / 100点**

### ② デザインシステムから外れている所
* **禁則§8-1・§8-10違反**：中央の入力カードが `cornerRadius(10)` 以上の丸角＋白いぼかしシャドウ（Blur）になっており、完全にモダンWebの入力フォームになっている。
* **禁則§8-2違反**：「これでいく」ボタンが枠線なし・影なしのフラットなグレー矩形（`#9E9E9E`）で、`YoseButtonStyle` の無効状態（`yoseGinNezu`＋斜めストライプ＋`yoseHaiSumi` 枠）になっていない。
* **タイポグラフィ違反（§3）**：プレースホルダーの「コンビ名」に丸ゴシック体（`.rounded`）が使われており、知育アプリ感が出ている。

### ③ AIっぽい所・UXの分かりにくさ
* 画面下半分（`y: 520〜852pt`）が完全に無地の空白で、キーボードが出る前とはいえ画面の密度が極端に低い。
* コンビ名を1から考えるのはプレイヤーにとって負荷が高いのに、「おまかせ（ランダム命名）」ボタンがないため、開始1分で手が止まる。

### ④ 直す設計図（優先順）
1. **入力枠を『寄席のめくり札（横額縁）』（`.yoseHarigami(isFeatured: true)`）に改装**
   * **部品・配置**：`y: 290pt`、左右マージン `24pt`（幅 `345pt` × 高さ `110pt`）。角丸 `2pt`、外枠 `yoseSumi` `2.5pt`、内枠 `yoseKin` `1pt`、下影 `yoseSumi` `y: 3pt`、上部左右の丸鋲は黒漆塗り＋墨枠の太鼓鋲（直径 `8pt`）にする。
   * **文字・色**：入力文字・プレースホルダーともに `YoseFont.mincho(28)`（明朝体W6）に統一。未入力時は `yoseDisabledText` で「例：なんば亭」、入力時は `yoseSumi`。下部に `captionBold`（11pt・`yoseHaiSumi`）で「※最大8文字・あとから変更できません」を添える。
2. **「おまかせ（候補サイコロ）」副ボタンの追加**
   * **部品・配置**：入力枠のすぐ下（`y: 414pt`）に高さ `40pt` の `YoseButtonStyle(.secondary)` で「🎲 候補から選ぶ / おまかせ」ボタンを設置。タップごとに漫才らしいコンビ名候補が `0.15秒` で切り替わる。
3. **決定ボタン「これでいく」への `YoseButtonStyle(.primary)` 適用**
   * **部品・配置**：`y: 470pt`、左右マージン `24pt`、高さ `54pt`。
   * **色・文字**：未入力時は `isEnabled = false`（背景 `yoseGinNezu`＋斜めストライプ・枠 `yoseHaiSumi` `2pt`・影 `0pt`）。1文字以上入力された瞬間に `yoseShu`（朱色）＋墨枠 `2pt`＋下影 `y: 3pt` に切り替わり、文字を「結成する！」（`buttonMain` 18pt Heavy）にする。
4. **上部への `YoseHeaderBar("コンビ結成")` 設置**
   * **部品・配置**：画面最上部が寂しいため、`YoseHeaderBar(title: "コンビ結成")`（高さ `48pt`）を置いて画面の天地を引き締める。

   * **部品・配置**：舞台下部（`y: 332〜384pt`、左右マージン `14pt`）。顔アイコン箱を撤去し、左に幅 `58pt` の朱色めくり札（上部に黒漆で `相方` 9pt金文字、中央に `谷口` 明朝15pt白文字）、右に `.yoseHarigami()` のセリフ枠（`dialogueBody` 明朝15pt）を配置。

## 05_練習選び

### ① 点数：**62 / 100点**

### ② デザインシステムから外れている所
* **禁則§8-2違反（「もどる」ボタン）**：左上の「`< もどる`」が枠線も影もない薄い白背景のフラットボタンになっており、iOS標準ナビゲーションに見える。
* **色トークン違反（§2）**：各練習カードの枠線がパステルオレンジ（`#E88546`）、タグがラベンダー紫・ピンク・明るいティールなど、正本パレット外のWebカラーで塗られており、『寄席と計器』の重厚な世界観から浮いている。
* **舞台ビューとの重なり崩壊**：下から練習パネルがせり上がった結果、上部の舞台エリアが潰れ、相方の顔アイコンがこけしの胴体にめり込み、「寄席」の掛け軸が半分隠れ、右上の「実力 115」箱が赤こけしの頭に被さっている。

### ③ AIっぽい所・UXの分かりにくさ
* 各カードの右上に黒い小さな三角（`◣`）が付いているが、装飾なのか「詳細が見られる印」なのか意味が不明。
* 経験点タグ（「間合い +14」「存在感 +14」等）の色が淡すぎて、第11画面（能力アップ）の5色オーブ（`expSen` / `expGo` / `expMa` / `expSon` / `expTan`）と色味が一致しておらず、どの練習でどの丸玉が貯まるのか直感的に結びつかない。

### ④ 直す設計図（優先順）
1. **練習カードの枠線・背景を `.yoseHarigami()` に統一し、経験点タグを5大経験点トークン色（§2）に完全一致させる**
   * **部品・配置**：2列×3段グリッド（左右マージン `14pt`、間隔 `10pt`、各カード高さ `104pt`）。外枠はすべて `yoseSumi` `2pt`＋下影 `y: 2pt`、左端に幅 `5pt` のカテゴリ縦帯（通常練習は `yoseShu`、有料練習は `yoseKin`）を入れる。右上の謎の黒三角は廃止。
   * **色・文字**：獲得経験点タグは `YoseTag`（角丸 `0pt`・枠 `1.5pt`）を使い、色を正本の5色（`閃: #D49A2A`, `語: #2A6E58`, `間: #5A3E7A`, `存: #B53D2A`, `胆: #2B547E`）に統一し、先頭に1文字丸紋（「間 +14」「存 +14」）を入れる。
2. **コスト表記（体力・お金）の視認性強化**
   * **部品・配置**：カード最下段にコスト行を固定配置。`体力 -20` はグレー背景ではなく `yoseTokiwa` 枠の角札または `▼体力 20`（`captionBold` 12pt Heavy・`yoseSumi`）、`-¥8万` は `yoseShu` 文字＋薄朱背景の角札にして、無料練習と有料練習の違いを一目で判別させる。
3. **サブメニュー見出し行（「`< もどる` ｜ 練習」）の物理木札化**
   * **部品・配置**：高さ `38pt`。「`< もどる`」は幅 `76pt` × 高さ `30pt` の `YoseButtonStyle(.secondary)`（背景 `yoseKi`・墨枠 `2pt`・下影 `2pt`・文字 13pt Heavy）。見出し「練習」は `sectionTitle`（17pt Heavy）＋右側に横罫線（`yoseKiDark` `1.5pt`）を引く。
4. **サブメニュー展開時の上部舞台エリアの整理（重なり防止）**
   * **配置・動き**：サブメニュー展開時（`0.18秒 .easeOut`）は、中途半端に舞台を潰して要素を衝突させるのではなく、相方のセリフ箱を非表示にして舞台の高さを `150pt` にコンパクト化するか、舞台全体に黒35%の暗幕をかけて下から「稽古場のお品書き板（背景 `yoseKinari`・上辺 `yoseSumi` `2pt`＋`yoseKin` `2pt`）」としてカッチリ被せる。

## 06_バイト

### ① 点数：**60 / 100点**

### ② デザインシステムから外れている所
* **色トークン違反（§2）**：カード枠線とアイコン背景にパステルミントグリーン（`#63B995`）が使われており、和の寄席トーンから完全に逸脱している（正本の緑は深緑の `yoseTokiwa` `#2E583C`）。
* **禁則§8-2違反**：左上の「`< もどる`」が枠なしフラットボタン。

### ③ AIっぽい所・UXの分かりにくさ
* 2列×3段分の領域があるのにカードが3枚しかなく、右下半分（約160pt四方）がぽっかり空いていて「作りかけの画面」に見える。
