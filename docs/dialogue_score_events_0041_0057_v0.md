# 選択肢イベント 0041〜0057 会話採点 v0

## 採点の基準（v3 バナーの要点）
1. キャラ会話にお笑いの要素・業界の言葉（ボケ・ツッコミ・オチ・間・呼吸・型 等）を入れない。生活・お金・体調・家族・相方との付き合いの日常会話にする。
2. 俺＝標準語で相槌・心配・決定だけ／谷口＝関西弁のタメ口／第三者＝標準語で用件を短く。1吹き出し2文・40字以内、地の文は場所と時刻だけ30字以内。
3. 選択肢は「押したら何をするか」が日常の言葉で分かること。意味が通らない・不自然な言い回しは△。（対象は ChoiceEventData.swift の地の文・台詞・選択肢文言・選択後の返事。直しは案のみで、コードは未変更）

## △× の行と直し案

### 0044 ハガキの仕分け
- △ 谷口（A・3行目）「変わったハガキあったら、俺にも教えてな」
  - 理由：面白いハガキを探す含みがあり、笑いを求める発言に読める（v3-1）。
  - 直し案：「夜食、俺の分も残しといてな」（生活の話に寄せる。効果は変えない）

### 0056 なくしたノート
- △ 俺（setup 2行目）「組んだ日から書いてるノートだよな」
  - 理由：何のノートか分からず、読み手には意味が通らない（v3「会話の意味がわからない」）。
  - 直し案：「二人の予定と、お金の記録を書いてるノートだよな」（日常のメモ帳と分かる。長さほぼ同じ）

### 0057 年末のライブ
- △ 谷口（setup 4行目）「今年の年越しそば、まだやったな。駅前の店、まだ開いとるで」
  - 理由：「まだ」が重なり、何が「まだ」か不自然（日常会話として不自然）。
  - 直し案：「年越しそば、まだ食べてへんな。駅前の店、まだ開いとるで」
- △ 谷口（A・3行目）「そばは、来年の楽しみにとっとくわ」
  - 理由：年越しそばは年内のものなので「来年の楽しみ」が意味的に合わない。
  - 直し案：「そばは、また今度にするわ」

- 0056 は選択肢Bの俺「もういい。」がやや冷たいが、相方を責める意図ではないので○。
