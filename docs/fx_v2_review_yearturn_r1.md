### 2. まだダサい・AIっぽい所
1. **画像1の定式幕が「ただの3色長方形のベタ塗り（カラーバー）」**
   布のドレープ（縦の陰影グラデーション）も仕様記載の「金房飾り・裾の重み」もなく、テレビのテストパターンに見える。
2. **画像2の3Dめくり途中が「半透明の二重露光（幽霊状態）」**
   不透明な和紙がめくれているのではなく、`opacity` で「1年目」と「2年目」が両方グレーに透けて重なっており、物質感が死んでいる。
3. **主役の「寄席めくり」が横長の卓上カレンダーに見える**
   仕様は「特大の寄席めくり**縦札**」だが、横長カードに細身の洋数字 `2` が置かれており、寄席のめくり台（木枠・金具）の重厚感がない。また `― 新シーズン開幕 ・ (見本) ―` のデバッグ文言が残っている。

### 3. 直す指示 3つ

1. **【めくりの不透明2枚構造化＋縦札プロポーション修正】**
   * めくり中に新旧の紙を半透明（`opacity`）で重ねるのを即廃止。下層に「結成 2年目（完全不透明の白和紙）」を固定し、上層の「結成 1年目」を `rotation3DEffect(..., anchor: .top)` で `-90度` まで跳ね上げて裏面（または影）に消すこと。
   * めくり札の上部に**黒漆のめくり台（太い木桟＋真鍮の留め具2つ）**を描き、文字上にコンビ名（例：`満月ロケット`）を入れ、`（見本）` を削除すること。
2. **【時間差（Stagger）の厳守と3連木札の重複解消】**
   * 画像2（めくり反転中）では下部カードとボタンを隠すこと。順序を **`0.00s` 定式幕閉 → `0.24s` 幕開＆1年目札 → `0.45s` めくり完了 → `0.58s` 朱印『開幕』着地＋画面微揺れ → `0.70s` 下部引き継ぎボード＆ボタンせり上がり** に修正。
   * 引き継ぎ3連木札の右端は最下部バーと被る「所持金」をやめ、仕様どおり**「勝負ネタ（最高ネタ名または継承ネタ数）」**にすること。
3. **【定式幕の布陰影（プリーツ）と火花パーティクルの刷新】**
   * 画像1の定式幕は各ストライプ内に水平方向の明暗グラデーション（布のヒダ陰影）を掛け、中央の合わせ目に金の縁飾り・上部に幕押さえの黒漆幕板を入れること。
   * 画像2のドーナツ状の四角い紙吹雪は廃止し、朱印『開幕』着地と同時に**大小ミックスの金箔・朱火花が初速減衰で弾けるバースト**に差し替えること。
