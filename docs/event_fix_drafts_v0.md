## §1 0019 続けて落ちた週
**①場面**：大会に3回続けて落ちた週の昼、稽古場。谷口が「毎日会うとると息が詰まる」と言う。一人で離れるか、毎日いっしょに続けるかを選ぶ。

**②今**
- 谷口「三回続けてやと、さすがにこたえるな」／俺「顔色悪いぞ。飯、食べてるか」／谷口「まあな。毎日会うとると、ちょっと息が詰まるわ」
- A「しばらく一人で知らない町を歩く」＝発想+2／表現-1／**相性-2**。選んだ後、谷口「しばらく連絡も控えとくわ」（控える期間の効果は無い）
- B「休まず毎日いっしょに稽古する」＝表現+2／相性+1／メンタル-1

**③直した会話**（setup と B は現行のまま。Aの後だけ変更）
- A：
  - 俺「少し離れよう。俺は一人で、知らない町でも歩いてくる」（現行のまま）
  - 谷口「わかった。戻ってきたら、また飯でも行こか」（「連絡も控える」を削除）
- B：現行のまま

**④直した効果**【仮】
- A：発想+2／表現-1／**相性 0**（案：-1でも可）。理由：距離を取るのは普通のこと（リサーチ §5）。重い減点だけ残るのが不自然。
- B：変更なし。
- 注：Aの相性を0にしても、Aは表現が下がるので、Bとの損得は残る。AがBより明らかに得になるなら相性-1に戻す（実測は入れる時に1本）。

**⑤ゲート自己採点**
①○ 「三回続けて」「息が詰まる」「離れよう」で分かる ②○ 谷口の「〜わ」「とる」で分かる ③○ ④○ ⑤○（俺＝心配・決定） ⑥○ ／ v3（業界語なし）○

## §2 0015 同期が辞める日
**①場面**：同期が芸人をやめて地元に帰ると聞いた日、稽古場。同期のために何かできる最後の機会で、手伝いか見送りかを選ぶ。

**②今**
- 谷口「あいつ、来月で辞めて地元に帰るんやて」／俺「そうか。寂しくなるな」／谷口「**商店街の手伝い、誰かに継いでほしいらしい**。見送りもせなな」
- A「商店街の手伝いを引き継ぐ」＝知名度+2／体力-10／メンタル-1。選んだ後「町の人にも顔を覚えてもらえる」
- B「二人で駅まで見送りに行く」＝メンタル+1／相性+1

**③直した会話**
- setup 3つ目：谷口「**最後のライブの手伝い、人が足りへんらしい**。見送りもせなな」
- A（ラベル「同期の最後のライブを手伝う」）：
  - 俺「最後のライブ、俺たちで手伝おう。お客さんにも顔を覚えてもらえる」
  - 谷口「ほな決まりや。しばらく忙しなるな」（現行のまま）
- B：
  - 俺「ライブの手伝いは断ろう。見送りは二人で行こう」
  - 谷口「せやな。最後に、ちゃんと礼言いたいわ」（現行のまま）

**④直した効果**【仮】：数値は**変更なし**（A＝知名度+2／体力-10／メンタル-1、B＝メンタル+1／相性+1）。理由：ライブの手伝いは実在する（リサーチ §3）ので、知名度+が筋の通る形になる。

**⑤ゲート自己採点**
①○ 「辞める」「ライブの手伝い」「見送り」で分かる ②○ ③○ ④○ ⑤○（俺＝寂しさへの相槌・決定） ⑥○ ／ v3：「ライブ」は場所の名前で業界語（間・型など）ではない○

## §4 0016 目が冴えた夜
**①場面**：深夜のファミレス、稽古の帰り。谷口が「目が冴えたから話したい」と言う。朝まで付き合うか、帰って寝るかを選ぶ。

**②今**
- 谷口「なんか今日、目が冴えてしゃあないわ」／俺「もう夜中だぞ。明日、起きられるか」／谷口「もうちょい粘ろか。話したいこと、まだあんねん」
- A「朝まで二人で話し込む」＝発想+2／表現+1／体力-15
- B「今日は帰ってぐっすり寝る」＝体力+5／メンタル+1／**画面に出ない効果：その後2週、ネタ合わせの効き目が1.6倍**（予告も札も無い）

**③直した会話**（場所はファミレスのまま。setup・Aは現行のまま）
- B：
  - 俺「今日は帰ろう。明日に響く」（現行）
  - 谷口「せやな。よう寝たら、次の稽古もはかどるやろ」（現行）
  - ト書き（新規・名前なし）「翌朝。よく寝て、頭がすっきりしている。」

**④直した効果**【仮】
- B：体力+5／メンタル+1／**稽古の効き目 ×1.6 を2週**（数値は変えない）。これを**札に出す**：選択肢の効果札に「2週間、稽古の効きがよくなる」を1枚足し、2週の間は稽古画面の隅にも同じ札を出す。

- 札を出せない場合の代案：ブーストそのものを無くす（Bは体力+5／メンタル+1だけ）。

**⑤ゲート自己採点**
①○ 「目が冴え」「夜中」で分かる ②○ ③○ ④○ ⑤○（俺＝心配・決定） ⑥○ ／ ト書き：場所・時間だけでなく状態（30字以内）で規定内○ ／ v3：「ネタ合わせ」は会話に出さず札の文は「稽古の効き」で業界語を避けた○

## §6 オーナーへの質問（1件1問・推奨が1番目）

   1) 推奨：仲は変わらない（相性0）。離れるのは普通のこと。 2) 少しだけ下がる（相性-1）。 3) 今のまま大きく下がる。

   1) 推奨：変える（数字はそのまま）。 2) 地元の話を聞く場面に変える（発想が上がる）。 3) 今のまま。

   1) 推奨：なくす（ゆっくり休む形）。 2) 友だちに会う側を「ネタを見てもらう」場面に変える。 3) 今のまま。
4. **目が冴えた夜（0016）**：寝るほうを選ぶと「次の2週は稽古がよく効く」と画面ではっきり知らせてよいですか。
