## 結論（3行）
1. 効いているのは率でなく上限：12%でも16%でも上限（15）は3年目あたりで使い切り、発火数は常にちょうど上限（無制限でも平均30〜31）。先着で埋まるので、**後ろの週にしか出ない物（帰省5%・夏祭り5%・年末5%）が割を食う**。率を上げても発火数は30.2→31.5しか動かない。
2. 帯（決勝・優勝・夜逃げ・解散）は全16設定でほぼ同じ（決勝31〜37%・優勝2.4〜3.5%・夜逃げ0%・解散1.5〜4.2%＝n=4000の揺れ内）。上限を上げても崩れない。
3. 推奨＝**上限15・率12%（現状のまま）＋夏祭り・年末のライブを窓内で確定**。3〜6割に入る種が最多（24/34）で帯も不変。ただし帰省5%・はがき16%など数種は3割に届かない（下記）。

## 読み方・推奨の理由
- 発火数は上限がそのまま平均（15→15.0・20→20.0・25→25.0）。率12→16%で動くのは上限なしの時だけ（30.2→31.5）＝自由週は十分多く、**率はほぼ効かない**。
- 上限が小さいほど先着の物が得をする。T18種は発火帯が常に開いており上限15で約57%・上限25で約91%。帰省（38週〜かつ本番3週以上先）は上限15で5%（上限なし74〜91%）。
- 「全種が3〜6割」は確定なしではどの設定でも満たせない：上限15は後ろの種が3割未満（7種）、上限20以上はTが7割台になり6割超が21種以上。
- **15＋確定**は 3〜6割の種が最多（"+str(band(8)[0])+"/34）。3割未満は帰省5・はがき16・fan19・fever22・tv25・先輩27ほか（先着負け）。夏祭り・年末は窓内確定で100%（3〜6割に抑えたいなら確定でなく確率で。参考：固定週17・35にすると大会週に当たり夏祭り68%・年末24%だった）。
- 帯: 15＋確定は 決勝32.8%・優勝2.9%・解散3.7%・夜逃げ0%（基準 15/12 は32.4/2.7/3.8/0）。10年目所持金は集計の中央値が混合ボットで揺れる（1276〜1560万）＝個別ボットでは必要充足が上限なし/率16%で2115→1450万に下がる以外は不変。
- 選択肢: ①15＋確定（推奨）②20＋確定（Tが7割台で見すぎ・3割未満2種・決勝35%/優勝2.8%で帯は崩れない）③先着負けの根本策は上限でなく**重み付け**（未見で発火帯が狭い物ほど引きやすく）。式の変更になるので提案のみ（決めるのはオーナー）。
