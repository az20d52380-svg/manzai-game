# パワプロ サクセス 能力アップ（経験点の振り分け）調査 v0

調査日 2026-10-15 / WebSearch 11回＋WebFetch数本。
**注意：検索で取れた一次情報は薄い。「確認できた」と「確認できず（一般知識・推測）」を分けて書く。確認できなかった点（画面の赤表示、取り消し、おまかせ、1練習の経験点の具体量）はゲーム実機または動画で要確認。**

## §1 経験点の種類・桁・必要量・等級
確認できたこと
- 必要経験点は「筋力＋敏捷（投手は変化球）＋技術＋精神」の4系統の合計で扱われる（アプリ版の査定表の定義、コツ0の場合）。
- 能力値は1〜100、等級は S/A/B/C/D/E/F/G の8段階。選手例から目安は S≒90台後半、A≒80台前半、B≒70台、E≒40台前半（公式の境界値は未確認）。
- 能力ごとに「値の区間ごとの必要経験点」の表があり、例：コントロール 40→41 は25、ミート 60→62 は14。つまり同じ+1でも能力・現在値で必要量が違う（上がるほど増える方向）。
- 練習レベル（機材レベル）が高いほど1回の練習で入る経験点が増える。試合は勝つほど多い。チームメイトのイベント完走で最大約100点。
- センスが高いほど必要経験点が下がる（100で約15%減。イベントでのみ上下）。能力アップ補助アイテム（パワー成長バット等）でも必要量が減る。
確認できず：1回の練習で入る点数の具体値、G〜Sごとの正確な必要量。
出典：https://gamerch.com/pawapro/77047 ／ https://gameranbu.jp/pawapuro2018/75fe6f9b3f0313187c16 ／ https://www.famitsu.com/news/202204/21258779.html
真似方：経験点を4系統にして桁を大きく（練習+10〜30、必要量50〜300程度）。必要量は「現在値が上がるほど増える」段階式にし、センス相当の割引を1つ持つと伸びしろが作れる。

## §2 能力アップ画面の並べ方
確認できたこと：攻略記事は「能力を上げるのはサクセス終盤にまとめて」「序盤は経験点を振らずセンス◯待ち」「最初のうちはコントロール・スタミナをDまで等」と書いており、経験点を貯めて後で一括して使う流れが前提。画面の並べ方そのもの（レイアウト）を書いた文章は取れなかった。
出典：https://game8.jp/pawapuro2018/214366 ／ https://game8.jp/pawapuro2022/460358
真似方（推測）：上に所持経験点を大きく固定、下に能力の行（名前・等級・必要量・＋）。行ごとに「今の等級→次の等級」を見せる。

## §3 押せる／押せない・演出・取り消し
確認できず：赤表示・グレー表示・確定前取り消しを書いた記事は見つからなかった（実機確認が必要）。
真似方（一般的なUI原則）：足りない時は「あと◯点」を文字で出し、＋は薄くせず色と形（鍵や×）で区別。押せる行だけ強調。確定前に「戻す」を1つ置く。

## §4 一括・おまかせ育成
確認できず：作品ごとのおまかせ振り分けの有無は検索で確認できなかった。アプリ版は「査定効率」の高い能力から上げる考え方が攻略側で一般化している（https://xn--odkm0eg.gamewith.jp/article/show/69572 の要旨）。
真似方：「おすすめで振る」ボタン（コンビの弱点から優先）を任意で用意。

## §5 特殊能力との関係
確認できたこと：特殊能力の必要経験点はコツ（ヒント）レベルで下がる。コツLv2でコツなしの約半分、Lv5で約2割（2020作）。金特はコツLv1以上が必要。コツ無しの特殊能力は極力取らないのが定石。2022作ではファイルの条件を達成していく方式。
出典：https://gamerch.com/pawapuro2020/181241 ／ https://gameranbu.jp/pawapro2022/0af623781e3ff2f8b63f
真似方：ネタ（特殊能力相当）の習得コストを、関連イベントで「ヒントLv」が上がるほど割引にし、画面に「ヒントで半額」と明示。

## §6 まとめ：このゲームへの案
1. 桁を大きく：1回の練習で+10〜30、必要量50〜300にする。+1〜+3と必要4〜8では「増えた実感」が出ない。
2. 必要量は現在値で段階的に増加（表を持つ）。センス風の割引を1つ。
3. 画面：上に所持経験点を大きく固定、行は「名前／等級→次の等級／必要量／＋」。足りない時は「あと◯点」を濃い文字で、＋は鍵アイコン等で形も変える（薄いグレー禁止）。
4. 確定前に戻す、おすすめ振りボタンを任意で用意。バーの意味は等級ラベル（G〜S）を併記して説明。
5. 上記のうち3・4は実機/動画確認後に最終化（本調査では未確認）。
