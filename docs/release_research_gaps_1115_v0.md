## §1 前払式支払手段（自家型）
法律の正式名は「資金決済に関する法律」（資金決済法）。自家型＝自社のサービスにだけ使える券。

### 条文（e-Gov 法令検索から取得・要点のみ）
| 論点 | 条文 | 本文のこと |
|---|---|---|
| 該当の定義 | 法3条1項1号・2号 | 金額（または物品・役務の数量）に応じた対価を得て発行され、電磁的方法で記録されたもので、発行者から物品を買ったり役務の提供を受けたりする代価の弁済に使えるもの（2号は数量を記録し、給付・提供を請求できるもの）。端末内の記録も「電子機器その他の物」に記録される場合を含む書き方。 |
| 基準日 | 法3条2項 | 毎年3月31日・9月30日。基準日未使用残高＝その日の未使用残高の合計。 |
| 自家型の届出 | 法5条1項 | 自家型だけを発行する者は、基準日の未使用残高が「発行を開始してから最初に基準額を超えた」時に届出書を提出する。 |
| 基準額 | 法14条1項＋施行令6条 | 法14条は「政令で定める額（基準額）を超えるとき」に発行保証金（残高の2分の1以上）を供託と定める。施行令6条が「千万円」。法5条の届出もこの基準額を使う。 |
| 適用除外（6か月） | 法4条2号＋施行令4条2項 | 法4条2号「発行の日から政令で定める一定の期間内に限り使用できる前払式支払手段」。施行令4条2項「法第四条第二号に規定する政令で定める一定の期間は、六月とする」。 |
| 期限切れの残高 | 前払式支払手段に関する内閣府令4条 | 基準日未使用残高の計算で、有効期限の到来などで代価の弁済に充てられなくなった金額は「回収額」に含める、と読める文言。 |

### 金融庁の事務ガイドライン（第三分冊 5 前払式支払手段発行者関係）で読めた所
- I-1-3(1)「発行の日」＝「①財産的価値が記録された日」「②利用者に券等が交付・付与された日」のいずれか遅い日。6か月の起算日の決め方。
- I-2-1(2) 基準日未使用残高には、財務諸表で収益（退蔵益）に計上された発行残高も含む。※上の内閣府令4条（期限切れは回収額）との関係は、本文を並べただけで私は結論を出していない。協会・財務局への確認事項。
- I-2-1(3) 一部を無償で発行した場合、①有償と無償が表示やデザインで明確に区別でき、かつ②帳簿上も発行額・回収額・未使用残高を区分管理している時に限り、無償分を計上しない扱いにできる。
- I-1-1(1)⑤ 本人確認の手段にすぎない番号等は対象外、とする箇所はあるが、ガチャ券を名指しした記述は見つからなかった（全文を機械で読み、「ガチャ」「ゲーム」の語は無し）。
出典：[事務ガイドライン 05.pdf](https://www.fsa.go.jp/common/law/guide/kaisya/05.pdf)

### ガチャ券・ゲーム内通貨は該当するか（見解）
- 金融庁（2010年・施行令案へのパブリックコメント回答）：「いわゆるゲーム内通貨についても、法第３条第１項の定義に該当すれば、前払式支払手段として法の適用対象となります」。個別事例ごとに実態で判断。対価を得ない「おまけ」は該当しない。ただし「おまけ」と称しても実質的に対価を払っているなら該当し得る。
- 同回答（オンラインゲーム協会の質問への答え）：複数種類のポイントは種類ごとに有効期間を判断。ただし A を使って B を買うことが想定される等、実質一体なら期限を通算し、6か月を超えれば適用除外にならない。使用期限が複数ある場合は最も長い期限が基準。
出典：[金融庁 コメントへの考え方（2010）](https://www.fsa.go.jp/news/21/kinyu/20100301-2/01.pdf)
- 「ガチャ券」を名指しした金融庁・JOGA の見解は、今回の検索では見つからなかった。有償ガチャ券は対価性があり、ガチャ（役務）を請求できるので1号か2号に当たり得る、というのは条文からの読みで、当局の個別判断ではない（解説記事の整理は既存メモ §1 参照）。

## §3 App Store の年齢区分（2025年改定）
- 経緯：2025-07-24 に Apple が 13+・16+・18+ を追加（4+／9+／13+／16+／18+）。全アプリが新しい質問（アプリ内コントロール・機能・医療や健康・暴力表現）に回答する必要があり、期限は 2026-01-31。未回答だと更新の提出が止まる。出典：[Apple Developer News](https://developer.apple.com/news/?id=ks775ehf)
- 区分の表（Apple 公式の定義ページ）：出典：[Age ratings values and definitions](https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions)
  | 区分 | 含まれる内容（抜粋） |
  |---|---|
  | 4+ | ペアレンタルコントロール、年齢確認、ユーザー作成コンテンツ、**広告**、たまの懸賞 |
  | 9+ | たまの下品な表現・恐怖・軽い暴力、**ルートボックス（ガチャ）** など |
  | 13+ | ソーシャルメディア、頻繁な下品な表現、たまの疑似ギャンブル など |
  | 16+ | 制限なしのウェブアクセス など |
  | 18+ | 頻繁な疑似ギャンブル、本物のギャンブル など |
- 広告の答え方：項目「Advertising」＝「アプリ内の商品・サービスの有料プロモーション（バナー・動画・プレイアブル・ネイティブ）」。表では 4+ の段に載っているので、広告があるだけでは区分は上がらない。AdMob の内容レーティング上限設定などは既存メモ §4。
- ガチャの答え方：項目「Loot Boxes」＝「購入できるランダムな仮想アイテムの容器」。表では 9+（世界共通）。オーストラリアは 16+、ブラジルは A18（同ページ）。購入できるものがランダムなら該当と読め、本作のガチャは確認が要る（有償券でガチャを回す＝購入した券でランダムを得る）。
- 疑似ギャンブル（実際のお金や換金可能な通貨を使わない賭け）は 13+ 以上。本作のガチャが「ルートボックス」か「疑似ギャンブル」のどちらで答えるべきかは、質問票の文言を実際の画面で確認する必要あり。
- 関連する審査ルール（App Review Guidelines）：[3.1.1](https://developer.apple.com/app-store/review/guidelines/) ルートボックス等は購入前に各アイテムの当選確率を開示すること。[1.3](https://developer.apple.com/app-store/review/guidelines/) Kids カテゴリは第三者広告・第三者分析を入れない（Kids カテゴリに載せなければ適用されない）。
- 影響のまとめ：広告あり＋ガチャありだと、質問票の結果は最低 9+ になる読み（ガチャが 9+ のため）。これを下げる方法は表からは見つからない（4+ にしたい場合はガチャ要素を外す案しか見えない）。決めるのはオーナー。
