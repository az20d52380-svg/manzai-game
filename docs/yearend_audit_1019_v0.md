## 所見（高0／中0／低3）
- 低-1 幕間の「結成 一年目」：大きな「一」が横棒だけで「年目」と離れ、数字が読みにくい（1・7 の字形差が大きい）。YearTurn の年数字ビュー（Sources 内 YearTurn 系、beginYearTurn 先）。直し案：漢数字をやめるか下の「年目」と詰める。
- 低-2 3年目 不出場の理由文「エントリー費が払えず、頂グランプリに出られなかった」が「頂グラン/プリに」で語の途中改行（YearResultView の見出しテキスト）。直し案：行頭を揃える改行ヒント（「頂グランプリ」を nowrap／改行位置を指定）。画像 docs/yearend_audit_1019_fail.png
- 低-3 DEBUG フックの食い違い：解散（careerOver）後でも MZ_YEARTURN は幕間「7年目を始める」を出す（本編は onNextYear が nil＝出ない、RootView.swift:125 vs 366）。本番影響なし。画像 docs/yearend_audit_1019_yearturn.png
- 備考：右上の「優勝／無双」は DEBUG チップ（RootView.swift:403-407）で本番では出ない。
