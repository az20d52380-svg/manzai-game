# 途中解散（すれ違いゲージ）正典案 v1 — 2026-10-15 夜

オーナー決定（10/15 夜）：途中解散を入れる。解散は二人の関係で決め、成績は引き金にしない（売れても売れなくても続くコンビがいる）。下敷き：docs/multi_ending_v0.md §2（案S2＝成績の加算0）。

## 設計の要点（親判断）
- **相性（compat）の式は変えない**（相性は本番の点に直結＝帯が動くため）。代わりに別の値「すれ違い（rift・0〜100・初期0）」を持つ。
- **乱数を使わない**（golden と乱数の消費順を壊さない）。年末の確率イベント（案Sの +6）は入れない。
- 成績・知名度・お金は rift に一切効かない（S2）。

## 週末の更新（生活費の後・夜逃げ判定の前）
- その週に相性が上がった（相方と過ごす／ネタ合わせ 等で compat が増えた）→ `rift = max(0, rift − RIFT_HEAL)`。
- 上がらなかった → `rift = min(100, rift + RIFT_GAIN × (COMPAT_CAP − compat) / COMPAT_CAP)`。
  - 相性が上限（20）なら増えない＝仲の良い二人は解散しない。
- 値【仮】：RIFT_GAIN = 0.5（実測 dissolution_rift_measure_v0 で 1.5 は強すぎ→0.5）、RIFT_HEAL = 3、COMPAT_CAP = 20。

## 予告と解散
- rift が初めて 50 以上になった週末：**予告**（アプリ側の選択肢イベント「すれ違い」・1キャリア1回）。選択肢の効果はアプリ側（イベント層＝golden 対象外）：向き合う＝rift −30・体力 −10／流す＝何もなし。
- rift が 100 に達した週末で、予告を見た後かつ2年目以降：**解散**でキャリア終了（夜逃げと同じ扱いで区切り・エンディング #2）。1年目は 100 でも解散しない（99 で止める）。

## 同期（規律A）
- Python：tools/sim_career.py の週末（生活費の直後）に rift 更新と解散判定。gen_golden は「解散が起きない」ことを assert（夜逃げと同じ）。golden の行に rift は入れない。
- Swift：GameState.rift（Codable・旧セーブは 0）・WeekRunner の週末・GameCareer の outcome に dissolved。
- 予告イベントの発火（rift≥50 の初回）はアプリ側（WeekRunner の状態を見て ChoiceEvent を出す）。Python の実測では「予告に反応する」ボットと「無視する」ボットの両方を測る。

## 実測で見ること（n=1000・NETA込み併記）
- 通常ボット3種の解散率（相性20に届くので0%近いはず）・相方を放っておくボットの解散率と時期・予告に反応するボットとの差。
