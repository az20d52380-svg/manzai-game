## 第1部 取り入れたい仕組み5つ

### 案1　食えない芸人の制約を、毎週の選択の重みにする（出典：THE 芸人）
- ②既にある：**ほぼ満たしている**。稽古／バイト／休みの三択、お金が溜まらないと有料の場所・休みが使えない、借金中は稽古が半減、夜逃げラインあり（`stuck_and_exploit_check_v0` §4）。実測では通常の遊び方で詰みは0%。
- ③足すなら：穴Aの2案が先行作の「突然終わる」に近い問題への手当て。**A2（所持金が−30万を切ったら谷口が「バイトに出よう」と勧める。強制はしない）**は台詞と表示だけ。A1（1回だけ肩代わり）は夜逃げの扱いが変わる。
- ④手間：A2 小／A1 中。
- ⑤バランス：A2 触らない／A1 触る（夜逃げ→続行になるので到達率が動く＝規律A）。
- ⑥質問：稽古ばかりしてお金が尽きた人に、終わる前に相方から一言注意を入れますか？（A2）それとも1回だけ救いますか？（A1）

### 案2　ぴったりの選択が決まった時の気持ちよさ＋だんだん難しくなる（出典：メガミの笑壺）
- ②既にある：難度の尻上がりは**ある**（GP 18→26→34→45→準決74→決勝80、王者ライン）。「選んで当たった」感は、大会の入口でのネタ選び・段階リビール・ファンレポ（ハマった夜）が担当。ただし**審査員ごとの好み（◎／×）は設計だけで、決勝の審査員札に出るのは任意の味付け扱い**（§4-4 Phase 0）。
- ③足すなら（表示だけ）：決勝で出す前に、選んだ型が各審査員に刺さる／刺さらないを札の端に1語（◎／△）。当たった時は講評の一言で「そこを見てくれた」と返す。点数の計算には乗せない。
- ④手間：中（`FinalsPresentationView` の札＋講評の型フック。講評は judge-comments Skill を通す）。
- ⑤バランス：触らない（表示のみ）。**相性を点数に乗せるのは別件（judge_design §0・オーナー未決・規律A）**。
- ⑥質問：決勝で、どの審査員にどんなネタが刺さるかを前もって匂わせる表示を入れますか？（点数は変えません）

### 案3　場所・客層によって効くネタが違う（出典：Frowntown、Comedy Night）
- ②既にある：**会場による差は無い**。型の相性は「審査員7名」にだけあり、ライブ（ネタ見せ会・フリーライブ）は「磨く」役で客層の概念が無い。会場の段階は勇退エンディングの表示にだけ使っている。
- ③足すなら：ライブ／大会の予選の会場に「客層ひとこと」（例：年配が多い小さな劇場／若い客の多いライブハウス）を付け、型ごとの反応の良し悪しを**反応の文だけ**で返す。案2の審査員の型相性の表をそのまま客層に当てはめれば新しい表は要らない。
- ④手間：中〜大（会場の型データ＋文面。数値に効かせるなら大）。
- ⑤バランス：表示のみなら触らない。反応を完成度の伸びに効かせるなら触る（規律A）。
- ⑥質問：ライブに行くたび客層が違い、ネタの型によって反応が変わる遊びを足したいですか？

### 案4　稽古の合間に入る意外な出来事で単調さを割る（出典：お笑いサッカー、人生ゲーム）
- ②既にある：選択イベント31件（確定発火＋週次抽選12%・年15件まで）。ただし**日常会話のみ**（オーナー決定）なのでバカバカしさでは割らない。背景が舞台固定の問題あり（判断待ち）。
- ③足すなら：笑いではなく**日常の出来事**で割る。例：雨で稽古場が使えない／近所の人から差し入れ／機材が壊れる／道で先輩に会う。ト書き1行＋一言＋効果チップ（体力・お金・相性）。選択肢は日常の言葉で。背景を場所ごとに差し替える判断待ち案と同時にやると効果が大きい。
- ④手間：小〜中（1本は短い。本数を増やす量産作業）。
- ⑤バランス：効果が体力・お金・相性・能力に触れるので、**既存イベントの効果量に揃えれば触らない**。新しい種類の効果を作るなら触る。
- ⑥質問：普通の暮らしの小さな出来事（雨・差し入れ・先輩と会う等）を増やしてよいですか？

### 案5　知名度が上がると出番の格が変わる段階（出典：キミは漫才師、THE 芸人）
- ②既にある：**数値の段階はある**（オファー率が知名度の帯で変わる・大会段階・シード）。ただし知名度が3年目に上限へ張り付くため、4〜10年目は差が出ない（`saturation_check_v0`・キュー62で対応中）。
- ③足すなら：数値でなく**見える格の変化**。出番の呼び名（前座→中堅→トリ前）、ライブの客の入り（8人→満席）、楽屋の扱い、控室の張り紙を、知名度の帯で文と絵だけ変える。キュー62の結論（知名度の頭打ち）が決まってから段数を合わせる。
- ④手間：中（段階の文面＋画面の小物。知名度の帯が決まった後）。
- ⑤バランス：触らない（表示のみ）。
- ⑥質問：知名度が上がったことが、数字ではなく「出番の場所・客の数」の描写で分かるようにしますか？
