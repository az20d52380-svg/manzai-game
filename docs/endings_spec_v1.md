## §0 要点3行

## §1 判定の仕様

### 1-1 判定の順番（上から最初に当たったもの）
| 順 | # | 名前 | 区分 | 条件（数字） | 起きる時 |
|---|---|---|---|---|---|
| 1 | #1 | 夜逃げ | バッド | `outcome.bankrupt == true`（所持金が夜逃げライン −100万 を下回った週） | 途中（何年目でも） |
| 2 | #2 | 解散 | バッド（ビター寄り） | `outcome.dissolved == true`（rift が100・予告済み・2年目以降。GameEngine.applyRiftWeekEnd が決める） | 途中（2年目以降） |
| 3 | #8 | 優勝×相方 | トゥルー上位 | `outcome.champion && state.compat >= 15` | 優勝した年の年末 |
| 4 | #7 | 優勝で勇退 | グッド | `outcome.champion && state.compat < 15` | 優勝した年の年末 |
| 5 | #6 | 十年、同じ舞台に立つ | トゥルー | 10年目の年末・`finalsCount >= 1 && compat >= 15` | 10年目の年末 |
| 6 | #5 | 十年で区切り | ノーマル | 10年目の年末・`finalsCount >= 1 && compat < 15` | 10年目の年末 |
| 7 | #4 | 売れなくても続けた二人 | ビター（温かい） | 10年目の年末・`finalsCount == 0 && compat >= 15` | 10年目の年末 |
| 8 | #3 | あきらめ | ビター | 10年目の年末・`finalsCount == 0 && compat < 15` | 10年目の年末 |

- `finalsCount` ＝ `yearHistory.filter { $0.reachedFinal }.count`（その年の分を含めて数える）。
- `compat` は判定する年末（解散・夜逃げはその週末）の `state.compat`。上限20・下がらない。
- 漏れ・重なりなし：夜逃げ／解散は年の途中で終わるので優勝と重ならない。優勝したら年末で終わるので、10年目の分類に来る人は優勝していない。
- 相性15の線は v0 §4④（トゥルーと続けた二人で共通・再測）。今の実測では通常ボットは10年末に相性20に届く＝#3・#5 は相方を放っておいた人の終わりになる（v0 §0-3）。

### 1-2 疑似コード（アプリ側・GameCore の式は変えない）
```
func endingID(o: YearOutcome, s: GameState, history: [YearRecord], year: Int, config) -> EndingID? {
    if o.bankrupt  { return .nightEscape }        // #1
    if o.dissolved { return .breakup }            // #2
    if o.champion  { return s.compat >= 15 ? .championPair : .championRetire }   // #8 / #7
    guard year >= config.careerYears else { return nil }   // まだ続く
    let finals = history.filter { $0.reachedFinal }.count
    switch (finals >= 1, s.compat >= 15) {
    case (true,  true):  return .tenYearsTrue      // #6
    case (true,  false): return .tenYearsClose     // #5
    case (false, true):  return .keptGoing         // #4
    case (false, false): return .gaveUp            // #3
    }
}
```
乱数は使わない（golden 安全）。セリフの差し替え（§3 #2 の一行）も記録から決まる。

## §2 判定に使う数字の点検（今あるか）

| 要る数字 | 今ある所 | 状態 |
|---|---|---|
| 夜逃げ | `YearOutcome.bankrupt`・`GameState.bankrupt` | ある |
| 解散 | `YearOutcome.dissolved`（WeekRunner.swift:380）・`GameState.dissolved` | ある（GameCore） |
| 予告の合図 | `GameState.riftWarned`（rift≥50 の初回で true） | ある |
| 優勝 | `YearOutcome.champion` | ある |
| 決勝進出回数 | `GameSession.yearHistory[].reachedFinal`（セーブに入る） | 数えれば出る |
| 相性 | `GameState.compat` | ある |
| 知名度・所持金・年 | `GameState.fame`・`.money`・`GameSession.year` | ある（判定には使わない） |

### アプリ側で数えて保存する項目（足りないもの・GameCore の式は変えない）
1. **careerOver に解散を足す**：GameSession.swift の `careerOver` は `o.champion || o.bankrupt || year >= careerYears` で、`o.dissolved` を見ていない。このままだと解散しても「◯年目へ」が出る。→ `|| o.dissolved` を足す（表示側の区切り）。
2. **YearRecord に解散の印**：`var dissolved: Bool? = nil`（旧セーブは nil＝解散なし）。年表に「解散」の行を出すため。
3. **予告で選んだもの**：`GameSession` に `riftWarnChoice: String?`（"A"＝向き合った／"B"＝流した／nil＝予告なし）をセーブに保存。#2 の一行の差し替えと図鑑の記録に使う。
4. **図鑑（周回をまたぐ）**：キャリアのセーブは区切りで消えるので、別の保存先（UserDefaults のキー `mz.endingsSeen`）に `[EndingID: {count, firstSeenAt, lastPartnerName}]` を持つ（§6）。

あわせて直す所（表示の食い違い）：
- YearResultView の `onEnding` は今「優勝の時だけ」。→ `endingID != nil` なら全エンドで「エンディングへ ▶」にする。
- YearResultView の年次独白 `yearEnd.dissolution`（キャリア最後の年・決勝なし・相性10未満で「解散することにした」）は #3 あきらめと話が食い違う。→ 発火条件を `o.dissolved` に付け替え、#2 の前置きとして使う（文面は §3 #2 の場面2と合う＝明日、事務所に行く）。

## §4 途中解散の予告イベント（rift≥50 の初回・1キャリア1回）

- 採番【仮】：0041（proposals の次の空き）。キー `event:0041.setup / .A / .B`。
- 発火：週末処理で `riftWarned` が false→true に変わった週の次の週頭（決定的フラグ・抽選なし）。
- 効果（アプリ側のイベント層・golden 対象外）：A 向き合う＝rift −30・体力 −10／B 流す＝何もなし。
- 幾何（E1・E7）：A は体力を払って二人の仲を戻す。B は何も払わないが、仲はそのまま。B のあとも、相方と過ごす週を入れれば戻せる（回収の余地＝谷口が次の約束を口にする事実1つで置く）。
- 選んだものは `riftWarnChoice` に保存（§2-3）。

## §5 採点の記録（manzai-drama-voice v3 の6問＋A表・B表・V表・E表）

### 前口上（自分の言葉で）
- キャラ会話は日常の会話で書く。笑わせにいかない。芸のやり方・業界の言葉は出さない。
- 俺は相槌・心配・決めることだけ言う。谷口は関西弁で前向き、本音は短く。第三者は用件だけ。
- 気持ちは言葉で名指ししないで、その場の物（鍵・段ボール・出番表・トロフィー）に持たせる。数字やシステム名は口にしない。
- （イベント）選択肢は正解のない取り合い。効果は方向だけ。乱数は使わない。

### 直した5か所
| # | 元 | 引っかかった項目 | 直し |
|---|---|---|---|
| 1 | #1 谷口「借りてた分は、俺がバイトで少しずつ返しとくわ」 | B6（誰の借りか状態から言えない・意味が曖昧） | 「借金、少しなら俺も払えるで」／俺「いい。それはお前の分じゃない」 |
| 2 | #2 場面1の一言目 谷口「話あるって言うたの、俺のほうやな」 | 6問①（ト書きを消すと何の場面か分からない） | 「今日は俺から話あるねん。座って聞いてくれるか」 |
| 3 | #6 俺「来年もいる」 | A7（うまいことを言って締める＝キザ）・6問⑤ | 「そうだな。出番、そろそろだ」（相槌＋段取り） |
