# 判断 #1 推奨C の手当て候補：追いつきの配り（2026-10-26 夕・定期の回・研究用）

目的：判断のまとめ #1（序盤の詰まる週）の推奨C「のんびり型だけ手当てして R2M@0.8 を入れる」の“手当て”の中身の候補（キュー130）。
案：**追いつきの配り**＝手持ちの経験点（5種の合計・内部値）が T 未満の時だけ、稽古でもらう量を今の量（R2M@1.0 相当）に戻す。余って詰まっている人は 0.8 倍のまま。
測り方：`tools/exp_q93_c_v0.py`（q93_r2m_current_v0 と同じ組A・hand・全部入り・ネタ込み）。n=1000。golden・既定値は不変。

## 読み方（決めない）
- 追いつきの配りは、のんびり型の決勝を一部戻す（APP=1 で 8.3→11.6、APP=0 で 7.3→8.3）が、**ローテも上がる**（APP=1 で +6〜11pt）。「余っている人だけ減らす」はずが、ローテも稽古の直後は手持ちが少ない週が多く、戻した量で伸びる。
- T を上げるほど詰まりが戻る（T=5 で のんびり 40%）＝詰まりを減らす目的と逆行する。
- つまり追いつきの配りは「のんびり型だけ」の手当てにはならない。C の候補は別の口が要る：例 ①休む・バイトの週に小さな経験点（のんびり型は休み・バイトが多い）②無料の稽古（ネタ作り・ネタ合わせ・フリーライブ）だけ量を戻す。次に測る（キュー130 の残り）。

- **R（休む・バイトの週に一番少ない経験点を少し）が C の手当てに一番近い**。R0.05〜0.1 で のんびり型の決勝が今の水準（12〜15%）に戻り、ローテは +3〜7pt、詰まる週は全ボットで大きく減る（調整型も 83→32〜34%）。
- 効きが非常に鋭い（R1 で のんびり決勝 54%）。理由：詰まりの多くは「1種だけ足りない」ことで起き、その1種を少し足すと溜まっていた他の4種が一気に使える。量は 0.05〜0.1 の幅で決める物で、0.25 以上は帯が上がる。
- F（無料の稽古だけ戻す）は効きが小さく詰まりも戻る＝不向き。
- 画面の注意：生の 0.05〜0.1 は、割引と表示の×10 を通すと 0.2〜0.4 点で、今の表示（切り捨て）では「+0」に見える。入れるなら「休むと少し閃く」等の言葉で見せるか、数週分を貯めてから出す見せ方が要る（決めるのはオーナー）。
- 規律A の注意：休む・バイトに経験点を足すのは式の変更（GameEngine の do_rest/do_job 相当・golden が変わる）。研究用の上書きだけで測った。

### R だけ（R2M を入れない）では詰まりは減らない（n=1000）
| 案 | のんびり APP=0 / 1 | ローテ APP=0 / 1 | 調整型の詰まる週 APP=0/1 |
|---|---|---|---|
| 今＋R0.05 | 13.4 / 81 ・ 15.6 / 78 | 33.6 / 60 ・ 58.5 / 70 | 86 / 70 |
| 今＋R0.1 | 14.9 / 77 ・ 18.0 / 76 | 36.9 / 56 ・ 61.9 / 70 | 86 / 67 |
- 詰まる週は今とほぼ同じ（76〜86%）で、帯だけ +1〜6pt 上がる。**詰まりを減らすのは R2M（配る比率の直し）で、R はその副作用（のんびり型の落ち込み）を埋める役**＝推奨C の「A＋手当て」の形がそのまま成り立つ。

### 本番ボット組（組B・exp_q93_retune_v0 の B と同じ・n=1000・スクリプトは scratchpad の groupb.py＝exp_q93_c_v0 の案を組Bで回すだけ）

|---|---|---|---|---|
| 今 | 4.7 / 0.0 | 18.8 / 0.4 | 55.9 / 3.5 | 55.0 / 4.8（6.0） |
| R2M@0.8 | 1.8 / 0.0 | 19.0 / 0.4 | 65.6 / 2.6 | 67.8 / 5.6（0.0） |

- 本番ボットでは のんびり改の戻りは小さい（1.8→2.1〜2.8・今は4.7）。組A（hand）ほど休む週に“一番少ない経験点”が効かない＝本番ボットの手配りは足りない1種を先に埋めないため。やり込みの決勝は R2M で +13pt（解散 6→0）で、R はさらに +3〜5pt。
- まとめ：R は「人の手配り（hand）」では のんびり型を今の水準に戻すが、本番ボットでは半分も戻らない。C の中身として出す時は、この2つの組の差を並べる（決めるのはオーナー）。
