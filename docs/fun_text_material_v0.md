## §A バイトの週の一言（18本）
※週のバイト結果の画面に1本ランダムで出す想定。

### A-1 キツい（引っ越し・マルタ運輸）
1. 班長の田渕「今日は階段のない現場や。先に水を飲んどけ」
2. 先輩の三好「五階でエレベーター無しや。箱は軽い物から行こか」
3. 田渕「ええ腰してるな。もう一件、頼めるか」／俺「はい。いけます」
4. 三好「冷蔵庫は二人で持つもんや。無理に一人でいくな」
5. 依頼のお客さん「麦茶、冷やしてあるので飲んでください」／俺「ありがとうございます。いただきます」
6. 田渕「今週もお疲れさん。帰りに弁当持っていき」

### A-2 標準（居酒屋「とり伍」）
1. 店長の大川「仕込みは焼き鳥の串打ちからや。端をそろえてな」
2. 先輩の美咲「ビールの注ぎ方、昨日より上手くなってるよ」
3. 常連の石井さん「今日も出前の電話、頼むわ」／俺「かしこまりました。すぐ聞きます」
4. 大川「忙しい日は、洗い場から先に埋めてな」
5. 美咲「まかないは親子丼やって。早めに食べとこ」
6. 石井さん「若いのに、よう働くな。おっちゃんは嬉しいで」

### A-3 楽（交通量調査）
1. 担当の小野寺「今日は数えるだけです。休憩は一時間おきです」
2. 同じ持ち場のユウタ「バスは別に数えます。自分が右側やります」
3. 小野寺「天気がいいので、人通りも多めですね」／俺「数えやすい日ですね」
4. ユウタ「このカウンター、押しすぎて指が痛いです」／俺「持ち替えながらやろう」
5. 通りがかりの人「お疲れさま。暑いから気をつけてね」

案（別欄・報酬は付けない前提）：各バイトで同じ人物が2回目以降に「先週の続き」を一言触れる（例：A-2 の石井さんの電話が次週に再登場）。

## §B 休みの週の一言（5種×5本＝25本）
※谷口の一言が基本。完全休養は谷口の連絡のみ。

1. 谷口「寝る前に連絡しとくわ。今日は何もせんでええで」
2. 谷口「起きたら、おにぎり買うてあるから食べや」
3. 谷口「今日は電話せえへんから、ゆっくりしてな」
4. 谷口「布団干しといたわ。ええ匂いになってるはずや」

## §C 月1の小さな節目（12本）
※1本＝場面2〜3行＋谷口の反応1行。報酬なし。場所・人物は架空（劇場「ひばり座」、番組の会場など）。

1. 【4月】ひばり座の受付。新年度の出番表が貼り出される。名前の位置が、去年より一段上にある。／谷口「去年とちゃうな。ちょっとだけ、前に出てるで」
2. 【5月】劇場の廊下。先輩コンビの「ひよこ堂」が、ネタの前に緊張して静かに座っている。／谷口「あの人らでも緊張するんやな。ちょっと安心したわ」
3. 【6月】ひばり座の客席。前の方に、いつも来ている常連のおばあさんが座っている。／谷口「今日もおるな。前に会うたら、挨拶しよか」
4. 【7月】劇場の楽屋。梅雨で傘が並んでいて、足元が狭い。／谷口「俺の傘、また誰かが持っていったかもしれへん」
5. 【8月】夏の特別興行の前日。劇場の掃除をスタッフと一緒にする。／谷口「舞台の床を拭くの、意外と好きやねん」
6. 【9月】ひばり座の査定の日。支配人の岸本さんが、客席の後ろから見ている。／谷口「今日は見られてるな。いつも通りやで」
7. 【10月】先輩コンビ「ひよこ堂」の舞台を、袖から見せてもらう。客席の静けさが違う。／谷口「あんな静かな客席、初めて見たわ。ええ勉強になった」
8. 【11月】終演後のロビー。若い客が「また観に来ます」と声をかけてくれる。／谷口「声かけてもろたの、久しぶりやな。嬉しいわ」
9. 【12月】忘年会の準備で、劇場全体が少し浮かれている。ポスターの隅に自分たちの名前がある。／谷口「ポスターの端やけど、名前あるやん」
10. 【1月】新年の初舞台。楽屋に鏡餅が置いてある。／谷口「今年もよろしゅうな。まず体を壊さんことやで」
11. 【2月】雪の日の劇場。客席は少ないが、来てくれた人の顔がよく見える。／谷口「少ないけど、ちゃんと聞いてくれてたな」
12. 【3月】年度の最後の週。支配人の岸本さんが「一年、よく通ったね」と声をかける。／谷口「一年、通い続けただけでも、ええことやと思うで」

案（別欄）：節目の翌週に、同じ人物（岸本さん・常連のおばあさん）が一言だけ再登場すると「次の山場まで」の道しるべになる。報酬を付けるなら「その月の名前だけ記録に残る」程度（数値なし）。

## §D 体力が低い時（12本）
### D-1 谷口が止める（6本）
1. 谷口「顔色が悪いで。今日は帰って寝よ」
2. 谷口「無理に続けても、ええことないわ。今週は休もう」
3. 谷口「声がかすれてる。のど飴あるから、持っていき」
4. 谷口「階段、息が切れてたやろ。休むのも仕事のうちやで」
5. 谷口「俺が頼んでもええ。今日はもう帰れ」／俺「分かった。今日は休む」
6. 谷口「焦る気持ちは分かる。でも、倒れたら元も子もないで」

### D-2 無理した時の舞台袖の一言（6本）
1. 舞台袖で、谷口「足、震えてへんか。無理しなや」
2. 袖の暗がり。谷口「水、持っとけ。終わったらすぐ座るで」
3. 谷口「声が少し細いで。ゆっくりでええからな」
4. 出番直前。谷口「呼吸、整えよ。三回だけ吸うて吐いて」／俺「ああ。落ち着いてやる」
5. 袖に戻った直後。谷口「今日は、ようもったな。もう座れ」
6. 舞台袖。谷口「最後まで立ってたな。あとは俺に任せて、休んでくれ」

案（別欄）：無理した週は、次の稽古の画面に谷口の一言「昨日は大丈夫やったか」を1行出す。数値の変更はしない。

## §E 年末の成長レポート（10本）
※見出し＋祝いの文の型。〔 〕は差し込み。

1. 見出し「一番伸びた能力」／〔表現〕が〔+8〕伸びました。今年の一番の変化です
2. 見出し「ランクが上がりました」／〔発想〕が〔C〕から〔B〕に上がりました
3. 見出し「通い続けた一年」／稽古に〔38〕週取り組みました。出番は〔6〕回でした
4. 見出し「名場面」／〔10月〕の先輩の舞台を袖から見た一日。あの空気は、次の舞台に残ります
5. 見出し「予選を越えました」／〔準決勝〕に進みました。去年の今頃より、一歩前です
6. 見出し「相方との一年」／谷口と過ごした週は〔12〕週。息が合ってきました
7. 見出し「体を守った年」／休みを〔9〕回、きちんと取れました。長く続けるための力です
8. 見出し「来年の課題」／一番伸びが小さかったのは〔間〕。来年は意識してみましょう
9. 見出し「稼いだ一年」／バイトと舞台で〔○○〕円を手にしました。生活の土台ができました
10. 見出し「次の一年へ」／今年の記録を残して、来年を迎えます。谷口「ほな、また来年もよろしく」

案（別欄）：優勝しなかった年でも、見出し3・5・7のように「手前の達成」を必ず1つ出す。数値の％は出さない（オーナー判断）。
