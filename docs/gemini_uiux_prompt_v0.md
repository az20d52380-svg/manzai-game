## プロンプト本文（ここから下をそのまま貼る）

あなたは、売れているスマホの育成ゲーム（実況パワフルプロ野球のサクセス、ウマ娘、アイドルマスター系）の UI/UX を手がけてきたゲーム UI デザイナーです。日本語で答えてください。

### 作っているゲーム
- iPhone 向けの「漫才コンビ育成シミュレーション」。売れない若手漫才コンビを最大10年育てて、年末の漫才の大きな大会（架空）で優勝を目指す。
- 1年＝48週。毎週「ネタを書く／練習／バイト／休む／能力アップ／お店」から1つ選ぶ。大会の週は大会に出る。
- 能力は5つ（センス・発想・表現・華・メンタル）。練習すると「経験点」が5種類（閃き・語彙・間合い・存在感・胆力）たまり、能力アップ画面でそれを使って能力を上げる（パワプロのサクセスと同じ仕組み）。
- ネタ帳（持ちネタの一覧・磨く・大会で使うネタを選ぶ）、大会結果（笑いの波形→合否の判子→審査員の講評）、決勝（劇場の舞台・審査員7人の採点）がある。
- 実装は SwiftUI（iOS 17〜）。画像素材はほぼ無く、図形と文字で描いている。キャラは丸い頭の簡単な絵。

### 困っていること
- 作者から「UI/UX が AI っぽすぎる」と言われている。白い角丸カードと色付きアイコンが均一に並び、どの画面も同じ箱の羅列で、ゲームらしい手応え（押した気持ちよさ・数字が跳ねる・結果を見る高揚感）が無い。
- 試作で、色を「墨・生成り・朱＋劇場の幕の臙脂と金」に絞り、見出しを寄席の看板文字風の太字にした（添付の all_*.png）。方向は作者に気に入られたが、まだ「作った感」が残る。
- 能力アップ画面は、パワプロのサクセスの能力アップ画面（添付の参考画像：上に能力ごとのランクと次のランクまでのゲージ、中央に「現在の経験点」を種類ごとに並べた行、その下に能力ごとの行で、各行に大きな＋ボタンと「その能力を1上げるのに要る各経験点の量」が経験点の列にそろって並ぶ、下に 戻る／リセット／おまかせ／確定 の大きなボタン）のようにしたい。

### お願い（この順で、具体的に）
1. **AI っぽさの原因**を、添付の今の画面から10個、具体的に指摘してください（どの要素の何が、なぜ AI っぽく見えるか）。
2. **このゲームの見た目の決まり（デザインシステム）**を作ってください：
   - 色：役割ごと（地・面・文字・強調・押せる・押せない・成功・失敗）に16進のカラーコード。墨・生成り・朱・臙脂・金を基本に。
   - 文字：見出し・数字・本文・小さい注記の大きさ（pt）と太さ。iOS の標準フォントで出せる範囲で、寄席文字・看板らしさを出す工夫（縁取り・影・字間）。
   - 形：角の丸み・線の太さ・影。「何でも角丸カード」をやめるための使い分けの決まり（何を箱にし、何を線と余白で区切るか）。
   - 動き：押した時・数字が増えた時・結果を出す時の演出（時間・大きさ・順番）。
3. **画面ごとの設計図**を、週のメイン画面・能力アップ画面・ネタ帳・大会結果の4つについて：
   - 画面を上から順に、どの部品がどの大きさでどこにあるか（iPhone の縦画面 393×852pt 基準の位置と大きさ）。
   - 能力アップ画面は、上のパワプロの参考の作りを、このゲームの「能力5つ×経験点5種類」に当てはめた表の形で。押せる／押せない（経験点が足りない）の見せ分け、上げた時の演出、おまかせ・リセット・確定の動き。
4. **SwiftUI で作るための指示**：上の決まりをそのまま書ける形（色の定義の一覧、部品の名前と役割、ViewModifier にするとよいもの）。コードを書く場合は短い例だけで十分です。
5. 避けること：絵文字アイコン、紫や青のグラデーション、光る影、全部が同じ大きさの角丸カード、説明文だらけ、％表示（作者の方針で通過見込み等の％は出さない）、実在のゲームの画像や名前をそのまま使うこと。

答えは見出しつきで、上の1〜5の順に。

## 自動でつなぐ方法（Gemini CLI）
Google の公式のコマンドラインツール「Gemini CLI」を入れると、Claude がターミナルから Gemini に質問して、答えを受け取れます（オーナーが毎回コピーしなくてよい）。

1. オーナーが1回だけ、ターミナルで入れる（Node.js 20 以上が必要）：
   ```bash
   npm install -g @google/gemini-cli
   ```
2. オーナーが1回だけ、ログインする（ブラウザが開くので Google アカウントで許可）：
   ```bash
   gemini
   ```
   起動したら案内に従ってログインし、終わったら `/quit` で閉じる。**APIキーなどの秘密はチャットに貼らない**（ログインはターミナルとブラウザだけで済む）。
3. あとは Claude が `gemini -p "（プロンプト）"` の形で呼び出し、画像は `@docs/proposal_shots/all_week.png` のようにプロンプトの中でファイルを指定して渡す。答えは `docs/gemini_uiux_answer_v0.md` に保存し、Claude が読んで実装に移す。
- 注意：コマンドの細かい書き方（画像の渡し方・オプション名）は、入れた後に Claude が `gemini --help` で確かめてから使う。無料枠の回数に上限がある。
