# 周回ボーナス（初期の経験点・所持金）の実測 v0（2026-10-20・【仮】・決定ではなく材料）
`tools/exp_meta_start_bonus_1020_v0.py`（式・GameCore・golden は触らず new_state の差し替えだけ）。ボット4種（のんびり改／ローテ／必要充足／やり込み）×ネタ無／込（NETA_ON=NETA_V2=True）の8セル平均。n=300（有望2組は n=1000）。周回の点は 0/5/10/15/20/30 に固定（「pt＋図鑑×1」「pt＋図鑑×2」の違いは点の貯まり方だけで、点が決まれば効果は同じ＝点式は別に決める）。

## §0 要約
- 初期の経験点・所持金を増やしても**優勝は増えない**（10年内優勝は点0で0.3%、最大でも2〜3%）。効くのは**決勝進出率（11%→35〜50%）と最初の昇格の週（13週→1週）と借金（95%→60〜70%）**。「点10で今の1.5倍・点30で3倍」の目安は優勝率では測れない（土台が0.3%）。決勝進出なら点10で約2.2倍・点30で約3.2〜4.5倍。
- 1年目の優勝は全組・全点で0%（点30でも）。夜逃げも全組0%（今も0）。
- 型2（初期装備）は、一番良い物を選べば型1より決勝・優勝が高い。遊び方に合う物を選ぶと型1と同程度〜やや上。型2は点が貯まるほど選択肢が増え、偏りの装備（ひらめき偏など）が効く。

## §1 前提
- 経験点：5通貨に既存 E0 の割合（35/27/18/10/10%）で配る（型2の偏り装備を除く）。**生の値を足す**（E0 と同じ扱い・sim 内の稽古の供給スケールとは別）。
- 型1：点1あたり 経験 小2／中4／大8／特12（上限 160、特は 360）・所持金 小1万／中3万／大5万（上限 100万）。組は「経験3段×金中」「経験中×金小/大」＋特。
- 型2：装備8個（経験袋 90／財布 +60万／バランス 45+25万+相性3／相性 +6(+20exp)／ひらめき偏・語彙偏・間偏 各60（70%偏り）／度胸偏 60（存在感・探究力に各40%））。点で解放（5点:2個・10:4・15:6・20:7・30:8）、選べる数（5〜10点:1・15〜20点:2・30点:3・同じ装備は重ねない）。経験の合計上限 360。
- 一番良い物＝解放済み装備を単品で別シード60本ずつ試して「10年内優勝＋決勝×0.5−夜逃げ」の上位を、ボット×ネタごとに選ぶ（重ねは足し算で近似）。遊び方に合う物＝ボットごとの固定の優先順（のんびり改:財布→相性→バランス、ローテ:バランス→経験袋→相性、必要充足:経験袋→バランス→財布、やり込み:経験袋→度胸偏→ひらめき偏）。
- 「借金経験」は所持金が一度でもマイナスになった率（今の式では点0で95%＝序盤の借金は日常）。「最初の昇格の週」は能力G→F（15以上）の1年目の週の中央値を8セルで平均。「10年目所持金」は10年目の年末まで残った人の中央値（万円）。

## §4 良い所・悪い所
- 型1（全部加算）：良い＝仕組みが単純で分かりやすい・点が増えるほど滑らかに決勝進出が上がる・どのボットにも同じように効く。悪い＝優勝率はほぼ動かない（経験を足すだけでは壁が越えられない）。点5で既に最初の昇格が1〜2週目になり（今は13週）、1周目との差が序盤に出過ぎる。
- 型2（初期装備）：良い＝選ぶ楽しみがあり、周ごとの違いが出る・「一番良い物」を選べば点30で決勝50%（型1最大の特でも45%）。悪い＝遊び方に合う物を選ぶと効果が小さい（型1同程度）・装備ごとの強さの差でボットが選ぶ答えがほぼ固定される（ひらめき偏＋経験袋が大半）＝選ぶ意味が薄くなる恐れ。点15と20は解放数の違いが小さく同じ結果になる（装備の増え方に谷）。

## §5 所見
1. 点が増えるほど決勝進出と序盤の安定は素直に上がるが、**優勝率の「1.5倍→3倍」は出ない**（0.3%→3%以内）。優勝まで引っ張るには、初期ボーナス（E0 のみ）では足りず、旧 §8(B)「E0 だけは周回の速さをほぼ消す」と同じ結論。J0（成長予算の上乗せ）や王者ライン側など別のつまみが要る。
2. お金は借金経験を95%→60〜70%に減らし、10年目の所持金は1139万→1550〜1700万に増える程度で、**余り過ぎない**。夜逃げは今も0なので、お金ボーナスは「序盤の借金で詰まる」を減らす目的としては小さい・中で十分（大5万/点でも変化は小さい）。
3. 経験は小（2/点）でも点10で最初の昇格が2週目、中以上では1週目＝**「最初の経験点」は少しで足りる**。大・特は決勝進出を上げるが上限（160/360）に早く届き、点20以降は頭打ち。
4. 1年目の優勝は点30でも0%＝目安の「数%以内」は満たす（むしろ全く増えない）。

## §6 推奨の組（材料）
- 型1なら「経験 中(4/点・上限160)＋所持金 中(3万/点・上限100万)」付近：決勝と序盤を十分に押し上げつつ、優勝・1年目は動かさない。
- 型2なら「装備8個・点で解放・選べるのは点15で2つ／点30で3つ」で、装備の強さを偏りと総合で拮抗させる案（今の候補は一番良い物が固定されやすい）。優勝まで動かしたいなら別途 J0 などの成長側のつまみが要る。
