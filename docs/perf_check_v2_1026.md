## 目立って悪くなった所（CPU平均が v1 の1.5倍以上 / メモリ +20MB 以上）
**0件。**
- CPU 平均：どれも v1 以下か同等（最大の増加は決勝 vtr の 10→11.1）。
- メモリ：全画面で +4〜+11MB 程度（最大は glossary・rankup・burst・yearturn の +8〜11）。+20MB には届かない。ベースが一律 +8〜11MB 上がっている印象（機能追加ぶんの目安）。漏れの兆候（20秒内の増加）は無し。
