# 作り直しの仕上げ（Argon r2 の残り）— 2026-10-15

## 親（Opus）の判断
- **出場・本番へのボタンは押せなくしない**：ネタ無しでも出場できる決まり（netaScoreBonus=0）・2本目未選択でも進める。押せなくすると決まりが変わる＝オーナー判断。代わりに「ネタ無しで出る（上乗せなし）」「2本目は選ばずに進む」のように**結果を言葉ではっきり出す**。体力0で夜行バスも同じ（押せるまま・「体力が尽きた状態で出る」を明示）。
- **本番前カードの中央の空白**：「審査傾向」の元データは無い→作らない。置くのは、ゲームが持っている事実だけ（通過ライン・今の実力・今夜のネタの完成度/飽き・前回の結果）。％は出さない。
- 予選結果は審査員の点数を出さない（B-9 オーナー判断待ち）。

- **「突破圏内」等の見込みの札は出さない**（通過見込みを出さない＝オーナー決定・no-win-percentage と同じ考え）。Argon が提案しても入れない（10/15 夜 親判断）。
