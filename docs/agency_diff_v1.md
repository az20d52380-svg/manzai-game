# 事務所4種の違い 設計案 v1（2026-10-20・コードは不変）

> 決定はしない（案と推奨）。数値は全て【仮】。実在の会社名は「材料」としてのみ書き、ゲームには出さない。画面に％は出さない。能力の縦の差（強さ）は付けない。
> 下敷き：`agency_options_v0.md`・`office_choice_v0.md`（実測済みの旧4種）・`iap_design_v0.md`。

## §0 要点
1. 違いは「お金の流れ」「出られる場の数」「手間（交通費・ノルマ）」「話の色」だけ。稽古・相性・審査の式は触らない。
2. 4種＝①大手（1周目の吉竹興行。位置づけは要確認＝Q1）②中堅 ③小さい事務所（自由）④個人事務所（自分たちの会社・有料600円）。
3. 作る時は規律A（収支の式）。n=1000 の実測で「強さに差が出ない」ことを確かめてから（§4）。

## §2 ゲームでの4種（違いの設計）
今のゲームの数字：生活費14万/4週、ネタ見せ会8万、フリーライブ0、お金重視オファー24万・経験重視12万、オファー率（知名度10/30/55未満で5/15/30%、以上50%）、大会の遠征は夜行バス1万・新幹線3万・エントリー費2千（交通費は大会遠征のみ）。

| | 大手（吉竹興行） | 中堅 | 小さい（自由） | 個人事務所（600円） |
|---|---|---|---|---|
| ギャラの取り分（オファー収入に掛ける） | ×0.6 | ×1.0 | ×1.2 | ×1.5（ただし月の会社費用あり↓） |
| 月の給料 | 月+2万（生活費の軽減）。売れたら無し | なし | なし | なし。かわりに会社の維持費（月-1万【仮】） |

差し替え箇所（コードの置き場）
- ギャラの取り分：`GameConfig.offerMoney/offerExp` の `income` に掛ける（事務所補正）。
- 月給・維持費：`livingCost`（140,000）と `livingInterval` に差分を足す。
- ネタ見せ会の費用：`GameConfig.swift:244` の `cost: 80_000`（TrainingSpec）を事務所で上書き。
- 事務所ライブ・自主公演：`フリーライブ`（cost 0・fame+1・存在感）の隣に新しい `TrainingSpec` を足す。週の回数は `Allocation.swift`。
- 交通費：`Calendar.swift:89-90` の `busTravel/trainTravel`、`entryFee`、StageViews の出場ボタン。
- オファー率：`GameConfig.swift:297` の `offerRates` に倍率。
- 事務所ごとの行動・場面：`ChoiceEvent.swift`/`ChoiceEventData` の出し分け（話は能力値を動かさない）。
- 事務所の持ち方：`GameState` に `agency` を足し、`GameSession` で2周目以降に選ぶ。画面は `iap_design_v0.md` に従う。

## §3 個人事務所の注意
- 売り物は「自由」と「話」。無料の事務所より稼げる設計にすると課金で強くなるので避ける＝取り分は高いが、維持費・自主公演の赤字リスクで10年後の所持金が基準帯に収まるように調整する。
- 600円（オーナー決定）。StoreKit・申告・購入復元の更新が必要（`iap_design_v0.md` §）。

## §4 「強さに差が出ない」確かめ方（実測計画）
1. `tools/exp_office_choice_v0.py` を雛形に、4種を実行中だけ差し替える（コードは変えない）。3ボット×n=1000（まず n=300 で当たり）。
2. 見る指標＝優勝率・決勝到達・夜逃げ・解散率・10年後の所持金・総合の合格率。4種とも優勝0〜4.5%・決勝到達が基準±数pt以内・夜逃げ0%を基準にする（旧実測と同じ帯）。
3. 個人事務所だけ「配信/自主公演」を選ぶボットと選ばないボットの両方で測り、どちらでも帯から出ないことを確認。帯外なら取り分・維持費の数字を調整する。

## §5 オーナーに聞くこと（最大3問）
1. 吉竹興行は「大手」と「中堅」のどちらの位置づけにしますか。
   - 推奨：大手（東京に劇場を持つ大きな会社）。
   - 理由：旧設計では1周目の事務所は「大手」として記録されていて、中堅を別に選べる方が違いがはっきりするから。
2. 個人事務所は「ふつうの事務所より稼ぎやすい」にしますか、「稼ぎは同じで、自由と話が違う」にしますか。
   - 推奨：稼ぎは同じ。
   - 理由：有料なのに強くなると、お金を払った人だけ有利に見えてしまうから。
3. 個人事務所のマネージャーは、最初から居ない（二人だけ）にしますか。
   - 推奨：居ない。後でお金を払って雇える行動を足す。
   - 理由：ラランドのようにマネージャー1人の例もあるが、二人だけで始める話の方が分かりやすいから。
