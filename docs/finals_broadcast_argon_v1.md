# 『頂グランプリ決勝』生放送・賞レース番組演出 再設計仕様書

## 0. 現状課題の診断（なぜ今の実機画面は「M-1っぽくない」のか）

実機スクリーンショット（`37_籤`〜`43_優勝`）と調査書（`m1_broadcast_presentation_research_v0.md`）を突き合わせると、「賞レースの生放送特番らしさ」が欠けている原因は以下の5点に集約される。

1. **「番組が始まった感（入口の儀式）」が丸ごと無い**
   * 現状はいきなり `1番目 満月書店 627点` の静止ボードから始まる。M-1を象徴する「煽りVTR → スタジオ暗転からの一斉点灯・タイトルコール → 審査員7人の紹介 → ファイナリスト集結」という**生放送の幕開け（オープニングの緊張と高揚）**がゼロのため、普段の週画面の延長に見えている。
2. **「昼間の寄席の床」が常時むき出しで、特番のスタジオ照明（闇と逆光）がない**
   * 全画面（`37`〜`43`）で、明るい木目の床と定式幕が同じ明るさでベタッと見えている。賞レース決勝の本質は**「漆黒のスタジオ空間を切り裂く金・赤・青のスポットライトと床スモーク」**であり、寄席の和の質感（黒漆・消金・臙脂・木札）を残しつつも、決勝だけは「夜の生放送特番照明」へ色温度と明暗比を落とす必要がある。
3. **「生放送のテレビ画面の記号（LIVEバッジ・番組L字/下三分テロップ帯・カウントダウン時計）」がない**
   * 画面上部に固定された看板（`決勝 頂 グランプリ`）がどの場面でも微動だにせず、テレビ中継特有の「生放送 LIVE」「現在時刻/残り時間」「画面下部の番組テロップ帯（Lower Third）」「ワイプ枠」がないため、書類の集計画面に見える。
4. **「暫定ボックス（3脚の王座）」の空間と、脱落の残酷さがない**
   * `41_ボード` では1〜10位が単なる縦リストで並び、`敗退` のグレー札が付くだけになっている。「3脚だけの赤い革張りの暫定席（座布団・黒漆の座）」に座っていた3位コンビが、高得点が出た瞬間に押し出されて立ち上がり、照明が落ちて去っていく「椅子取りゲームの残酷なドラマ」が視覚化されていない。
5. **優勝の瞬間（`43_優勝`）に「こけし型の丸頭シルエット」が出ており、デザインシステム禁則（§8-4）に抵触している**
   * `43_優勝` の舞台中央に描かれた青・赤の丸頭シルエットは、デザインシステムが禁じる「幾何学図形のこけし人間」そのものになっており、クライマックスの格を下げている。また紙吹雪がまばらな四角片だけで、**「大砲から噴き上がる金テープ（ストリーマー）＋逆光フラッシュ＋大判の優勝めくり＋賞金ボード」**の圧倒的物量が足りない。

## 1. 決勝の番組の流れ（全12場面・完全演出コンテ）

* **画面基準**：`393 × 852pt`、左右マージン `14pt`（有効幅 `365pt`）、ダークモード非対応（ただし決勝は `yoseKuroUrushi #1E1916` と `#0D0A09` の「特番スタジオ暗転ベース」を主背景とする）。
* **スキップ規約**：
  * **画面タップ**：現在の1カット（または1人分の開票・1行のセリフ）を即座に完了して次へ進める。
  * **画面右上「早送り ▶▶」木札ボタン（または長押し）**：現在の場面の末尾（結果確定状態）まで一気に飛ばす。**ただし「場面11：優勝の瞬間」の最初の2.5秒（金テープ発射）だけはスキップ不可**とし、カタルシスを守る。
  * **初回／2回目以降**：プレイヤーが初めて決勝に到達した回は「初回尺（フル演出）」、2回目以降の決勝進出時はオープニング・審査員紹介・NPC出番を自動圧縮した「短縮尺」で再生する。

public struct FinalsStageLightingView: View {
    let mood: FinalsLightingMood
    var spotlightCount: Int = 4

    public init(mood: FinalsLightingMood, spotlightCount: Int = 4) {
        self.mood = mood
        self.spotlightCount = spotlightCount
    }

    private var baseTopColor: Color {
        switch mood {
        case .openingDark:      return Color(hex: 0x090707)
        case .standardGold:     return Color(hex: 0x24100E)
        case .lotterySuspense:  return Color(hex: 0x0E1524)
        case .finalDuelCrimson: return Color(hex: 0x3A0D0C)
        case .championBurst:    return Color(hex: 0x4A2E0B)
        }
    }

    private var beamColor: Color {
        switch mood {
        case .openingDark:      return YoseColor.kin.opacity(0.18)
        case .standardGold:     return YoseColor.kinBright.opacity(0.28)
        case .lotterySuspense:  return YoseColor.kinBright.opacity(0.42)
        case .finalDuelCrimson: return YoseColor.shu.opacity(0.35)
        case .championBurst:    return YoseColor.kinBright.opacity(0.55)
        }
    }

    public var body: some View {
        TimelineView(.animation) { timeline in
            let t = timeline.date.timeIntervalSinceReferenceDate
            Canvas { context, size in
                // 1. スタジオ暗転グラデーション背景
                let bgRect = CGRect(origin: .zero, size: size)
                context.fill(
                    Path(bgRect),
                    with: .linearGradient(
                        Gradient(colors: [baseTopColor, YoseColor.kuroUrushi, Color(hex: 0x0D0A09)]),
                        startPoint: .zero,
                        endPoint: CGPoint(x: 0, y: size.height)
                    )
                )

                // 2. 定式幕の縦ストライプ（暗がりにうっすら浮かぶ和の縦縞）
                let stripeCount = 13
                let stripeW = size.width / CGFloat(stripeCount)
                for i in 0..<stripeCount where i % 2 == 0 {
                    let r = CGRect(x: CGFloat(i) * stripeW, y: 0, width: stripeW, height: size.height * 0.72)
                    context.fill(Path(r), with: .color(YoseColor.enji.opacity(0.14)))
                }

                // 3. 天井から降り注ぐスポットライト光線（台形ポリゴン）
                for i in 0..<spotlightCount {
                    let progress = Double(i) / Double(max(spotlightCount - 1, 1))
                    let originX = size.width * (0.15 + 0.70 * progress)
                    let sway = sin(t * 1.1 + Double(i) * 1.4) * 28.0
                    let targetX = size.width * (0.20 + 0.60 * progress) + sway

                    var beam = Path()
                    beam.move(to: CGPoint(x: originX - 8, y: 0))
                    beam.addLine(to: CGPoint(x: originX + 8, y: 0))
                    beam.addLine(to: CGPoint(x: targetX + 75, y: size.height * 0.78))
                    beam.addLine(to: CGPoint(x: targetX - 75, y: size.height * 0.78))
                    beam.closeSubpath()

                    context.fill(
                        beam,
                        with: .linearGradient(
                            Gradient(colors: [beamColor, beamColor.opacity(0.08), .clear]),
                            startPoint: CGPoint(x: originX, y: 0),
                            endPoint: CGPoint(x: targetX, y: size.height * 0.78)
                        )
                    )
                }

                // 4. 舞台の床（夜の特番仕様：黒漆と金の照り返しがある檜舞台）
                let floorY = size.height * 0.68
                let floorRect = CGRect(x: 0, y: floorY, width: size.width, height: size.height - floorY)
                context.fill(
                    Path(floorRect),
                    with: .linearGradient(
                        Gradient(colors: [Color(hex: 0x3D2B1F), Color(hex: 0x1E1510)]),
                        startPoint: CGPoint(x: 0, y: floorY),
                        endPoint: CGPoint(x: 0, y: size.height)
                    )
                )

                // 5. 床スモーク（複数の楕円グラデーションが床面をゆっくり横に流れる）
                for s in 0..<6 {
                    let drift = CGFloat(fmod(t * (18.0 + Double(s) * 4.0) + Double(s) * 70.0, Double(size.width + 160))) - 80
                    let smokeY = floorY - 18 + CGFloat(s % 3) * 16
                    let smokeRect = CGRect(x: drift - 90, y: smokeY, width: 180, height: 44)
                    context.fill(
                        Path(ellipseIn: smokeRect),
                        with: .radialGradient(
                            Gradient(colors: [YoseColor.kinari.opacity(0.16), .clear]),
                            center: CGPoint(x: smokeRect.midX, y: smokeRect.midY),
                            startRadius: 4,
                            endRadius: 90
                        )
                    )
                }
            }
        }
        .ignoresSafeArea()
        .animation(.easeInOut(duration: 0.45), value: mood)
    }

                        Path(CGRect(origin: .zero, size: size)),
                        with: .color(YoseColor.kinBright.opacity(flashAlpha))
                    )
                }

                // B. 金テープ（ストリーマーリボン 36本：左右下から中央上へ放物線を描いて伸びる）
                let tapeCount = 36
                for i in 0..<tapeCount {
                    let seed = Double(i) * 1.732
                    let fromLeft = (i % 2 == 0)
                    let startX: CGFloat = fromLeft ? -10 : size.width + 10
                    let startY: CGFloat = size.height * 0.78

                    let launchProgress = min(max(elapsed * 1.8 - Double(i % 5) * 0.06, 0), 1.0)
                    guard launchProgress > 0 else { continue }

                    let dirX: CGFloat = fromLeft ? 1.0 : -1.0
                    let vx = CGFloat(140.0 + fmod(seed * 97.0, 210.0)) * dirX
                    let vy = CGFloat(-520.0 - fmod(seed * 131.0, 260.0))
                    let gravity: CGFloat = 340.0

                    var ribbon = Path()
                    let segments = 12
                    for step in 0...segments {
                        let segT = CGFloat(launchProgress) * (CGFloat(step) / CGFloat(segments)) * 1.35
                        let px = startX + vx * segT + sin(segT * 6.0 + CGFloat(seed)) * 14.0
                        let py = startY + vy * segT + 0.5 * gravity * segT * segT
                        if step == 0 {
                            ribbon.move(to: CGPoint(x: px, y: py))
                        } else {
                            ribbon.addLine(to: CGPoint(x: px, y: py))
                        }
                    }

                    let tapeColor = (i % 3 == 0) ? YoseColor.kinBright : ((i % 3 == 1) ? YoseColor.kin : YoseColor.shu)
                    context.stroke(
                        ribbon,
                        with: .color(tapeColor.opacity(0.92)),
                        lineWidth: (i % 4 == 0) ? 4.5 : 3.0
                    )
                }

                // C. 金・銀・朱・白和紙の角紙吹雪（220枚）
                let confettiCount = 220
                let palette: [Color] = [
                    YoseColor.kinBright,
                    YoseColor.kin,
                    YoseColor.shu,
                    YoseColor.washi,
                    YoseColor.enji
                ]

                for i in 0..<confettiCount {
                    let s = Double(i) * 3.14159
                    let speedY = 75.0 + fmod(s * 43.0, 110.0)
                    let initialY = -fmod(s * 89.0, Double(size.height))
                    let y = CGFloat(fmod(initialY + elapsed * speedY + Double(size.height), Double(size.height + 60))) - 30
                    let baseX = fmod(s * 197.0, Double(size.width))
                    let swayX = sin(elapsed * 2.8 + s) * (12.0 + fmod(s * 7.0, 16.0))
                    let x = CGFloat(baseX + swayX)

                    let w: CGFloat = 6.0 + CGFloat(i % 4) * 2.5
                    let h: CGFloat = (3.5 + CGFloat(i % 3) * 1.5) * CGFloat(abs(cos(elapsed * 4.0 + s)) + 0.25)

                    var piece = Path()
                    let rect = CGRect(x: -w / 2, y: -h / 2, width: w, height: h)
                    piece.addRect(rect)

                    var transform = CGAffineTransform(translationX: x, y: y)
                    transform = transform.rotated(by: CGFloat(elapsed * 2.2 + s))

                    let color = palette[i % palette.count]
                    context.fill(piece.applying(transform), with: .color(color))
                }
            }
        }
        .allowsHitTesting(false)
        .onChange(of: isActive) { _, newValue in
            if newValue { startTime = .now }
        }
    }

## 3. 予選の大会結果に足す『番組感』4個（デザインシステム型D準拠）

   * 点数は出さない代わりに、審査員席から1名（その大会の担当審査員）の名札付き `YoseSpeechBox` を出し、右上に `YoseHankoStamp("秀", isSquare: true)` を叩きつける。「テレビのダイジェスト番組で審査員が1人だけコメントを抜かれた」手触りになり、決勝の7人採点への憧れを高める。
