## 2. 説明文（4,000字以内・約1295字）
```
相方と組んで十年。小さな舞台から、年に一度の大舞台を目指す、漫才コンビ育成ゲームです。
稽古と生活とネタ作りを重ねるうちに、相方との距離も少しずつ変わっていきます。
十年の終わりに待っているのは、勝ち負けだけではありません。

【漫才師コンビの十年】
一週間ごとに、稽古、アルバイト、休養、ネタ書きから行動を選びます。
十年のあいだに、予選、準決勝、そして決勝があります。
稼ぎと生活費、体力、知名度、ネタの鮮度。どれも使えば減り、整えれば戻ります。
目の前の一週間をどう使うかが、その年の舞台につながります。

【相方との関係で変わる結末】
十年の終わり方は一つではありません。
舞台で勝ち切る道、売れないまま続ける道、生活に押されて夜逃げする道、気持ちが離れて解散する道。
結果を左右するのは、成績だけでなく相方との関係です。
同じ十年でも、二周目は別の結末にたどり着きます。たどり着いた結末は図鑑に記録されます。

【寄席の和の世界観】
墨と朱、金の色づかいで、寄席の空気を画面に描きました。
暖簾、提灯、高座の座布団。舞台に上がる前の静けさから、拍手が起きる瞬間までを、落ち着いた和の意匠でまとめています。
ネタの本文は書きません。笑いは想像にゆだね、コンビの歩みを描くことに集中した作品です。

【生放送さながらの決勝】
決勝は、煽りの映像、審査員席の紹介、扉からの登場、開票、講評、暫定ボード、最終決戦と、一本の番組のように進みます。
審査員はそれぞれ見る点が違い、講評には直せる一点が入ります。
どこが良くて、どこを直すか。次の年の稽古に読み替えられる講評です。

【選択肢のあるできごと】
後輩に誘われた夜、先輩に呼ばれた帰り道、相方の口数が減った週。
暮らしの中で起きるできごとに、答えの決まっていない選択肢が出ます。
どちらを選んでも、得るものと手放すものがあります。

【舞台衣装を集める】
舞台に立つ二人の衣装を、ガチャで集められます。衣装は見た目が変わるだけで、強さや成績には影響しません。
毎日のログインボーナスをためると、無料でも回せます。好きな一着と交換できる天井もあります。
手に入れた衣装は iCloud に保存され、機種変更をしても残ります。
提供割合は、アプリ内の「提供割合」のページで、回す前にいつでも確認できます。

【遊びかた】
・ひとり用です。基本無料で、広告が表示されます（大会の結果の後、年の幕間、ログインボーナスの2倍のごほうび）。
・1,000円の「広告カット」（買い切り・衣装1着つき）で、広告は表示されなくなります。
・ガチャは1回100円、10回1,000円です。ガチャを回さなくても、物語の最後まで遊べます。
・セーブは自動で、中断してもそのまま再開できます。
・縦向きの片手操作です。

【ご注意】
本作に登場する人物、団体、大会、番組はすべて架空のものです。
お酒の席や、お金に困る場面の描写が含まれます。
アプリ内課金（有料のランダムな衣装を含む）があります。お子さまの課金は、端末のスクリーンタイムなどで制限できます。
```
