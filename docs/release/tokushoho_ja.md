# 特定商取引法に基づく表記

| 項目 | 内容 |
|---|---|
| 販売業者 | 【氏名または屋号】 |
| 運営責任者 | 【氏名】 |
| 所在地 | 【案】請求があった場合、遅滞なく開示します |
| 電話番号 | 【案】請求があった場合、遅滞なく開示します |
| 問い合わせ先 | 【メールアドレスまたはサポートページのURL】 |
| 販売価格 | 各商品の購入画面に表示します（広告カット 1,000円、衣装ガチャ 1回 100円・10回 1,000円。いずれも税込【仮】） |
| 商品の代金以外に必要な料金 | アプリのダウンロードや通信にかかる通信料は、お客さまのご負担です |
| 支払い方法 | Apple が定める方法（App Store の決済） |
| 支払いの時期 | App Store の購入の手続きが完了した時点（Apple の定めによります） |
| 商品を引き渡す時期 | 購入の手続きが完了した後、すぐにご利用いただけます |
| 返品・キャンセル | デジタルの商品のため、購入後の返品・キャンセルはお受けできません（法令および Apple のルールによる場合を除きます）。返金の申請は Apple の窓口で受け付けています |
| 動作環境 | iOS 17.0 以上の iPhone |

衣装ガチャの提供割合は、アプリ内の「提供割合」のページと[提供割合のページ](gacha_rates.html)でご確認いただけます。
