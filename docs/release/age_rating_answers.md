# 年齢区分の質問への答え案（v0・2026-11-02）

> App Store Connect の「年齢制限」の質問票に答えるための下書き。質問の文言・項目名は Apple が随時変える（2025年に 4+/9+/13+/16+/18+ へ改定、各項目は「なし／まれ／頻繁」型）。**提出時に画面の文言を見て合わせる**。以下は記憶に基づく項目名なので、画面と違う項目名は読み替える。
> 元の案：docs/store_listing_draft_v0.md §5（旧）。今回は「ガチャ（有料のランダムアイテム）あり・広告あり」に更新。
> 確認方法：`ManzaiGame/Sources`・`GameCore/Sources` を grep（2026-11-02）。

## 3. 見込みの区分
- **13+ 相当**（アルコールの言及が「まれ」で最も重い回答の場合）を第一の見込みとする。
- ただし **ルートボックス「あり」と広告「あり」が区分を押し上げる可能性**がある。ガチャ「あり」で 13+ から 16+ 以上になる扱いかは、**提出時の画面で自動計算された区分を見て確認**する（検索で裏が取れていない＝要確認）。
- 区分が思ったより高いとき：①飲み会の台詞から酒の語を外して「なし」にする案（世界観を削るため非推奨・docs/store_listing_draft_v0.md §5 のとおり）②区分が高くても配信は可能（日本のみ配信なら、その区分で足りる）。
- 区分を自分で上書き（引き上げ）する欄もある。下げることはできない。
- 日本の CERO 等は家庭用機向けで、iOS の App Store には適用されない。
- 広告配信側の「最大広告コンテンツ区分」は、アプリの年齢区分より厳しめに設定する（例：広告会社の管理画面で「全年齢」寄りに）。
- 年齢区分と別に、「アプリのプライバシー」の回答（広告識別子・購入・iCloud 等）を同時に更新する。privacy_policy_ja.md と同じ内容にそろえる。
