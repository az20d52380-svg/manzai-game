## よくある質問

### 機種変更で衣装は引き継げますか
衣装・券・かけら・天井ポイント・ログインの札は iCloud に保存され、同じ Apple ID なら引き継がれます。iCloud をオフにしている場合は、端末の中にだけ保存されます。

### 機種変更でゲームの続きは引き継げますか
ゲームの続きのデータは、端末の中に保存しています。端末の移行やバックアップで一緒に移ることがありますが、必ず移るとはお約束できません。アプリを削除すると消えます。

### 「広告カット」を買い直さずに戻せますか
設定の「購入を復元」から戻せます。同じ Apple ID でご利用ください。

### ガチャの券を買ったのに回せませんでした
通信が切れた場合などは、買った分が「未開封」として残ります。次にガチャの画面を開くと、そこから回せます。無料の券を持っているときは、無料の券から先に使うので、買った分が未開封に残ります。

### 買ったものを払い戻せますか
購入の手続きは Apple が行っています。払い戻しの申請は Apple の窓口（reportaproblem.apple.com）で受け付けています。

### 提供割合はどこで見られますか
アプリの設定、ガチャの画面、購入の確認の画面から見られます。[こちらのページ](gacha_rates.html)にも同じ内容を載せています。

### 子どもの課金を制限できますか
iOS の「スクリーンタイム」や「承認と購入のリクエスト」で制限できます。
