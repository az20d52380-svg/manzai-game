# まとめ（2年目・48週を毎週選んで遊んだ）

数字：実力10→22（1年目は10→17）・知名度6→24（+18）・賞金110万・最終所持金21.2万（1年目9.8万）・借金に落ちたのは1回だけ（W9・-6.4万・1週で解消）。大会7回＝優勝4（春新人A・春新人B・大阪戒・若手限定）・通過1（GP1）・敗退2（夏中堅・GP2）。頂GPは2回戦敗退（1年目は3回戦）。決勝は客席から観戦（夕凪優勝）。

## ① 一番楽しかった瞬間 3つ
1. **大会の本番〜講評（W29 大阪戒・W35 若手限定賞）**：出る前の「実力30／ライン22」と結果板の「実力30」が一致し、「優勝——どっと沸いた！」＋「秀」の札＋具体的な講評（卯月「癪ばらしの場面で新しい方へ曲げられた」）＋賞金。1年目の数字の食い違いが消え、信用して見られた。
2. **足りない粒の注記が次の行動を決める（W1・W18→W22・W38）**：能力アップの詰まった升に「胆（胆力）あと2→エントリーライブに出る」「閃あと6→ネタを書く・ファミレスで朝まで」と出る。W18にエントリーライブを選ぶ→W22にセンスが上がる、という因果が読めた。1年目の最大の穴が使える形になった。
3. **選択イベントで1年目に選べなかった物が選べた（W17 劇場の改装「隣町に通って出る」・W45 短期バイト）**：金があると選択肢が効く（知名度↑体力↓所持金↓の表示）。前の年の反省が活きる実感。W29の優勝直後、W46の決勝観戦（7人の札めくり・「観戦」札が出て分かりやすい）も良い。
