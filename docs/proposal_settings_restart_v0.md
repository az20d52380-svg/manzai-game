# 試作：設定に「最初からやり直す」＋見た目をそろえる（main未反映）

## 何を変えたか
- キャリアの途中で設定を開くと「このキャリア」に「最初からやり直す」が出る。押すと確認が2回。
  - 1回目：「最初からやり直しますか？今のコンビの記録は消えます。」（やめる／やり直す）
  - 2回目：「本当に消しますか？もとには戻せません。」（やめる／消して最初から）
  - 2回目の「消して最初から」でセーブを消してタイトルへ戻る（既存の「やめてタイトルへ」と同じ処理を使用）。
- 見た目：週のメイン画面と同じ、臙脂＋金の見出し帯・生成りの面・墨の罫線パネル・朱の縁・太い書体。丸×と角丸カードはやめ、「閉じる」を金枠の文字ボタンに。
- 数式・数値は触っていない。文字は最小10.5pt（クレジット）、他は12pt以上。絵文字なし。
- 目視用：MZ_UI=settings、MZ_STEP=0/1/2 で通常／確認1／確認2へ直行（DEBUGのみ）。
