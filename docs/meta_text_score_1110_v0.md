## §2 照合

- 判定は `TrophyBook.onStage`／`onYearEnd`（Meta.swift）と `GameSession.swift` L352（夜行バス）・L381（稽古）・L1400（年末）・L1435（玉座奪還）。
- t15・t16：`r.name.hasPrefix("GP") || r.name == "敗者復活"` の時だけ。道中の大会・HANA は対象外 → 説明に「GPの」が要る（×）。
- t22：`outcome.champion, smallEntered >= 5, smallWon == smallEntered`。出た大会が4つ以下だと全勝＋GP優勝でも取れない → 説明と食い違い（×）。HANA は1大会＝1と数える（`smallTournamentCount`）。
- t05：準決勝は結果の名前だけで判定＝「出る」で合う。t21：敗者復活の通過で `finalist=true`＝「決勝へ進む」で合う。
- t18：`year >= careerYears(15)`・`!wonBefore`・夜逃げ/解散でない＝説明は合う。名前の「十」だけずれる（キュー172・寄せるだけ）。
- t12・t13：`TrophyBook.bump` は UserDefaults に周をまたいで積む＝通算。
- 暦：`CalendarView.monthLabel` は「第1週=4月・4週で1ヶ月」。第12週＝6月・第27週＝10月・第41週＝2月。季節の名前を持つ t03・t06・t08 は暦とずれる（t06・t08 は大会名の季節に合わせた名前＝大会名側の問題）。

## §4 判断が要る論点（名前の変更＝オーナー決定）

1. **t18「十年選手」**：結成15年と合わない（キュー172）。案A「十五年選手」（推奨：条件そのまま）／案B 名前を年数なしに（例「走り切った二人」）。
2. **t10「五年目の全力」**：1〜5年目のどこで勝っても取れる。案A「若手の全力」（推奨）／案B 5年目に勝った時だけにする（条件の変更＝ロジックに触る）。
3. **t22「六冠の年」**：道中は今7大会（寒梅漫才杯）＋女コンビは HANA。条件は「5つ以上」。案A 名前を数なしに（例「総なめの年」・推奨）／案B 条件を「6つ以上」にして名前に合わせる（ロジック変更・取りにくくなる）。
4. **季節の名前**：t03「冬の手前まで」（2月）・t08「真夏の頂」（10月）・t06「春一番」（6月）。暦（第1週=4月）と大会名の季節がずれているのが根。案A 大会の週・暦の見せ方は触らず t03 だけ名前を変える（例「三回戦の先へ」）／案B 大会名・暦ごと見直す（大きい）。
5. **t04「準々の壁に爪痕」**：通過したのに「爪痕」。案「準々の壁を越えて」。
6. **t07「結成組の意地」**：春新人賞A と B に出場条件の違いが無く、「結成組」が説明できない。案「もう一つの春」など B の立ち位置が分かる名前。
7. **t06「春一番」**：実在した芸人の芸名と同じ（一般語でもある）。架空ルール（CLAUDE.md 4）の範囲としてよいか。
8. **t19「雨天決行」**：解散危機の和解の仕組みを作るか・トロフィーを外すか（作るなら名前も条件に寄せる）。
