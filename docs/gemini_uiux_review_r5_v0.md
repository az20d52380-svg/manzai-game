### ■ 週メイン画面（`g4_week.png`）改善指示 TOP5

#### 1. 【即効・空気感爆発】漫才師とマイクの足元に「接地シャドウ（楕円影）」を追加
*   **問題**: キャラとマイクが畳の上に浮いており、舞台の臨場感・立体感がない。
*   **実装指示**:
    *   漫才師2人の足元およびマイクの台座の下に、ぼかしを効かせた薄い黒の楕円を敷く:
        ```swift
        // キャラの足元影（2人分それぞれに配置）
        Ellipse()
            .fill(Color.black.opacity(0.25))
            .frame(width: 80, height: 14)
            .blur(radius: 4)
            .offset(y: 110) // 足元の位置に合わせる
        ```
    *   これだけでキャラクターが舞台にドッシリと立ち、画面の「ペラペラ感」が一瞬で消滅する。

#### 2. 【バグUI除去】木札の「実力」下にある空っぽグレーバーの完全撤去
*   **問題**: 実力数値の下に意味不明な空バーがあり、バグに見える。
*   **実装指示**:
    *   木札内のレイアウトを修正:
        *   「実力 115」の下にあるゲージ（Rectangle/Capsule）は**完全削除**。
        *   実力と相性の間に、極薄の水平区切り線（`Divider().opacity(0.3)`）を1本入れるだけにする。
        *   「相性 10」の下の赤ゲージだけをプログレスバーとして残す。

#### 3. 【ガラケー感の脱却】下部3ボタン（日程・コンビ・設定）のトーン統一
*   **問題**: 黒地に金枠のボタンが、昔のモバイルWebサイトやガラケーの共通メニューのように浮いている。
*   **実装指示**:
    *   上部のコマンドボタンと同じ「オフホワイト背景＋チャコールグレー枠＋濃墨文字」のトーンに統一する。
    *   あるいは、底面バー全体を木目調（ダークウッド `#2D1E18`）のトレイに見立て、その上にフラットな押しボタンとして配置する。

#### 4. 【目標の格式化】「春新人賞A まで あと11週」バナーのブラッシュアップ
*   **問題**: 上部の目標バナーがただの暗い茶色帯で、ゲームの主目標としての高揚感がない。
*   **実装指示**:
    *   帯の背景に、薄く伝統的な和柄（市松模様や紗綾形）のテクスチャを透過度0.05で重ねるか、両端に「巻物」風の意匠（または金色の飾り爪）を添える。
    *   「あと11週」の数字フォントを大きくし、色を鮮やかな山吹色（`#F1C40F`）にして「締め切り感」を際立たせる。

#### 5. 【操作感の向上】吹き出し右下の「▼」を「点滅バウンド」させる
*   **問題**: 「来月まで本番なしやて。長いな」の右下の▼が、HTMLのセレクトボックスのように固まっている。
*   **実装指示**:
    *   ▼アイコンに対し、SwiftUIの `withAnimation(.easeInOut(duration: 0.6).repeatForever()) { offset(y: 2) }` を適用して上下に優しくバウンドさせる。
    *   静止した画面の中に「タップして次へ進める」というゲーム的な生命感を吹き込む。

### ■ 能力アップ画面（`g4_allocate.png / after`）改善指示 TOP5

#### 1. 【最優先・脱臼修正】「確定」ボタンの枠線ズレと発光お漏らしの完全修正
*   **問題**: 金枠が下方向に外れて脱臼し、黄色いグローが「おまかせ」ボタンを汚している。
*   **実装指示**:
    *   ボタン自体の外側に変なpaddingやoffsetを噛ませるのを全廃し、同一矩形の内側に `.overlay` で収める:
        ```swift
        Button(action: { ... }) {
            Text("確定")
                .font(.headline.bold())
                .foregroundColor(.white)
                .frame(maxWidth: .infinity, maxHeight: .infinity)
        }
        .frame(height: 48)
        .background(
            LinearGradient(colors: [Color(hex: "B83A2A"), Color(hex: "8A1F13")], startPoint: .top, endPoint: .bottom)
        )
        .cornerRadius(6)
        .overlay(
            RoundedRectangle(cornerRadius: 6)
                .strokeBorder(isChanged ? Color(hex: "FFD700") : Color.clear, lineWidth: 2)
        )
        // shadowのradiusを小さく抑え、隣接ボタンへの侵入を防止
        .shadow(color: isChanged ? Color(hex: "FFD700").opacity(0.5) : .clear, radius: 4, x: 0, y: 0)
        ```
    *   これで枠線は1ミリもズレず、ビシッと美しい金枠ボタンになる。

#### 2. 【品格の統一】「実力帯」の和風漆黒・金線化（脱・エアコンリモコン）
*   **問題**: `実力 42 (+1) ➔ 43` の背景がただの真っ黒（#1E1E1E）で安っぽい。
*   **実装指示**:
    *   背景を純黒から、画面全体の臙脂色に調和する「深い黒漆色（`Color(hex: "1C1412")`）」に変更。
    *   上下のフチに `0.5pt` の極細金線（`Color(hex: "D4AF37").opacity(0.6)`）を通す。
    *   これだけで「格式高い寄席のスコアボード」に昇華され、画面の高級感が跳ね上がる。

#### 3. 【アセット品質の統一】ランクバッジ（F/D/A）のグラデーション統一
*   **問題**: Aだけが立派で、FやDがのっぺりしたプラスチックゴミに見える。
*   **実装指示**:
    *   すべてのランク（F〜S）に統一された「メタリックグラデーション＋立体フチ」を適用する:
        *   **F / E**: 鈍いアイアン（鉄・鋳物調グラデ `#4A4A4A` ➔ `#2C2C2C` ＋ 薄いシルバー枠）
        *   **D / C**: 重厚なブロンズ・青銅（銅グラデ `#795548` ➔ `#4E342E` ＋ 銅枠）
        *   **B / A**: 鮮やかな金・真鍮（赤金グラデ ＋ 金枠）
        *   **S**: プラチナ・紫紺
    *   バッジの「厚みと光沢」のルールを全ランクで統一し、育成の階段を視覚化する。

#### 4. 【下部ナビの黄金比】「戻る・リセット・おまかせ・確定」のグリッド整流
*   **問題**: 「戻る」「リセット」「おまかせ」の横幅が不均等で、確定ボタンだけが肥大化してバランスが悪い。
*   **実装指示**:
    *   HStackで幅の比率をきっちり定義する:
        *   `戻る`: `リセット`: `おまかせ`: `確定` ＝ `1 : 1 : 1.2 : 2` の比率。
        *   全体の高さを `46pt` で完全統一。
        *   「リセット」ボタンは変更がない時は `opacity(0.4)` で非活性にし、ポイントを振った時だけ黒文字化する。

#### 5. 【情報密度の適正化】「現在の経験点」タイルの横長スリム化
*   **問題**: 左端の「現在の\n経験点」という臙脂色の正方形が重苦しく、右の5つの丸アイコンを圧迫している。
*   **実装指示**:
    *   正方形のボックスをやめ、上部に小さく「所持ポイント」と控えめな木札風ラベルを添えるか、幅を `54pt` 程度にスリム化して丸アイコン同士の水平マージン（隙間）を広げる。
    *   アイコンが息を吹き返し、ポイントの数字がさらに見やすくなる。
