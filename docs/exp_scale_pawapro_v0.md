## §1 パワプロの桁（出典）

**確認できた数字（能力を1上げるのに要る経験点）**
- スタミナ(アプリ版)：F帯(20台) 筋力8/精神6 → E(40台) 10/7 → C(60台) 12/8 → A(80台) 14/10 → S(99→100) 15/11。ランクが1段上がるごとに約+1〜2の階段。
  出典 https://www.arimurasaji.xyz/entry/2017/11/18/184518
- 基礎能力(査定効率からの逆算の概算)：ミート 40→42 で約42、58→60 で約48、78→80 で約64、98→101 で約200。パワー 40→41 約20、59→60 約24、95→101 約323。コントロール 40→41 は25。弾道 2→3 が90、3→4 が150。
  出典 https://gamerch.com/pawapro/77047 （サイト自身にコメントで計算ミスの指摘あり＝概算扱い）
- 特殊能力の取得に要る経験点の区分：C=100以下／B=101〜150／A=151〜249／S=250以上。
  出典 https://xn--odkm0eg.gamewith.jp/article/show/41292
- 高ランクほど1段あたりが増える（特に最上位で数倍）、センスが高いと必要点が減る：https://gameranbu.jp/pawapuro2018/75fe6f9b3f0313187c16

**確認できなかった数字**（検索6回＋ページ取得では数値表が出なかった。推測を事実として書かない）
- 1回の練習で入る経験点の具体値、1回のサクセスで貯まる総量。出典は「練習レベルが高いほど1回の練習の経験点が増える／試合は勝つと多い」という定性説明のみ（上記 gameranbu、https://www.konami.com/pawa/app/guide.html）。
- 補足：私の一般知識では、練習1回は各能力に数点〜十数点が複数入り、1回のサクセス総量は数千点規模。ただし未確認＝参考値。数字の裏取りが要るなら「練習別経験点表」を攻略wikiで直接見る追加調査が必要。

**桁の結論**：能力1アップは序盤で約6〜25、中盤で約40〜65、終盤で約100〜300。つまり「2桁〜3桁」が日常。本ゲームの「1アップ=1〜4程度」は1桁で、パワプロから見ると約10分の1。

## §3 案と見え方

### 案① 表示だけ×10（内部は不変）
画面の経験点・必要点・所持点に表示時だけ ×10 を掛ける。内部式・golden・セーブは不変。

| 場面 | 内部 | 画面(×10) | パワプロ相場 |
|---|---|---|---|
| ネタ作り main | +1.44 | +14 | 練習で十数〜数十点 |
| ネタ見せ会 main | +2.88 | +29 | 同上 |
| ネタ見せ会 sub | +1.44 | +14 | |
| ネタ作り sub | +0.48 | +5 | |
| 能力+1(序盤 <15) | 1.0 | 10 | 序盤6〜25 |
| 能力+1(25〜35) | 1.15〜1.35 | 12〜14(丸め) | 中盤40前後 |
| 能力+1(55〜70) | 2.5 | 25 | |
| 能力+1(S 90〜) | 4.2 | 42 | パワプロ終盤100〜300には届かない |

×10 で序盤〜中盤はパワプロ相場に収まる。終盤まで寄せたいなら ×20〜×30 だが、練習が +29〜+86 と大きくなりすぎる。×10 が無難。

### 案② 内部の値ごと変える（例：稽古値と ALLOCATION_STEP を×10、または EXP_SUPPLY_SCALE を 4.8 に）
見え方は案①とほぼ同じ。違いは中身：式の桁が変わる＝規律A（数式変更）、balance_sim と Swift の両方を直し、golden を作り直し、POUR_EPS(1e-9)・丸め・粒の比率が変わって帯（等級境界）が数点ずれる危険。得るものは「小数が整数になる」程度で、案①で足りる。

| 項目 | 案① | 案② |
|---|---|---|
| 式・golden・sim | 不変 | 全部作り直し |
| セーブデータ | 不変 | 旧セーブの所持点を×10する移行が必要 |
| 丸めのずれ | 表示のみ | 内部の帯がずれうる |
| 作業量 | 表示箇所の置換 | 大 |

## §4 推奨

**案①（表示だけ×10）。** 理由：オーナー要望（数字が大きい手応え）は画面の問題で、式を触るリスク（golden・帯のずれ・セーブ移行）を負う利点が無い。将来バランスを直すときも内部の小さい数字のままで考えやすい。

注意点：
- **端数**：各項目を別々に丸めず、内部の合計に×10してから四捨五入して出す（表示の合計が合わなくなるのを避ける）。+0.48 は +5(4.8)。「能力+1に必要」は 10〜42 の整数に出る帯倍率（1.15→11.5）は小数1位まで持つか四捨五入で統一する。
- **能力アップ画面の表との整合**：所持点・必要点・消費点・練習の獲得点の全箇所に同じ×10の変換関数1つを通す（箇所ごとに ×10 を書かない）。テキスト中に「+1」と書いた説明文や、おすすめ表示の閾値も確認。
- **セーブデータ**：案①では内部値のまま保存するので移行不要。表示倍率はコード定数にし、セーブへ入れない。
- 倍率の定数名案：`expDisplayScale = 10`（表示専用・式から参照しない）。
- 終盤(S)が 42 に留まる点は、パワプロの終盤(100〜300)より軽い。ここは「階段を急にする」＝RANK_COST_BANDS の変更になり規律A扱い。別論点として推奨はしない（オーナー判断）。
