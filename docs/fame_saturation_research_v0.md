# 知名度の張り付きを防ぐ型の調査 v0（2026-10-14）

## 0. 要点3行
1. 調べた範囲で裏付けが取れたのは少ない（FM の評判が3値別管理・勝敗/格で増減、アイマスの「ファン数しきい値→ランクアップ祭」、ホットスプリングの半年ごとの相対ランキング、Elo の相対性）。他の型は**記憶ベース**で、減衰の具体値を載せた一次資料は見つからなかった。
2. 型は6つ（減衰／段階ごとに必要量が増える／上限が段階で上がる／相対評価／旬と評判の二本立て／伸びの逓減）。saturation_check §4〜§6 の結果（減衰は70〜80で横ばい・伸び×0.3は帯が逆向き）から見て、単独の減衰より「逓減」「段階ごとの必要量」「相対評価」のほうが張り付きに効く構造。ただし帯への影響は全型とも未測。
3. 決めるのはオーナー。§3 に選択肢と根拠だけ並べた。

## 3. このゲームへの選択肢（決めない）
前提：知名度の伸び（大会・GP回戦）が毎年大きく、3年目に100。4〜10年目の連動先はオファー（80以上で50%）と決勝の人気補正。

- 案1 逓減（F）：80以上の伸びだけ鈍らせる。根拠：序盤の伸びを変えないので §6 の「低い間のオファー変化→帯が逆向き」を避けられる見込み。弱点：10年目に全員100近い形は変わらないかもしれない。
- 案2 段階ごとの天井（C）：既存の段階（予選／準決勝／決勝など）に知名度の上限を結びつける。根拠：saturation_check の主題が「段階が働いていない値」で、見た目にも段階の意味が出る。弱点：決勝に届かない層がさらに不利（格差拡大）。
- 案3 旬＋知名度の二本立て（E）：オファー率と人気補正は旬（減衰あり）に連動、長期知名度は肩書き用。根拠：§4 の減衰は単独だと70〜80で横ばいだが、旬なら「出ていない人」が確実に落ちる。弱点：値と表示が増える（％表示は出さない方針あり）。
- 案4 相対評価（D）：同期の中央値との差で人気補正やオファーを決める。根拠：全員100でも相対では差が出る。弱点：ライバルの知名度の持たせ方が必要で実装が最大。
- 案5 組み合わせ（案1＋案3 など）：§6 の結論どおり、単独の変更は帯がずれるため、どの案も帯のライン再調整とセットで決める前提。
- 案0 何もしない／付け替え：オファー率や人気補正を知名度以外の値に結び直す。張り付きは残るが「全員同じ最大値」の問題は消える。

測る順の目安（決めない）：案1→案3→案2。n=300で当たり→結論だけ n=1000。
