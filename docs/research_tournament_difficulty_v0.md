## §2 何年目で決勝か・優勝までの年数

出場資格：第1〜2回は結成10年未満→第3〜10回は10年以内→第11回〜は15年以内（休止期間は除外）。

検索で確認できた王者の例（結成→優勝の年数は一部は出典の換算値で±1年）：

|---|---|---|---|
| 2005 | ブラックマヨネーズ | 約7年（1998結成・換算） | |
| 2018 | 霜降り明星 | 6年目 | 当時の最年少王者 |
| 2020 | マヂカルラブリー | 約13年（2007結成・換算） | |
| 2021 | 錦鯉 | 約9年（2012結成） | 2020に初決勝→翌年優勝。6回目の出場で初決勝 |
| 2022 | ウエストランド | 約14年（2008結成・換算） | 2度目の決勝で優勝 |
| 2023 | 令和ロマン | 5年 | 初決勝＝優勝。トップバッター優勝は第1回以来 |

| 2007 | サンドウィッチマン | 【結成年未確認】 | 敗者復活からの優勝は史上唯一 |

- 確認できた範囲の分布：最短5年・最長約14年。中央値は 9〜10年目前後（確認できた7例：5,6,7,9,10,13,14）。サンプルが少なく、残りの王者の年数は【未確認】。
- 決勝の約半数が毎年「初進出」（2023は9組中5、2019は9組中7）。つまり「長年挑戦してやっと」より「突然来る」型が多い。
- 初決勝＝優勝は令和ロマン（2023）・たくろう（2025）など近年も出ている。一方で錦鯉は6回目の出場で初決勝。
- 敗者復活組の決勝進出は延べ24組前後（資料で20組以上〜24組と食い違い）。

## §4 比べて分かること

1. 段差の形は現実と同じ方向：序盤は易しく（18→45）、準決勝で急に難しくなる（45→74）。現実も準々決勝まではほぼ数百組の足切り、準決勝30枠で壁になる。
2. 実在は「全エントリーの約1/1,150が決勝」だが、ゲームは「プレイヤーは最初から“漫才師として続ける一人”」なので、決勝到達8〜41%は選抜後の比較になる。この差そのものは問題ではない（ゲームは主役視点）。
3. 年数：現実の優勝は5〜14年目・中央値9〜10年目前後。ゲームの優勝中央値は8〜10年（やり込み／のんびり改）で、帯はほぼ一致。ただしゲームは10年で打ち切るため11〜14年目の優勝（ウエストランド・マヂラブ型）は構造的に出ない。
4. 「突然来る」型（初決勝＝優勝）：ゲームの優勝は1年目ほぼ不可能（0.2〜2.7%・初回）。現実の近年は初決勝＝優勝が複数あり、「ブレイクの急さ」はゲームがやや堅い可能性（周回ボーナスや相性で補う設計は別にある）。
5. 通過数の見え方：ゲームには「何組中何位で通過」の概念がなく、ライン到達で通過。現実の「準決勝30枠・約23%」と、ゲームのライン74（実測の通過率は未確認）が対応しているかは未測定。

## §5 案（決めるのはオーナー・規律Aは決めてから）

- **案A：据え置き＋注釈（変更ほぼなし）**。ライン・帯は現実と同じ形で、優勝中央値も一致。変えるのは「説明文」だけ（例：王者の年数は5〜14年と載せる）。リスク最小。
- **案B：段ごとの通過率を測ってから微調整（推奨）**。`tools/exp_v2_anchor.py` を使い、各回戦の通過率（1回戦〜準決勝）を測って表にする。現実の形（準々決勝→準決勝 約23%、準決勝→決勝 約30%）と比べ、離れすぎている段（特に準々決勝45と準決勝74の間）だけ調整案を出す。理由：今回の調査で「現実の形」は分かったが「ゲーム側の段別通過率」が文書に無く、ここだけが比較できていないため。式は変えず、測定→オーナー判断→規律A。
- **案C：careerYears を10→15に伸ばす**（実在のM-1資格に合わせ、11〜14年目の優勝を出す）。ゲーム全体の長さ・成長上限・周回設計に波及する大きな変更で、現段階では勧めない（検討メモとして残す）。

推奨：B（測定だけ先に・変更は後）。測定は sonnet サブエージェント＋背景スクリプトで可能。
