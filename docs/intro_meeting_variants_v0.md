## §1 出会い方の型（4種）と相方の結びつけ

| 型 | 場面 | 実態の根拠（研究 §6） | 合う相方（人物像から） |

| ② 養成所の同期 | 養成所の教室→帰り道 | 同期で結成の例が多い | 二階堂（大阪から上京）・東雲（養成所を主席で出た）・朝比奈 |

結びつけ方の案（§4 の質問1で聞く）：
- **案ア 相方ごとに決まる（推奨）**：相方の生い立ちと出会い方が食い違わない。谷口は今の「同級生」のまま。新しい相方を入れた時に、その人の回想が自然に増える。
- 案イ ゲームの最初にプレイヤーが選ぶ：同じ谷口でも4通り遊べる。ただし選ぶ画面が1つ増え、最初の一歩が重くなる。
- 案ウ 周回ごとにくじで変わる：2周目以降の新鮮さは出るが、相方の生い立ちと合わない組み合わせが出る。

> 補足: 今のコードでは相方は谷口だけ・回想は最初の1回だけ流れる。案アだと、今すぐ画面に出る変化は無く、相方が増えた時に効く。今すぐ変化が欲しいなら §4 質問2（谷口の出会い方）で決める。

## §3 場面の説明（ト書き）を会話の前に出すか、後に出すか

今は、会話の吹き出しが上・ト書きの紙が下に**同時に**出る（読む順は「会話→場所」＝実質 B）。

同じ ② 養成所の同期（谷口版）1枚目で並べた見本（上から読む順）：

**A 会話の前**（ト書きを先に1行読ませてから会話）

```
［紙］養成所の教室。昼休み。
谷口：ここ空いてる？ 谷口や、同じクラスの
俺　：どうぞ。入学式で隣だったよな
谷口：せや。帰り、牛丼でも行かへん？
```

**B 会話の後**（今と同じ並び）

```
谷口：ここ空いてる？ 谷口や、同じクラスの
俺　：どうぞ。入学式で隣だったよな
谷口：せや。帰り、牛丼でも行かへん？
［紙］養成所の教室。昼休み。
```

- **推奨：A（会話の前）**。理由：出会い方が4種類になると場所が毎回違う（教室・休憩室・喫茶店）ので、先に場所を見せた方が最初の吹き出しから迷わずに読める。
- B の良さ：会話から先に入るので、引き込みは強い。場所が1種類（今の同級生だけ）なら B でも困らない。
- A にする時の見た目の案（決まったら作る）：紙を吹き出しの上へ移すだけ（タップの数は今と同じ）。

## §4 オーナーへの質問（1問ずつ・1番目が推奨）

**質問1　出会い方は、どう決めますか？**
今は谷口と「高校の同級生」として出会う場面しかありません。相方によって出会い方を変える決め方を選んでください。
1. 相方ごとに決まる（谷口＝同級生、二階堂＝養成所、八雲＝前のコンビの解散後…）← 推奨（相方の生い立ちと食い違わない）
2. ゲームの最初にプレイヤーが選ぶ
3. 周回ごとにくじで変わる

**質問2　谷口との出会いは、今の「高校の同級生」のままでいいですか？**
1. そのまま（同級生）← 推奨（今の会話・谷口の思い出話と合っている）
2. 2周目からは別の出会い方（養成所・バイト先・解散後）も出る
3. 別の型に変える（どれか1つ）

**質問3　場面の説明（「養成所の教室。昼休み。」などの一行）は、会話の前と後、どちらに出しますか？**
1. 会話の前 ← 推奨（場所が毎回違うので、先に分かる方が読みやすい）
2. 会話の後（今のまま）

**質問4　出会い方で、始めの仲の良さを変えますか？**
（調べた話では「同級生は付き合いが長い」「養成所の同期は組み替えが多い」）
1. 今回は変えない（文だけ変える）← 推奨（数字を動かすと全体の試算をやり直す必要がある）
2. 変える（別の作業として試算してから案を出す）

**質問5　出会い方は4種類で足りますか？**
1. この4つ（同級生・養成所・バイト先・前のコンビの解散後）← 推奨
2. 足したい（例：幼なじみ・地元の先輩後輩・ライブ会場で声をかけられた）
