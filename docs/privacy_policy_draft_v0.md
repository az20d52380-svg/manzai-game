## §2 プライバシーポリシー本文（案）

# 「四分の夜」プライバシーポリシー
（アプリ名は確定前の作業名。確定したら差し替え）

制定日：【未定】　最終改定日：【未定】
事業者（開発者）：【未定】　連絡先：【未定】

【未定】（以下「開発者」）は、iOS アプリ「四分の夜」（以下「本アプリ」）における情報の取り扱いを、次のとおり定めます。

**1. 収集する情報**
開発者は、本アプリを通じて、利用者の個人情報その他のデータを収集しません。氏名・メールアドレス・位置情報・連絡先・写真・端末識別子（広告 ID を含む）などを取得することはありません。

**2. 端末内に保存される情報**
本アプリは、次の情報を利用者の端末内にのみ保存します。
- ゲームの進行状況（セーブデータ）と、エンディングの図鑑の記録
- 利用者が入力したコンビ名・ネタの題材名などの文字
- 音量などの設定
これらは端末の外へ送信されず、開発者が閲覧することはできません。本アプリを削除すると、端末内のこれらの情報も削除されます。ゲーム内の「はじめから」等の操作でも、セーブデータは消去されます。

**3. 外部への送信・第三者提供**
本アプリはインターネット通信を行いません。解析ツール・広告・クラッシュ報告などの外部サービスも組み込んでいません。そのため、情報を第三者に提供・共有することはありません。

**4. 通知**
本アプリは、利用開始時に通知の許可をお願いすることがあります。通知の許可は、端末の「設定」からいつでも変更できます。通知の内容や許可の状況が、開発者や第三者に送信されることはありません。

**5. 子どもについて**
本アプリは個人情報を収集しないため、年齢にかかわらず同じ取り扱いです。【年齢区分はストア申告の確定後に追記】

**6. ポリシーの変更**
本ポリシーを変更する場合は、本ページに掲載して告知します。将来、通信を伴う機能（追加シナリオの販売など）を追加するときは、あらかじめ本ポリシーを改定します。

**7. お問い合わせ**
【未定：連絡先（メールアドレスまたは問い合わせフォーム）】

## §3 Apple「Appのプライバシー」回答案
- 「このアプリまたはサードパーティパートナーは、このアプリからデータを収集しますか？」→ **いいえ（Data Not Collected）**。
- 追跡（Tracking）：なし。`NSPrivacyTracking=false`。
- 入力文字・セーブは端末内のみで外部送信しない＝Apple の定義では「収集」に当たらない。
- store_listing_draft_v0.md §6 との照合：回答案「データを収集しない」・追跡なし・PrivacyInfo 内容、すべて**一致**。差分は通知の行番号のみ（321→691）。
- 注意：(a) 通知を実際に送る機能を足しても申告は変わらない（ローカル通知のみなら）。(b) StoreKit／iCloud／解析SDKを足すなら再申告。(c) 通知の許可依頼は §6 の推奨どおり出す場面が決まるまで外すのが安全（本文 §4 はそれでも成立）。

## §4 公開の置き場と URL 設定
**置き場の案（無料）**：GitHub Pages（推奨）。他に Notion の公開ページ・Google サイトも可。
手順（3行）：
1. 公開用リポジトリ（またはこの repo の `docs/` ）に `privacy.html`（または `privacy.md`）として §2 を置く。
2. GitHub の Settings → Pages で公開ブランチ／フォルダを指定 → `https://<アカウント>.github.io/<repo>/privacy` が発行される。
3. その URL を App Store Connect の「プライバシーポリシーURL」と `AppInfo.privacyPolicyURL`（SettingsView.swift:176）の両方に入れる。

**注意**
- 公開は外向きの操作＝オーナー承認が必要。連絡先（メール）は公開されるので、専用アドレスを推奨。事業者名は個人名か屋号かを決める。
- `privacyPolicyURL` は現在 `URL?` で nil の間は設定画面の行が出ない。入れると行が出るので、申請前に**ストア欄と同一の URL**にし、**https・ログイン不要・日本語表示・アプリ名が本文に出る**ことを確認。
- repo が private だと Pages は有料プランが要る場合がある。公開リポジトリにするとソースも公開になる＝ポリシー専用の小さな公開 repo を別に作る案が安全。
- URL を後で変えると審査の再提出になり得るため、安定したものを選ぶ（独自ドメインなら将来移転しやすい）。
- アプリ名・連絡先が確定したら本文の【未定】を埋め、最終改定日を更新。
