# 敗者復活で散る場面の繰り返し回数（2026-10-26・キュー127 の材料）

## 要点
- アプリは敗者復活で負けるたびに、同じ9ページの場面（TournamentResultView.revivalLoss＝決勝を立ち見→帰り道）を出す。
- 実測（tools/exp_revival_loss_count_1026.py・ネタ込み NETA_ON/V2・EVENTS_APP=True・n=1000）：**1キャリアで平均 3.5〜4.4 回**。
  - Balanced：平均 4.44 回（5回が最多・7回以上 9%）
  - Smart：平均 3.54 回（0回 9%・5回 17%）
- 準決勝で落ちた時の1ページ（semifinalLoss）も同じ回数だけ先に出る。
- 「1年版デモの実質最終戦」として書かれた場面なので、10年では重い。キュー127 の推奨②（2回目から短い版）の根拠を補強。

## 案（オーナー判断・キュー127）
1. 今のまま
2. 2回目以降は短い版（地の文1行＋谷口1行）＝確定文は1回目に残す【推奨】
3. 言い換えを足す（0019・§102 と同じ口＝週で替える。9ページ×数通りは書く量が多い）

## 関連（同じ型・判断はオーナー）
- 予選（1回戦〜準決勝）で落ちるたびに、結果画面の講評の下に谷口「……次や、次」（TournamentResultView.taniguchiLossLine・オーナー決定の台詞）が毎回同じ1行で出る。1行なので重さは小さい。言い方を替えるかは台詞の決定に関わるため触っていない。
