## §1 測り方
- スクリプト `tools/exp_q93_r2m_current_v0.py`（生出力 `docs/measure_raw/q93_r2m_current.txt`＝n=1000、`q93_r2m_current_n300.txt`＝n=300。3分半）。式・既定値は変えない。案は子プロセス内の上書きのみ。並列は `Pool(maxtasksperchild=1)`＋`chunksize=1`。

- ボットは §93 の組A（hand＝人の手配り近似）：のんびり改+喫茶、ローテ+喫茶、バランス（CareerBalanced）、調整型（CareerSmart）。n=1000/ボット。（n=300 で当たりを取り、全案が3分半で済むため全部 n=1000 で撮った。）
- 指標：詰1/詰13＝週末に経験点5以上・伸び余地あり・押せる＋が0の週の割合（1年目／1〜3年）。間残＝3年末に残った間合い÷もらった間合い。能力10＝10年目年末の 感性/発想/表現/華/メンタル（10年目まで続いた人の平均）。
- 注意：詰まりは特技購入の前の週末で数える（特技は余りを使う）。間残は特技購入後。優勝は初優勝でキャリア終了、決勝は到達率。

## §3 所見と選択肢（決めない）
**所見**
- 詰まりは R2M@0.8 で、のんびり/ローテ/バランスの1〜3年が 64〜81% → 20〜34%（APP=0）に減る（§93 の旧 n=1000：93/81/92 → 49/50/52 より大きく減る＝特技・アイテム入りの本体で余りが使われるぶん）。1年目はほぼ解消（2〜9%）。
- 帯：ローテは決勝・優勝とも今と同水準（決勝 29.7→30.0／51.1→51.8、優勝 1.1→1.0／2.8→3.1）。旧文書の「ローテ決勝 34.8→20.8」は再現しない。
- 帯が動くのは稽古の少ない型：のんびり決勝 12.3→7.3（APP=0）／13.6→8.0（APP=1）＝約4割減。全体の量を 1.0 にすると 12.2/14.7 に戻り、ローテは 45.1/60.2 に上がる＝量は帯を決めるつまみ。
- 調整型（CareerSmart）は R2M でも詰まりが残る（83→51〜61）うえ、解散が 0.1→1.9〜2.6%（APP=0）。旧測定の 5→28% ほど増えない（「二人の週」§94 の取り込みが効いている可能性）。ただし APP=1 では 0。
- バランス/調整型は APP=1 で詰まりが APP=0 より多い（イベントで週が埋まり、おまかせの経験点の消化が減るため）。R2M だけでは直らない。
- 間残（間合い）は 100%近く残っていたローテが 14〜28% になる＝「余らない」目標は達成。

**選択肢**
1. R2M@0.8 を入れる：詰まりは半分以下、ローテの帯は不変。代償＝のんびり型の決勝が約4割減（12→7%）。ローテ決勝は動かないので「稽古が少ない人が伸びにくくなる」が唯一の副作用。
2. R2M@0.9：詰まり 28〜41%（APP=0）、のんびり決勝 9.0/11.5、ローテ決勝 34.6/56.4（今より +5）。中間。
3. R2M@1.0：のんびり決勝は今と同じ（12〜15%）、ローテ決勝 +15pt（45/60）で帯が上がる。詰まりは 30〜43% と @0.8 より多い。ローテの帯を上げたくなければ不向き。
4. 入れず、特技（余りの使い道）を足して受ける（§93 の旧推奨）。今の本体は特技入りでも詰まり 64〜83% なので、特技の種類・値段を増やすなら別測定が要る。

**推奨の理由（決めるのはオーナー）**：帯（ローテ）を動かさずに詰まりを半分以下にできるのは @0.8 だけ（選択肢1）。のんびり型の落ち込みが許容できるかが判断点で、許容できないなら @0.9（2）が次点。調整型の詰まり残りは R2M の外（ボットの選び方か §94）で扱うのがよい。
