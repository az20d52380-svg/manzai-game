## ⑤ 4画面共通で直すべき「1手」

### **【共通の1手】すべてのボタン・カードを「角丸2pt ＋ 墨2pt枠 ＋ Y軸2ptのベタ影（Blur 0）」の『木札・貼り紙コンポーネント（`YoseCard` / `YoseButtonStyle`）』に強制統一せよ**

現在、4画面がバラバラで「AIっぽく」見える最大の原因は、**画面ごとに角丸（0pt / 4pt / 6pt / Capsule）と枠線の有無が違い、ところどころに枠線なしのフラットUIが混ざっていること**です。

SwiftUIで以下の2つの共通Modifier / ButtonStyleを定義し、**4画面すべてのカード・ボタン・タグから個別の `.cornerRadius()` や `.background()` を剥がしてこれに差し替えてください**。これだけで4画面の統一感と「パワプロ・寄席の手触り」が一気に商業レベル（80点台）に乗ります。

```swift
// 1. 4画面共通のカード枠（ネタ帳のカード、審査講評、能力アップの行すべてに適用）
struct YosePaperCard: ViewModifier {
    var borderColor: Color = Color(hex: "2B2B2B")
    var backgroundColor: Color = Color(hex: "FBF8F1")
    
    func body(content: Content) -> some View {
        content
            .background(backgroundColor)
            .clipShape(RoundedRectangle(cornerRadius: 2))
            .overlay(
                RoundedRectangle(cornerRadius: 2)
                    .stroke(borderColor, lineWidth: 2)
            )
            .background(
                RoundedRectangle(cornerRadius: 2)
                    .fill(Color(hex: "2B2B2B"))
                    .offset(x: 0, y: 2) // Blur 0 のハードシャドウで「置かれた厚み」を出す
            )
    }
}

// 2. 4画面共通の物理ボタン（コマンド、+ボタン、勝負ネタにする、型を変える、確定、次へ進む すべてに適用）
struct YosePushButtonStyle: ButtonStyle {
    var fill: Color = Color(hex: "F5F0E1")
    var border: Color = Color(hex: "2B2B2B")
    
    func makeBody(configuration: Configuration) -> some View {
        configuration.label
            .background(fill)
            .clipShape(RoundedRectangle(cornerRadius: 2))
            .overlay(
                RoundedRectangle(cornerRadius: 2)
                    .stroke(border, lineWidth: 2)
            )
            .offset(y: configuration.isPressed ? 2 : 0) // 押した瞬間に2pt沈む
            .background(
                RoundedRectangle(cornerRadius: 2)
                    .fill(Color(hex: "2B2B2B"))
                    .offset(y: 2)
                    .opacity(configuration.isPressed ? 0 : 1) // 沈んだら影が消える
            )
            .animation(.easeOut(duration: 0.06), value: configuration.isPressed)
    }
}
```
