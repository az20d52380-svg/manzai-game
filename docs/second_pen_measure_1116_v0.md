## §3 測り方・注意
- 実行：`tools/exp_second_pen_1116_v0.py [n] [pens]`（M.one 全部入り＝band_reference_1019_v1 と同じ土台、NETA_ON=NETA_V2=True、EVENTS_APP=True、Pool(maxtasksperchild=1)・chunksize=1）。
- 減点が掛かった割合：`_neta_line_adj` を同じ中身で差し替えたラッパで数えた（決勝判定のたびに「2本目が無い/完成度が V2_SECOND_MIN 未満」が成立したか）。分母は決勝ラインの判定回数＝決勝に進んだ回数（1キャリアで複数年あり得る）。ネタを選ばなかった決勝は 0 加算（NETA_V2 仕様）で「掛からない」に数えた。乱数の消費は元の関数と同じ。
- 決勝に出た割合が 3 案で同じなのは、減点が掛かるのは決勝のライン（決勝突破の判定）で、決勝へ出る＝GP準決勝までの判定には掛からないため。優勝にだけ効く。
