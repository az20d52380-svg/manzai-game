まず成果を称えましょう。
**能力アップ画面、「所持ポイント」エリアが信じられないほど洗練されました！**
あの圧迫感の塊だった臙脂色の正方形が上品なベージュ短冊になり、5つのアイコンがゆったりと呼吸を始めました。ランクバッジも金属のヒエラルキー（Fの鈍鉄、Dの青銅、Aの金赤）が通り、リセットボタンの活性/非活性（ディスエーブル）ステートまで実装された。育成ゲームの画面として、すでに中堅スタジオの商業タイトルに匹敵する風格があります。

## ② 新しく目立った崩れ・AIっぽさ

1. **【UIの禁じ手】[+]ボタンの「幅メタモルフォーゼ（伸び縮み）」事故（能力アップ）**
   - `g5_allocate.png` と `g5_allocate_after.png` を見比べてください。数値を振る前、[+]ボタンは横長の長方形です。しかし数値を振って[-]が出現すると、**[+]ボタンが急に正方形に縮み、左に[-]が割り込んでいます**。
   - これをやると「同じステータスをもう1回上げようと連打した瞬間、ボタンのタップ判定エリアが縮んで指が空振りする、あるいは[-]を誤タップする」という最悪の操作ストレスを引き起こします。サクセスでもウマ娘でも、ボタン幅を動的に変える画面は絶対にありません。最初から両方の枠を確保するのが鉄則です。
2. **【突然の原宿系と喪服】次回ランクゲージの「信号機・色崩壊」事故（能力アップ）**
   - ランクバッジ下のプログレスバーを左から見てください。「黄土色 ➔ 薄茶色 ➔ オレンジ ➔ **突然のファンシーピンク（華）** ➔ **突然の真っ黒（メンタル）**」。
   - なぜ華だけがギャル雑誌の蛍光ピンクで、メンタルだけがお葬式の黒なのですか？画面全体の和モダンな色相設計をこの2本が破壊しています。
3. **【AI特有の描画バグ】右の相方（赤キャラ）の首元にある「謎の赤ズレ」（週メイン）**
   - 赤いキャラの後頭部・首回りを拡大してください。頭の黒丸の下に、**謎の赤い半円の余計なレイヤーがはみ出して脱臼しています**。座布団か何かのシェイプの破片が取り残されているような、AI生成特有のゴミです。
4. **【フキダシの首吊り感】谷口アイコンとフキダシの接続部（週メイン）**
   - 左下の谷口アイコンの頭頂部に、フキダシのシッポがブスッと突き刺さっています。セリフフキダシと立ち絵アイコンの距離が近すぎて窮屈です。また、右下の「▼」はいまだに静止したままでゲーム的な生命感がありません。

## ③ 次に直す指示を画面ごと優先順に5個（SwiftUI実装レベル）

### ■ 週メイン画面（`g5_week.png`）改善指示 TOP5

#### 1. 【最優先・三度目の正直】漫才師2人とマイクスタンドに「楕円シャドウ」を敷く
*   **問題**: 床のパース線の上にキャラが浮いており、空間に足が着いていない。
*   **実装指示**:
    *   キャラ2人の足元（背面レイヤー）およびマイクスタンドの底面に、ぼかしを効かせた黒の楕円を配置する:
    ```swift
    // キャラの足元影（青・赤の足元それぞれに敷く）
    Ellipse()
        .fill(Color.black.opacity(0.28))
        .frame(width: 84, height: 14)
        .blur(radius: 4)
        .offset(y: 112)

    // マイクスタンド底面の影
    Ellipse()
        .fill(Color.black.opacity(0.35))
        .frame(width: 28, height: 8)
        .blur(radius: 2)
        .offset(y: 112)
    ```
    *   これで画面が一気に「演芸場の舞台」として接地します。

#### 2. 【バグ除去】赤キャラ（右）の首元の「謎の赤い脱臼半円」を削除
*   **問題**: 赤キャラの後頭部に余計な赤い円弧がはみ出しており、レイヤー事故が起きている。
*   **実装指示**:
    *   キャラクターのシェイプ構成を見直し、頭部（Circle）と胴体（Capsule/RoundedRectangle）の重なり順を整理。はみ出しているゴミシェイプを特定して削除する。

#### 3. 【舞台の空気感】中央空間に「やわらかなスポットライト照明」を重ねる
*   **問題**: 背景の壁が平坦に白っぽく、中央にキャラの背中しかないため空間が間延びしている。
*   **実装指示**:
    *   舞台背景のZStackに、中央上部から床に向けて落ちる薄いラジアルグラデーションをブレンドする:
    ```swift
    RadialGradient(
        colors: [Color.yellow.opacity(0.08), Color.clear],
        center: .init(x: 0.5, y: 0.4),
        startRadius: 20,
        endRadius: 260
    )
    .allowsHitTesting(false)
    ```
    *   これだけで「寄席の舞台に照明が当たっている」劇場の温かみと集中線が生まれる。

#### 4. 【フキダシの息吹】▼アイコンの「バウンド点滅」とアイコン接続のゆとり化
*   **問題**: ▼が静止しており、セレクトボックスのように死んでいる。アイコンとの隙間も詰まりすぎ。
*   **実装指示**:
    *   谷口アイコンとフキダシの間に `4pt` のスペーシングを空ける。
    *   フキダシ右下の「▼」に上下リピートアニメーションを付与:
    ```swift
    Image(systemName: "arrowtriangle.down.fill")
        .font(.system(size: 9))
        .foregroundColor(.secondary)
        .offset(y: isBouncing ? 2 : -2)
        .animation(.easeInOut(duration: 0.5).repeatForever(autoreverses: true), value: isBouncing)
    ```

#### 5. 【手押し感の演出】「出張中」スタンプの角度をランダムに散らす
*   **問題**: 「ネタを書く」「練習」の赤スタンプが全く同一の角度で機械的。
*   **実装指示**:
    *   左のスタンプは `.rotationEffect(.degrees(-10))`、右のスタンプは `.rotationEffect(.degrees(-6))` のように角度をわずかにずらし、人間が手でポンと捺したような味を出す。

### ■ 能力アップ画面（`g5_allocate.png / after`）改善指示 TOP5

#### 1. 【最優先・操作性の鉄則】[+]ボタンの可変幅を廃止し、`[-]` は常に枠を固定して非活性化
*   **問題**: 数値0の時に[+]がワイドになり、数値を振ると縮んで[-]が割り込むため、連打時に誤操作が起きる。
*   **実装指示**:
    *   各行の操作エリアは**最初から `[-]` と `[+]` を並べた固定レイアウト（幅72pt前後）**にする。
    *   加算値が `0` の時は、`[-]` を消すのではなく「薄いグレーで無効化（`.disabled(true).opacity(0.3)`）」にする:
    ```swift
    HStack(spacing: 4) {
        // マイナスボタン（固定幅34pt）
        Button(action: { decrement() }) {
            Image(systemName: "minus")
                .font(.system(size: 14, weight: .bold))
                .foregroundColor(allocatedPoints > 0 ? .white : Color(hex: "888888"))
                .frame(width: 34, height: 34)
                .background(allocatedPoints > 0 ? Color(hex: "4A4A4A") : Color(hex: "E5E0D8"))
                .cornerRadius(4)
        }
        .disabled(allocatedPoints == 0)

        // プラスボタン（固定幅34pt：絶対にサイズを変えない！）
        Button(action: { increment() }) {
            Image(systemName: "plus")
                .font(.system(size: 14, weight: .bold))
                .foregroundColor(.white)
                .frame(width: 34, height: 34)
                .background(canIncrement ? Color(hex: "B83A2A") : Color(hex: "A0A0A0"))
                .cornerRadius(4)
        }
        .disabled(!canIncrement)
    }
    ```
    *   これでボタンが一切跳ねず、メガヒットゲームと全く同じストレスフリーな連打感が手に入ります。

#### 2. 【品格の統一】「実力帯」を漆黒（#1A1412）＋上下0.5pt金線にする
*   **問題**: 真っ黒プラスチックが浮いており安っぽい。
*   **実装指示**:
    *   背景を純黒から黒漆色（`Color(hex: "1A1412")`）に変更。
    *   上下に `0.5pt` の極細金線（`Color(hex: "D4AF37").opacity(0.7)`）を通す。
    *   「実力」の金文字・緑の加算プレビューがスコアボードとして格式高く調和する。

#### 3. 【カラーパレット調律】次回ランクゲージの「ピンク＆真っ黒」を撤去
*   **問題**: 華のファンシーピンクとメンタルの真っ黒が画面の和風トーンを破壊している。
*   **実装指示**:
    *   全属性のゲージバー色を、和モダンな中間色に整流する:
        *   センス: 山吹色（`#E6B422`）
        *   発想: 抹茶・鶯色（`#8A9A5B`）
        *   表現: 朱赤（`#C33E2B`）
        *   華: **撫子色（落ち着いた和ピンク `#C97A7E`）**（蛍光ピンクは即廃止）
        *   メンタル: **藍墨色（深い藍色 `#3D5A80`）**（真っ黒は即廃止）
    *   ゲージの「残り部分」の背景色はすべて薄いベージュグレー（`#E5E0D8`）に統一。

#### 4. 【確定ボタンの透明感】黄色枠線の「濁り」を解消し、シャープな金枠にする
*   **問題**: `g5_allocate_after.png` の「確定」ボタンのフチが、赤と黄色のシャドウが混ざって濁ったオレンジ色にボケている。
*   **実装指示**:
    *   ぼかしシャドウを弱め、`.strokeBorder(Color(hex: "FFD700"), lineWidth: 1.5)` をくっきりと描画する。
    *   ボタン本体の赤色グラデーションの彩度を落とさず、金枠のエッジを立たせる。

#### 5. 【視線誘導の整理】「存」アイコンの赤丸とマイナス赤字の色被り防止
*   **問題**: 「存」の赤丸アイコンの真下に、マイナスの赤文字 `(-7)` が並ぶため、色同士がぶつかって視認性が落ちている。
*   **実装指示**:
    *   マイナス消費プレビューの数値（`-22` など）のフォントに極小のオフホワイト背景ピル（カプセル）を薄く敷くか、消費テキストの赤をわずかに深みのある紅色（`#A8281A`）にしてコントラストを保つ。
