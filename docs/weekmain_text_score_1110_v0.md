## §2 同じ言い回しの重なり・ゆれ
1. **撮影の週**：トースト「稽古の時間がない」／札「練習できない」／判子「出張中」／帯「ネタは来週から」。同じ状態を「稽古・練習・出張・撮影」の4語で言う。ネタを書く札にも同じトーストが出るので「稽古」は両方を含む語としては通るが、画面の分類名は「練習」「ネタを書く」。
2. **体力不足**：トースト「体力が足りない。今週は休もう。」（修正後）／札「体力が足りない ・ 休もう」／判子「休演」。判子だけ語が違う。
3. **オファーの二度押し**：トースト「もう一度押すと、このオファーを受ける。」と札「もう一度押すと受ける」が同時に出る。トースト＝句点あり、札＝句点なしの決まりどおりで、重なりは意図的（見落とし防止）＝現状維持でよい。
4. **ネタを足す**：「新しいネタ」「新しく書く」「ネタを書く」（ui_copy §8 既知）。
5. **未振分あり／振れる経験点あり**：送り仮名ゆれ。
6. **見飽き**：WeekMainView:1514 と SettingsView:249 の用語集が同じ「新しいネタを書くと元どおり」。直すなら2か所同時。
