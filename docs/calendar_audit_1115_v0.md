# 日程表・カレンダーの表示のコード点検（11/15・読むだけ・コードは直していない）

**要点3行**
1. 新規の食い違いは **中2・低4・高0**（既出の 157 と HANA 2件は別に再掲）。大会の週・名前・資格（芸歴10年／若手5年／推薦制＝知名度30／HANA の段）は GameCore の Calendar.swift・sim_career.py と**全部一致**。
2. 一番重いのは **中-1：前の年に準々決勝以上へ行くと GP 1回戦（第30週）はシードで免除なのに、日程表は赤い「GP1回戦」のまま**（過ぎた週は稽古の判子も隠れる）。2年目以降の多くの年で起きる。表示だけ。
3. 次は **中-2：見送った・払えず出なかった道中の大会（春新人・夏中堅・大阪戎・寒梅）が、過ぎた週でも赤い「大会」のまま**で、長押しの文は「稽古」と食い違う。帯（次の大会まで n 週）は資格・見送り・GP 敗退・HANA の段・年末を全部正しく数えている（例外は低-4 の1点）。

節：§1 大会の並びと資格の突き合わせ／§2 過去週の印（categoryLog）／§3 「次の大会まで n 週」の帯／§4 年またぎ・15年目／§5 既出／§6 問題なし一覧

## §1 大会の並びと資格の突き合わせ（問題なし）
- 道中7大会（週12/15/27/29/35/38/46）・HANA 4段（32/37/42/44）・GP 回戦5＋決勝（30/39/41/43/45・47）は、画面が `cal.tournament(inWeek:state:)`・`cal.gpRounds`・`cal.gpFinalWeek` から引く＝**名前・週・資格は Calendar.swift が唯一の出所**（CalendarView.swift:199-207, 158-176）。週の重なり0（全12大会が別週）。
- 資格：芸歴10年以内（春新人A/B・夏中堅・寒梅）＝`year <= 10`、若手限定賞＝`year <= 5`、推薦制中堅賞＝`fame >= 30`、HANA＝女コンビ＋前の段通過。tools/sim_career.py:147-185 と同じ。画面の資格判定（`isEligible`）・帯（upcomingStages・GameSession.swift:729）・入口（WeekRunner.swift:399）は同じ関数を見る。
- 年数切れの大会は過ぎた週でも塗らない（`isAgedOut`・CalendarView.swift:197）＝11年目に春新人A/B・夏中堅・寒梅が一斉に消え、6年目に若手限定賞が消える。実際の入口も出ない＝一致。

## §2 過去週の印（categoryLog）

### 中-1 GP シード（1回戦免除）の年も、第30週が赤い「GP1回戦」のまま
- 場所：CalendarView.swift:205-206（`gpRounds.contains → true`、資格・シードを見ない）／GameSession.swift:1184-1188（`gpSeeded: o.roundsPassed >= 3`）／WeekRunner.swift:163（シードは `gpStage = 1` から）
- 手順：前年に GP 準々決勝以上へ行く（ボット実測で約75〜80%の年が「準決勝まで通る」＝2年目以降は多くの年が該当）→ 翌年の第30週は大会が起きず自由行動（帯は第39週の GP2回戦まで数え直す＝正しい）。しかし日程表は第30週を朱の「GP1回戦」で塗り、過ぎた後も塗ったまま＝**やった稽古・バイトの判子が隠れ、長押しの文は「第30週 稽古。」と赤い大会の表示と食い違う**。凡例の「出られなかった大会は塗りません」にも反する。
- 既出か：157／calendar_ineligible_paint_1108 は「GP で落ちた後の週」だけを数えていて**シード週は未出**（同じ原因の仲間）。
- 直し方の案：①GP の回戦は、いま実際に出る回戦だけ塗る（`gpRoundsPassed` 以降の回戦）。過ぎた週は `categoryLog[w] == .taikai` の時だけ塗る＝157 案②と一体。②シード週だけ薄い「シード」の印に（判子は出す）。推奨①（表示だけ・golden 不変・テスト `PastWeekPaint1108Tests` に GP の列を足す）。

### 中-2 見送った・払えず出なかった道中の大会が、過ぎた週でも赤い「大会」のまま
- 場所：CalendarView.swift:181-192（`paintsPastWeek`／`paintsPastTournamentWeek`：HANA と推薦制だけ `category == .taikai` を見る。春新人・夏中堅・大阪戎・若手・寒梅は常に塗る）／同:117-119（長押し）
- 手順：大会の入口で「見送る」（StageViews.swift:228）、または出場費が足りず出られない → その週は自由行動（categoryLog＝稽古など）。過ぎると日程表は赤い「大会」を塗り、判子は隠れる。長押しは「第12週 稽古。」と出て、**赤い大会の表示と文が食い違う**。凡例「出られなかった大会は塗りません」は「出られなかった」を資格だけの意味で書いているので、見送りは説明が無い。
- 既出か：code_review_1108 #1 は推薦制だけ直した。hana_audit_1115 §6 は「HANA は実際に出た週だけ塗る」まで。**道中の大会の見送りは未出**。
- 直し方の案：①過ぎた週は全大会 `category == .taikai` の時だけ塗る（`paintsPastWeek` の HANA 限定を外す＝1行）。出た週だけ朱・出なかった週は判子＝凡例も「出た大会だけ塗ります」と素直に書ける。②今のまま（「予定されていた大会」として赤を残す）。推奨①。

### 低-3 長押しの文・凡例と実際の印の食い違い（小）
- 場所：CalendarView.swift:133（凡例は稽/バ/回の3つだけ）・:103（判子は `cat.label.prefix(1)`）・GameSession.swift:385,392（撮影週の稽古は休みに差し替え＝「回」）
- 手順：①オファーを受けた週の判子は「仕」（金）だが凡例に無い。②選択肢イベントで拘束された週（`preoccupyNextWeek`）は稽古が出来ず休みになり、判子は「回」＝画面の週メインは「出張中」「今週は撮影」なのに日程表は「回復」。
- 直し方の案：①凡例に「仕＝仕事」を足す（判子は4種）②「出張中」の週を別の印（仕）にする（GameSession の `categoryLog[week]` に preoccupied を見て `.offer` を入れる＝表示のみ）。どちらも任意。

### 低-5 結成11年目から大会が4つ一斉に消えるのに、知らせは5年目の若手限定賞だけ
- 場所：WeekMainView.swift:1527-1531（`caps.min()` ＝5 だけ。10年内の4大会には知らせが無い）
- 手順：10年目の次の年の年初、日程表から春新人A/B・夏中堅・寒梅の4つの朱が消える。理由の説明は画面に無い（凡例にも）。
- 直し方の案：①10年目の年初にも谷口の一言（「若手の大会に出られるのは今年が最後」と同型・1回だけ）②そのまま。判断が要る（文言）。

## §3 「次の大会まで n 週」の帯（GameSession.upcomingStages・WeekMainView.swift:1680）
- 資格の無い大会：入口と同じ `isEligible` で絞る＝出ない大会は数えない（推薦制は知名度30に届いた時点で現れる＝カレンダーの塗りと同じ時に変わる）。**正しい**。
- 見送った大会：自由週は `week > 今週` だけ＝見送った週・済んだ週は数えない。**正しい**。
- THE HANA：1回戦は毎年出る。2回戦以降は同じ年に前の段を通過した時だけ列に載る（通過した週の次の自由週から「HANA2回戦まで あと n 週」が出る）。落ちる・見送ると以後の段は載らず、次の GP などに移る。**正しい**。
- GP：`runner.gpRoundsPassed` 以降だけ載せる＝シードの第30週は数えない（帯は正しい・食い違うのは日程表＝中-1）。敗退後は回戦も決勝も外れる。準決勝敗退は敗者復活（第47週）に切り替わる。GP の後（第48週）は載るものが無く帯が「年末　今週！」（`weeksLeft = weeks − week = 0`）。第47週以前に GP が閉じれば「年末まで あと n 週」。**正しい**。
- 年末の帯の分岐（WeekMainView.swift:466-481）：`weeksLeft <= 0` の時だけ「今週！」。第48週の「年末　今週！」はそのまま読める。

### 低-4 帯は出場費を見ない＝所持金が2,000円未満だと GP の帯だけ「あと n 週」→突然消える
- 場所：GameSession.swift:731-735（`isGPAlive` だけ）／WeekRunner.swift:408（その年最初に出る回戦の週に所持金 < 2,000円なら `gpAlive = false`）
- 手順：夜逃げ寸前（所持金<2,000円）で GP 最初の回戦の週を迎える→帯は「GP2回戦まで あと1週」と数えていたのに、その週に何の画面も出ず自由行動になり、帯が次の大会／年末に飛ぶ。以後その年の GP は消える。
- 既出か：入口の出場費の食い違いは entry_audit_1115 で確認済みだが、帯の「飛び」は未出。実害は小さい（借金寸前の年だけ）。
- 直し方の案：①帯に「出場費が足りないと出られない」を足さずそのまま ②`upcomingStages` を所持金<出場費の時だけ GP 先頭を外す（ただし1回戦週より前の週は払えるかもしれない＝微妙）。推奨①（据え置き）。

## §4 年をまたぐ・15年目
- 年が変わる：`startNextYear`（GameSession.swift:1197）が `categoryLog = [:]`・`totalPrize = 0`・runner を新しい年で作り直す＝日程表は新年の第1週で全部空になる。`session.week` は pump の `default` 分岐で `runner.week` に揃う（GameSession.swift:1483）＝「X年目 第1週」が正しく出る。行動内訳帯（YearResultView.swift:240）は年末の `categoryLog` を読む＝その年の分だけ。
- 15年目（最終年）：`careerYearAtMost(10)`・`(5)` の4＋1大会は年数切れで塗られず、残るのは大阪戎・推薦制（知名度）・HANA（女コンビ）・GP6週。**崩れ・食い違いなし**（暦の言葉の件は AUTOPILOT 128＝既出）。
- 中断→復元：`categoryLog` は SaveData に載り（GameSession.swift:337,1259,1347）、種別を知らない週だけ捨てる緩い復号（:1989）。AppSaveFixtureTests が全 case を押さえる。結果を見せる段（`pendingResult`）の保存時点では `.taikai` が既に入っている（:1420 が `break loop` より前）＝復元後も印が欠けない。休みに差し替わった稽古（:401）・体調ダウンと療養（:1402）も保存前に入る。**問題なし**。

## §6 問題なし一覧
- 大会名・週・資格の突き合わせ（§1）／全大会の週の重なり0／長押しのトーストは過去週だけで押せる範囲は正しい。
- 稽古→休み差し替え（体力ゲート・お金不足・体調ダウン・撮影拘束）の判子は「回」で残る（GameSession.swift:385,401,1402）。療養週も「回」。
- 大会の週に出た時は `.taikai`（:1420）が行動の判子を上書き＝大会＞稽古の順で正しい。大会に出た週は自由行動が無い（`acted = true`）ので二重に数えない。
- 解散・夜逃げ週：`yearDone` で年が閉じる＝その週の判子は不要（年末の帯は別画面）。
- 「年末へ」の早送り（:1003-1021）：休みで進み、判子は「回」＝実際にした事と一致。
- 週の月表示（第1週＝4月・4週＝1か月・第47週＝3月第3週）は CalendarView.swift:210 と GameCore で矛盾しない。
