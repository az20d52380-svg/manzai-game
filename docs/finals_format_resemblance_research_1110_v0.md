# 決勝の形式が実在番組に似る件：調査材料（1110・v0）

結論（3行）
- 事例調査は検索8回の枠内で「確認できた」架空大会が2件止まり（下記§1）。「実在形式をどこまで使うか」の一般傾向は裏付け不足で、断定できない。
- 一般論として、番組の形式・ルール（アイデア）は著作権で守られにくい。守られやすいのは番組名・ロゴ・決め台詞に近い固有表現・セット等の具体的表現。だが本ゲームの指摘は法的リスクより「連想の強さ（印象）」の話。
- 推奨は②言葉だけ言い換え（固有性の強い語から）。形式は残し、寄席・和風の語感に寄せる。決めるのはオーナー。

## §2 権利の一般論（法的助言ではない。断定しない）
- 番組フォーマット（形式・企画）そのものは著作物になりにくく、日本では裁判例がまだ乏しいとされる。仕様書（バイブル）や具体的な美術・セット・映像は著作物になりうる、という整理が示されている。
- 一般不法行為での救済も、最高裁の厳しい解釈のため難しいとされる（近畿大学リポジトリの報告）。
- アイデアそのものは著作権の対象外、セットなど具体的表現の複製は侵害の可能性、という解説もある。
- 番組名・ロゴは、商標や不正競争防止法（周知な商品等表示の混同惹起）の問題になりうる。短い決め台詞は著作物性が否定されやすい一方、固有の言い回しを使うと商標・不競法・印象の面で問題になる余地がある（この点は検索で直接の裏付けが取れず、一般的な理解としての記述）。
- 実務上の線引き：形式（暫定席・敗者復活など一般語に近いもの）＞要注意度は低め／番組名・ロゴ・固有の決め台詞・特徴的な呼称・同じ見た目の再現＞高め。

## §4 オーナーへの選択肢
- ① 今のまま：形式も語も維持。長所＝作業なし・手触りの一貫。短所＝採点の「連想が強い」指摘が残り、将来の公開時に印象面で不利。形式は一般型の範囲という整理もあるので、公開予定が遠いなら選べる。
- ② 言葉だけ言い換え（推奨）：形式は残し、固有性の強い語（暫定席・敗者復活・日本一・漫才師の頂点・最終決戦）から寄席・和風の語へ。理由＝権利面の一般論でも印象面でも効果が大きい割に、ロジックを触らず安全。数字・バランスに影響しない（文言のみ）。
- ③ 形式も変える：段階構造・採点の見せ方も独自化。長所＝連想が最も薄い。短所＝大改修、golden・ゲームバランス・演出に波及（最大エフォート案件）。①②で足りない場合の次手。
