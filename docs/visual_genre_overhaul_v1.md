# 見た目と手触りを育成SLGの水準へ v1 — 統合の正本

## §0 結論（3行）

1. **「ちぐはぐ・暗い」の正体は、日常の物語（回想・イベント）まで本番の暗い紫で描き、本番も「闇に小さな部品が浮く」だけだったこと**。加えて**ゲームフォントが名前の食い違いで1文字も描かれていない**（`FontLoader.swift:27`）。どちらも絵を描き足さずに、週メインに既にある部品の水平展開で直せる。
2. 採用は**「昼は週メインの紙、本番は光る舞台」**：日常6画面は週メインの部品（白カード＋太縁＋ハード影・顔＋名札＋吹き出し・獲得チップ）で組み直し（B1）、本番5画面は暖色の客席の中に明るい舞台と金屏風を大きく置く（B2 を明るく寄せた版）。文字の段・コントラスト・送りの合図・飛ばせる待ちは B3 の規格で全画面を検収する。
3. 実装は**第1便（土台・不具合・オーナーが名指しした画面）約20日＋第2便（残り・仕上げ）約9日【仮】**、GameCore・golden・乱数は不変。オーナーに聞くのは3点（本番の地／決勝の採点の開き方／承認範囲）。

節構成：§1 オーナーの声／§2 リサーチ要約／§3 現状監査（画面×点数）／§4 採用案と要オーナー判断／§5 レッドの指摘と対処表／§6 画面別の実装計画／§7 やらないこと／§8 試遊の記録（Phase 7 で追記）

### §4-5 要オーナー判断（1論点ずつ・推奨つき）

> **オーナー判断（2026-10-09）**：Q1＝**A「暖色の客席に光る舞台」**（推奨どおり）／Q2＝**「M-1と同じく1人ずつ」**（推奨Cではなく現行の1人ずつタップを正典化。`finals_direction_v0.md` §2-2 に正典移行バナー）／Q3＝**第1便＋第2便の全部**（推奨どおり・第1便の後に試遊を挟む）。以下は判断前の記録。

**Q1. 本番（大会結果・決勝・優勝・タイトル・勇退）の地をどちらにするか**
- **推奨：A「暖色の客席に光る舞台」**（B2 を明るく寄せた版）。客席と幕は臙脂〜暖黒、舞台・金屏風・光の芯で画面の35%以上を明るくする。紫はゼロ、暗いのは溜めの1.5秒だけ。理由：①2026-08-01 のオーナー批評「全くM-1のエフェクトじゃない」を受けて今の決勝演出が作られた（X2-03）＝本番の格は「光る舞台」で出すのが筋 ②同ジャンルの前例も暗い会場から煌びやかなセットへ移った（R5）③日常との差（緩急）で本番が特別になる。
- 対案：B「全部明るい舞台」（B1）。地も明るく、緊張は寄り・幕・音の抜きで出す。ちぐはぐは最も消えるが、本番と日常の差が小さく、決勝が「普段の大会の色違い」に見える危険がある（X1-05）。

**Q2. 決勝の審査員7人の点の開き方**
- 事実：設計 doc は 2026-07-07 に「7人一斉オープン」をオーナー指示で確定（`docs/finals_direction_v0.md` §2-2）。現コードの「1人ずつタップ」は 07-17 の `3bb6b1e` が一斉の実装当日に変えたもので、オーナー指示の記録が無い（X2 付録A-1）。一方「1人ずつ」の画面は本作で一番点が高い（3.5点・X1-12）。
- **推奨：C「7枚を一斉に開き、合計は左から順に自動で足し上がる（約3秒・タップで飛ばせる）」**。確定済みの「一斉」を守りつつ、1人ずつの積み上げの手触りを残し、決勝のタップ数を最短18→約10に減らす。
- 対案：A 一斉（足し上げなし）／B 現行の1人ずつタップのまま。
