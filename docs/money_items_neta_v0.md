# お金・アイテム・ネタ育て v0（2026-10-12 夜・決定ではない＝選択肢と推奨）

> **【v1 移行バナー（2026-10-13）】お金とアイテムは `money_items_neta_v1.md` が優先。** オーナー決定「アイテムで能力は上がらない／お金で伸びるのは良い場所で練習した時だけ」で §2・§3 は置き換え。§4 ネタ育て step2 はこのまま有効。

出発点（オーナー 2026-10-12）：「休むもサウナとか金払って休めるイベント増やしたら？」「アイテムとか金使うとかも色々考えてね」「ネタ増やすとかあるけど、その要素全くなくない？ネタ育てるとか」「タイトル決めとかこっちでかけるように」。

## §0 要点
- お金は10年で約2800〜4000万余る（item_design_v0 §6）。使い道が「能力を買う」アイテムしかなく、それが強すぎる（勉強会が主因 §6-2）。
- 案：お金の使い道を**強さ以外**（時間・体調・相方・知名度・ネタ・見た目）に広げ、能力に直結する物だけ成長予算の中に入れる（推奨④）。
- ネタ育ては step1（選ぶ・題名を付ける・完成度の見える化）を作った（6710f5b）。step2 の候補は §4。

## §2 原則（オーナー判断・推奨＝A）
- **A【推奨】お金→能力の直変換は成長予算（器）の中。それ以外は自由**：どれだけ買っても伸びの総量は同じ上限＝帯が壊れない。お金は「早く・楽に・楽しく」育てる手段になる。
- B お金→能力も自由（値段と効果で調整）：調整が終わらない（§6 で値段3倍でも効かなかった）。
- C お金は強さに一切変えない（研究 replayability の禁輸リスト寄り）：お店の品の多くを作り直すことになる。

## §4 ネタ育て step2 の候補（オーナー判断）
1. **型を自分で選ぶ**（新ネタを書く時。型名は普通の言葉に言い換える：例「二人の言い合い」「最後に全部つながる」）【推奨：題名と並んで「自分のネタ」感が一番上がる】
2. ネタの見どころ（ネタごとに強い所1つ。大会の審査員の好みと合うと少し有利）＝審査員の好みの論点とつながる
3. 客前でかけた時の反応（よかった／いまいち）が出て、次の直しで伸びる所が変わる
4. 古いネタを寝かせて、数年後にかけ直す（保管庫はもうある）
5. 決勝の2本目を意識させる表示（決勝は2本要る）

## §5 推奨の順番
1. お金を払う休み（オーナー案・GameCore）→ 2. 持ち物 → 3. ネタの型選び → 4. 原則Aでアイテムを成長予算に入れる（item_design §6-2 ④と同じ）
