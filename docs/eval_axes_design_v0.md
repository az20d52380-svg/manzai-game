# 評価軸と手動能力アップの式 v0（2026-10-11・Opus 5.5）

> 位置づけ：作り直し v2 の②（`core_loop_reconsideration_v0.md` §7：評価が「審査員の好み・ネタの型・大会の形式」で変わる＋手動能力アップ）の**式の案**。オーナー判断（2026-10-11）「1年目は1回戦落ちが当たり前・数年たっても落ちる・道中大会も甘くない（低すぎはダメ）」を合格線に入れた。
> 材料：`balance_research_v2/` b1 §5・b3 §6（骨格はこの2本の提案と同じ）＋本書の実測（`tools/exp_eval_axes/`。sim_career を monkeypatch した試作で、正典ではない）。
> 数値は全て【仮】。コード・golden は未変更（規律Aは §8 の手順で別コミット）。

## §0 要点（3行）

1. **今の式の診断（実測）**：帯を測る正典ボットが v3 経済（5通貨）で壊れている。上手く育てると3年目以降ほぼ毎年「成長予算」が伸びを止める＝振り方で変わるのは能力の**形**だけ。今のラインは序盤の回戦と道中大会が数年で全勝になり、準決勝だけが壁（§1）。
2. **式の案**：実力値の重みを**その場に座る審査員**で傾ける（倍率形・7人そろうと中立・均等な育ちは不変）＋ネタの型×審査員の◎○△×＋尺の合う/合わない＋席の人数で変わるブレ＋**スベった夜**。乱数は今と同じ2本（§2）。
3. **難しさ**：ラインの引き直し（序盤を上げ、準決勝の手前に壁を順に置く）とブレの床で、試作の実測が「1年目は1回戦落ちが当たり前→3回戦→準々決勝→準決勝の壁が数年ずつ」になった（§4）。のんびり型が決勝に届かないのは経済の偏りが原因で、別に直す（§5・Q4）。

節の地図：§1 診断／§2 式／§3 係数の幅／§4 難しさの曲線と実測／§5 手動能力アップと経済／§6 採らなかった案／§7 連覇との関係／§8 実装手順と検証／§9 オーナーに聞くこと

### 1-4 経済の偏り（手動割り振りの前提を崩す）
- **閃き**はネタ作りでしか出ないのに、センス・発想・華の3能力が奪い合う。**胆力**は有料稽古（ネタ見せ会・ランニング）でしか出ず、センスの材料。→ 無料稽古中心の人はセンスが10年で12〜19のまま（ローテ・のんびり改）。
- **間合い**は余るので、どのボットも表現だけ伸びる（10年で72〜93、他は40台）。振り方の意図より経済の偏りが形を決めてしまう。
- 経済そのものはビルド間の差を作っていない（審査員・型・尺を全部切った試作で、5つのビルドの初回優勝が5.7〜7.0%で同じ）。差は §2 の式で作る。

## §2 式の案

### 2-1 式（1本）
```
score  = Σ_k w0_k × M_k(席) × 能力_k          … 実力値（審査員の傾き込み）
       + 相性
       + 型の相性(ネタの型, 席)               … ◎+2／○+1／△0／×−2 の席平均（ネタを選んだ時だけ）
       + 尺(ネタ, 大会)                        … 合わない −2（ネタを選んだ時だけ）
       + ネタ補正                              … 現行どおり（完成度・手応え・決勝2本目）
       + β(席) × ブレ                          … ブレ = 一様(±B)、B = 8 + 12×(1−メンタル/100)
       + ハマった夜 / スベった夜              … 同じ一様乱数で u<0.10 → +12、u≥0.90 → −10
       + 体力ペナルティ ＋ φ(大会)×知名度補正
通過   = score ≥ ライン
M_k(席) = 1 + α × (席に座る審査員の倍率 m_jk の平均 − 1) ＋ 予選の尺の傾き   … Σ_k w0_k·M_k = 1
```
- w0＝(センス.30・発想.30・表現.25・華.15) は今のまま。**能力が均等な組は、どの席でも実力値が変わらない**（行の Σw0·m=1）。
- **7人全員が座る決勝は中立**（7人の倍率の平均が各能力で1）。好みが合否に効くのは、席が少ない道中・準々決勝・準決勝。
- ネタを選んでいない本番（golden の台本）は「型の相性」「尺」が0。審査員の傾き・ブレ・スベった夜はネタの有無に関係なく効く。

### 2-5 ブレ・スベった夜
- ブレの幅 B＝8＋12×(1−メンタル/100)（今は 5＋15×…）。メンタル100でも±8残る＝「数年たっても落ちる」。
- 席の人数で倍率 β：予選1.1・3〜5人1.1・7人1.0・観客票0.85（b3 §6-1：個人の揺れは人数で薄まる）。
- **スベった夜**：ハマった夜の判定と同じ一様乱数の上端（u≥0.90）で −10。乱数の本数は今と同じ2本。強い組でもたまに落ちる（売れっ子が3回戦で落ちる、の再現）。

### 2-6 乱数・golden への影響
- 乱数は1回の本番で2本のまま（ブレ→ハマ/スベリ）。席は決定論、ネタの選択は乱数を引かない。
- ブレの式・スベった夜・ライン・席は全本番に効く → golden は再生成（規律A）。型の相性と尺は「ネタあり」の時だけ → gen_golden にネタを選ぶ台本ケースを足して式を固定する。

## §5 手動能力アップと経済（③の前提）
- アプリ：`GameSession.swift` の `autoPourAllocation = true` を false、のばす入口（`AllocationView`）を戻す。経験点は貯めて節目に一括（パワプロ式・作業化を避ける）。
- **おすすめは2つ**（b1 §5-4）：「万能（今のおすすめ＝最低値へ回す）」と「次の席に寄せる」。割り振り画面の見出しに、次の大会と今年の準々・準決の席。全リセットは不可（予算律速なので戻すと無意味）→ 代わりに「前回の振り方を呼べる」（周回）。
- **経済の手直し（Q4）**：閃きの一極集中と胆力の有料限定を直さないと、手動で振っても形が経済に決められ、のんびり型が決勝に届かない（§1-4）。候補：①センスのレシピから胆力を外す（閃き・間合い・語彙）②無料稽古のどれかに胆力を少し出させる（フリーライブ＝度胸）③閃きをネタ作り以外でも少し出す。試作で②だけでは足りなかった（センスが19止まり）→ ①＋②を sim で測る。

## §6 採らなかった案（試作で測った）
| 案 | 結果 | 理由 |
|---|---|---|
| ネタの型が能力の重みを変える（型ごとに使う能力が違う） | 特化型が均等の約3倍の優勝率（同じライン） | 型を選べる限り特化に損が無く一強化。育ちとネタ選びの二重計上（b1 §5-7） |
| b3 の差分表をそのまま使う | 華型が最強（予算あたり2倍得） | 成長予算が w0 換算のため（§2-2） |
| 成長予算を「生の伸び×0.25」の均等換算にする | センス型・発想型が均等の約2.5倍 | w0 の高い能力が予算あたり得になる |
| 型ごとのブレ倍率（飛び道具×1.35） | 決勝で飛び道具が常に得 | 決勝は下からの一発勝負なのでブレが大きいほど得（b1 P6 の符号反転を強める） |
| 甘辛を点に入れる（b3 の s 項） | — | ラインと二重。**表示点のバイアスのみ**（今のまま） |
| 相性の倍率（花園×1.5） | — | 相性はほぼ全員が3年で20に届く＝席の難しさが変わるだけ |
