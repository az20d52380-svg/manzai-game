# アート発注書 v0（画像生成AI用プロンプト集）

## §0 使い方（3ステップ）

1. 下の各プロンプトを **ChatGPT（画像生成）や Gemini にそのまま貼る**
2. 生成された画像を**指定のファイル名で保存**（PNG・立ち絵は透過必須）
3. `ManzaiGame/Resources/Art/` フォルダに入れて「入れた」と CLI に言う → 組み込みは実装側がやる

> 💡 コツ: 一発で理想は出ません。**3〜5回引き直して一番良いのを採用**。
> 気に入った1枚が出たら「このキャラのまま表情だけ◯◯に変えて」と追撃すると一貫性が保てます。

## §1 スタイル統一指定（全プロンプト共通・これがブレると台無し）

```
スタイル: 日本のスマホゲーム風のフラットなアニメ調イラスト。太めのアウトライン、
明るくポップな配色（クリーム・朱色・金色基調）、2.5頭身のデフォルメキャラ。
陰影はセル塗り2段階まで。実写・3D・劇画調は禁止。
```

## §2 発注リスト

### ① 俺（ツッコミ・青）の立ち絵 表情シート → `ore_sheet.png`

```
日本のスマホゲーム風フラットアニメ調で、漫才師の若い男性キャラクターの立ち絵を描いてください。
【キャラ設定】20代前半のツッコミ担当。黒髪短髪、青いジャケット（袖をまくっている）、
黒スキニーパンツ、白スニーカー。まっすぐ立って正面向き。全身が入ること。
【構図】同一キャラの表情違い3体を横に並べた「表情シート」：
左=通常（キリッと真顔）／中=笑顔（歯を見せて笑う）／右=焦り（額に汗・眉が下がる）
【仕様】背景は完全な透過（または単色グリーン）。太めアウトライン、セル塗り、
2.5頭身デフォルメ、明るくポップ。1枚の画像に3体、等間隔、同じサイズ。
```

- 保存名: `ore_sheet.png`（3面が入った1枚のまま・切り出しは実装側）
- 推奨サイズ: 横長・最低 1536×1024

### ② 谷口（ボケ・朱）の立ち絵 表情シート → `taniguchi_sheet.png`

```
（①と同じスタイル指定を貼った上で）
【キャラ設定】20代前半のボケ担当「谷口」。黒髪マッシュルームカット、
朱色（レッドオレンジ）のジャケット、ゆったりした黒パンツ。少し猫背で人懐こい雰囲気。
【構図】同一キャラの表情違い3体を横に並べた表情シート：
左=通常（ぽかんとした半笑い）／中=大笑い（目を閉じて大口）／右=真剣（ネタ帳を覗き込むような目）
【仕様】①と完全に同じスタイル・同じ頭身・同じ塗り。背景透過。1枚に3体。
```

- 保存名: `taniguchi_sheet.png`

### ③ キービジュアル（タイトル画面）→ `keyvisual.png`

```
日本のスマホゲームのタイトル画面用キービジュアルを描いてください。
【場面】夜の劇場の舞台。中央にセンターマイク1本。その両脇に漫才師の二人組
（青いジャケットの男と朱色のジャケットの男）が客席側を向いて立っている後ろ姿のシルエット。
頭上から一筋のスポットライト。舞台の縁の向こうに暗い客席。光の中に塵がきらめく。
【トーン】ドラマチックだが温かい。深い紺〜紫の闇、金色の光、朱のアクセント。
アニメ映画のポスター風。文字は入れないこと。
【仕様】縦長 2:3（スマホ縦画面）。
```

- 保存名: `keyvisual.png`・推奨 1024×1536 以上

### ④ タイトルロゴ「四分の夜」→ `logo.png`

```
日本のゲームタイトルロゴをデザインしてください。文字は「四分の夜」の4文字（縦書きでも横書きでも可）。
【トーン】漫才・お笑いの世界観だが、夜の劇場の情緒がある。太い筆文字とポップな丸文字の中間。
金色の縁取り＋白抜き文字、少し傾いた勢いのあるレイアウト。
【仕様】背景は完全な透過。ロゴ以外の要素（キャラ・背景）は入れない。正方形〜横長。
```

- 保存名: `logo.png`

### ⑤ アプリアイコン → `appicon.png`

```
スマホゲームのアプリアイコンをデザインしてください。
【モチーフ】暗い舞台に立つセンターマイク1本＋頭上からの金色のスポットライト。
下部に朱色の緞帳の縁がのぞく。シンプルで遠目でも分かる構図。文字なし。
【トーン】深い紺の背景・金の光・朱のアクセント。フラットで太い描線。
【仕様】正方形 1024×1024。角丸は不要（OS側で付く）。
```

- 保存名: `appicon.png`
