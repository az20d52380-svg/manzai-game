## §2 照合
1. 観戦版の帯：checkSpectatorFinal は「決勝週の自由週・決勝にも敗者復活にも出ない」で立てる。GP に最初から出なかった年・準決勝で敗れた年も含む。「予選敗退のため」は事実とずれる。
2. 順位・席：standings→prefix(3)、ousted は「前の上位3組にいて今は外れた組」＝文「暫定席を離れる／敗退」と一致。
3. 点：7人×100＝700（yearRoster のNPCは565〜662＝上限内）。表示の分母と合う。
4. 最終決戦：4票で決着し残りの札は後でめくる＝「4票先取」「王手」と一致。
5. 出場数：観戦は NPC10組・出場は NPC9＋自組＝どちらも「全10組」。

## §3 直し案（候補ブランチ claude/finals-screen-text-fix-cand）
- ×①（Presentation 306）：「※ 予選敗退のため、客席から決勝を観戦しています」→「※ 今年は決勝に進めなかったため、客席から観戦しています」（31字）。条件を言い換えるだけでロジックは触らない。

## §4 判断が要る論点
1. 番手：「第N番手」「N番目」「第N番」の3つ。「第N番手」に寄せる案（推奨・文字列のみ）。
2. 1本目の呼び名：「ファーストラウンド」「1本目」「決勝・1本目」。番組の用語の丸写し感があるなら「1本目」に寄せる案。決めるのはオーナー。
3. 「開票」：点の発表（7人開票）と最終決戦の票の両方。点は「採点」、票は「開票」に分ける案。
4. 頂グランプリ／頂GP／頂：tournament_result 採点 §4 と同じ論点。そちらの決定に合わせる。
5. 冒頭字幕「漫才師の頂点」：実在番組の売り文句に近いので「漫才の頂」等への言い換え案。
