# 0019「続けて落ちた週」の言い換え（2026-10-26・v0）

## §1 なぜ

- 0019（ChoiceEventKind.styleTalk）は大会に3回続けて落ちるたびに出て、1キャリアで約6回出るのに文面が1つしかなかった。
- 親が作った切り替え口 `styleTalkVariants`（`ManzaiGame/Sources/ChoiceEventData.swift`）に言い換えを3つ足した（元を先頭に残して合計4）。先例は `weekendInviteVariants`。
- 変えていないもの：場所（稽古場・昼）・発火の条件・選択肢の文字列（共通の定数 `styleTalkLabels` にまとめた）・効果の数値・A＝少し離れる／B＝離れずに毎日稽古する、という意味。
- 規律：manzai-drama-voice の v3 バナー（日常会話・お笑いの要素なし）。年数や季節の言葉、業界の言葉は使っていない。谷口は男女どちらの形でも自然な語尾（combo_gender §8 の型）。ビルドのエラーは0件。

## §2 4つの要約と採点

採点は v3 の6問（①台詞だけで場面が分かる ②話者が分かる ③1吹き出し2文以内・40字以内 ④ボケていない ⑤俺は相槌・心配・決定 ⑥ネタ本文なし）。
