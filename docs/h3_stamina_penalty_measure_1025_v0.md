体力<N％は「本番（perform 呼び出し）のうち、その時点の体力が N 未満だった割合」（全ボット合計の本番回数は各セル約 9〜10 万回）。A と B で割合がわずかに違うのは、案によって以降の経過が変わるため。

## 要点
- (10,-15) の段だけを外した案B は案Aとほぼ同じ：決勝は -1.3〜+0.4pt、10年優勝は -0.5〜+0.4pt で、n=1000 の誤差（約±1.3pt）の範囲。-15 の段の寄与は小さい。全部外す案C でも差が出たのは主にローテ（決勝 +9.7pt）と必要充足（優勝 +2.2pt）で、効いているのは主に <30 の -10 と <50 の -5。
- ボットが本番に体力<10 で出る頻度は、ローテ 8.1%・必要充足 7.0%・やり込み 6.7%・のんびり改 0.3%（<30 は 1.6〜15%、<50 は 22〜33%）。頻度は無視できないが、-15 と -10 の差（5点）では結果がほとんど動かない。
- 注意：ボットは体力<20 で稽古しない規則（STAMINA_GATE）を持つなど、人間とは体力の使い方が違う。人間が体力<10 で出る頻度はここからは分からない。
