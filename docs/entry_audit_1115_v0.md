## §1 指摘（新規3・既出2・全部 低〜中）

### E1【中・確信度 高・新規】夜行バスの体力の減りが、本番の点の減点に先に効く（入口の文は「体力を使う」だけ）
- 場所：WeekRunner.swift:213-215（交通の体力を `add(.体力, -25)` してから）→ 218 `GameEngine.perform`（GameEngine.swift:259-262 の `staminaPenalties` ＝体力50未満−5／30未満−10／10未満−15 を、バスで減った後の体力で判定）。画面は StageViews.swift:177-182・219「体力を使う」・208 の「体力が尽きた状態で出る」札（これは**今の**体力 ≤0 の時だけ）。
- 手順：体力 20 の週に大阪の大会（春新人賞A 等）→「夜行バスで出場」を押す。
- 見えること／実際：画面は札なしで「体力を使う」／実際は体力 20→0 になり、−15 の減点で本番（新幹線で出れば体力20＝−10）。体力 70 でも 70→45 で−5。バスは「お金が安い代わりに点も下がる」のに、点が下がることはどこにも出ない。
- 重さ：中（合否に効く・乱数は触らない表示だけの話）。
- 最小の直し：バスの副文を「体力を25使う（体力が減ると本番の点も下がる）」に。体力が `今−25 < 50` になる時だけ「バスだと体力〇〇まで下がる」と事実だけ添える（％や見込みは出さない）。判定は不変。
- 既出か：新規。`gate-stamina-*-cand` は稽古の体力ゲートの話で別物。

### E2【低〜中・確信度 高・新規】お金が足りないボタンは、必要額が消える
- 場所：StageViews.swift:262 `Text(enabled ? sub : "残高不足で出られない")`。
- 手順：所持金 11,000 円で大阪の大会 → バス（12,000）・新幹線（32,000）が灰色で、副文は両方「残高不足で出られない」。
- 見えること／実際：いくら足りないのか分からない（金額は `sub` にしか無く、無効時に捨てている）。見送るしか無いので、それ自体は正しいが、次の大会に向けて何円貯めればよいかが読めない。
- 最小の直し：無効時も「残高不足（あと ¥1,000）」のように必要額を出す、または `sub` の金額を残して先頭に「足りない」を足す。
- 既出か：新規（docs の「残高不足」は choice 系の話のみ）。

### E3【低・確信度 中・新規】入口の「出られない」は借金で出ることを許さないが、他の支出は借金を許す
- 場所：WeekRunner.swift:211 `state.money >= need`／UI の `enabled`。一方 bankruptLine=-1,000,000（GameConfig.swift:244）・飲みの誘いは借金で押せる（AUTOPILOT 224 行）。
- 見えること／実際：入口は「足りないと出られない」と明記（hintSpec 106 行）＝表示と実際は**一致**。ただし他の支出との整合は設計判断。そして出場で所持金が ほぼ0 になった週が生活費の週（4の倍数＝春新人賞Aは12週）と重なると、その場で借金（体力−10・メンタル−3）になるが、入口には何も出ない。
- 重さ：低（挙動は正しく、情報が足りないだけ）。
- 最小の直し：入口の所持金バーの下に、その週が生活費の週なら「今週は生活費 ¥14万 が引かれる」の1行（WeekMainView の livingHint と同じ文言）。判断が要る＝オーナー決定の案件。
- 既出か：新規。

### E4【中・確信度 高・既出】東京開催・動画審査でも「夜行バス」で数え、トロフィー「夜行バスの常連」が誤付与される

### 補足（指摘ではなく所見・低）
- 「六冠の年」（t22・Meta.swift:193）は「出た大会が5つ以上かつ全部優勝」なので、1〜2大会を見送れば取りやすい。説明文は「同じ年に出た大会をすべて優勝」で一致しているが、名前の「六冠」と、見送りで条件が緩む点がずれる。trophy_design_v1 §75-79（最難のグランドスラム）の意図に合うかはオーナー判断。直すなら「その年に出られた大会（出場資格があった大会）の全てに出て全て優勝」。既出ではない。

## §2 問題なしと確かめた主な所

- 出場費：入口の表示（東京＝エントリー費のみ・大阪＝交通費＋エントリー費）と `resolveTournament`（`entryFee` ＋ 大阪だけ `ts.cost`）は同じ式。金額は両方とも `config.calendar` から読む。hintSpec の金額（エントリー費・バス・新幹線・体力）も config 由来で本体と一致。
- 新幹線回数券：UI（211行）と WeekRunner（209行）が同じ条件で 交通費0・体力そのまま。回数券は年替わりで消える（Item.swift:84）。東京開催の大会では交通費は引かれない（`spec.osaka` のときだけ）。
- お金が足りない時：UI は無効化＋「見送る」だけが押せる。エンジンは払えなければ**何も引かず**不出場＝借金にはならない・二重取りも無い。足りないのに押せて通ってしまう経路は無い（`>=` の比較で UI とエンジンが同じ）。
- 体力が足りない時：体力 0 でも出られる（UI の札・hint「0のまま出ることもできる」と一致）。体力はエンジンで 0 に切り上げ（GameEngine.swift:52 clamp）＝マイナスにならない。ただし表示の「25使う」は体力 25 未満だと実際の減りより大きい（実害なし）。
- 出場資格：`isEligible` と `proceed` の判定（398-402行）は同じ。週の衝突（大会 12/15/27/29/35/38/46・HANA 32/37/42/44・GP 30/39/41/43/45/47）は無し＝同じ週に2つ入口が出ない。若手限定賞（5年以内）・推薦制中堅賞（知名度30以上）・10年以内の4大会は、入口に出る／出ないが `isEligible` で一貫。
- THE HANA：女性コンビだけ。2回戦以降は「その年に前の段を通過」した時だけ入口が出る（`hanaYear==year && hanaNext==i`）。1回戦を見送る・落ちると、その年は以降の段が出ない＝設計どおり。優勝後の再入場も無い。
- カレンダー・「これから出る本番」の一覧（GameSession.upcomingStages 737行・CalendarView 189-202）は同じ `isEligible` を使うので、入口に出ない大会が予定に載る／載らない不一致は無い（推薦制は知名度の変化で現在値の見え方が変わるだけ）。
- 見送りの扱い：不出場の週は `weekResults` に何も積まず（戦績・トロフィーの数えに入らない）、`acted=false` のまま自由行動週（稽古・休養）に進む。見送った大会の記録・賞金・知名度は無し。`fastForwardToYearEnd`（GameSession.swift:1008）・療養明け（RootView.swift:238）の自動見送りも同じ経路。連続出場の数えは本体に存在しない（FinalsBroadcastIntro 518 行のコメントどおり元データ無し）。
- 年10超：careerYears=15 で「10年以内」の4大会は11年目から入口に出ない（谷口の知らせは5年以内の若手限定賞だけ）。10年目の知らせは `youth-notice-y10-cand` が既出（点検対象外・既出扱い）。
- 二度押し・段違い：`decideTournament` は `.tournamentDecision` 以外では何もしない（懸念の台帳 L37）。
