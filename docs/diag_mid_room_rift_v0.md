# 診断：中の部屋に固定すると解散が増える（R2）v0 — 2026-10-19

**要点3行**
1. 推定は大筋で合う。ただし原因は「家賃で貯金が薄くなる」より手前で、**ボットの規則「所持金<15万→標準バイト」が中の部屋では永久に解けない**（家賃込みの月支出19万≒標準バイト約36週分の稼ぎ→稽古に回せる週がほぼ0）。ネタ合わせ（相性が上がる唯一の定常手段）が年0.3〜0.5週に落ち、相性が伸びず rift が溜まる。家で休む回復の増減や閾値の変化ではない。
2. **主にボットの罠**。「キツいバイト」に替えるだけで解散0%（ローテ・中の部屋・n=300）。人は rift 警告（50で予告）に「向き合う」でも解散52.7→16.7%。ただし人も「標準バイトだけ・貯金が薄いまま・予告を無視」なら同じ道を行ける（弱い罠）。
3. 直し案は表示・台詞が先（引っ越し確認に月収支、すれ違い警告の文言）。数値変更は決めない。

## §3 原因
1. 中の部屋の家賃は4週5万＝週1.25万。生活費14万/4週と合わせて月支出19万＝年228万。標準バイトは6.4万/週なので、稼ぐだけで**年約36週のバイト**が要る。48週のうち休む約10週（体力≤35で休む・大会前に休む・療養）を引くと稽古に回せるのは約2週。基準は支出168万＝約26週で、下積み後半はオファー収入で自立する。
2. ボット側の規則：必要充足＝`money<150,000 なら ("job","標準")`、ローテ＝同じ閾値、やり込み＝金策優先。所持金が家賃の後で15万を超えないので**閾値の下に居続け、稽古の選択肢が毎週消える**。月初に払う生活費で毎回15万を割る。
3. 相性は ネタ合わせ(+1)・相方と過ごす(+1)・イベントでしか上がらない。バイトと稽古(他)では上がらないので、バイト漬けの週は rift が `0.5×(上限−相性)/上限`（相性10なら約0.25/週）ずつ増え続ける。二人の舞台の週（ネタ見せ会・フリーライブ・大会）は増えないが、バイト漬けではその週も無い。
4. 家で休む回復の加算（+10）は効いてむしろ体力は保てる。ボットの休む閾値（体力35・大会前60/75）は部屋で変わらない。→ 推定にあった「閾値が部屋で変わる」は不成立。
- 結論：推定「貯金が薄くなりバイト週が増え、相性が伸びず rift で解散」は**合っている**。補足として、バイト週が増えるのは家賃が小さくないため（年60万＝標準バイト約9.4週分）だけでなく、ボットが「所持金15万未満→標準バイト」しか持たないためで、固定になる。

## §4 人も踏むか
追加実測（ローテ＋中の部屋固定、n=300）：

| 条件 | 解散 | 夜逃げ | 終了所持金(中央) | 終了相性 |
|---|---|---|---|---|
| そのまま（ボット） | 52.7% | 0% | 2万 | 13.7 |
| rift警告(50)に「向き合う」で応える | 16.7% | 0% | 41万 | 14.7 |
| バイトを「キツい」に替える | 0% | 0% | 1407万 | 19.9 |

- 「ボットだけの罠」の部分：①警告に応えない（実機は50で予告が出て選べる）②バイトを標準しか選ばない③閾値15万を守り続ける。人は①②のどちらかで避けられ、特に「キツい」は1週あたりの稼ぎ（9.6万／体力−30）が標準の1.5倍で、同じ体力コストで稽古の自由週が約14週に増える。
- 「人も踏む」部分：移る前に家賃が月収支にどう効くかが画面に出ない（R1①）。中の部屋に引っ越して、貯金が薄いまま標準バイトで回し続け、予告を読まずに流す人は同じ軌道に乗る（相性が伸びる手段を使う余裕が消えるため）。弱い罠：やり込みボットの100%は「金策優先」の方針が自分で首を絞めた結果。
- 判定：**主にボットの罠（人は避けられる）。人が踏むのは、引っ越し前の収支が見えないことと、警告を無視する場合のみ。**

## §5 直し案（決めない・表示や台詞で解けるものを先に）
1. 【表示】引っ越し確認画面に「毎月の収入と家賃の差し引き」「今の貯金で何か月持つか」「バイト何週分の家賃か」（R1①と同じ）。中の部屋の家賃は年60万＝標準バイト約9週。
2. 【台詞】すれ違いの予告（rift 50）の文言に「ネタ合わせを入れると相性が上がる」「相方と過ごすで回復できる」と手段を書く。予告のあと「バイトが続いて稽古に回せない」状況で谷口（相方）が一言触れる。
3. 【表示】バイト選択に「キツい＝1週あたり稼ぎ多い（体力−30）」を示し、貯金が薄い時に「稼ぎ重視ならキツい」と出す（式は変えない）。
4. 【表示】貯金が15万未満で2か月連続したら「部屋の家賃が重い」ヒントを出す。
5. 【数値（オーナー判断）】家賃を軽く（中の部屋4週5万→3〜4万）／引っ越し条件を「所持金≥家賃×N」に（R1②・auto の honest 線は N=26）。直す前に1〜4を入れて再測。
6. 【ボット側（計測用）】ローテ・必要充足に「家賃込みで貯金が薄い時はキツいに替える」を足すと、部屋の罠の過大評価が消える（式は変更しない）。
