## §5 案ごとの良い所・悪い所（1行）
- **今のまま**: 良＝帯が既知。悪＝最初の昇格が11〜32週（Smart の演技4は1年目に上がらない）。
- **GF0.7**: 良＝のんびり/ローテ/Balanced は 7〜8週で最初の昇格・決勝は +1〜2pt程度で帯はほぼ不変（解散も不変）。悪＝Smart の演技4は上がらないまま（74%全G）・Smart は 6週。
- **GF0.8 / GF0.9**: 良＝帯はほぼ今のまま（決勝 ±1pt）。悪＝最初の昇格がほぼ動かない（のんびり/Balanced は 11・19 のまま、演技4が20〜24週。ローテの演技4が24→18〜20週、全能力全G が少し減る程度）・Smart 解散が 6→7〜9%。
- **GF0.5**: 良＝4ボット中3が 6〜8週・センスF が Balanced で 2〜3%。悪＝のんびり/ローテの決勝が +2〜5pt、やり込みの決勝が 55→45%（ネタ込）・解散 6→8%と動く。
- **GF0.3（n=300のみ）**: 良＝3週で最初の昇格。悪＝早すぎ（3週）・やり込み決勝 56→36%・解散 12%。
- **GFE0.7/0.5/0.3**: GF との差は昇格週ではほぼ無し（最初の昇格は G→F の帯だけで決まる）。F→E 帯も下げると、のんびり/ローテの決勝が上に動く（GFE0.3 でのんびり 4→23%）。

## §6 所見（帯を崩さず最初の昇格を10週前後にできる案はあるか）
- **0.7 と 0.8 の間に崖がある。** G→F 帯 ×0.7 では 7〜8週、×0.8/×0.9 では今と同じ 11週（演技4は 18〜24週）。10週前後に当たる倍率は 0.7 台前半〜0.75 付近（0.8 では届かない）で、細かい刻みは未測定。
- **×0.7 は帯がほぼ動かず（決勝 +1〜2pt・解散不変）10週より少し早い 7〜8週になる。** ×0.5 は 6〜8週で帯が動く。×0.8/×0.9 は帯は動かないが昇格もほぼ動かない。
- **Smart の演技4は全案で上がらない**（×0.7 でも 74%、×0.9 で 81%）＝コストでなく配り方の問題。F→E 帯を下げても昇格週は変わらない。
