# 飽きの説明を実際の仕組みに合わせる（候補・週メイン採点 §4 論点①の推奨形）

## 仕組み
- 飽きはネタ単位（Neta.tiredYears・Neta.swift:52）。前の年に大会で掛けたネタだけ、年初に1段進む（WeekRunner.swift:150-157・しまったネタも同じ）。
- 1段につき本番の補正が1.0下がる（GameEngine.swift:278、netaTiredPenalty=1.0）。上限2段（GameConfig.swift:402-404）。
- 回復はしない（寝かせても戻らない・減らす処理なし）。新しく書いたネタは tiredYears=0 から始まる。
