# パワプロ サクセス育成画面UI調査 v0（2026-10-12）

注意：Web検索9回＋ページ取得。攻略サイト(altema等)は403で本文取得不可。画面レイアウトそのもの(配置・タブ)を書いた公開テキストは少なく、**確認できた事実**と**未確認**を分けて書く。未確認はゲーム内スクショ/実機で要確認。

## §1 メイン画面の構成（コマンド）
- 確認：初心者ガイドによるとコマンドは「練習／遊ぶ／能力アップ／イベント／練習試合／ドラフト／休む」。デートは彼女ができると解放。「ガイド」アイコンが進行アドバイスを出す。(bluestacks https://www.bluestacks.com/ja/blog/game-guides/commentary-powerful-professional-baseball/pow-beginner-guide-ja.html)
- 確認：2022のアオハル学園は「練習コマンドが無く、行動コマンドの中に練習や行事」。千将高校はキャプテンサークル配置・CP強化練習など、シナリオごとにコマンド体系が変わる。(famitsu https://www.famitsu.com/news/202204/21258779.html)
- 未確認：ボタンの配置(縦/横・位置)、「アルバイト」コマンドの有無(今回の資料に記述なし。お金は毎月のおこづかいという記述あり→§4)。

## §2 練習メニュー画面
- 確認：練習にカーソルを合わせると右側にその練習で評価が上がるキャラが出る。ケガ率と獲得経験点を目安にできる。光る練習＝仲間とのスペシャルタッグ(経験点多め)。赤い「！」＝優先候補/イベントあり。(bluestacks 上記)
- 確認：得意練習はキャラの左側に表示。得意練習アイコンが黄色になるとSPタッグ。監督の評価ゲージが青になるまで監督が見ている練習を追うのが基本。(famitsu 上記)
- 確認：練習機材レベルが高いほど経験点が増えるが消費体力も増える。同じ練習の反復/イベント/アイテムで上がる。(famitsu 上記)
- 確認：練習画面にケガ(故障)確率が表示され、体力が少ないほど上がる。体力が十分なら0%。ケガで能力値と経験点を失う。(gameranbu 2018 https://gameranbu.jp/pawapuro2018/e27d0aa89b2f4eeee321 ほか)
- 確認：複数キャラがいる練習を選ぶとまとめて評価が上がる(複数人=お得という見せ方)。

## §3 能力アップ画面
- 確認：経験点(練習・試合・イベントで得る)を能力アップで使う。「おまかせ」で基本能力と特殊能力にバランスよく自動振り分け。(bluestacks)
- 確認：コツ取得・成長系アイテム・センス100で、能力を上げる必要経験点が下がる(センス100で約15%減)。(famitsu / gameranbu https://gameranbu.jp/pawapuro2018/9aa7c4832826a42937f8 ほか検索結果)
- 未確認：画面上のボタン並び(＋/−の操作、能力一覧の並び順)。

## §4 アルバイト・お金・アイテム・お店
- 確認：毎月おこづかいが振り込まれ、主な使い道はショップ。ショップで道具や特殊能力の本(コツ/特能)を購入。推奨アイテムは練習効率/体力まわり(すけすけゴーグル等)。(famitsu)
- 確認：癒しタオル・トルマリンリングは体力消費減/回復増。パワマップ(公園)のイベントやショップで入手(2018)。(gameranbu 2018)
- 確認：アイテムは「チャレンジ」報酬でも入手(アプリ系ガイド)。
- 未確認：アルバイトコマンドの仕様、ショップを開く導線(どのボタンか)。

## §6 常時表示
- 確認できたのは「体力・評価・ポイント」が増減する表現のみ。日付・目標・やる気の画面上の位置は資料に記述なし。**未確認**。

## §7 1ターンの流れ
- 確認(断片)：コマンド選択→(練習は結果で経験点獲得)→イベント(固定/ランダム)で体力・評価・ポイントが増減。「休む」は体力60回復、一定確率で「ぐっすり眠る」(体力80＋やる気アップ、失敗時30)。(famitsu)
- 確認：赤「！」やガイド、光る練習など、「選ぶ候補をアイコンで絞る」工夫。「おまかせ」振り分けでタップ数削減。
- 未確認：演出スキップ等のタップ削減機能の詳細。

## §8 ウマ娘（短く）
- 確認：毎ターンの選択肢は5つ＝トレーニング／お出かけ／お休み／保健室(バッドステータス時のみ)／レース(デビュー後)。目標レースの時期はトレーニング等が選べずレースとスキルだけになる。(altema gamesystem 検索要約 https://altema.jp/umamusume/gamesystem)
- 確認：トレーニングは体力を消費(賢さのみ消費なし)、体力が少ないと失敗率が上がり、失敗でステータス低下＋練習ベタ。失敗率10%以上は避けるのが目安。お出かけでやる気を確実に上げられる。(https://altema.jp/umamusume/yaruki / https://gameranbu.jp/umamusume/791597c035b76c96a854)
- 確認：サポカの絆ゲージが約8割で得意練習が友情トレーニングに。選択画面の右上にサポカ/絆の情報。(altema ikuseikotu 要約)
- 未確認：体力/やる気/日付/目標の正確な画面位置。

## §9 漫才ゲームに移す時の要点
1. 選択肢は「毎ターン5〜7個」の固定コマンドに絞る。シナリオごとに増減させるのはパワプロ、ウマ娘とも共通。
2. 練習(ネタ作り等)の選択画面に「得られるもの＋失敗/ケガ率＋誰が来ているか」を1画面で並べる。ただし％表示は本ゲームでは冷めるというオーナー判断あり→率は段階表現(安全/注意/危険)や顔アイコンで代替を検討。
3. 「光る＝おいしい」「！＝優先」「ガイド」のアイコンで候補を絞り、悩む手数を減らす。
4. 休む/遊ぶ系は「回復量＋たまの大当たり(ぐっすり)」で単純な反復に揺らぎを入れる。
5. 能力アップは「おまかせ」ボタンを用意し、手動は上級者向け。
6. お金は毎月定額＋ショップ1か所に集約。アルバイトは未確認のため、導入するなら別途決定が必要(オーナー判断)。
7. 未確認の§5・§6(ステータス画面・常時表示位置)は実機/スクショ確認が必要。
