# 『寄席と計器（Yose & Gauge）』v2.0 実機画面デザイン監査レポート（第4巡・イベント会話群）

商業リリース基準（85点合格）に基づき、日常イベント会話画面11枚を厳格に審査しました。

## 47_0011_イベント会話_0011

### ① 点数
**76点**（不合格：あと9点）

### ② まだ設計どおりでない所
* **セリフ箱と下部ボタンの間の巨大な空白（Y: 530〜730pt付近）**：デザインシステム第1章「画面に無意味な余白を作らず高密度にする」および第8章9項「`Spacer()`で巨大な空白を空けることの禁止」に違反しています。ト書き1行の箱が上部に張り付き、その下に約200ptの無意味な生成り色の空き地が広がっています。
* **セリフ箱のハードシャドウ欠落**：`YoseHarigamiModifier` で規定された下方向のソリッド影（`yoseSumi`, `offset(y: 2)`）が見えず、枠線1pt程度の平板な箱になっています。
* **背景ビューの上下境界線**：ヘッダー直下および舞台ビュー下端の区切り線が細く、`yoseSumi`（2pt）＋`yoseKin`（1.5pt）の額縁感が不足しています。

### ③ 崩れ・AIっぽさ・初めての人が迷う所
* **街灯の光と場所札の干渉**：左上の場所木札「公園｜夜」の右端に、街灯の四角い光源（`Rectangle`）が食い込んで接触しており、レイアウト衝突（ニアミス）を起こしています。
* **街灯のラジアルグラデーションのAI臭**：ぼかした円形グラデーションがデザインシステムの「Blur 0（ハードエッジ）」のトーンから浮いています。
* **操作の迷い**：画面中央の空白が大きすぎるため、「ここに選択肢やイラストがまだ読み込まれていないのではないか」と初見プレイヤーが一瞬戸惑います。

### ④ 85点に届くための直す指示（優先順・3個）
1. **`EventSceneView`（背景画エリア）と `YoseSpeechBox`（ト書き・セリフ箱）の縦レイアウト再配分**：背景画エリアの高さを現在の約`280pt`から`340pt`へ拡大し、その分セリフ箱の最小高さ（`minHeight`）を`110pt`（3行分相当）に固定して、セリフ箱と「次へ 進む ▶」ボタンの間の空白を`24pt`以下に圧縮すること。
2. **`ParkNightBackground`（公園・夜の街灯パーツ）の座標修正**：街灯オブジェクト全体のX座標を右へ`+48pt`（`x: 110pt`付近へ）移動させ、左上の場所木札（`YoseKifudaCard`）との間に最低`16pt`のクリアランスを確保すること。また、光源のぼかしグラデーションを廃止し、透過度を変えた2段階のソリッド円（`opacity(0.15)` / `0.08`）に変更すること。
3. **`YoseSpeechBox`（ナレーション・ト書き枠）の枠・影の強化**：外枠を`YoseColor.sumi`の`2.0pt`、左端の臙脂帯を幅`6pt`、下影を`YoseColor.sumi`で`offset(y: 2)`に厳密適用し、背景色を`YoseColor.washi`（`#FBF8F1`）に明るくして地色（`yoseKinari`）とのコントラストを出すこと。
