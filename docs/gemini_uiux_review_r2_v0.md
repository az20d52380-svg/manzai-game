# 【辛口UIレビュー】「パワプロ」「ウマ娘」になれず「業務管理ツール」で止まっている

売れているスマホ育成ゲーム（パワプロのサクセス、ウマ娘など）のUIデザイナーとして、容赦なく辛口でレビューします。

前回の設計図（`docs/gemini_uiux_answer_v0.md`）の意図が半分も消化されていません。
現状の画面は、**「WebエンジニアがTailwind CSSで作った社内管理画面」**あるいは**「確定申告アプリの試作品」**に見えます。プレイヤーがワクワクして何百時間も周回する「ゲームの手触り」が完全に死んでいます。

---

## ① 設計図どおりになっていない所（仕様の無視・実装の破綻）

### 【週メイン画面（g1_week.png）】
1. **「体力の表現」の完全な無視**
   - 設計図で「無機質な細いプログレスバーはダウンロード中に見えるから廃止。湯呑みや提灯で表現せよ」と明記したのに、一番下にあるのは**ダークグリーンの細い無機質バー**そのものです。退屈極まりない。
2. **情報カードの重なり事故（致命的なレイアウト崩壊）**
   - 「春新人賞A あと11週」の焦茶色バナーが、下の「実力・相性」の白いカードに斜めに突き刺さって重なっています。デバッグすらしていないレベルの表示崩れです。
3. **情報の二重表示**
   - ヘッダーに「1年目 第1週」とあるのに、一番下のフッター帯にも黄色で「1年目 1週」と重複して表示されています。画面の貴重な縦領域を無駄遣いしています。
4. **「貼り紙」ボタンの形骸化**
   - 「木札や貼り紙の質感」を指示したはずが、ただの「白い角丸長方形の左端に赤い1本線を引いたWebコンポーネント」になっています。

### 【能力アップ画面（g1_allocate.png）】
1. **マトリクスの列（X座標）がズレている（致命的UI欠陥）**
   - 上段の「所持経験点（丸アイコン5つ）」と、下段の消費ポイント表（8, 0, 6, 0, 4...）の**縦列がまったく揃っていません**。プレイヤーは「この8は、閃なのか語なのか？」をいちいち目線を行き来させて照合させられます。パワプロのUIの基本である「Gridの厳密な垂直整列」が守られていません。
2. **ボタンの主客転倒（一番目立つべきボタンが沈んでいる）**
   - 設計図で「『確定』のみ臙脂（または金）で太く」と指定したのに、**なぜか一番明るい朱色で目立っているのは「おまかせ」**です。プレイヤーが一番押したい「確定」は暗い臙脂色で文字が背景に沈んでおり、押していいのか迷います。
3. **パステルカラーの逆戻り**
   - 排除を求めたはずの水色・紫・ピンクなどのOS標準パステルカラーが、経験点アイコンや細いゲージにそのまま復活しています。
4. **「+を押すと1つ上がる」という無駄な説明文**
   - ゲームUIにこんなサポート窓口の案内文のようなテキストは不要です。デザインの機能性で直感的に伝えるべきです。

## ② まだ『AIが作ったっぽい』所（テンプレ臭・均一性・演出不足）

1. **「等幅・等間隔・同じ線幅」の機械的配置**
   - コマンドボタンも、ステータスカードも、能力アップの行も、すべて「同じ高さ、同じパディング、同じ角丸」で機械的に割られています。「ゲーム画面」には必ず**「主役（今一番見てほしいもの）」**と**「脇役」**のダイナミズム（強弱）が必要ですが、すべてが等価に並んでいるため視線が迷子になります。
2. **文字で説明しようとしすぎ（記号・ビジュアル言語の不在）**
   - 「今週は撮影」「お金を稼ぐ」「経験点で能力を上げる」「+を押すと1つ上がる」。画面が注記テキストだらけです。ウマ娘やパワプロは、アイコン1つ、色1つ、バッジ1つで直感させます。文字が多すぎて「読むゲーム」になっており、「触るゲーム」になっていません。
3. **物質感（テクスチャ・重み）の欠落**
   - 画面全体がフラットなデジタルベタ塗りです。和風・寄席をテーマにしているのに、紙の温かみ、木札の厚み、インクの滲み、押したときの物理的な「カチッ」という手応えが一切感じられません。
4. **数字の「躍動感」の無さ**
   - 「115」「42」「140」といった数字が、銀行アプリの残高明細と同じ冷たさです。育成ゲームの醍醐味は「数字が跳ねる快感」です。数字のフォントサイズ、ウェイト、袋文字（アウトライン）の工夫が足りません。

## ③ 画面ごとの改善指示 TOP5（SwiftUI実装レベル）

---

### ■ 週メイン画面（`g1_week.png`）改善指示 TOP5

#### 1. 【最優先】目標バナーと実力カードの重なり解消＆「木札化」
*   **問題**: 「春新人賞A」のバナーと「実力/相性」の白い枠が被って大事故を起こしている。
*   **実装指示**:
    *   上部に「目標看板（横幅いっぱい）」を独立して配置。
        *   背景: `Color(hex: "3E1F18")`（濃茶）、金縁（`Color(hex: "C1A550")`, 幅: 1.5pt）。
        *   「春新人賞A まで あと11週」を金文字・Bold 16ptで中央配置。
    *   「実力」「相性」は別枠にし、画面右上に**縦長の木札**として配置（ZStackで背景右上にピン留め）。
        *   サイズ: `width: 90pt, height: 110pt`
        *   背景: `Color(hex: "E8D8BA")`（木札風の薄茶）＋右下に黒のシャドウ（`radius: 0, x: 2, y: 2`）。
        *   実力数値を特大の26pt Heavy DinCondensedで墨色（`#2B2B2B`）表示。

#### 2. 【脱・無機質】下部ステータスの「提灯ゲージ」化
*   **問題**: 一番下の体力バーがダウンロード中ゲージになっている。
*   **実装指示**:
    *   細いプログレスバーを即座に破棄。
    *   最大体力100を「5つの提灯アイコン（または俵アイコン）」の横並び（HStack, spacing: 4）で表現。体力20ごとに提灯が1つ点灯。
    *   点灯色: `Color(hex: "2E583C")`（満タン時は緑）、ピンチ時（40以下）は`Color(hex: "BD3C28")`（朱色に発光点滅）。
    *   残り体力数値は「100 / 100」として提灯の横に白抜き文字（14pt Bold）で添える。

#### 3. 【触感向上】コマンドボタンの「貼り紙・木札」化と非活性演出
*   **問題**: ボタンが安っぽい白いWebコンポーネント。利用不可の「今週は撮影」が文字だけで分かりにくい。
*   **実装指示**:
    *   ボタン基本形状:
        *   背景: `Color(hex: "F7F3E8")`（生成り）。角丸はあえて小さく `RoundedRectangle(cornerRadius: 3)`。
        *   枠線: `Color(hex: "2B2B2B")`（墨色、幅: 1.5pt）。
        *   立体感: `.shadow(color: Color(hex: "C8BFA8"), radius: 0, x: 0, y: 3)` で厚みを出す。
        *   タップ時: `offset(y: 2)` で物理的に沈み込ませる（自作`ButtonStyle`）。
    *   「今週は撮影」等で押せないボタン:
        *   ボタン全体を暗くするのではなく、ボタンの上に**赤い「休演」または「出張中」の斜め千社札テープ**を上からペタッと貼るデザイン（Rotation: -12度、背景: `#BD3C28`、白文字8pt Heavy）。文字で言い訳せずビジュアルで「選べない」ことを伝える。

#### 4. 【重複削除】フッターとヘッダーの整理
*   **問題**: 「1年目 1週」が上下に重複。
*   **実装指示**:
    *   フッターの黒帯から「1年目 1週」を完全削除。
    *   フッター黒帯（`Color(hex: "2B2B2B")`）には「所持金（金文字 `#C1A550` で ¥500,000）」と「体力提灯」のみを収め、高さを `60pt` から `44pt` にスリム化。
    *   空いた縦領域を使って、真ん中の「舞台ビジュアル（コンビの背中とセンターマイク）」を縦に広げ、臨場感を出す。

#### 5. 【キャラ立ち】セリフ吹き出しとキャラアイコンのブラッシュアップ
*   **問題**: 谷口の丸いアイコンがTwitterのアバターのようで世界観に合わず、吹き出しがマイクの前に不自然に浮いている。
*   **実装指示**:
    *   アイコン枠: 単なる白丸をやめ、**寄席の「名札（木札枠）」**にする（角丸4ptの正方形、枠線墨色2pt、名前「谷口」を座布団風の赤い帯に乗せる）。
    *   吹き出し: 背景を `Color(hex: "FDFBF7")`、枠線 1.5pt 墨色。逆三角形のしっぽを谷口のアイコンに向けて明確に出す。フォントは明朝系・中太（15pt）。

### ■ 能力アップ画面（`g1_allocate.png`）改善指示 TOP5

#### 1. 【最優先・Grid整列】所持経験点とテーブルのX座標完全一致
*   **問題**: 上の丸アイコンと下の数字テーブルの位置がズレていて、どの数値を消費するのか瞬時に判別不能。
*   **実装指示**:
    *   画面幅全体を `Grid(alignment: .center, horizontalSpacing: 8, verticalSpacing: 6)` で構築。
    *   列の比率を厳密に固定:
        *   第1列（能力名・現在値）: 幅 `70pt`
        *   第2列（＋ボタン）: 幅 `50pt`
        *   第3〜7列（閃・語・間・存・胆）: 各幅 `42pt` 等幅
    *   ヘッダー（現在の経験点）もこのGridの3〜7列目に丸アイコンを配置。下の消費数字と**ピクセル単位で中心線を垂直一致**させる。
    *   アイコン色: 水色やピンクを廃止。和の五色で統一。
        *   閃: `#D4A017`（金茶） / 語: `#1F5E5B`（青緑） / 間: `#4A2E6D`（紫紺） / 存: `#A63A2A`（弁柄） / 胆: `#2A4B7C`（藍色）

#### 2. 【主客転倒の是正】「確定」ボタンの最大強調と「おまかせ」の格下げ
*   **問題**: 「おまかせ」が主役の朱色で、「確定」が沈んでいる。
*   **実装指示**:
    *   ボタン4つの横並び構成を見直す:
        *   左側: 「戻る」「リセット」（幅: 各 `60pt`、背景: `Color(hex: "E8E2D2")` 生成りグレー、文字: 墨色）
        *   中央: 「おまかせ」（幅: `80pt`、背景: `Color(hex: "F5F0E1")`、枠線: 朱色1pt、文字: 朱色14pt）
        *   右側（主役）: **「確定」（幅: 残り幅いっぱい・最低 `130pt`、高さ: 52pt）**
    *   「確定」ボタンの装飾:
        *   背景: `Color(hex: "BD3C28")`（鮮やかな朱）またはグラデーション（`#BD3C28` → `#8B1E0F`）。
        *   文字: 20pt Heavy 白抜き ＋ 金のシャドウ。
        *   立体感: 下部に `Color(hex: "6A1207")` の3pt押し出し影。
        *   1ptでも能力を上げているときは、確定ボタンの周囲に金色のパルスアニメーション（外枠がゆっくり光る）を付与。

#### 3. 【ゲームの手触り】［＋］ボタンの物理感と数値跳ねアニメーション
*   **問題**: ［＋］がただの平べったい四角で、押した快感がない。
*   **実装指示**:
    *   経験点が足りて押せる行の［＋］:
        *   背景: `Color(hex: "BD3C28")`（朱色）。
        *   下部に `2pt` の濃い影（`#7A1F13`）。
        *   タップした瞬間に `UIImpactFeedbackGenerator(style: .medium).impactOccurred()` を発火。
        *   タップ時、対象の能力値（例: 「43」）が `scaleEffect(1.3)` に0.1秒膨らんで元に戻る（スプリングアニメーション）。
    *   経験点が足りず押せない行の［＋］:
        *   背景: `Color(hex: "D0CBC0")`（銀鼠）。
        *   文字色: `Color(hex: "9E988D")`。
        *   影をなくし、完全に「平面的で押せない状態」であることを一目で分からせる。

#### 4. 【格付けの重み】ランク表示（D, F, A...）のエンブレム化
*   **問題**: ランク表示が単なる薄い四角い枠に文字が入っているだけで、Excelの表のよう。
*   **実装指示**:
    *   上部のランクボックス（センス〜メンタル）の装飾:
        *   四角い箱をやめ、**将棋の駒型**または**六角形エンブレム**にする。
        *   ランク文字（S, A, B, C, D, E, F）のフォント: 24pt Heavy（Din Condensed）。
        *   ランクに応じた色分け（パワプロ・ウマ娘の文法）:
            *   **S**: 金背景（`#C1A550`）＋白文字
            *   **A**: 赤背景（`#BD3C28`）＋白文字
            *   **B**: 橙背景（`#D97724`）＋白文字
            *   **C**: 緑背景（`#2E583C`）＋白文字
            *   **D〜F**: 藍・グレー背景（`#5A6265`）＋白文字
    *   「Cまで2」のゲージ: バーの背景を墨色にし、ゲージが満タンに近づくにつれて金色に発光させる。

#### 5. 【説明文の排除とプレビュー表示】「実力 42」エリアの刷新
*   **問題**: 「実力 42　+を押すと1つ上がる」という文字が非常に素人くさい。
*   **実装指示**:
    *   「+を押すと1つ上がる」の注記テキストを即刻削除。
    *   「実力 42」のカード全体を**「巻物」または「黒板」風**のプレート（背景: `#2B2B2B` 墨色、枠線: 金色1.5pt）に変更。
    *   能力を＋した際、実力値の横に**緑色の太字で「(+3) → 45」**とリアルタイムでプレビュー表示（緑色 `#38A169`、点滅フェードイン）。
    *   「確定を押す前に、どれだけ強くなるかが一目でわかる快感」を作る。

## デザイナーからのまとめ

ゲームUIの本質は、**「プレイヤーの指先に快感を与えること」**と**「0.1秒で状況を理解させること」**です。

現在の画面は「要素を言われた通りに並べただけのワイヤーフレーム」に過ぎません。まずは**「Gridの垂直整列」「確定ボタンの最大強調」「提灯ゲージ」「数字の躍動感」**の4点を改修してください。これが入るだけで、一気に「商業レベルの育成ゲーム」の顔つきに化けます。
