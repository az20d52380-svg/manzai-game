## §2 同じ言い回しの上位5つ（50本中）
1. 「山の場面」9回（#3・7・17・21・25・28・29・30・43）。型なし語彙の「中」4語（展開・転換・山・真ん中）のうち、固定文との相性で山が選ばれやすい。
2. 「つかみの入り」7回（#2・11・22・28・34・43・47ほか）。「つかみ」と「入り」が同義で、冒頭を指す語がほぼこの1語に寄る。
3. 「結末の締め」5回（終盤・オチ・幕切れの締めも計8回）。「締め」の口が4語とも似た位置を指し、変化が弱い。
4. 「審査員の顔して座ってたのに、{中}で普通にお客さんになってた。ごめん、仕事する。」3回（#3・7・50）。同文が3本。
5. 「真ん中の場面」4回、「一つ目/合いの手/返しのツッコミ」計6回。ツッコミの口は1語ずつ分散しているが、「ツッコミ」自体が全体で6回出る。
