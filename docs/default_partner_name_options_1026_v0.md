# 相方の既定名「谷口」と女性の形 — 選択肢 v0（2026-10-26・材料のみ・決定ではない）

キュー126 の材料。発端は docs/female_kind_audit_1025_v0.md の低「既定の相方名 谷口は男寄りの響き」。

## §1 いまの作り
- 既定名は `Names.defaultPartner = "谷口"`（ManzaiGame/Sources/Names.swift:14）。名前欄は自由入力（6字まで）。
- データ側（台詞・イベント・講評など）には「谷口」が約395か所 直書きで、`Names.show` が表示の時に入れた名前へ差し替える。既定名を変えても差し替えの口は1か所。

## §2 見立て
- 「谷口」は**名字**で、名字には男女の別が無い。女×女・相方が女の形でも、名字で呼び合うコンビは自然。
- 監査の「男寄り」は、これまで男の相方として描いてきた印象によるところが大きい。

## §3 選択肢
| 案 | 中身 | 良い所 | 気になる所 |
|---|---|---|---|
| ①（推奨）今のまま | どの形でも「谷口」 | 手間0・名字は男女どちらでも通る・台詞の一貫性 | 「谷口＝男」の印象が残る人もいる |
| ② 相方が女の時だけ別の名字 | 例：女の相方の既定を別の架空の名字に（候補はオーナーが決める） | 形を選んだ手応えが出る | 名字に男女の別は無いので、変える理由が説明しにくい。台詞の差し替えは `Names.defaultPartner` を形で返すだけ（1か所） |

## §4 推奨の理由
①：名字は男女共通で、直す必要が薄い。どうしても形の手応えを出したいなら②（実装は1か所・30分程度）。
