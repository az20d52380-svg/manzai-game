# 本体マージ後のお金と会場の段（測り直し） v0

要点
1. 部屋＋アイテム＋特技の全部入りでも、10年目の所持金は中央値 約580万（やり込み・のんびり）〜1400万（ローテ・必要充足）。以前の「使わない約2040万」から2〜4割減に留まり、会場の段はローテ・必要充足で95〜97%がまだドーム（800万以上）。
2. ボット4種のうち段が働くのは、元々稼ぎの少ない のんびり改・やり込み（ドーム15〜18%・300〜800万が77%）だけ。ローテ・必要充足は吸い込み口がまだ足りない。
3. 決めない：選択肢と推奨理由は §3。

節：§1 条件と測り方／§2 表／§3 所見（吸い込み口・会場の段・選択肢）

## §1 条件と測り方
- スクリプト `tools/exp_money_after_merge_v0.py`（式・既定値は変えない。部屋は R3-8_H10-20＝家賃3/8万・体力+10/+20、アイテムは回復ドリンク大・衣装・喉ケア＝値段の3倍以上ある時に買う、特技は5種を上から覚える、体調ダウン§97入り。q90/q103/q106 の近似を1本に統合）。
- ボット：のんびり改／ローテ／必要充足／やり込み。条件：none（使わない）／room（部屋だけ）／all（部屋＋アイテム＋特技）。ネタ無し・込み。n=1000/ボット（n=300 の事前走行と同傾向）。
- 所持金は万円で Q1/中央/Q3。10年目＝10年目まで続いた人のみ（括弧は人数）。会場の段は終了時の所持金で <0／0〜300／300〜800／800以上（＝ドーム）の%。run_career は初優勝で打ち切るので、終了時所持金も併記（ほぼ同じ）。
- 生の出力：`docs/measure_raw/money_after_merge_n1000.txt`

## §3 所見
- 吸い込み口：全部入りでローテ・必要充足は中央値約1340〜1370万残る（Q1でも1100万超）。部屋・アイテム・特技の合計で削れたのは約700〜800万（none 約2100〜2180万比）で、足りない。以前の部屋単独（約1150万）より更に下がったが帯は動かない。
- 会場の段：none は のんびり改84%・ローテ/必要充足100%・やり込み57%がドーム。全部入りでもローテ95%・必要充足97%。段が働くのは のんびり改・やり込み（ドーム15〜18%、300〜800万が約77%）だけ＝稼ぎ方で段が分かれる状態にはなっている。
- 決勝到達はアイテム・特技入りでやり込みが 55→67% と上がる（体調ダウン軽減が効く）。お金を使う物が強さにも効く点に注意。
- 選択肢（決めない）：
  A. 吸い込み口を足す（単独ライブの段階買い等・推奨）。理由：全部入りでもローテ/必要充足が1300万超残り、お金の使い道としての意味が薄い。ただし能力へ変換しない形に限る。
  B. 会場の閾値を上げる（例 800万→1500万。ローテ/必要充足の約半数が1段下に）。理由：実装が軽く、段の演出がすぐ働く。のんびり改・やり込みは大半が下の段になる点に注意。
  C. 何もしない。理由：やり込み・のんびり改では段が既に働き、稼ぐ人ほどドームという筋は通る。
  推奨：A を主、B を補助（A の後に分布を測り直してから閾値を決める）。
