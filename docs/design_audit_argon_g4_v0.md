## 47_0011_イベント会話_0011.png

### ① 点数
**24 / 100点**（商業リリース不可・イベント会話レイアウト未完成）

### ② デザインシステムから外れている所
* **カプセル型（`Capsule`）タイトルバッジの使用（§4-2・§8-1違反）**：「月末の飲み会」の帯が完全な丸ピル型（`Capsule`）かつ金グラデーション＋白枠＋ぼかし影（Blur）で作られており、禁則事項に直撃している。
* **ヘッダー帯の欠落（§5-①・§7違反）**：画面最上部に `YoseHeaderBar` がなく、SafeArea下がすぐイラスト背景になっており、現在の週数やイベント種別が不明。
* **テキストボックスの角丸・枠線・書体違反（§3・§4・§5-⑨違反）**：ト書き枠の角丸が約 `10pt` と丸く、枠線が薄いベージュ（1pt）＋ぼかし影になっている。文字もゴシック体（システムフォント）で、`YoseSpeechBox` / `.yoseHarigami()` の「明朝体 `15pt`・墨枠 `2pt`・角丸 `2pt`・ハードシャドウ `y: 2pt`」が一切守られていない。
* **画面下半分（約420pt）の完全空白（§1「高密度・高コントラスト」違反）**：Y座標450pt〜852ptまでが `yoseKinari` の無地空間として放置されており、画面が未ロードのように見える。

### ③ AIっぽい所・UXの分かりにくさ（初めての人が迷う所）
* **後ろ姿の「青・赤こけし図形」（§8-4違反）**：首元の横線と丸頭だけの青・赤カプセル人間が並んでいる光景が、典型的なAI生成プリミティブ絵に見える。さらに「月末の飲み会（帰り道）」なのに居酒屋の提灯や夜道の情緒がなく、茶色い床とピンクの壁の謎空間になっている。
* **操作アフォーダンスの欠如**：「稽古場の帰り道。月末の夜。」の1行だけで画面の半分以上が空白のため、プレイヤーは「テキスト枠の中だけをタップするのか、画面のどこを押しても進むのか、選択肢が下に出るのか」が直感的に分からない。また、オート/スキップやバックログ等の会話補助UIも皆無。

### ④ 直す設計図（優先順）
1. **イベント見出しをカプセルから「ヘッダー帯＋黒漆看板」へ変更**
   * **部品**：`YoseHeaderBar(title: "日常イベント")` を `[000-048pt]` に配置。舞台エリア上部（`y: 60pt`）には `Capsule` を廃止し、角丸 `0pt` の黒漆箱（背景 `yoseKuroUrushi`、外枠 `yoseKin` `2pt`、内枠 `yoseSumi` `1pt`、ハードシャドウ `y: 2pt`、高さ `36pt`、水平パディング `16pt`）で「月末の飲み会」（`YoseFont.gothic(17, weight: .heavy)`、色 `yoseKin`）を掲げる。
2. **会話・ト書き枠を `.yoseHarigami()` / `YoseSpeechBox` に統一し、舞台直下へ拡大配置**
   * **部品**：`YoseSpeechBox`（ト書き時は話者札を `roleLabel: "情景"`・文字 `"―"` または左端 `6pt` の `yoseEnji` 縦帯つきの `.yoseHarigami(isFeatured: true)`）を使用。
   * **配置・寸法**：左右マージン `14pt`（幅 `365pt`）、最小高さ `110pt`（3行分確保）、角丸 `2pt`、外枠 `yoseSumi` `2pt`、下影 `y: 2pt`（Blur `0`）。
   * **文字**：`dialogueBody`（`YoseFont.mincho(15)`、行間 `6pt`、色 `yoseSumi`）。右下の送り三角（`▼`）は `yoseShu`（`#BD3C28`）で `10pt`。
3. **画面下半分の空白を埋め、ステータス帯＋進行ガイド（または選択肢枠）を常設**
   * **部品**：`[756-792pt]` に `YoseVitalMoneyBar` を常時表示し、イベントによる体力・所持金の増減が即座に分かる計器構造にする。会話領域の下部（`[520-740pt]`）には、選択肢がないターンでも「太鼓紋章＋『画面をタップして次へ ▶』」の控えめな木札ガイド（`yoseKiDark` 枠）または会話ログ2行プレビューを置き、420ptの虚無空間を解消する。
4. **背景イラストの夜道・居酒屋ディテール補強と墨枠区切り**
   * **配置**：舞台ビュー（`[048-360pt]`）の下辺は `yoseSumi` `2pt`＋`yoseKin` `1.5pt` の二重線で引き締める。背景のピンクグラデーションを廃止し、夜道（`yoseKuroUrushi` ベースに山吹金 `yoseKinBright` の赤提灯・暖簾の矩形シルエット）へ変更。
   * **動き**：画面突入時、黒漆のイベント題名札が `offset(y: -12) -> 0`（`0.18秒 .spring(response: 0.25, dampingFraction: 0.8)`）で落ちてきて、テキスト枠が下から `offset(y: 10) -> 0` でせり上がる。

## 47_0012_イベント会話_0012.png

### ① 点数
**23 / 100点**（商業リリース不可・背景オブジェクトの重なり破綻あり）

### ② デザインシステムから外れている所
* **イベント題名カプセルと背景の衝突（§4-2・§8-1違反）**：「短期バイトの話」の丸カプセル（`Capsule`）が、背景の「寄席」の額縁のちょうど上に被さり、「席」の下半分しか見えない文字切れ事故を起こしている。
* **ト書きボックスの角丸・ぼかし影・ゴシック体（§3・§4違反）**：角丸 `10pt`・薄枠・ぼかし影・ゴシック体のWeb風カードになっている。
* **画面下半分の巨大な空白とステータスバーの欠落（§1・§7違反）**：バイトの話（金銭・体力に関わるイベント）であるにもかかわらず、現在の所持金・体力を見せる `YoseVitalMoneyBar` が画面に存在しない。

### ③ AIっぽい所・UXの分かりにくさ（初めての人が迷う所）
* **「稽古場。月末の昼。」なのに背景が「寄席のセンターマイク前」**：ト書きは「稽古場」と言っているのに、背景には「寄席」の額とスポットライトとサンパチマイクが描かれており、場所の設定と絵が食い違っている。
* **バイトの判断材料がない**：この後に「バイトに行く／行かない」の選択肢が出ても、今いくら持っていて体力がいくつなのか画面上で確認できないため、プレイヤーが判断に迷う。

### ④ 直す設計図（優先順）
1. **舞台上の「寄席」額縁とイベント題名札の座標分離（重なり解消）**
   * **部品・配置**：最上部 `[000-048pt]` に `YoseHeaderBar(title: "日常イベント")` を設置。イベント題名札（「短期バイトの話」）は角丸 `0pt` の木札カード `.yoseKifuda(showNail: true)`（背景 `yoseKi`、外枠 `yoseSumi` `2pt`、高さ `36pt`）とし、舞台上端 `y: 58pt` に配置。背景の額縁は削除するか `y: 104pt` 以下に下げ、文字被りを完全にゼロにする。
2. **場所設定に合わせた「稽古場」背景への差し替え**
   * **配置・色**：昼の稽古場として、スポットライトと「寄席」額縁を外し、壁面に長机・ホワイトボード・パイプ椅子（`yoseKiDark` と `yoseSumi` 枠の幾何学構成）を配置して本番舞台と明確に描き分ける。
3. **会話枠の `.yoseHarigami()` 化と明朝体適用**
   * **部品**：左右マージン `14pt`、角丸 `2pt`、枠 `yoseSumi` `2pt`、ハードシャドウ `y: 2pt`。本文は `YoseFont.mincho(15)`（行間 `6pt`）、右下に `yoseShu` の `▼` アイコンを配置。
4. **下部に `YoseVitalMoneyBar` を常時連結**
   * **部品**：`[756-792pt]` に `YoseVitalMoneyBar`（体力ゲージ `yoseTokiwa` ＋ 所持金 `yoseKinBright` `17pt Heavy`）を固定配置し、バイトを受けるべきか一目で判断できるようにする。
   * **動き**：次ページ送りタップ時、ボタン押下と同じ `UIImpactFeedbackGenerator(style: .light)` を鳴らし、送り矢印 `▼` を `0.6秒` 周期で上下 `2pt` ステップ点滅させる。

## 47_0013_イベント会話_0013.png

### ① 点数
**25 / 100点**（商業リリース不可・背景の上端見切れとUI未統一）

### ② デザインシステムから外れている所
* **カプセル型タイトルバッジ＋ぼかし影（§4-2・§8-1・§8-10違反）**：「先輩のおごり」が丸い `Capsule`＋金グラデーション＋白枠＋Blurシャドウで描かれている。
* **背景オブジェクトの上端見切れ**：画面上端（`y: 52pt` 付近）にある赤い丸（照明または提灯）が上枠で真っ二つにちょん切れており、レイアウト計算が崩れている。
* **テキスト枠の角丸10pt・ゴシック体・下半分の空白（§3・§4違反）**：他イベントと同様、Webカード風のト書き枠と画面下半分420ptの空白がある。

### ③ AIっぽい所・UXの分かりにくさ（初めての人が迷う所）
* **焼肉屋の網（ロースター）の位置とパースの違和感**：カウンターの茶色い壁の手前、黒い床のような場所に楕円形のオレンジ色の網が1つだけ浮いており、青と赤のこけし人間が壁に向かって並んでいるように見える（テーブルの奥行きや先輩の姿がない）。
* **誰におごられているのか分からない**：「先輩のおごり」なのに画面にはコンビの2人（後ろ姿）しかおらず、先輩の存在感（名前札やシルエット）がない。

### ④ 直す設計図（優先順）
1. **ヘッダー帯の追加と上端提灯の見切れ修正**
   * **部品**：`[000-048pt]` に `YoseHeaderBar(title: "交流イベント")` を配置。舞台領域を `[048-350pt]` とし、上端の赤い提灯は `y: 56pt` から下に完全に収まるよう配置し直す。
2. **「先輩のおごり」タイトル札の角札化**
   * **部品**：`Capsule` を廃止し、黒漆背景 `yoseKuroUrushi` ＋ 二重金枠（外枠 `yoseSumi` `2pt`、内枠 `yoseKin` `1.5pt`、角丸 `0pt`）の横看板（高さ `36pt`）に `YoseFont.gothic(17, weight: .heavy)`（色 `yoseKin`）で「先輩のおごり」を表示。
3. **焼肉テーブルの前後レイヤー整理**
   * **配置・色**：2人の手前ではなく「2人の間の奥（テーブル上）」に七輪/ロースターを配置し、壁のメニュー短冊（現在は無地の赤とベージュの四角）に縦書き風の黒い擬似文字線（`yoseSumi.opacity(0.4)` の細線）を2〜3本入れて「焼肉屋の短冊」として認識させる。
4. **セリフ枠の `YoseSpeechBox` 化と下部ステータス帯の統合**
   * **部品**：ト書き・会話枠を `.yoseHarigami()`（角丸 `2pt`、墨枠 `2pt`、ハードシャドウ `y: 2pt`、明朝体 `15pt`）に置換。画面下部には `YoseVitalMoneyBar` を配置し、焼肉による体力回復（`+20` 等）が起きた瞬間に `yoseTokiwa` のゲージが `.spring(response: 0.35, dampingFraction: 0.78)` で伸びる演出に繋げる。

### 1. この画面群に共通する5大問題
1. **イベント会話画面（`47_0011`〜`47_0029`）がデザインシステム『寄席と計器』の適用外のまま放置されている**
