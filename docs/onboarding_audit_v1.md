## §1 迷う所の一覧（見つけた順）
1. **週メインの数字**（実力・相性・体力・知名度）が説明なしで出る。実力10が強いのか弱いのか不明。→ 足した（§2-A）
2. **経験点**が「たまってる」と出るが使い道が週メインでは分からない。能力アップ画面は閃・語・間・存・胆／ランク G／「Fまで5」／「+2段階」と未説明語が一度に並ぶ。→ 足した（§2-C）
3. **生活費**: 4週ごとに14万円が引かれるが、画面上の説明はゼロ（台詞の匂わせのみ）。第5週に所持金が33万→19万に減って初めて気づく。→ 足した（§2-B）
4. 「通過ライン」「舞台尺」「上乗せ」「エントリー費」「体力を使う／温存」がエントリー画面で説明なし。夜行バスと新幹線の違い（お金か体力か）は副題から読めるが、「ネタ無しで出る」の赤帯は理由が分からない。→ 案（§3）
5. **バイトを押したのに週が進まない**（第3週）: 先に日常イベントが割り込み、バイトは実行されないまま週メインに戻る。初めての人は「押したのに無視された」と感じる。→ 案（§3）
6. 選択肢イベントの終わりで「メンタル↑」が出るが、メンタルは週メインのどこにも出ない（能力アップ画面の列にだけある）。
7. 能力アップ確定後も実力が「10」のまま（ゲージだけ動く）。効いたのか分からない。
8. 日常イベント画面で最後の台詞が下の「次へ進む」ボタンに少し隠れる（第3週・稽古場）。タップで進むので実害は小さい。
9. 週メインの「優勝／無双」チップは DEBUG のみ（本番では出ない・点検対象外）。
10. 良かった所: 行動カードの収入・体力コスト表示／大会の3段階表示（客席の反応→結果発表→講評）／敗退の「直せる一点」講評／「大会まであと◯週」帯。

## §2 足した物（コミット fac0094・preview-all・UserDefaults `mz.hint.<key>` で一度きり）
- **A. 初週の説明（key=firstWeek）**: 第1週の最初に1回。実力／相性／体力／経験点の4語を1行ずつ＋「黒い帯＝次の大会までの週数」。「わかった」で閉じる。
- **B. 生活費の説明（key=living）**: 1年目の第4週（最初の引き落としの週）に1回。「4週に1度、週の終わりに14万円」「足りないと借金」。金額・間隔は GameConfig から読む。
- **C. 能力アップ初回（key=abilityUp）**: 初めて開いた時に1回。経験点／＋／おまかせ／ランク。
- **D. 小さな「？」**: 週メイン左上と能力アップ右上。押すとA／Cを読み返せる（記録は見ない）。
- 他の知らせ（借金・イベント・バースト・各画面表示中）とは重ならない。DEBUG の MZ_UI/MZ_SMOKE では出ない（MZ_HINT=1 で強制）。台詞・GameCore・ボタンの押せ方は不変。％表示なし。

## §3 大きな案（作らず記録）
1. エントリー画面にも同じ仕組みで初回1回の説明（通過ライン＝この数字に実力が届けば通りやすい／遠征の違い／エントリー費）。最初の大会前に出すのが最も効く。【要オーナー判断：文言】
2. 「バイトを押したが日常イベントが先に出た」時、イベント後に行動が実行されない理由を一言（または行動を先に実行してからイベント）。**後者は進行順の変更＝golden/乱数消費に触れる可能性があり要相談。**
3. 能力アップ確定直後に「実力 10→11」の表示（実力が整数で動かない週は「↑」）を結果として見せる。
4. 用語集ページ（設定内）に実力・相性・経験点・完成度・知名度・生活費・通過ラインを並べる案。
5. 谷口の台詞による導線（onboarding_design_v0 の週別誘導）の実装度合いの確認。
