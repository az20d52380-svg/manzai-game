## 0. 要点3行
1. 係数（完成度 0.04＋反応 0.02 を同倍率で動かした）は帯に強く効く：ローテ(True・決勝30〜40%帯)は 0倍→2倍で決勝 21.5→46.6%、必要充足(True)は 54→87%、優勝は 0.2→1.8%／3.2→19.5%。「今の値(1倍)」は ネタ無し(ローテ 30.4%)より決勝 +4pt・必要充足 +13pt、やり込みは優勝 10.9→13.2% と、効かないどころか上げ側に寄っている。

3. 値を変えるかはオーナー判断（規律A）。0.5倍(0.02/0.01)なら ローテ True は決勝 28.0%・ネタ無し(30.4%)とほぼ同水準、必要充足/やり込みの優勝はネタ無しにほぼ戻る。

## 2. 読み方
- 帯 30〜40% の該当：ローテ True 込み(34.6%)、ローテ True 無(30.4%)、必要充足 False(無 43.1/込 45.2 は上端)。ローテ False(19.8%)は帯の下、のんびり改は弱すぎ(2〜7%)で除外。
- ローテ True：0.5倍 28.0% → 1倍 34.6% → 1.5倍 39.3% → 2倍 46.6%。1倍あたり約 +6〜7pt 動く（帯 30〜40% の幅とほぼ同じ）＝係数の 1 段階で帯を出入りする感度。ローテの優勝は 2倍でも 1.8% と低い（優勝は別要因＝強いボットの話）。
- ローテ False は 0倍 12.6% → 2倍 26.6% と同じ傾向（False は全体に低め）。
- ネタ無しとの比較：1倍 ≒ ネタ無しに対し ローテ True 決勝 +4.2pt、必要充足 True +13.5pt、やり込み True +3.3pt／優勝 +2.3pt。0.5倍 ≒ ほぼネタ無し〜わずかに下。0倍は完成度の差が効かず、疲れペナ(V2_TIRED_PEN)のみ残るため無しより下がる。
- 1年目決勝は全セル 0.0%。

## 3. 方法
- スクリプト：scratchpad の coef.py（コード不変）。`measure_band_reference_v1.one` をそのまま呼び、ワーカーで `sim_career.NETA_COEF_COMP`(0.04)・`V2_COEF_BUZZ`(0.02) を倍率で上書き（NETA_CLAMP ±5・決勝2本目ペナ・疲れペナは不変）。Pool(maxtasksperchild=1)＋map(chunksize=1)。n=300 で当たり→全セル n=1000。
- n=300 も同傾向（ローテ True 決勝 18.7/26.3/34.0/37.7/45.0）。
- 注意：完成度係数と反応係数を同倍率にした。ボットは磨いたネタしか掛けない(neta_bonus_remeasure §2)ため、負の補正側の効きは見えない。ネタを磨かない人の側の差は未測定。NETA_CLAMP=5 は 2倍でも上限が効く場面がある（ボーナスが +5 で頭打ち）。

## 4. 推奨（決めない・値の変更は規律A：GameConfig→sim→golden→swift test を1コミット）
- A. 今の値のまま：ネタ込み(True)の帯を新基準とみなす。ローテの決勝 34.6%は帯内だが、必要充足・やり込みは 75〜87%/優勝 9〜13% で neta_bonus_remeasure の「初回優勝 2〜4%」目標を超える。
- B. 0.5倍（0.02/0.01）：ネタ無しの帯にほぼ戻る(ローテ 28.0/必要充足 64.9/やり込み 81.0%)。neta_bonus_remeasure の案②と同じ。
- C. 係数は触らず反応 −10（案③）を採る：係数感度が大きい（上記）ので、組み合わせは再測（②③重ねてもほぼ片方分）。
- 係数の感度が高い＝0.01 刻みでも帯が動く。変えるなら n=1000 でローテ・必要充足の両方を見る。
