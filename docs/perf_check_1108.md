## 読み方の注意（この表は重さの判断に使えない）
- **測った時、Simulator のアプリは非表示だった**（System Events の visible=false）。動く演出ほど CPU が低く出ている可能性が高い。
  - 優勝演出（`MZ_FX=champion`）を起動1秒後から測っても平均 0.1。v1（10/16）の同じ画面は 33 で、起動直後は約200 だった。
  - `MZ_SMOKE=4 MZ_FIN=champ` は平均 5.1・最大 42.1（v1 は 30）。
- したがって v1 より軽くなったとは言えない。週 6.2→0.7 も改善の根拠にならない。原因が非表示だとは断定していない（表示した状態で測り直せば確かめられる）。
- メモリはどの画面も 30〜41M で、10秒の範囲で増えていない。ただし描画が止まっていたなら、これも少なめの値。長時間の漏れは 10/27 の soak を参照。
- 測り直しは Simulator の窓を出した状態で `SETTLE=1 tools/run_perf.sh <dd> MZ_FX=champion` など。発熱・電池の答えは実機の Instruments でしか出ない。
