## §2 直す候補
### 表示だけで直せる物
1. 年末総算の朱印が見出しに被る: YearResultView.swift:176-178。朱印の scaleEffect を外す／.padding(.trailing) を増やす／VStack 側に leading の逃げ（朱印幅ぶん）を確保。
2. 最終年に出る「来年」の文（10年目でも出る条件を確認済み）。表示の差し替えのみで直せる:
   - WeekMainView.swift:1506 満了トースト「今年の実力の伸びは、ここまで。来年また伸びる。」→ session.year >= config.careerYears なら「今年の実力の伸びは、ここまで。」。

   - YearResultView.swift:380,401,403,417,418（yeStall / yeLeap の独白）の「来年は／来年も」。独白は bankrupt・dissolved・決勝進出年を除き10年目の年末にも出る（L325-351。careerOver の分岐なし）。最終年は pool から「来年」を含む行を除く（L342 の1年目と同じ filter 方式）。
