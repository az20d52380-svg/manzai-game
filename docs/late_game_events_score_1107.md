### 直す優先の5本
1. **N7**：谷口「よく笑ってくれてるね」に禁止字「笑」（絶対禁止）。客席の反応というお笑い側の話でもある。
2. **N6**：「間を使って、テンポで見せよう」は業界語（v3 バナー1の「間」＋テンポ）で、意味が日常で通じない。
3. **N5**：冒頭の自己採点は「直した」と書いてあるが、本文は谷口「僕も出すよ」のまま。効果「お金−1万」とも合わず、B の「お金+0.5万」は冒頭の「お金増は N2・N3・N8・N15 の4本のみ」に反する（実際は5本）。
4. **N10**：「ネタが昔と変わった／今の方が落ち着いて聞ける」は芸の出来の話。しかも白井は E15 と同じ常連・同じ「劇場の出口」で題材が重なる。
5. **N19**：「新しいネタを一本入れる／構成を組み直そう」＝ネタ作りの話。「守りに入る／攻める」も勝負の比喩。

次に直す塊（ネタの話をまとめて日常に置き換える）：N2・N3・N14・N16・N20。

### 横断の所見（全本に効く）
- **ネタ・間・構成の混入が一番多い**：N2、N3、N6、N10、N14、N16、N19、N20。v3 バナー1「芸・ネタ作り・稽古のやり方の話、業界の言葉は使わない」に触れる。日常（体調・お金・家族・付き合い）の話に置き換える。
- **「僕」**：谷口の一人称が N1、N4、N5、N17 にあり、男女どちらが言っても自然（⑧）を外れる。「僕」を消して主語なしにするか、谷口を「私たち」にする。
- **吹き出し数**：setup が3つの本が大半（N1〜N16 の多く）。バナーは4〜6。足すか、現状を許容するかはオーナー判断。
- **数値の復唱**：なし（○）。「十年以上」は経過年数で、効果の復唱ではない。
- **関西弁**：なし（○）。
- **相方と遊びに行く場面**：なし（○）。N12 の年末の集まりは幹事＝事務所の仕事で、遊びではない。
- **実在の芸人名・大会名**：なし。ただし冒頭の「GP優勝」は略称で、実在の大会名に似た響きがある。ゲーム内の呼び名に揃えるか、「優勝」だけにする。
- **E1〜E20 との重なり**：「重ねていない」と冒頭にあるが、N10(白井)↔E15、N16(昔を聞き返す)↔E12・E20、N14(後輩の前に出る)↔E1・E16、N20(後輩に聞かれる)↔E1、N2(局の仕事を断るか受けるか)↔E9、N11(野々村の紹介)↔E3・E9 は構造が近い。冒頭の記述は言い過ぎ。
- **冒頭の自己採点表**：「N5 を直した」が本文に反映されていない。「業界語なし」の検査項目が無い（N6 などを見落とした原因）。
