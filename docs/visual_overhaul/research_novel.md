### 0-2. 実データの形（設計の前提）

- 選択肢イベント全18本の本文を数えた：**地の文 21ブロック（平均 約115字・最大195字・最小49字）／台詞 112本（平均 約23字・最大45字・最小4字）**。`Advice(name?, text)` の1要素＝1タップ。
- つまり台詞は **1〜2行で終わる短文**、長いのは各イベント冒頭の地の文だけ。ノベルの「1行ずつ送る会話窓」にそのまま載る形で、すでにデータが ADV 向きに切れている。
- 地の文は文ごとに `\n` が入っている（約30字で改行）が、画面は27字/行で折り返すため、**「る と、」「て、やめた。」のような2〜6字の切れ端行**が出る（05_event_choice_live_w03 の2・3・5段落目）。「二／脚」のように語の途中でも切れる。読みにくさの一因。

### 0-3. 弱さの正体（作品の手本と突き合わせる前の仮説）

1. **部品が足りない**：名前札・顔・会話窓・送り合図・背景の5部品のうち、イベント文章画面には「金の小文字の名前」と「小さい灰色の合図」しかない。週メインには5部品が揃っている。
2. **文字が小さく、細く、薄い**：13〜14pt の明朝・白75〜92%を紫地に置く。明朝は縦が太く横が細い書体で[S25]、小さく暗地に置くと横線・濁点・句読点が地に溶ける（本作のスクショで確認[S28]）。
3. **面の使い方が逆**：文字が上 1/3 に詰まり、親指の届く下 2/3 が空く。選択肢だけが下に落ちる。縦持ち片手で「読む場所」と「触る場所」が離れている。
4. **反応がない**：タップしても本文が一括で出るだけ（回想）／1行ずつ増えるだけで音・動き・人物の反応がない（イベント）。
5. **色の言葉が違う**：週メインは「白地・太い縁・ハード影・丸ゴ・暖色」。他は「暗紫・細い明朝・半透明」。同じアプリに見えない。

**この表から読めること**（原理の根拠になる点だけ）：
1. 本表の範囲では、「暗い地に細い字を小さく置く」作品は見当たらない。暗い地を使うペルソナ5・ダンガンロンパも、**3色への絞り込み・蛍光色・色札**で読ませている（文字の太さ・縁取りの有無は【記憶】）。
2. 立ち絵を持たない**LINE型のチャット小説**でも、スマホ読者が日常的に長時間読んでいる（アプリ平均利用1日2時間・報道）。吹き出しとアイコンで話者を示す形は【記憶】だが、本作の `adviceBox` と同じ文法。
3. 学マスの縦コミュは、**カメラ2種・立ち位置固定・背景厳選・動きは使い回し**という「固定ルール」で量産し、ここぞの1話目だけ専用演出を入れている。個人工数に最も近い手本。
4. 育成ゲームのうち、ウマ娘・パワプロは**選択の結果（上昇量・報酬）を画面に出す**（ウマ娘は選ぶ前、パワプロは選んだ後に確認できる）。本作のイベントはどちらも出していない。

## 2. 本作にそのまま効く原理 5つ

画面の基準寸法：402×874pt（iPhone 17）。安全域は上 約59pt／下 約34pt。以下の pt・秒・hex は全て【仮】。新規のゲーム内文言は一つも要らない（既存の地の文・台詞・選択肢ラベル・イベント名をそのまま使う）。足りなくなった時だけ【要 drama-voice】。

### 原理1　色：「場面の主色1つ＋白＋墨」を**明るい地にベタ塗り**する（暗くしたい時も暗転させない）

- **手本の具体**
  - ペルソナ5：UIを赤・黒・白に絞り、グラデを使わず「全部ベタ塗り」にした（UI担当の談）。選択のハイライトだけ青で、3色の中で浮かせる。[S12][S14]
  - バラエティのテロップ：白文字＋色縁を基本に、演者ごとに色を変える。強調は太さと縁で作る。[S21]
  - 本作の週メイン自身：クリーム地・白カード・太い縁・ハード影・朱と青。ここだけ完成している。[S28]
- **本作のどの画面にどう当てるか**
  - **イントロ回想（02_intro_01〜03）**：黒を捨て、**色で時間を進める**。①昼の教室＝クリーム（`Theme.bgTop`→`0xFFE9B8`）／②放課後の廊下＝夕焼けの橙（`0xFFD2A0`→`0xF59A6B`）／③「それから何年」＝夕暮れから藍へ落ちるが**明るさは残す**（`0xF2A27A`→`0x6E6FA8`）。「暗い・重い」を見せたい③でも、黒ではなく藍の夕方で言う。文字は墨 `Theme.ink`（`0x2C2740`）を白〜クリームのカード上に置く。
  - **イベント文章（05_*, 06_*）**：背景は週メインと同じクリーム→`bg2`。場面の主色は金1色（章タイトル札・選択肢の縁）。話者色は既存の**俺＝青 `0x4A7BE8`／谷口＝朱 `Theme.verm`**で固定する（顔グラの襟・名前カプセル・吹き出しの縁に同じ色を使う）。
  - **暗い場面（負けた翌週・終電後など）**は暗転ではなく**彩度を落とした青み**（例 `0xE9EDF7`→`0xD6DEF0`）で言う。「暗い＝つまらない」というオーナーの評価と、イベント文の静かな温度を両立させる一つの道。
  - 03_naming（クリーム地）とつながり、タイトル→回想→名付け→週メインの**色の言葉が一本になる**。
- **該当スクショ**：02_intro_01／02／03、05_event_choice_live_w03、05_event_narration_w05、05_event_0011、06_event_0013（現状＝全て暗紫）。手本は 04_week_w02、つながり確認は 03_naming。

### 原理2　構図：**上＝絵、下＝親指の帯**。構図は2種に固定し、1画面1枚の絵を必ず持つ

- **手本の具体**
  - 学園アイドルマスターの縦画面コミュ：カメラは「引き」「寄り」の**2種に固定**、立ち位置は**身長で固定**、背景は**厳選**、モーションは**使い回す**。そのうえで**1話目だけ**人となりが一目で伝わる専用カット（専用エフェクト・専用モーション）を入れる。これで毎月100話以上を作っている。[S4][S5][S6]
  - ウマ娘の育成UI：ヘッダー／フッターを固定し、**メイン情報を親指の届く位置**に置く。間にサブ情報（キャラ・アドバイス）が入る。[S8]
  - 縦持ちゲームは「片手で遊べる」ことが価値。[S27]
- **本作のどの画面にどう当てるか**
  - **イベント文章**：現状は文字が上1/3に詰まり、下2/3が空く（05_event_choice_live_w03）。これを**上に絵・下に文字**へ反転する。
    - 上 約60〜330pt（安全域の下から）：**場面の絵**。背景は色面＋小道具1点（本文に出てくる物：パイプ椅子・ネタ帳・香盤表・ケーブル・鍵・名刺など。図形で描ける）、手前に**ちびの二人**（`ManzaiFigure` 流用）。
    - 下 約330〜874pt：**親指の帯**。地の文カード → 会話窓 → 選択肢が**同じ場所**に入れ替わりで出る（指が動かない）。
    - 構図は2種：**引き**（地の文のあいだ。二人を全身で見せる）／**寄り**（決め台詞の1行だけ。話者の顔を 120〜140pt に拡大。目・眉・口の差分が要る＝§4）。**寄りは1イベントに最大1回**に絞る（学マスの「1話目だけ専用」と同じ配分）。
    - 話者が変わっても人物の立ち位置は動かさない（**俺＝左・谷口＝右**＝04_week_w02 の舞台の並びと同じ）。話者強調は「話している方を拡大 1.06＋上下ゆれ、もう一方は彩度を半分に落とし 0.94」で足りる。【推定】
  - **イントロ回想**：3カットを**引き／寄り／引き**に割り振る。①教室＝引き（谷口が窓際で喋る全景、俺は奥の小さな青い影で笑う）。②廊下＝**寄り**（名台詞を画面中央の大文字カードにする：下記）。③それから何年＝引き（誰もいない舞台とパイプ椅子、カレンダーが1枚めくれる）。**専用演出はこの②だけに全力をかける**（学マスの1話目専用カットと同じ考え方）。
  - **名台詞カード（02_intro_02）**：「コンビ、組まへんか」を 28〜32pt の太い丸ゴ＋白文字＋墨の二重縁で画面中央に置く（テロップ文法）。地の文の残り（「谷口はそう言った。放課後の、誰もいない廊下で。」）は下の小さな帯に落とす。
- **該当スクショ**：02_intro_02（灰カプセル2つ＋下に文字）、05_event_choice_live_w03（上詰め・下空き）、05_event_choice_live_w03_close（「閉じる」だけ下端）、05_event_narration_w05。

### 原理3　話者：**顔＋名前札＋吹き出し**で「誰が言っているか」を先に見せ、地の文は**別の器**に入れる

- **手本の具体**
  - 逆転裁判：名前札は**キャラごとの色**。文字色で意味を分ける（白＝通常／青＝心の声／灰＝ささやき）。[S17][S18][S19]
  - パワプロのサクセス：**顔アイコン付きの会話窓**（本作の週メインの `adviceBox` はこれを写したもの）。[S23][S28]
  - チャット小説：立ち絵ゼロの**LINE風チャット型**（縦スクロール）。アプリ平均利用は1日2時間（報道）。顔アイコン＋吹き出しで話者を示す作りは【記憶】。[S20]
  - ダンガンロンパ：弱点語＝橙（または黄）、妨害雑音＝紫と**色に役割を持たせる**。[S10][S11]

### 原理4　文字：**大きく・太く・明るい地**。行長18〜21字・行送り1.6〜1.7。明朝は主役から降ろす

- **手本の具体（数値の根拠）**
  - iOS：本文の標準は **17pt**、下限の推奨は **11pt**、細いウェイトは避ける。[S3]
  - 日本語組版（W3C 日本語組版タスクフォースの議論）：横組みの行長は **35字程度、多くても40字**まで。行長が短い場合の行間は **全角の1/2程度**＝行送りで約1.5倍。[S1]
  - Xbox のアクセシビリティ指針：2行を超える文章は **CJKで40字以下／行間1.5倍以上／段落間は行間の2倍以上**、**サンセリフを最低1つ**用意する。[S2]
  - ノベルのUI実務：本文30px・行間1.7の例、文字欄を画面幅の30%未満に寄せない。[S22]
  - 明朝は縦が太く横が細い書体で「読ませる」長文向きと説明される一方、小さな文字を暗い地に白抜きにすると横線が地に溶ける（本作の 02_intro・05_event で実際に起きている）。[S25][S28]
  - **明朝を本文に使うノベルと使わないノベルの違い**：本表の全作（キャラの会話が中心でポップ寄り）は、会話文にゴシック／丸ゴ系を使う。明朝が似合うのは**全画面で長文を読ませる文学・ミステリ・ホラー系**【記憶・低】。本作の台詞は短く、喜劇である。→明朝は合わない側。
- **本作の数値案**【仮】

### 原理5　送りと返し：**1タップ＝1ビート**。打って・鳴らして・▼で待たせ、選んだら**必ず絵と数字で返す**

- **手本の具体**
  - 逆転裁判：1文字ずつ表示し、話者ごとの**ブリップ音**（短い電子音）を鳴らす。長押しで早送り、既読は一括スキップ。[S18][S19]（ただし「音楽が無いとブリップが耳につく」という報告もある＝控えめに）
  - 学マス：タップ待機を挟み、**連続タップで演出をスキップ**。待機中は演出時間を延ばし、タップした瞬間に正しい時間へ戻す。[S4]
  - ダンガンロンパ：テンポを優先して**フルボイスにしない**。台詞が表情に対して長ければ書き直す。結果表示は最後にまとめる。[S9]
  - ウマ娘：トレーニングを選ぶ**前に**上昇量を見せ、基礎能力を**常時**表示する。[S8]（ただしイベント選択肢の効果を**選ぶ前**に出すのは本作では採らない＝§3 #8）／パワプロ（新作）：選んだ選択肢の報酬を後から確認できる。[S23]／ペルソナ5：メニューで選択中の項目は**大きくなって色が付く**。[S14]
- **本作のどの画面にどう当てるか**
  - **台詞は打つ・地の文は一括**：台詞（平均23字）は約40字/秒【仮】＝約0.6秒で打ち終える。句読点で0.12秒止める。**打っている最中に再タップ＝即全表示、次のタップ＝次の台詞**。地の文（平均115字）を打つと約2.9秒待たせるだけなので**一括表示（フェード0.25秒）**にする。

  - **テンポ衝突**：W4 でネタを書いた直後にイベントが被さり、週の獲得バーストが見えない問題（05_event_narration_w05）は、**バーストが終わって約0.8秒後**にイベントを出す順序で解く。【仮】

## 4. 図形・ちびキャラで立ち絵を代替する手法

### 4-1. 結論

**立ち絵を絵で持つ必要はない。** 人物の「誰か」を色・髪型・襟で、「どんな気分か」を**動き・構図・小道具・顔窓の差分4種**で言えば、会話ゲームの文法は成り立つ。本作はすでに半分持っている。

- 舞台上の人物：`StageScene.swift` の `ManzaiFigure`（後ろ向きの無貌の人形・呼吸と揺れつき・青と朱）。
- 会話の顔：`CharacterAvatars.swift` の `CharacterFace`（丸顔＋髪5種＋眼鏡・髭・襟色。目は点2つのみ）と `FaceCatalog`（俺・谷口・審査員7人）。

### 5-1. 取れなかった一次情報と、裏取りが要る点

検索ツールでは各社のUI寸法（窓の不透明度・名前札の位置・文字サイズ・▼の形）を直接示す資料がほぼ見つからなかった。表（§1）の該当セルは【記憶】【推定】のまま。**実機のスクリーンショット／プレイ動画で確かめるべき項目**：
1. 逆転裁判：窓の不透明度・名前札の位置・▼の動き・ブリップの周期。
2. ウマ娘：育成イベントの窓・選択肢ボタンの形・上昇量のポップ。
3. 学マス：縦コミュの窓の位置と文字サイズ・名前の出し方（記事は演出論のみ）。
4. ブルーアーカイブ：窓の不透明度・名前（所属）の出し方。
5. ペルソナ5：会話窓の形と文字の縁取り。
6. テラーノベル：吹き出し・アイコン・タップ送りの実際（記事は形式の概要のみ）。

オーナーが手元で上の6本のスクリーンショットを1枚ずつ撮って `feedback_shots/` に置けば、§1 の【記憶】を【確認】に置き換えられる。本書の結論（§2）は、これらの寸法に依存しない原理だけで組んである。
