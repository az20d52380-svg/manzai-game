## 出力の形（4人とも同じ）
`docs/visual_overhaul/red_<angle>.md`
- §0 判定（3行）：3案それぞれを一言で（このまま通すと何が起きるか）
- §1 指摘表：| ID | 案 | 重さ（致命／重大／軽微） | 指摘（言い切り） | 根拠（doc§・`File.swift:行`・スクショ） | 直し方の提案 |
  - **致命**＝オーナーの声を解かない／既決や絶対制約を破る／実装すると壊れる・戻せない。**重大**＝効きが大きく落ちる・工数が倍以上ずれる。**軽微**＝磨きで直る。
  - ID は `X1-01` のように自分の班番号＋連番。
- §2 3案から「採るべき所」（攻撃の結果、残すべき良い部分）
- §3 統合するならこう組む、という提案（1段落）
- 3案を比べて同じ問題を指す時は、案ごとに行を分ける。
