# R1：育成SLGの王道の「画面の作り」（visual overhaul v1・2026-10-08）

担当：リサーチ班 R1。範囲＝週送り／会話／イベント／育成結果／大会・レース前後の「画面の作り」（色・明るさ・書体・文字サイズ・部品・動き・音）。`docs/fun_uiux_overhaul_v0.md` §3 の原理P1〜P8は繰り返さない。コード・git・simulatorには触れていない。

確信度の凡例：**高**＝一次情報（講演スライド・公式ストア画像・記事の画面写真）を目で確認／**中**＝大手媒体の本文・攻略記事の要約／**低**＝非公式のファン調査・記憶。出典IDは §4。

## 0. 先に結論

1. 王道の育成SLGは**「額縁を1つ決めて全場面に出し続け」「会話は1セットの部品を使い回し」「結果は動く数字で閉じ」「日常の地は明るい昼の色、暗さは本番にだけ」「結果は育ちを形で見せる」**の5点で画面を作っている。本作は**週メインだけがこの文法を満たし**、イントロ・イベント・大会結果・決勝の地は別のゲームの言葉で書かれている（オーナーの「ちぐはぐ」の正体）。
2. 直すべき部品は**新規に描くものではなく、週メインに既にあるものの水平展開**で足りる。週画面には「丸顔アイコン＋朱の名前札＋白い吹き出し＋▼」「下段の濃紺帯」「色チップ」「行動カードの色枠」が既にあり、これが手本（パワプロ・ウマ娘・ときメモ）と同型。
3. 王道の画面は**色・書体の一次情報が公開されていない**（講演にも公式ページにも記述なし）。色・書体・文字サイズは公開画像の目視とファン調査から読んだ（確信度に差がある）。一方、**構造（固定ヘッダー／イベントでも出す／効果を数値で出す／カメラと立ち位置の固定／結果の強調1点）は講演スライドで確認できた**。本作に効くのは後者。

## 2. 本作にそのまま効く原理（5つ）

座標は `feedback_shots/overhaul_v1/*.png`（402×874pt 基準）。数値・色・書体は全て【仮】。GameCore・乱数・GameConfig には触れない（触れる案は【規律A】と明記）。ネタ本文は一切書かない。新しい文言が要るところは【要 drama-voice】。

### 原理1：額縁を1つ決めて、全場面に出し続ける

- **手本の具体**：ウマ娘は画面を「ヘッダー（育成全体の情報）／サブ（演出）／メイン（操作）／フッター（メタ操作）」の4段に固定し、トレーニング・レース選択・結果に加えて**イベント画面でもヘッダーとフッターを消さない**（スライド43・50・51「常に意識してもらうためイベント画面でも表示」）[U1]。ときめきメモリアルは場所札・日付帯・メッセージ窓・パラメータ板の**位置が全場面で不変** [T1]。パワプロは会話中もヘッダー（残りターン・体力）を出し続ける [P1]。狙いは「いまどこで、あと何で、何をしているか」を迷わせないこと。
- **本作のどの画面にどう当てるか**：週メインの**上ピル（「春新人賞A あと11週」）と下段の濃紺帯（年週／大会まで／体力／所持金）を本作の「額縁」と定義**し、選択肢イベント・地の文イベント・大会入口・大会結果・年末リザルト・ネタ帳に**同じ帯を出す**。外すのは没入が要る場（イントロの回想・決勝の本番・勇退エンディング）だけで、そこでも色と書体は額縁と共通にする。帯の中身は表示のみ（数値・式に触れない）。
- **スクショの該当**：`04_week_w01` の下帯（約780〜874pt）と上ピル（約72〜109pt）が額縁の現物。帯が無く別ゲームに見えるのは `02_intro_02`・`05_event_choice_live_w03`・`05_event_narration_w05`・`08_tourney_result_fail_b`。`10_finals_win_07` の最下部（約835〜874pt、「あなたのコンビ 結成1年」）には決勝系だけの別の帯が既にあり、**これを週の帯に揃えるだけで一本化できる**。
- **効く理由**：新規部品ゼロ（既存の帯を再配置）。ちぐはぐの最大要因（画面ごとに枠の言葉が違う）を最小工数で潰せる。

### 原理2：会話は「大きい人物＋白い角丸窓＋名前札＋▼＋スキップ常設」の1セットを使い回す

- **手本の具体**：パワプロは**画面下に白地・濃青の太縁・角丸の窓**、右下に緑の▼、左下に**ログ／オート／スキップの小ボタンを常設**、人物は窓の上に大きく [P1]。ウマ娘は窓の中に**「根性が10上がった」のような数値つきの文**を出す [U1]。学マスの縦コミュは**カメラ2種・立ち位置・背景位置を固定してフォーマット化**し量産 [G2][G3]。デレステは**吹き出し枠も部品の1個として定義**し、画面ごとに素材を足さない [S-D1]。ウマ娘の縦会話は**表情・モーションの変化をテキスト1つにつき1回に制限**してテンポを守る [U3]。
- **本作のどの画面にどう当てるか**：週メインに既にある**左下の丸顔アイコン＋朱の名前札＋白い吹き出し＋▼**（`04_week_w01`、窓は約70〜325pt×417〜476pt）を共通部品にして、**イベント（選択肢・地の文）・イントロ・決勝後の一言・講評**に流用する。
  - 人物：半透明の灰色カプセルを廃止し、週画面と同じデフォルメ立ち絵（朱＝谷口、青＝俺【仮・要確認】）を**画面の中段に大きく**（週画面の舞台と同じ構図）。表情差分は3種（通常／笑い／困り）まで【仮】＝「テキスト1つにつき1回」の天井で工数を固定。
  - 窓：画面下1/3（約290pt）に収め、白地・角丸、**本文は太めの丸ゴ16〜17pt【仮】・1窓2〜3行・1タップ1窓**。地の文は名前札なし（ナレーション用に札の色を変える）。選択肢は窓の上に白地の大ボタンで出す（暗紫の枠は廃止）。
  - 操作：**スキップ／ログを左下に常設**し、薄い灰色の「タップで進む」は廃止して窓の▼に一本化。
  - 文面：既存の `DialogueData`／`ChoiceEventData` の文をそのまま窓に流し込む。新しい文は書かない。
- **スクショの該当**：`02_intro_02`（人物の灰色カプセル約472〜620pt、本文は明朝16ptで約669〜743pt、「タップで進む」約808pt・白45%）／`05_event_choice_live_w03`（本文が上詰めの約127〜280pt、下の約284〜708ptが空き、選択肢が約715〜806pt）／`05_event_choice_live_w03_result`（話者名「俺」が極小の金文字・1タップ1行・区切り線の下が空）／`10_finals_win_07`（谷口の一言が灰色の板で約559〜627pt）。
- **効く理由**：週画面の「いちばんゲームらしい会話」を他へ広げるだけで、「人物がただの灰色の形」「吹き出しも名前札もない」「タップで進むが読めない」が一度に消える。

### 原理3：選んだ結果は必ず「動く数字」で閉じる（効果は選ぶ前は隠し、選んだ後に見せる）

- **手本の具体**：ウマ娘のイベントは**選択前に効果を出さず**（攻略サイトの検索ツールが使われる）、**選択後に窓の中で「根性が10上がった」と数値で出す** [U1][W1]。トレーニングは選ぶと上昇値が出る [U1]。プリンセスメーカー系は**実行中に左下へ能力の上昇と所持金の減少が同時に流れる** [M1]。パワプロは打撃を「カッキーン!!」の**巨大な文字**で打ち抜く [P1]。いずれも**入力に対して必ず目に見える返事がある**。
- **本作のどの画面にどう当てるか**：選択肢イベントの選択後、窓の直下に**週の行動カードで既に使っている色チップ文法**（青「実力↑」・赤「相性+1」のピル型）を出して閉じる。**効果が実在する選択肢だけ**に出し、無いものに偽の効果を足さない【規律A境界＝表示のみ・数式不変】。週メインでは、舞台の獲得バーストが見えない週（W1〜W3で実力10→10・`04_week_w01_tap_burst`）は**持ちネタの完成度・手応え（`15_neta` のバー）など実在する別の値**を動かして返事にする案を他班の設計に渡す。W4→W5のようにイベントが0.5秒で被さる場合は、**週のバーストを0.6秒【仮】出し切ってからイベント窓を出す**（演出順の変更のみ）。音：数値が出る瞬間に短い上昇音1つ（既存 `SoundManager` の範囲で足りるか未確認）。
- **スクショの該当**：`05_event_choice_live_w03_result`／`_close`（効果が何も出ないまま閉じる）、`04_week_w01_tap_burst`（伸び0でバーストが写らない）、`05_event_narration_w05`（0.5秒で被さる）。
- **効く理由**：「押しても何も動かない」を演出と表示だけで潰せる。数式・乱数不変。

### 原理4：日常の地は明るい昼の色で統一し、暗さは「本番」にだけ使う（色は最初に決め、メインは1色）

- **手本の具体**：ウマ娘・学マス・パワプロ・ときめきメモリアルとも、**育成中の日常（イベントを含む）は明るい昼や室内の背景**で、暗転はレース・ライブ・特別演出に寄せる [U1][U4][G1][P1][T1]。ペルソナ系の講演は「**色を最初に決める（人は色を最も覚える）**」「メイン色1色（3青／4黄／5赤）にサブ色は最小」「優先度の高い所を明るく、低い所を暗く」「縁取りと白線で視線を導く」と明言し、**低予算だからこそUIをタイトルの顔にする**判断を語っている [A1]。パワプロは**黄の縁取り＋白窓**で文字を地から立てる [P1]。
- **本作のどの画面にどう当てるか**：イベント・イントロ・大会入口・大会結果の地を**週画面と同じクリーム〜暖色**（`Theme.bgTop #FFF7EC`→`bgBottom #FFDDBE`、カードは白）にそろえる。イントロの回想は夜でなく**夕方の暖色**（`#FFDDBE` から朱寄りの帯）で「昔」を出す【仮】。本文は `ink #2C2740` の太め丸ゴ16〜17pt以上。**メイン色＝朱 `#E8402C`、アクセント＝金 `#F6B301`、サブ＝既存の能力色のみ**。暗紫（`#2A2440` 近辺）は**決勝の本番・敗退判の一瞬・勇退の余韻と下帯**に限定。明朝は「谷口の一言」「年末の地の文」のような短い"手紙"に限り、**17pt以上・黒インク**とし、**暗い地×細い明朝×小さい文字の組み合わせを禁止**【仮】。
- **スクショの該当**：暗紫地で別ゲームに見えるのは `02_intro_01〜03`・`05_event_*`・`06_event_0013`・`08_tourney_result_fail_a／b`・`09_tourney_result_pass_*`。**基準側（明るい）**は `03_naming`・`04_week_*`・`12／13_year_result_*`。`10_finals_win_07` は地が黒でも金の放射光と紙吹雪で成立しているので**「本番」として暗地を残す**。
- **効く理由**：オーナーの不満（暗い・細い明朝・小さい・灰色）の4つ全てに同時に当たる。色の変更だけで、レイアウトの変更を伴わず先に効かせられる。

### 原理5：結果は「判定→育ちを形で1点→次の一手」の順に置く

- **手本の具体**：ウマ娘は**目標達成の専用画面（紙吹雪＋大文字）**、結果画面は**ファン数ピラミッドで「効く数字1つ」を強調**、育成完了は評価点とランク [U1][W2]。学マスは**能力別のランク文字**を結果に並べ、**ライブの演出が育成の成果で変わる** [W2][G1]。ダービースタリオン2は**愛馬カードの印が成長に応じて増える** [D2]。プリンセスメーカー系は**最終ステータス画面を見せてから結末を告げる** [M1]。ときめきメモリアルは結末（告白）が**育てた結果として来る** [T2]。共通は「勝敗の判」の**後ろに「何が育ったか」の形がある**こと。
