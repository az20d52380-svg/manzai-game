## §0 案の一言と思想

**一言：「1画面に主役は1つ。文字は3段、合図は▼1種、待ちは全部タップで畳める」。**

1. **何を大きくするか**：画面ごとに「判断（押す物）」か「結果（判・数字）」のどちらか1つだけを主役にし、表示を最大（34pt）にする。それ以外は2段下げるか、下層（スクロールの下・タップで開く）へ送る。華やかさは足し算ではなく、**主役に光と動きを集中させる引き算**で出す。
2. **何を消すか**：薄い灰色の補助文字（`inkDim` 3.46:1 以下の全文字）・「タップで進む」の文字（6か所）・同じ情報の二重表示（目標の大会名と残り週が上下2か所／「タップで札をめくる」と「タップで進む」）・判より先に結果をばらす表示・押しても返事のない待ち時間。
3. **何で揃えるか**：全画面に同じ「型」を当てる＝**文字の段（34/20/17/13pt・Dynamic Type 対応）／色の役割（文字は全て 4.5:1 以上）／送りの合図（▼1種）／親指の帯（判断は画面下40%）／待ちの規格（入力遮断 1.5秒以内・溜めは必ず畳める）**。週メインの明るいチャンキーな面はそのまま「型の手本」として残し、他の画面をこの型に流し込む。

**この案が一番強く解くオーナーの声**：「**読みにくい**」と「**UI/UXがゲームっぽくない**」。
- 読みにくい：暗い画面の本文はコントラスト比が足りている（地の文 白75%×#2F2540＝8.74:1）。読めない原因は**細い明朝W3×13〜14pt×1行28字×段落の塊×合図の遠さ**と、明るい画面の**灰色の補助文字（inkDim 3.46:1・inkFaint 2.05:1）**。本案は両方を「段・色・行長・合図」の規格で一度に潰す。
- ゲームっぽくない：ゲームらしさの芯は「押す→即返事→効いたが見える→次の判断が親指の下にある」の速い循環。現状は決勝が最短18タップで早送りなし、大会結果は2.6秒固定でスキップ不可、イベントは選んだ結果が何も出ない。本案はこの循環を全画面で同じ速さにそろえる。
- 「暗い」「華やかさの欠如」には、読む画面を明るい地へ移すこと（他案と共通の前提）と、暗い本番画面で**光る主役を1つに絞って大きくする**ことで答える。照明・幕の作り込みは他案の領分として深追いしない（§5）。

### §1-2 書体と文字サイズの階層

**書体**：ゲームフォント M PLUS Rounded 1c に一本化する（前提：名前の修正 `RoundedMplus1c-*`＝§3 の順1）。明朝 `.system(design:.serif)` 30か所と、`.system(size:)` の文字68か所は全て丸ゴの段トークンへ移す。明朝は**使わない**（例外を作らない＝「この画面だけ明朝」の判断を毎回しなくて済む）。決勝ロゴ「頂 グランプリ」も丸ゴ Black＋金。

**段（4つ・1画面で3つまで）**——サイズは iOS の標準テキストスタイルの既定値と同じ値にそろえ、Dynamic Type の追従を素直にする。

## §5 やらないこと

| 捨てるもの | 理由 |
|---|---|
| 明朝の部分的な温存（回想だけ・講評だけ・独白だけ等） | 例外があると「この画面は明朝か」を毎回判断する規則になり、段の規格が崩れる。講評の紙の質感は紙の色と罫で出す |
| 1字ずつの表示（タイプライター）・話者ごとのブリップ音 | 平均23字の台詞でも1回0.6秒待たせる。読む速さはプレイヤーが決める（R6） |
| 地の文を `\n` ごとに別のタップにする | イベントの平均タップが 6.1→8.2 に増える。泣き別れは行長と段落の描き方で解く |
| 読む画面の自動送り・オート再生 | 読む画面で勝手に進むと読み落とす。自動で進めるのは判断のない「観る」画面（決勝・客席版）だけ |
| 照明・幕・客席の粒の描き込み・袖の写真の壁 | 他案（舞台演出路線）の領分。本案は暗い地の4条件（§1-7）だけを決める |
| 新しい一枚絵・表情差分・立ち絵の大型化 | 情報設計の課題ではない。既存の `ManzaiFigure`・`CharacterFace` の再配置で足りる |
| 通過ラインと実力の差をゲージ・棒・色で描く | 「どれくらい届くか」が絵になると％（通過見込み）と同じ読まれ方をする。既決の％禁止の趣旨を守り、数字2つを並べるだけにする |
| 選択肢の効果を選ぶ前に見せる | 物語の選択が損得の計算になる。効果は選んだ後に結果チップで返す |
| 優勝の画面に1年の総括（伸びた能力・賞金）を足す | 1画面1メッセージ。総括は年末リザルトの仕事 |
| 画面内の「文字の大きさ」設定 | 端末の Dynamic Type に任せる（設定が二重になる） |
| 常時動く飾りの追加（キラキラ・背景の流れ） | 読む時間を奪い、Reduce Motion の対象を増やす。常時動くのは▼と人物の呼吸だけ |
| 決勝の出囃子籤ループ（10組の籤→ネタ→採点）の全面実装 | AD正典の理想形（A）だが工数が大きく、本案の課題（タップ数・読めなさ）は5ビート＋自分たちの4分で解ける |
| `Theme.inkDim` の値そのものを書き換える | 60か所の用途に「文字」と「淡い飾り」が混ざっている。値を変えると飾りまで濃くなる。新設の `inkSub` に文字だけを移す |
