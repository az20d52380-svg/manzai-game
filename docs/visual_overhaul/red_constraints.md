- UI専用の乱数：`uiEventRng`（`:64-66`・SaveData に保存）が、`evaluateChoiceEventFire()`（内の `rollWeeklyRandomEvent()`＝`:387`）→`rollWeekBanter()`（`:847`）の順で消費される。3案とも、この列に draw を足す記述は無い。`FinalsData` の表示用乱数は B2 が「引き順不変・0票の白票の夜は引き順が変わるので見送り」と明記、B1 も `FinalsData` の生成を変えないとしている。
