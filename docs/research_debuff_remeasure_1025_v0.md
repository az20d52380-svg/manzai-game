# 研究されるデバフの再実測 1025 v0（懸念台帳 L49・材料・数値は変えていない）

## §1 結論
1. **B 飽きられは今のスケールでも一度も発動しない（効かない）。** n=1000×16セルで基準と1桁まで同一。原因は sim_career.py:703 で「他大会を1回通過」するたびに連敗カウンタが全消去されること（コメントは「優勝」だが実装は通過）。連敗最大は1止まり、boredom_applied=0。
2. **A 客層二層(K=1.1)と C 波乱(±3)は、ハマった夜の欠落を直すと効きは小さい（±1〜3pt・ほぼ誤差）。** 効きすぎでも死んでもいないが、旧スケール較正の意味での「帯を守る調整」は今は不要。
3. **コードのままの A は測定として壊れている。** `_gp_perform` の二層版は B.perform の「ハマった夜(+12・10%)」を落としており、K=1.0 でも決勝が約−20pt、K=1.1 で −30pt に見える（見かけ上の「効きすぎ」）。台帳 L49 の再走は、この欠落を直してから採るべき。

## §3 測り方
- tools/measure_band_reference_v1.py の one()（M.one 全部入り・ボット4種×ネタ{無,込}×EVENTS_APP{F,T}）を再利用し、sim_career の AUDIENCE_SPLIT / BOREDOM_ON / UPSET_ON を1つずつ ON にして比較。基準は全OFF（＝今の既定値で、GameCore に未採用）。
- 実測スクリプト：scratchpad/debuff_remeasure.py（コードのまま）・debuff2.py（A を B.perform と同じ乱数順＋ハマった夜で上書き）。Pool(10, maxtasksperchild=1)・chunksize=1。n=300 で当たり→n=1000 で採用。
- B の診断：scratchpad/chk.py・chk2.py（CHALLENGER_STATS と RUN_BOREDOM の年次推移）。
