# アクセシビリティ点検 a11y_audit_v1（preview-all／iPhone 17）

スクショ: feedback_shots/a11y_v1/（xxl_* = extra-extra-large、ax_* = 直す前の accessibility-medium、ax2_/ax3_* = 直した後。コミットしない）

## 1. 文字の大きさ
- 原因: Font.maru/mincho 以外の `.system(size:)`（約40箇所＋YoseFont.gothic/number）は固定サイズで、設定を変えても大きくならなかった（会話文だけが追従して箱をはみ出した）。
- 直し: `Font.mzScaled`（Theme.swift）＝端末の文字サイズに追従し最大1.35倍で止める。maru/mincho/gothic/number と直書き .system(size:) をすべて経由（StageScene の看板「寄席」だけ除外）。標準サイズ（large）は従来と同一。
- 見切れ・折り返しを直した所: 能力アップのフッターボタン（リセット/おまかせ）・実力札の数字・ネタ帳の点数・設定の音量（BGM と数値）・大会エントリーの通過ライン/実力・黒帯の「知名度」・練習カードの見出し・千秋楽の注意文。
- 残り: 週メインの会話吹き出しは大きい文字で2行に（名札と軽く重なる）／練習カードの長い名称は縮小表示／xxl・ax-medium で撮れていない画面（決勝演出・イベント選択肢）は未確認／文字サイズの切替は起動時の値を使う（アプリ起動中に設定を変えると画面を開き直すまで反映されない）。

## 2. 読み上げ
- 追加: 能力アップの行（「センス、いま43、押すと能力を上げる」）と［−］、設定の音量［−］［＋］、実力バッジ、体力・知名度・所持金（借金はその旨）。
- 外した（accessibilityHidden）: 矢印/再生/チェック等の記号アイコン21箇所、ゲージ（隣に数字あり）、紙吹雪・光粒・集中線・粉塵・光芒・イベント背景。
- 残り: 週メインのカード・判子・舞台の図は既存の文字読み上げに任せている（個別ラベルなし）。VoiceOver の実機通し確認は未実施。

## 3. 色
- 体力ゲージ＝数字（体力 100/100）併記／足りない粒＝朱＋右上の点／通過・敗退＝「優勝」「敗退」の判子文字／借金＝「借金」タグ＋マイナス記号／ランク＝文字（S〜F）。色だけで分けている所は見つからず、追加は不要だった。

## 4. 動き（視差効果を減らす）
- 既に対応済み: Juice・各演出（祝賀・ランクアップ・年越し・結果）。
- 追加: 舞台の呼吸・粉塵・波形・結果の光粒（TimelineView を pause）、カード横ブレ、バウンス矢印、吹き出しの点滅、判子のズーム、数字のバウンス。
