# 【辛口UIレビュー R3】骨格は劇的に進化したが、今度は「AI特有のパッチワーク破綻」が炸裂している

売れているスマホ育成ゲーム（パワプロのサクセス、ウマ娘など）のUIデザイナーとして、今回の改修画面（`g2_week.png`、`g2_allocate.png`）を容赦なく辛口でレビューします。

率直に言って、**能力アップ画面（allocate）は見違えるほど良くなりました。**
垂直Gridの整列とボタンの主客是正により、ようやく「ゲームUIの骨格」が通りました。

しかし、**週メイン画面（week）は新たな地獄（レイアウト多重衝突事故）**を引き起こしています。
指示された要素を前後の文脈を考えずにツギハギした結果、**「AIが指示されたパーツを盲目的にマージした時に起きる典型的なパッチワーク破綻」**が起きています。

以下、容赦なく解体・再指導します。

---

## ① 前回の指示が効いた所・効いていない所

### 【週メイン画面（g2_week.png）】
*   **効いた所**:
    *   **目標バナーの独立化**: 「春新人賞A まで あと11週」が最上部に独立帯として切り出され、中央カードとの最悪なめり込みは解消された。
    *   **フッターの重複削除**: 下帯にあった「1年目 1週」が消え、ヘッダーに一本化されて画面が整理された。
    *   **プログレスバーの廃止**: ダウンロード中だった細い無機質バーが消え、提灯アイコン5個＋「100 / 100」の数値表示に変わった。
    *   **「出張中」テープの導入**: 押せないボタンに対して斜めテープを貼るアプローチ自体は実装された。
*   **効いていない所・中途半端な所**:
    *   **ステータス札の配置事故が別ベクトルで悪化**: 木札を右上に置いた結果、**背景の「寄席」看板に真上から覆いかぶさり、さらに木札の中で「実力 115」に「優勝」バッジ、「相性 10」に「無双」バッジがモロ被り**して文字が完全に潰れている。重なりを解消しろと言ったのに、別の場所でさらに醜い大事故を起こしている。
    *   **出張中テープの下地テキストがそのまま**: 「今週は撮影」を残したまま上から「出張中」を重ねたため、二重の言い訳になっており文字が渋滞している。
    *   **提灯の和風情緒の欠如**: 提灯がただの「緑の楕円に横線3本」。和の風情がなく、スイカか緑のカプセル剤に見える。

### 【能力アップ画面（g2_allocate.png）】
*   **効いた所**:
    *   **X座標の垂直Grid完全整列（最大の前進）**: 「閃・語・間・存・胆」のアイコンと、下の消費ポイントの列が垂直にビシッと揃った。どの経験点を消費するのか瞬時に視線が通る。
    *   **ボタンの主客転倒の是正**: 「確定」が最大幅・深紅の主役ボタンになり、「おまかせ」が白地に赤枠のサブボタンに格下げされた。タップ優先順位が明白。
    *   **六角形エンブレムの導入**: Excelの四角枠から六角形のゲームらしいエンブレムに進化した。
    *   **説明テキストの削除**: 「+を押すと1つ上がる」という窓口案内文が消え、画面が引き締まった。
    *   **和の五色の適用**: パステルカラーが消え、深みのある和風カラーで統一された。
*   **効いていない所・中途半端な所**:
    *   **「確定」ボタンの質感不足**: 赤く大きくはなったが、立体感・ツヤ・金の縁取りがなく、「業務システムの送信ボタン」の域を出ていない。
    *   **プレビュー表示の欠落**: 実力エリアを黒帯にしただけで、能力を振ったときの「(+3) → 45」のようなリアルタイムプレビューがないため、依然としてプレイヤーに暗算を強いる。

## ② 新しく目立った崩れ・AIっぽさ

1. **【指示パッチワーク病】前後の文脈を無視した「言われたことだけ機械的適用」**
   - 「木札を右上に置け」と言われたから置いたが、元々そこにあった「寄席」の看板の上にそのまま重ねて潰している。
   - 「出張中テープを貼れ」と言われたから貼ったが、元の「今週は撮影」の赤字を消していない。
   - 「六角形にしろ」と言われたからエンブレムだけ六角形にしたが、**前バージョンのカード左端にあった「謎の赤い縦線」がゴミのように残っている**。
   - 周辺要素との整合性を確認せず、差分コードだけを盲目適用したAI特有の雑さです。
2. **【数字マトリクスの『0の海』】（能力アップ）**
   - 消費しないマスにデカデカと「0」が15個も並んでいる。スプレッドシートの空セルをゼロ埋めしたような見た目で、視覚的ノイズが極大。「どこが消費ポイントなのか」が0の群れに埋もれて瞬時に読み取れません。
3. **【木札内のバッジ衝突事故】（週メイン）**
   - 実力「115」の上に「優勝」バッジ、相性「10」の上に「無双」バッジがダイレクトに突き刺さっています。文字とバッジが重なってどちらも読めない。UIにおける「重ね順（Z-Index）とマージン計算」が完全に破綻しています。
4. **【墓石のような暗黒ランクエンブレム】（能力アップ）**
   - DとFの六角形が暗黒のチャコールグレー（#333333前後）でベタ塗りされており、まるで「墓石」か「壊れた装甲」。育成ゲームのランク表示は、たとえ低ランクであっても「これから育てる楽しさ」を感じさせるトーンであるべきなのに、画面全体がお通夜のように重苦しくなっています。
5. **【吹き出しのしっぽの不自然な突き刺さり】（週メイン）**
   - 吹き出しの三角形のしっぽが、谷口アイコンの口元ではなく、アイコンの右端フレームに唐突に突き刺さっています。

## ③ 次に直す指示を画面ごと優先順に5個（SwiftUI実装レベル）

---

### ■ 週メイン画面（`g2_week.png`）改善指示 TOP5

#### 1. 【最優先・大事故修正】右上木札のレイアウト再構築（バッジ衝突＆寄席看板被りの完全解消）
*   **問題**: 木札が「寄席」看板に被り、中のバッジ（優勝・無双）が数値（115・10）に覆いかぶさって読めない。
*   **実装指示**:
    *   背景の「寄席」看板（暖簾）は木札の**真上または左側**にセパレート配置（重なりを完全排除）。
    *   木札サイズを `width: 105pt, height: 130pt` に設定。
    *   木札内部をVStackで厳密にレイアウト:
        *   **実力行**: HStackで「実力」ラベル（12pt）＋「115」（`22pt Heavy`, DinCondensed）。その**右横**に「優勝」バッジ（`height: 16pt`, `padding(.horizontal, 4)`, 背景 `#C1A550`、白文字 `9pt Bold`）を配置。**数値の上には絶対に重ねない**。
        *   **相性行**: HStackで「相性」ラベル（12pt）＋「10」（`20pt Heavy`）＋「無双」バッジ（`height: 16pt`）。
        *   その下に相性ゲージ（高さ `5pt`、角丸 `2.5pt`、ゲージ色 `#C0392B`）。

#### 2. 【視覚ノイズ根絶】「出張中」コマンドボタンの二重テキスト整理
*   **問題**: 「今週は撮影」の上に「出張中」テープが重なり、文字だらけで大渋滞。
*   **実装指示**:
    *   「ネタを書く」「練習」のボタン内で、下地の赤文字「今週は撮影」を**完全削除**。
    *   ボタン全体を薄いグレーマスク（`Color.black.opacity(0.08)`）で覆う。
    *   赤い「出張中」テープ（角度 `-10度`、背景 `Color(hex: "A62B1E")`、白文字 `12pt Heavy`、ドロップシャドウ `x: 1, y: 1, color: .black.opacity(0.3)`）をボタン中央に斜め貼り。
    *   文字で言い訳せず、テープ1枚で「選べない」ことを直感させる。

#### 3. 【記号の洗練】「提灯ゲージ」の和風リデザイン（脱・スイカカプセル）
*   **問題**: 提灯がただの緑の楕円に線が入っただけで、カプセルやスイカに見える。
*   **実装指示**:
    *   提灯コンポーネントをSwiftUIで再構成:
        *   上下の張木: 上下に幅 `14pt`, 高さ `2pt` の黒い長方形（`Color(hex: "1C1917")`）。
        *   中央の胴体: 幅 `16pt`, 高さ `20pt`, 角丸 `4pt`。
        *   **点灯時**: 満タン時は深みのある若竹色（`Color(hex: "2E583C")`）に和紙の透過ハイライト。ピンチ時（残り2個以下）は朱赤（`Color(hex: "D9381E")`）でゆっくり点滅。
        *   **消灯時**: 煤けた暗灰（`Color(hex: "4A453E")`）。
    *   これで「寄席の軒先に並ぶ提灯」の風情が出る。

#### 4. 【文字の引き算】コマンドボタンの解説テキスト全廃と判子アイコン化
*   **問題**: 「お金を稼ぐ」「体力を戻す」などの説明文が所帯じみている。
*   **実装指示**:
    *   コマンドボタン内のサブテキスト4行（お金を稼ぐ、体力を戻す、経験点で能力を上げる、アイテムを買う）を**全廃**。
    *   代わりに、コマンド名の左に小さな墨絵・判子風アイコンを配置（バイト: 小判、休む: 座布団、能力アップ: 扇子、お店: 暖簾）。
    *   コマンド名（「バイト」「休む」等）のフォントサイズを `17pt Bold` から `20pt Heavy` に拡大し、タップしやすさを強調する。

#### 5. 【キャラ立ち】吹き出しのアンカー（しっぽ）位置修正
*   **問題**: 吹き出しの三角が谷口のアイコンの右端フレームに突き刺さっている。
*   **実装指示**:
    *   吹き出しのしっぽ（Path）の始点を、谷口アイコンの**右上角（口元の延長線上）**から吹き出し下辺に向かって自然に伸びる形状に変更。
    *   セリフのフォントを「ヒラギノ明朝 ProN W6」にし、寄席の肉声感を出す。

### ■ 能力アップ画面（`g2_allocate.png`）改善指示 TOP5

#### 1. 【最優先・視覚革命】「0の海」を全廃し、ハイフン化または空欄化
*   **問題**: 消費しないマスにデカデカと「0」が15個も並び、スプレッドシート化している。
*   **実装指示**:
    *   消費ポイントが `0` のセルは、すべて**極小の薄いハイフン「-」**（色: `Color(hex: "C5BFB0")`、14pt Regular）に変更するか、**完全非表示（空欄）**にする。
    *   これだけで画面のノイズが60%削減され、実際に消費する「8」「6」「4」「23」「42」といった重要数字だけが目に飛び込んでくるようになる。

#### 2. 【爽快感の創出】「実力 42」のリアルタイム変動プレビューと番付札化
*   **問題**: 実力エリアがただの黒い帯で、能力を上げた際の変化が分からない。
*   **実装指示**:
    *   「実力 42」の黒帯を、金縁付きの「番付札」（背景: `#231F20`、金枠: `1.5pt Color(hex: "D4AF37")`）に変更。
    *   ［＋］ボタンをタップしてポイントを仮割り振りした際、実力数値の右横に**鮮やかなエメラルドグリーン（`#2ECC71`）の太字で `(+3) ➔ 45`** とリアルタイム表示（`transition(.scale.combined(with: .opacity))`）。
    *   確定前に「どれだけ強くなるか」を実感させ、育成の指先快感を作る。

#### 3. 【脱・墓石＆ゴミ掃除】ランクエンブレムのブラッシュアップと謎の赤線削除
*   **問題**: カード左端に謎の赤い縦線が残り、D/Fのエンブレムが黒すぎて墓石に見える。
*   **実装指示**:
    *   カード左端に残っている前バージョンの「赤い縦線」を**完全削除**。
    *   D・Fのエンブレム背景色を調整:
        *   **F**: 鈍い木肌色・真鍮色（`Color(hex: "8A7F73")`）に濃灰文字。
        *   **D**: 落ち着いた鉄紺・青銅色（`Color(hex: "4A6572")`）に白文字。
        *   **A**: 燃えるような朱紅（`Color(hex: "C0392B")`）＋金枠（`#F1C40F`）。
        *   **S**: 黄金グラデーション（`#F39C12` ➔ `#F1C40F`）＋黒文字。
    *   エンブレム上部に白の線形グラデーション（`LinearGradient(colors: [.white.opacity(0.25), .clear], ...)`）を入れてメタリックな光沢を付与。

#### 4. 【ゲームの手触り】［＋］ボタンの物理プッシュ感と［−］ボタンの出現
*   **問題**: ［＋］を押した時のフィードバックがなく、振りすぎた時に戻せない。
*   **実装指示**:
    *   ［＋］ボタン（背景 `#B83A2A`）をタップした瞬間に `scaleEffect(0.92)` ＆ 下部シャドウが `2pt ➔ 0pt` に沈み込むアニメーションを付与。
    *   同時に `UIImpactFeedbackGenerator(style: .light).impactOccurred()` を発火。
    *   1ポイント以上振った行には、［＋］の左側に小さく**［−］ボタン**（幅 `30pt`, 背景 `Color(hex: "5D6D7E")`）をスライド出現させ、安全にやり直せる操作性を確保する。

#### 5. 【決定感の頂点】「確定」ボタンのゴールド発光＆パルス
*   **問題**: 「確定」ボタンが赤くなっただけで、業務ツールの送信ボタンに見える。
*   **実装指示**:
    *   背景: 単色ベタ塗りから、漆塗りのような深みグラデーション（`LinearGradient(colors: [Color(hex: "C0392B"), Color(hex: "8A1F13")], startPoint: .top, endPoint: .bottom)`）。
    *   枠線: `1.5pt` のゴールド枠（`Color(hex: "E5C158")`）。
    *   文字: `20pt Heavy` 白抜き ＋ 下部にドロップシャドウ（`radius: 1, y: 1, color: .black.opacity(0.5)`）。
    *   1ポイントでも能力アップが予約されている時、ボタン外周に金色の光が呼吸するように明滅するパルスアニメーション（`repeatForever(autoreverses: true)`）を走らせる。

### デザイナーからの総括

能力アップ画面は**「Gridの垂直整列」**というUIデザインの最重要関門を突破しました。あとは「0の海」を消してプレビューと手触りを磨けば、余裕で80点（商業リリース基準）に届きます。

問題は週メイン画面です。「要素を足した結果、別の要素と被って文字が読めなくなる」のは**UIデザイン以前の初歩的なバグ**です。右上の木札とバッジの衝突をミリ単位で整頓し、コマンドボタンの冗長な説明文を捨ててアイコン化してください。それだけで見違えるようにプロの画面になります。
