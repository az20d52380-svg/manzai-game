# 選択イベントの背景を場所ごとに変える（試作 v0）

## 何を変えたか
これまでは、どの選択イベントも背景が「昼の稽古場＋センターマイク」か「夕景」のどちらかで、ト書きの場所（焼肉屋・楽屋など）が絵に出ていなかった。
場所が稽古場以外のイベント 5種の背景を、図形で描いた小物と色味で差し替えた（表示だけ。効果・数値は触っていない）。

| 場所 | イベント | 背景の小物 |
|---|---|---|
| 焼肉屋 | 0013 先輩のおごり | 朱の提灯・朱と生成りののれん・手前に赤く燃える網のテーブル（暗い墨茶の壁） |
| 劇場の楽屋 | 0025 ライブの順番、0027 ライブのあと | 金縁の電球つき大鏡・朱/臙脂/金の衣装掛け |
| 駅のホーム | 0014 ライブ帰りの駅 | 駅名の札・灰色の柱・黄色い線 |
| 深夜のファミレス | 0016 目が冴えた夜 | 夜の窓・金色の吊りランプ・臙脂のボックス席 |
| 事務所 | 0022 撮影の話 | ブラインドの窓・予定表の札・手前に木の机 |

稽古場・稽古場の帰り道（夕景）のイベントは従来のまま。バイト先の休憩室（正社員の話）は今回未対応（昼の稽古場のまま）。
