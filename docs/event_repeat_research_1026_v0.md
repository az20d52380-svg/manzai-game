# 長期育成ゲームのイベント再発の扱い（材料）

調査日 2026-10-26。Web検索8回＋Fetch1回。**検索では各作品の内部仕様まで確認できたものは少ない。「未確認」を多く残す（推測で埋めていない）。**

## 例（観点ごと）

### ①同じイベントの再発（間隔・文面の差し替え）
- **RimWorld**：イベントごとに再発までの待ち日数（クールダウン）がある。例：毒の降下物90日、火山の冬140日、熱波・寒波・ビーバー・胴枯れ30日、日食・サイキックドローン15日、黒服の男60日、隕石は約1年。襲撃・害虫などはクールダウン記載なし。熱波中は寒波が出ない等の排他もある。「古代の危険」はマップに1回のみ。→ 出典[1]。ストーリーテラー側にも「襲撃が出たら一定間隔待つ」クールダウン段階がある（モダー向けガイドの記述）→ 出典[2]。
- **CK3**：プレイヤーから「ランダムイベントが20〜30種の使い回しに感じる」という不満がある。開発側は、状態＋ランダムタイマー方式から、プレイヤーやAIの行動の結果として起きる方式に移行中と説明。MODでは一部イベントに5年クールダウン等を足して対処。→ 出典[3]。mean_time_to_happen（平均何か月で起きるか）に条件で倍率をかける書き方が使われる→ 出典[4]。
- **ウマ娘**：同じ隠しイベントが育成内で2年目・3年目の2回起きる例（テイエムオペラオー、条件はレース勝利）。毎周条件を満たす必要あり。2回目の文面差し替えの有無は**未確認**。→ 出典[5]。
- **栄冠ナイン**：日付固定マス（七夕など）は毎年起きると思われるが、2年目以降に文面や効果が変わるかは**未確認**。白・青パネルのイベントは基本ランダム。→ 出典[6]。
- **カイロソフト（ゲーム発展国）**：表彰イベントや新ハード発売が起きる、までは確認。再発の仕組みは**未確認**。→ 出典[7]。

### ②年数や段階に応じた後半専用イベント
- **RimWorld**：開始からの日数・襲撃ポイント（成長度）で解禁される。例：毒の降下物・火山の冬は60日目以降、メカノイドは襲撃ポイント300以上、害虫は400以上。＝「進行度の閾値で新しい物が出る」型。→ 出典[1]。
- **ウマ娘**：育成3年目1月前半に確定で福引、2年目11月前半に二人三脚など、年・時期で固定のイベントがある。条件を満たさないとイベントは起きるが恩恵が無い（発生と効果が別）。→ 出典[5]。
- **栄冠ナイン**：3年で卒業し毎年新入部員が入る＝イベントの内容でなく「状況」を回す作り。後半専用イベントの有無は**未確認**。→ 出典[6]。

### ③連続イベント（続き物）
- **ウマ娘**：「次のターンから桐生院トレーナーのランダムイベントが発生する」のように、条件達成後に特定の続きイベントが出る形。→ 出典[5]。
- **CK3**：イベントが別のイベント・決定・戦争結果から呼ばれる連鎖（is_triggered_only）が基本。→ 出典[4]。
- ときめき系・カイロソフトの連続イベント：**未確認**（検索で該当なし）。

### ④その他
- **RimWorld**：ストーリーテラーごとに出方の波が違う（Cassandraは山と谷、Randyは完全ランダム）。→ 出典[1]。
- **ウマ娘**：遭遇済みイベントを見返せる「育成イベントギャラリー」。→ 出典[5]。
- **CK3**：イベントを増やす／行動の結果にする、という「量」と「きっかけ」で単調さを減らす方針。→ 出典[3]。
- ときめきメモリアル・プリンセスメーカー・ダビスタ：検索で情報なし＝**未確認**。

## このゲームへの当てはめの候補（決めない・選択肢だけ）
1. **再発クールダウン方式**：1キャリア1回をやめ、各イベントに「再発まで◯週（または◯年）」を持たせる。長さをイベントごとに変えれば出方に濃淡が出る（RimWorld型）。
2. **2回目以降の文面差し替え**：同じイベントの2回目・3回目は台詞や結果を変える（「また来た」「恒例」）。作る量は増えるが、既存25種を活かせる。ウマ娘の2回起きる隠しイベントが近い（文面差し替えの実態は未確認）。
3. **年数・段階の解禁**：7〜10年目でだけ出る後半専用イベントを数種足す（例：ベテラン・後輩・賞レース常連向け）。RimWorldの「閾値で解禁」型。
4. **続き物**：前に選んだ選択肢を条件にした続編を後半に置く。同じ25種を再利用せず、後半に出る理由が自然になる（CK3の連鎖型）。
5. **併用案**：基本は1、後半の厚みに3、余力があれば2と4。1だけなら最小コストだが、同じ文面の反復に冷める恐れ（CK3の不満の例）。
6. **観点**：再発を許すと選択の影響（ステータス・好感度）が積み上がるので、バランス確認が要る（数式に触る作業）。
