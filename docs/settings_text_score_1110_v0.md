## §2 照合した仕組み
- 実力＝センス・発想・表現・華の重み付き和（GameEngine.jitsuryoku）。本番スコア＝実力＋相性＋ブレ＋ハマった夜＋体力ペナルティ（perform）。
- ブレ幅＝5＋15×(1−メンタル/100)（blurWidth）＝「メンタルはばらつきを小さくする」と一致。
- 体力ペナルティ：50未満 −5／30未満 −10／10未満 −15（staminaPenalties）＝用語集に記載なし（235 △）。
- ネタ補正：(完成度−50)×係数＋(客の反応−50)×係数（上下限あり）−飽き1点×段（netaTiredPenalty=1・上限 netaTiredCap=2）。飽きは年初に「前の年に大会で掛けたネタ」が1段進む・しまっても戻らない（WeekRunner 150-156）。
- 生活費：livingInterval=4 週・livingCost=14万円・部屋の上乗せ roomRents=[0,5万,15万]・休みの戻り roomHeals=[0,10,20]（完全休養・気分転換）。
- 夜逃げ：money < bankruptLine(−100万)。
- 回数券：新幹線＝その年の大阪の交通費0・体力0（WeekRunner 209・年初に解除 Item.swift 84）。銭湯＝休みの戻り＋（枚数制）。稽古場の年契約＝練習の伸び＋itemStudioBonus・年初に解除。
- オファー：ひな壇・ラジオ・ロケ・営業（offersNamed）。札は知名度30・55で増える（offerCardFames）。
- 交通：夜行バス 1万円・体力−25／新幹線 3万円・体力0。
- 予選：1回戦・2回戦・3回戦・準々決勝・準決勝（gpRoundNames）。敗者復活は準決勝敗退のみ・決勝と同週。決勝は第47週。決勝ラインは知名度で上下（WeekRunner 301）。
- すれ違い：相性が上がった週に減る・二人で舞台の週は増えない・それ以外は (上限−相性) に比例して増える・予告（riftWarn）→100で解散（applyRiftWeekEnd）。
- 王手：7審査員の勝者の3票目の瞬間（FinalsPresentationView "oute"）。
- 画面の語（番付・真剣勝負・未振分あり・温存の一手・月末の支払い・仕上がりの4段・自信作・頂GP・持ち分・戦績・年間香盤・部屋を選ぶ・勝負ネタにする・出張中・休演・体調ダウン・出順・しまう・日程・ツカミ/中盤/オチ）は全部、他の画面に実在。
