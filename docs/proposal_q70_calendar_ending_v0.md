# 試作q70 カレンダー・エンディング（表示のみ・main未反映）

根拠：docs/uiux_not_ai_audit_v0.md の 05・12 と「全画面共通の直し方トップ5」。週メイン画面の試作（7e17d92）と色・書体をそろえた。GameCore・数値は触っていない。

## カレンダー（CalendarView.swift）
- 上に臙脂の帯と金の罫線で「年間香盤」の見出し。劇場の香盤表のような見た目にした。
- 角丸のマス目をやめ、墨の罫線だけの番付表にした。月は生成り色の左の欄に太字で書く。
- 大会の週は朱の色面に白抜きで「大会／GP／決勝」と書く（いちばん大事な週が一目で分かる）。いまの週は金の栞枠。
- 過去の週は小さな色の点をやめ、やった事の頭文字（稽・バ・回）にした。凡例も同じ印で、文字は11pt。

## エンディング（S6bView.swift の最初の画面）
- 黒背景を臙脂の幕に変え、中央に生成りの名ビラ（金の二重縁）を置いた。
- 大きな寄席文字で「千秋楽」、下に残金と、会場名を朱の判子風の札で出す。
- 客席の点は金の控えめな色にして、名ビラの下に残した。
- 後ろの画面（年表・壁の写真）の背景も同じ幕の色になる。
