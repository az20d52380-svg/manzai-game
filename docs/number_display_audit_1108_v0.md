# 数値表示の端の値 静的点検 v0 / 2026-11-08

## 結論（3行）
- 負の所持金で実際に崩れるのは 3 か所：帳面の名札（`¥-3,000`）、年替わりカーテン（`¥-3,000`／`¥-15万`）、そして負号の字が場所で違う（`-` と `−`）。いずれも表示だけの修正で判断不要。
- 「+」付きの増分表示（知名度・経験点・相性・ネタ）は全て `> 0` のガードがあり、`+0`／`+-` は出ない（ただし知名度の下がりは出ない＝仕様かは未確認）。
- 大きい値は `Yen.man` が「億」「桁区切り」を持たず `10000万` になる、`99,999` が `10.0万` になる等が残る。整数割り（`/10_000`）で 4.5万 が `4万円` になる所は、金額が1万の倍数でなければ要確認。
- 金額の書式の統一（¥万／¥,区切り／円／万円）自体は既知：`docs/money_format_inventory_1027_v0.md`（§1 現状の表／§2 統一案 A・B・C／§3 推奨）。下表で「既知」とした所は重複。

行番号は 2026-11-08 時点の ManzaiGame/Sources。「例」は式から机上で出した文字（実機未確認）。

## 小数（観点4）の結論
Double をそのまま文字にしている所は見つからなかった（知名度は `rounded()`、金額は Int、`Yen.man` は意図した小数1桁）。`12.0` は出ない。
