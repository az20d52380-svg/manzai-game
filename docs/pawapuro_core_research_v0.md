# パワプロ「サクセス」システムデザイン調査レポート（漫才師育成SLG向け）

## §1. 毎週/毎ターンの意思決定構造 — なぜ「コマンドを選ぶだけ」で悩ましいのか

**ターンの基本形**: 1ターン=1週。コマンドは「練習（複数種）／休む／遊ぶ／通院／デート／能力アップ」程度の一列メニューだけ。それでも悩ましいのは、**1つの選択が最低4つのリソースに同時に触る**ため。

- **体力**: 練習で消費。体力が低いと**ケガ率が上昇**（各練習コマンドにケガ率%が明示表示される）。「休む」の回復量は約60固定＝**60以上減らしてから休まないと損**という「回復の無駄」計算が生まれる。睡眠に乱数（ぐっすり=80回復+やる気UP／浅い眠り=30回復）があり、「休む」すらギャンブル。
- **やる気**: 絶好調〜絶不調の5段階。**獲得経験点と試合成績の両方に乗算**でかかる。「遊ぶ」「デート」で回復。つまり「練習しない週」が間接的に将来の練習効率を買っている。
- **ケガ率**: 体力が余っていても「あえてケガ率10%の練習を踏む」期待値判断が攻略の定石。「爆弾」（肩・肘・足）は放置すると爆発して能力ダウン/ゲームオーバー→「通院に1ターン払うか賭けるか」の保険問題。
- **評価（デッキ/仲間/彼女）**: 評価を上げると**同じ練習マスに彼らが立った時にタッグ練習**が発生し経験点が跳ねる。→「どの練習が伸びるか」は毎ターンのキャラ配置（乱数）で変わるため、**同じコマンドリストでも毎ターン盤面が違う**。

**毎ターンの天秤**: ①今の経験点効率（タッグが光っている練習）vs ②将来の効率（評価上げ・やる気上げ・体力温存）vs ③リスク（ケガ率）vs ④締切（次の試合までにノルマ）。**「最適解が毎ターン乱数で動く4変数のポートフォリオ選択」**が正体。

- **原則**: コマンド数を増やすのではなく、1コマンドが触るリソース数を増やす。かつ「どの選択肢が今おいしいか」を乱数（キャラ配置＝タッグ）で毎ターン揺らす。
  **適用案**: 5コマンド固定でよい。毎週「相方や先輩芸人がどの稽古場にいるか」を乱数配置し、噛み合った週だけ「合わせ稽古」で経験点が爆発する構造。
- **原則**: 「休む」を無料の安全牌にしない（回復量固定＋機会損失で、休むタイミング自体を意思決定にする）。
- **原則**: リスクは隠さず数値（ケガ率%）で見せる。悩ましさは不透明さではなく期待値の綱引きから作る。
  **適用案**: 「スベり率」「炎上率」等をコマンド上に%表示。

## §2. イベント密度とテンポ

**1周の長さ**: 近年は1年間に短縮がスタンダード。アプリ版は**4セクション・計約48ターン、既読スキップ込みで1周20〜30分**。サクサクセスは1周約5分。シリーズ全体が「短縮」方向に進化。

**イベントの二層構造**:
- **セクションイベント（固定）**: 必ず同じ週に起きる（新キャラ登場、クリスマス、大会）＝物語の背骨とペース配分の目印。
- **ランダムイベント**: デッキ採用キャラごとにイベントテーブルを持ち込む（**イベントデッキ制**）＝プレイヤーが周回前に「今周のイベント群」を自分で編成する。
- 体感密度は「ほぼ毎ターン何かある」。イベントは大半が**1画面・選択肢1〜2個・即時報酬**で完結。1ターンのループは数十秒。

- **原則**: 固定イベントで背骨を作り、ランダムは「デッキ」として事前編成させる＝乱数が「引き」の楽しみに変わる。
  **適用案**: 「相方・師匠・同期・恋人」カードのデッキ編成。大会日程は固定イベントとして全周共通（実装済に合致）。
- **原則**: 1周は20〜40分／約50ターン。1ターンのループを数十秒に保つ。

## §3. 試合パート — 「見てるだけ」の回避

サクセスの試合は**基本オート＋要所だけ手動**（野手は自分の打席のみ、投手は得点圏ピンチのみ）。近年作は試合前に**操作粒度をプレイヤーが選択**（「サクッと自分の打席のみ」〜「COMにおまかせ」）。

1. **操作するのは「勝敗が動く瞬間」だけ**。消化イニングは高速スキップ。
2. **育てたパラメータが操作感に直結**＝育成の答え合わせが試合。
3. **試合結果が育成に還流**（経験点・評価・称号）。乱数が強い＝負けても引きのせいにでき、次周動機になる。
4. 栄冠ナインは「采配のみ」で成立＝**全操作でなく「介入の質」でも見てるだけは回避できる**。

- **原則**: 触るのは山場だけ。介入粒度をプレイヤーに選ばせる（介入するほどリターン増）。
  **適用案**: 本番は「ツカミ／中盤の分岐／オチ」の3箇所だけ介入（どのネタ玉を切るか・テンポ調整）。「全部見る/山場だけ/おまかせ」を出番前に選択、介入するほどウケ経験点ボーナス。
- **原則**: 本番は育成の答え合わせであり、結果が次の育成資源として返る双方向ループ。

## §4. 報酬設計 — 経験点の気持ちよさと周回動機

**二段階報酬（サクセスの核）**: 練習→経験点（複数通貨）→任意タイミングで「能力アップ」画面で自由割り振り。
- ①毎ターン数字が跳ねる小報酬（タッグで数十〜百点のインフレ感）、②貯めて一気に注ぐ大報酬（**G→…→A→Sとランク文字が色と効果音つきで段階昇格**）の2層。
- 割り振り自体が意思決定。特殊能力は金特（虹/金の演出）で希少度を視覚化。
- 完成時は選手ランク＋スカウト評価＋ドラフト順位の多軸成績表で1周を採点。

**周回動機**: 継承（過去の自作選手が後輩に出る）／持ち越し資産（ポイント・称号・シナリオ解放）／出口の多さ（作った選手を使う場がある＝育成が消費でなく生産）。

- **原則**: 報酬は「稼ぐ（毎ターンのジャラジャラ）」と「使う（一括昇格演出）」に分離。
  **適用案**: 実装済の粒→割り振りはこの型に合致。ランク昇格の音・色の演出強化＝D→Cで音が変わる。
- **原則**: 1周の成果物を①総評ランク採点②次周資産③別モードで使う、の3出口。

## §5. ウマ娘によるサクセスの現代化

| 要素 | サクセス | ウマ娘 |
|---|---|---|
| ターン | 1週×約48〜150 | 1ヶ月2ターン×3年=72（トレ可能40〜45）・1周約30分 |
| 経験点 | 複数通貨→割り振り | ステ直上げ＋スキルPt一元化（認知負荷削減・「使う楽しみ」はスキル購入に残す） |
| タッグ | 評価を上げてタッグ | **絆ゲージ可視化→オレンジで友情トレ**＝序盤絆上げ/後半回収の周リズム定型化 |
| 試合 | 一部手動 | **観戦のみ**＋スキル発動演出。**目標レース（中間締切）5〜7個・未達=即敗北**の緊張で回避 |
| 継承 | おまけ的 | **因子＝周回の主目的化**（完了時に乱数生成→3世代継承）＝「強い子を作るために親を作る」自己増殖ループ |
| 失敗 | ケガ・ゲームオーバー | 体力起因の即死廃止・目標未達のみ失敗・コンティニュー有 |

- **原則**: 割り振り自由度（サクセス型）と直上げ手軽さ（ウマ娘型）はトレードオフ。買い切り/濃い1周ならサクセス型。
- **原則**: **中間締切を4〜7個置き「未達=失敗」の緊張だけで観戦パートは成立する**。
  **適用案**: 「オーディション→深夜番組→3回戦→準決勝→決勝」を目標列に固定し、各締切までの要求値（ファン数/ウケ力）を提示。
- **原則**: 周回報酬自体を乱数化（因子）すると育成完了画面が「ガチャ開封」に変わり、もう1周の引力が最大化。

（出典・確度メモは調査agentの参照リンク一覧どおり。ターン数・操作方式・因子/絆は複数ソース裏取り済み、回復量等の具体数値は作品差あり。）
