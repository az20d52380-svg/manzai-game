## §4 所見
1. 【設計上の懸念・オーナー判断待ち】周回ボーナス 型1は、全部入りの状態では**優勝を上げない**。①演技4能力は「キャリア累計の成長予算」で天井があり、初期の経験点は前借り（早く伸びるだけ）。②大会の経験点と役が重なる（どちらも序盤を早める）。③初期の経験点・所持金で、能力だけを追うボット（必要充足）が相性の上がるネタ合わせを選ばなくなり、3年目の相性が 16.6→10.3、解散が増える（A で予告に応えるボットにしても 点0→10 で 2.7→10.2%）。③は人なら避けられる部分もある。上がる形にする材料：成長予算も点で足す（+0.03/点で3ボット平均 2.9→3.8/3.3%・+0.1/点は点30で 5.3% と急）・初期の相性も足す（+0.2/点で点30の解散が 8%に戻る）。どれも決定事項の外なので数値は選んでいない。
2. のんびりの決勝 5→53% の跳ねは、どの段のライン・量・配り方でも分けられなかった（足りない種類の詰まりが少しの経験点で解けるため・tourney_exp_options_1020 と同じ）。抑えられたのは**優勝**の差（4.8→2.8pt）。決勝の差を小さくしたいなら、体感（決勝の重みの見せ方）側で解く方が規律 B-5 に合う。
3. 必要充足は A で 3.5→1.4% に下がる（4ボットで唯一）。準決勝・決勝のライン上げが、能力の伸びを大会の経験点に頼らないボットに効くため。
4. 解散 1.6→7.5% は 15年化そのもの（F15 7.1%）で、全部入りでの上乗せは小さい（+0.4pt）。10年目の所持金は +6.5%（帯の組）／+17%（アプリ相当の組）。
5. THE HANA の「難」は 10年・大会の経験点なしの較正だったので、15年＋経験点では +14 が要る。HANA の段も道中大会として経験点を配る扱いにした（HANA を GP 並みの重みにすると女性の差が広がる見込み・未測）。週44＝12月上旬は暦が1月始まりの時（the_hana_measure §7）。
