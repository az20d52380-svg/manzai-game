# トゥルーエンドの案 v0（AUTOPILOT キュー82・決定はオーナー）

## §0 要点3行
1. 今は「優勝＝勇退（S6b）」「夜逃げ」「結成10年目の年末＝もう一度」の3つの終わりしかなく、**優勝（実測0〜5％）に届かなければ区切りの絵が弱い**。トゥルーエンドは優勝に縛らない案を推奨。
2. 推奨：**案T-2「相方と並んで10年（絆×ネタ×舞台の三点セット）」**。決勝に残る/優勝するかは問わず、「10年一緒にやり切った」ことを称える終わり。優勝はその上の「優勝×トゥルー」＝最上位の見せ方に回す。
3. 条件の達成率は、今ある実測（決勝到達 12〜66％・優勝0〜5％）から**案T-2で2〜4割【見込み・要実測】**。実装前に tools/ で再測が要る（コードは触っていない）。

## §2 他ゲームの作り（Web・WebSearch 5回。取れた範囲）
- **学園アイドルマスター**：トゥルーエンドは「各アイドルごとに決まった3つのアチーブメントを全部達成」が条件。中身は親愛度レベル・特定ステータスの到達など**複数条件の組み**。手前のノーマル結末は常に見られる（[game8](https://game8.jp/gakuen-idolmaster/610274)／[電撃](https://dengekionline.com/article/202405/5350)）。
- **ウマ娘**：育成はURAファイナルズ（目標を全達成して出場→全勝で優勝）が最終関門。優勝した周だけ後日談イベント（温泉イベント等）が出る＝**優勝は「おまけの場面」の鍵**で、結末の分岐とは別（[ゲームランブ](https://gameranbu.jp/umamusume/416c5c3375737ff98cf8)）。
- **ときめきメモリアル**：卒業式の日、伝説の樹の下で**相手から告白される**のが最高の終わり。ステータス・好感度・傷心させない管理の積み重ねが条件で、プレイヤーは告白を「待つ」しかない＝**条件は隠れているが、日々の相手の反応が手がかり**（[ファミ通](https://www.famitsu.com/article/202505/41535)ほか）。
- **パワプロ**：検索では結末条件を取れず（未確認）。一般に結果（ドラフト指名・活躍）で結末が分かれ、隠し条件は少なめ、と認識するにとどめる。
- 取り出せる型：①**複数条件の組（1つでなく3つ）**②**手前の結末は常に見られる＝失敗でも終わりがある**③**条件は「相手との関係」を含む**④**条件のヒントは数字でなく相手の反応**⑤優勝は「上乗せの場面」。

## §4 トゥルーエンドの条件案（3つ）
共通：優勝は不要にしない（案T-3のみ優勝必須）／条件は3つ組で「全部」。ゲームの％表示は出さない。

### T-1「頂に立つ＋相棒」（優勝縛り・分かりやすい）
- 条件：優勝 ＋ 相性が高い位置（例15以上）＋ 谷口（相方）との重要イベントを一通り経験。
- 手がかり：決勝前夜の相方の様子・ネタ合わせの手応えの文言が変わる。
- 達成率の目安：優勝が0〜5％なので**1〜3％**（既存実測 stuck_and_exploit_check の優勝率が上限）。ほぼ見られない。
- 長所：筋が通る。短所：**多くの人に一生見られない**。優勝＝勇退と区別が付きにくい。

### T-2「十年、同じ舞台に立つ」（推奨・優勝に縛らない）
- 条件（3つ全部）：
  ① 相方を変えず、結成10年目の年末まで続けた。
  ② 相性が高い（例15以上＝「慣れの外し方」0021が発火する水準を基準に再測）。
  ③ 舞台の積み上げ：決勝に1回以上出た（または準決勝以上を複数年）／知名度が一定以上。
- 手がかり：年次独白と相方の言葉が10年目に近づくほど変わる。年末に「あと1つ足りない」を言葉で（例：相方の視線・楽屋の貼り紙）。数字や％は出さない。
- 達成率の目安：決勝到達 のんびり12／ローテ36／必要充足55％（10年内に1回以上かは別集計が要る）。相性の分布は tools に集計あり得るが未確認＝**2〜4割【見込み・要再測】**。
- 長所：優勝の運に左右されない／遊び方（相方を大切にする）が結末を決める／夜逃げ・ノーマルとの差が明確。短所：相方を変えるガチャ周回（束B）と相性が悪い（変えない縛りが「相方選択」と衝突しうる）。

### T-3「優勝の先で（王者編の終わり）」
- 条件：王者編（累計18pt以上）に入り、続投した先で一定年数（例：3連覇か5年）務めて勇退。
- 手がかり：トロフィー棚の空き段が見える（設計書にあり）。
- 達成率：優勝0〜5％のうえ18pt解禁が前提＝**ほぼ0〜1％**。周回の長い先のやり込み目標向け。
- 長所：束B/Cの「殿堂」に直結。短所：到達不能に近く、トゥルーの名にそぐわない。

**推奨：T-2**。理由：優勝が運寄りで差が見えないため（fun_audit_v0）、結末を「選び方（相方・舞台）」に結び付けた方が遊びが反映される。T-1/T-3は「優勝×トゥルー」として上位の見せ方（演出の加算）に使える。

## §5 論点：トゥルーを優勝に縛るか
| | 縛る（T-1/T-3） | 縛らない（T-2） |
|---|---|---|
| 達成感の筋 | 通る（頂点で報われる） | 「優勝しないのにトゥルー？」の違和感が出うる→名前を「相棒エンド」等にして逃がす手 |
| 見られる人 | 1〜3％以下 | 2〜4割【要再測】 |
| 運の影響 | 大（優勝は運寄り） | 小（相性・継続・舞台の積み上げ＝選び方） |
| 優勝＝勇退との関係 | 区別が付きにくい（二重） | 別物になる（優勝は最高の「見せ場」、トゥルーは「関係の完成」） |
| 周回との相性 | 殿堂・王者編と直結 | 相方固定が必要＝相方選択（束A/B）との衝突に注意 |
| 作り | 見せ場は既存S6bの加算で済む | 新しい見せ場が要る（量は中） |
折衷案：**トゥルー本体は縛らず、優勝した周は「優勝×トゥルー」でS6bの最後に1場面を足す**（優勝しなくても見られ、優勝すると深まる）。

## §6 オーナーが決めること（推奨付き）
1. トゥルーを優勝に縛るか → 推奨：縛らない（折衷案）。
2. トゥルーの条件に「相方を変えない」を入れるか → 推奨：入れる（相方選択は周回開始時のみ、という整理）。
3. ノーマル（10年）の終わりにS6b短縮版を通すか → 推奨：通す（設計書の記述どおり・10年を走り切った人の受け皿）。
4. 夜逃げはバッドとして残す（決定済み）＋称号を付けるか → 推奨：0pt称号。
