## 足す本数の目安（概算）
- 式は前回と同じ：キャリアあたりの本数 n に対し、在庫 V なら再掲率は約 1−V/n。
  - ファンレポ通過側（n≈340・V≈165）：V=200（+35）→約41%（10年時の42%並み）／V=250（+85）→約26%／V=340（+175）→0%。
  - 飲みの誘い（n≈29・V=6）：V=12（+6）→約58%／V=18（+12）→約38%／V≈29（+23）→0%。さらに「年が替わっても同じ週が同じ文」になる並びの偏り（`年×48` が6の倍数）は、並びの式を変えれば在庫を増やさずに最大回数14→約5に下がるが、**式の変更は本体の挙動に触るのでここでは提案のみ**。
- 合計：**最低 約40本（通過+35＋誘い+6）／再掲を約半分にするなら 約100本（通過+85＋誘い+12）**。年末独白・敗退側・ハマった夜は足さなくてよい。

## 限界
- 写した選び方が本体と違う可能性のある所：①年末独白は `session.log` の文字列ではなく結果オブジェクトから戦績を数えた（体調ダウンや客席観戦の週は数えていない）。②ファンレポは `session.fanVoices`（同じ key の再描画キャッシュ）を使わず、各週の最後の本番1つだけ `voices` を呼んだ。③誘いの発火は `GameEngine.rollInvite` を summary.week で呼ぶので、本体が表示する週（次週頭か）と1週ずれる可能性があり、文面が回る位置が変わるだけで再掲率の傾向は同じ。④ボットは優勝後も15年目まで続けるが、実機は優勝で勇退する（年末独白・ファンレポとも11〜15年目は実機ではもっと少ない）。
- styleTalk（3連敗の相談）はボットが連敗しにくく、300キャリアでほぼ発火せず再掲率は測れていない（本体コメントの「1キャリア約6回」は実機の人間プレイの数字で、この測定では未検証）。
- 種類（在庫実測値）は5分割の最大値＝下限。ネタ名は伏せ字にしていない（ファンレポは本体の通り名前だけ〈名〉置換）。選択イベントは文面そのものではなく「どの種類か」で数えた。
