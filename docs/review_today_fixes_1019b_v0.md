## §1 所見

### 1. selftest の「選択直後の保存」行が、MZ_ALLOWSAVE=1 の時に実機側のセーブを上書きして消す（確度 中）
- コミット 91b201d・`GameSession.swift:1689-1697`（`saveNow()` のあと `removeObject(forKey: "manzai.save.v1")`）
- 手順：すでに遊び途中のセーブがあるシミュレータ／端末で `MZ_ALLOWSAVE=1` 付きの selftest を走らせる→テスト用の状態で保存→最後にキーごと消すので、元のセーブが戻らない。環境変数を付けた時だけの話（既定は skip）。同型の `oldsave` 行（1682）にも前例あり。
- 直し案：実行前に `Data` を退避して最後に書き戻す（または別のキーで確かめる）。

### 2. 審査員点の補正：total が 350 未満・693 超なら和は合わないまま静かに終わる（止まりはする）（確度 中）
- コミット c1e8681・`FinalsPresentationView.swift:1247-1258`
- 手順：total<350 なら全員 50 に張り付き、`diff<0` は動けないまま idx が 700 に達して抜ける＝**無限ループにはならない**（idx は毎回増える・|diff|≤343<700 で範囲内なら必ず収まる）。範囲外では和≠合計のまま表示される。
- 守りのテスト 5b6bb7f は `debugMaxedState()` だけ（total は高い側）。低い側（弱い状態×下位）は未確認。実運用の total が 350〜693 に必ず収まるかは別途の保証が要る。
- 直し案：selftest に弱い状態（初期状態）×1〜40年も足す。または抜けた後に `assert(sum==total || total範囲外)` を DEBUG で出す。

### 3. 「通算戦績」の見出しの下に「今年の出場」が混ざる（確度 中）
- コミット ae04ccf・`NotebookView.swift:192`
- 手順：ネタ帳の記録ページ→3カラム木札の左だけ「今年」、中央（優勝）と右（賞金）は通算（`yearHistory` を足している）。2年目以降は出場数だけが今年にリセットされ、優勝が出場より多く見える年がありうる。
- 直し案：出場も `yearHistory` に出場数があれば足して通算にするか、木札の見出し（コメントの「通算戦績」）を外して列ごとに「今年／通算」を小さく添える。

### 4. returnToTitle の `NetaStage.lastSeen` 初期化が、旧画面の再描画に上書きされうる（確度 中・影響小）
- コミット 1d2916b・`RootView.swift:312`（リセットが `session = GameSession()` と `started=false` の前）
- 手順：エンディング→タイトルへ。`withAnimation(.easeInOut(0.3))` の間は旧画面が新しい session で再評価される可能性があり、`NetaStage` の更新（NetaStage.swift:44-45）が空の新周のネタ ID で `lastSeen` を書き直す。ID が旧周と衝突するとネタ札の光り方がずれる。
- 直し案：リセットを `session = GameSession()` の直後（または `started` が false になった後）に移す。
