# 周回後（クリア後）の案 v0 — 相方を選ぶ・引き継ぎ・周回ごとの解放・やり込み（AUTOPILOT キュー79）

> 位置づけ：案のみ。**決めるのはオーナー**。数値は全て【仮】。コード変更なし。
> 日付：2026-10-15 ／ 作った人：Claude（調査＋整理）

## §0 要点3行
1. 売れている育成ゲームの周回は「**失敗しても残るもの**（図鑑・解放）」と「**次は別の組み合わせを試したい**（選べる幅）」の2本柱。強さの引き継ぎだけを主役にすると「周回が義務」になって冷める（調査より）。
2. このゲームは周回の土台（トロフィー30pt・人脈P・相方ガチャ・事務所・王者編・ネタの型7種）が**設計済みだが、Swift側は ネタの型（Neta.swift）以外ほぼ未実装**。案は「設計済みのどれを、どの順で作るか」の束になる。
3. 推奨は**B（中）**。ただし最初の一歩は A の「相方を選べる」＋「図鑑・称号」で、そこから B へ伸ばせる作り。

## §2 このゲームの今の作り（grep・索引で確認）

- **キャリア**：最大10年で終わる（勇退）。決勝で優勝すると**王者編（連覇モード）**があり、累計18pt以上で解禁（`dynasty_design_v0.md`、`meta_report_v0.md`）。
- **相方**：実装は谷口固定。設計上は**相方ガチャ（名鑑所有制）**があり、R/SR/SSR で「相性の初期値と成長上限」が上がる（`partner_gacha_design_v0.md`）。相方10人（男6・女4）は `partner_characters_v0.md`、後輩・先輩の量産型22類型は `character_archetypes_v0.md`。
- **周回メタ（設計済み・未実装）**：トロフィー21個＋称号（総枠30pt、1pt＝才能の逓減D＋1、最大+20）→ 人脈P（完走8＋準決15＋決勝20＋優勝15×回数＋知名度/20）→ 相方ティア解放（R60/SR140/SSR260）（`trophy_design_v1.md`、`meta_report_v0.md`）。
- **事務所**：架空事務所の選択で序盤の条件が変わる設計（`agency_fanbase_design_v0.md`）。
- **ネタの型**：7種（王道しゃべくり／関係性／伏線回収／リターン／非定型／瞬発／華先行）と尺3種が `GameCore/Sources/GameCore/Neta.swift` にある。審査員の好み・型の相性は `eval_axes_design_v0.md`。
- **名前の生成器**：`name_generator_v0.md`。
- **継承の翻案案**：後輩への継承（前周コンビの「型」が次周の後輩の芸風に出る）と、前周の「経験済み選択肢の済マーク」の保持（`replayability_research_v0.md` §1-C）。
- **既に分かっている落とし穴（実測）**：初期能力や相性の加算は逓減で吸収され「序盤が楽になるだけ」。周回報酬は**天井を上げる形（D）**でないと意味が出ない一方、積みすぎると易化が制御不能（`endgame_design_v0.md` §2-3）。トロフィー配分が緩いと周回寿命が3〜4周で尽きた（`meta_report_v0.md`）。
- 注意：上記の数値は旧正典のもの。現行正典（`canonical_v2_spec.md`）で再測が要る。

## §3 案の3つの束

共通の方針（どの束でも）：①強さの引き継ぎは控えめ（天井D以外は「序盤の快適さ」止まり）②解放は「選択肢の幅」を広げる③周回数ではなく判断の成功で報われる④失敗した周にも図鑑・称号が残る。

### 束A 小さく始める「選べる＋残る」
- **相方を選べる**：周回開始時に、名鑑に載った相方（出会った・組んだ人）から選ぶ。初回は谷口のみ。2周目から、前周で組んだ相方が名鑑に入って選べる（ガチャは使わない簡易版）。
- **図鑑・称号**：コンビ名鑑（相方・ライバル・優勝者・審査員）と称号（0pt、見せるだけ）。完走するだけで1件は埋まる＝失敗しても残る。
- **やり込み目標**：「全相方で完走」「全ネタの型で決勝到達」の2本の収集チェックリスト。
- **引き継ぎ**：ネタの「済」マーク（経験済み選択肢）と、前周の自コンビの記録（名鑑のページ）。能力は引き継がない。
- **作る量の目安**：小（目安3〜5日相当）。名鑑の保存（GameState の Codable 保存先）＋周回開始の選択画面1枚＋チェックリスト画面。相方は既存の台詞量が足りるかが律速。
- **オーナーが決めること**：①初回から相方を選ばせるか、2周目からか ②相方ごとに性能差（得意能力）を付けるか、見た目と台詞だけの差か ③称号に強さの効果を付けるか（推奨：付けない）。

### 束B 中「系譜と解放」（推奨）
束Aに加えて：
- **トロフィー→才能解放（D）**：設計済みの30pt制を実装。天井が上がる唯一の強さ引き継ぎ（最大+20、D140まで）。
- **後輩への継承（ダビスタ／パワプロ継承の翻案）**：前周のコンビの「型」が次周の後輩ライバルの芸風として登場。会話イベントを重ねると**ネタの型のコツ**（その型の初期習熟）を貰える。能力値の直接加算はしない。
- **相方の相性（ウマ娘の◎〇△の翻案）**：相方×ネタの型、相方×審査員の相性で「得意な型」が決まり、毎周の最適解がずれる。
- **周回ごとの解放**：2周目＝事務所の選択／3周目＝ネタの型の追加（非定型・華先行など）／4周目以降＝相方の追加枠（名鑑所有）／王者編は累計18pt。
- **やり込み目標**：トロフィー全21個、全相方×全型の制覇、10連覇（殿堂）。
- **作る量の目安**：中（束Aの2〜3倍）。トロフィー判定＋D反映＋人脈P＋事務所選択＋後輩の継承イベント。**D反映は数式に触るので最大エフォート＋再測が要る**。
- **オーナーが決めること**：①相方入手をガチャ（運）にするか、名鑑所有（出会い＝確定）にするか ②解放の順番（何周目に何が開くか）③事務所は周回解放か最初から選べるか ④課金（相方ガチャ・コスメ）にどこまで繋げるか（業態の論点とセット）。

### 束C 大「世代交代サイクル」
束Bに加えて：
- **コンビの殿堂入り＋世代**：引退したコンビが「殿堂」に入り、次周の相方候補・師匠・審査員・ライバルとして**名前付きで再登場**（ダビスタの世代交代）。自分で作った名前（生成器）も継承対象。
- **因子的な継承**：殿堂コンビの芸風を「ネタの型の因子」として最大2組選んで次周に持ち込む（相性◎で効きが強い）。
- **シーズン制目標**：「今季は伏線回収の型で優勝」のような縛りモード（パワプロのシナリオ違いの翻案）。
- **作る量の目安**：大（束Bの2倍以上）。保存形式の設計、因子のバランス再測（天井と乗算で易化しやすい＝`endgame_design_v0.md` §2-4 の注意）、演出・台詞の大量追加。
- **オーナーが決めること**：①殿堂コンビを他プレイヤーと共有するか（今は端末内だけを前提）②持ち込みの上限数 ③縛りモードを入れるか ④どこまで厳選周回を許すか（ウマ娘型は義務化の恐れ）。

## §5 推奨と理由
**束B**（まず束Aの部分から着手して、伸ばす）。理由：本作の周回メタは既に束B相当まで設計・実測が終わっており、新設計よりも実装が主で、かつ「強さは天井だけ・解放は横に広げる」という調査の落とし穴回避と一致するため。
