## ①予選の紙講評（半紙）
- 優勝側・敗退側の2枚とも、枠からはみ出さず2行で収まる。改行位置も自然（「…ネタが追えば決勝。」「最後の一つまで同じ強さで。」）。崩れなし。
## ②決勝の吹き出し
- 司会の振り＋審査員の講評の2吹き出し。最大3行で切れない・長すぎない。
- 折り返しが語の途中: 「前のめりだっ／た！」「圧／ね。」（機種幅の都合で許容範囲だが、読点か句点で区切れる文にすると綺麗）。
## ③差し込み
- 「『』」が空・助詞の重なりは出ていない。ただし 「出だしの一言の一言目で」（JudgeTalk.swift:243、{入り}＝「出だしの一言」＋「の一言目」で重複）。
- 「圧ね。」は口語として少し唐突（意図なら可）。
## ④枚数
- 決勝は最高点・最低点の最大2人。紙講評は1枚。いずれも最大4枚以内。
## 直すべき点1つ
- JudgeTalk.swift:243 の「{入り}の一言目」を「{入り}で」に（「一言の一言目」重複の解消）。
## 限界
