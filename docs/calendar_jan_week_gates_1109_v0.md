# 候補（claude/calendar-jan-candidate）の週の数字の点検 11/09 v0

## ①要点（3行）
- 週の数字で季節・月を表す所は **GameCore 12件（直し済み3・未9）＋アプリ 8件（直し済み5・未3）**。候補が数字を直したのは月が名指しの3イベント（homecomingCall・summerFestivalGig・yearEndLive＝sim_career.py の鏡像も同時）と暦の表示だけで、**4月始まり前提のまま残る週の数字（ゲート）は見つからなかった**。
- 未直しの9＋3件の大半は大会の週（1月始まりでそのまま読める＝直す必要なし）と、季節語を持たない週ゲート（そもそも暦に依存しない）。本当に食い違うのは **コメント1件（寒梅漫才杯の「1〜3月」）と文面と週のずれ2件（夏祭り「来月」・帰省「年末の夕方」）・後輩の「1年目の後半」1件**で、どれも判断が要る。
- 大会の週・GP の週は全部 1月始まりで正しく読める（sim_career.py のコメントが元々「1月起点48週」）。つまり本体（4月始まり）側の方が食い違っていて、候補は大会の週を触らず暦だけ合わせる形で一貫している。

## ③件数（GameCore と アプリ）
- **GameCore（golden・tools/sim_career.py の鏡像に関わる）12件**：直し済み3（homecomingCall・summerFestivalGig・yearEndLive。sim_career.py も同時に更新済み）／未で週の数字が要るのは **kouhaiInvite 1件のみ（判断が要る）**／コメントだけ未1（寒梅の「1〜3月」）／大会・GP の週は変更不要で合う（8件分：春新人A・B／夏中堅／大阪戎／若手／推薦制／HANA／GP）。季節語なしの週ゲート（stageCrew・douki・TV・renovation・classmate・fever・notebook・peerChair・earlyFormality）は対象外。
- **アプリだけ 8件**：直し済み5（monthLabel・幕間2行・コメント群・暦で解消した年末独白／出番表／t03・t06・t08）／未3（夏祭りの文「来月」・帰省の文「年末の夕方」・YoseFXPreview の見本）＝すべて判断が要る。
- **golden が動く可能性があるのは kouhaiInvite の週を変える場合だけ**（候補が直した3件は週の数字を変えている＝候補を採るなら golden／sim の再生成が要る点は既知）。

## 親の照合（11/09 夜）
- kouhaiInvite（week>=24「1年目の後半」）：48週の後半＝第24週〜は暦の始まりに関係なく「年の後半」。1月始まりでは6月末＝年の半ばで、コメントの意味は崩れない。週を動かす必要は無い（動かすと golden・sim_career の鏡像が動く）。
