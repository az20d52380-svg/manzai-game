# お金の吸い込み口 調査 v0（2026-10-14・決定はオーナー・案のみ）

## §0 要点
- 余ったお金の使わせ方は大きく6型：①見た目・称号の収集 ②大きな一回きりの買い物 ③周回へ持ち越し ④物語の出口（寄付・後輩育成） ⑤維持費が増える仕組み ⑥お金を別の通貨・実績に替える。
- 本作の「能力は上がらない」原則に反しないのは ①②③④⑤（⑥は替え先次第）。§6-6 の実測どおり値段上げは効かないので、「帯に効かない大きな買い物」を足す方向が筋。
- 推奨案は §3 の A（単独ライブ・劇場の段階買い）＋ C（後輩・寄付の物語出口）。決めるのはオーナー。

## §2 型の表
| 型 | 例 | 漫才の世界での使い道 | 原則（能力は上がらない）に反するか |
|---|---|---|---|
| ①見た目・称号の収集 | WoW の高額マウント／Stardew の飾り | 衣装（ステージ衣装・スーツ）、楽屋の飾り、コンビ名入りの看板、称号「劇場の顔」 | 反しない（見た目のみ）。ただし効果を付けると崩れる |
| ②大きな一回きりの買い物 | Stardew 金時計・オベリスク／カイロソフトの大型施設 | 単独ライブの開催（会場代・宣伝費）、自前の小劇場、事務所の拡張、冠番組の制作費 | 反しない（人気・ファン・物語に出す。ネタの出来には効かせない）。能力に効く形にすると反する |
| ③周回へ持ち越し | 周回要素のあるシミュ全般 | 「師匠の遺産」「次の世代に残す基金」、2周目の初期所持金・初期の人脈 | 持ち越しが能力なら反する。所持金・人脈・衣装などに限れば反しない |
| ④物語の出口 | 寄付・後輩育成（栄冠ナインの母校の流れに近い／記憶ベース） | 後輩コンビの育成、養成所への寄付、劇場の建て替え、恩人への恩返し。エンディングの語りに反映 | 反しない（エンディング・称号に出す）。後輩が強くなる等を本人の能力に返さなければ可 |
| ⑤維持費が増える仕組み | カイロソフト（維持費）／FM（賃金枠） | 事務所のスタッフ、劇場の家賃、弟子の生活費、後援会の付き合い（毎週・毎月出る） | 反しない。ただし「払わないと罰」だと強制になり、プレイヤーが嫌う（一般論） |
| ⑥別の通貨・実績に替える | Stardew Qi・ウマ娘カラット | 賞レースの協賛、ご祝儀、名誉職（協会の役）。金→名声の交換 | 替え先が能力なら反する。名声（演出・物語）だけなら可 |

## §3 このゲームへの選択肢（3〜5個・決めない）
- **A. 単独ライブ・劇場の段階買い（②）**：1回数百万、段階（小箱→中→大ホール）。効果は人気・ファン・エンディングの語り。実測（§6-6）で帯に効かない使い道の方が値上げより効くとあるので整合。推奨理由：実装が小さく、能力原則に最も安全。
- **B. 見た目・称号コレクション（①）**：衣装・看板・楽屋・称号。高額を数点置く。推奨理由：実装が軽く、オーナーが嫌う％表示にもならない。ただし単体だと「使っても何も起きない」で冷めるかも。Aとの併用が安全。
- **C. 後輩・寄付の物語出口（④）**：終盤に「後輩を育てる／養成所へ寄付」を出す。金額に応じて語りと称号が変わる。推奨理由：金が余る終盤に気持ちのよい出口になり、漫才の世界の言葉と合う。会話はボケない決定（要確認）に注意し、文章は正典を先に読む。
- **D. 周回へ持ち越し（③）**：所持金の一部を「基金」として次周へ。能力は持ち越さず、衣装・人脈・初期所持金だけ。推奨理由：周回を前提にするなら金の価値が続く。ただし初期所持金が大きいと序盤の帯が崩れる恐れ（実測要）。
- **E. 維持費（⑤）**：事務所・劇場を持つと毎月出る。推奨理由：余剰を自然に減らすが、強制感と罰の印象に注意。AやCと組む時は「任意」にする。
- 推奨案（理由つき）：A＋C を軸に、B を薄く足す。D・E は様子見（帯への影響の実測が先）。決定はオーナー。
