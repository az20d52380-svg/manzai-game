## §2 照合
1. **新春**：Calendar は第1週＝4月・4週で1か月（monthLabel）。幕間の caption も「4月 ・ 第1週」。「新春」は1月の語で、同じ画面の caption と季節が食い違う。
2. **通過演出**：TournamentResultView:181 は GP の通過のみ（準決勝までの回戦突破＝すべて予選扱い）で、上帯は優勝演出と同じ「漫才の頂、ここに決まる」。回戦突破の場面では強すぎるが、仕組みとは矛盾しない。
3. **優勝演出の「日本一」**：呼び出しは FinalsPresentationView（頂GP決勝）と TournamentResultView（THE HANA 決勝）の2か所。後者は女コンビだけの別大会。
4. **年数**：careerYears=15。エンディング判定は year>=15 で優勝・解散以外は終わる＝幕間は最大14→15年目まで（漢数字 10〜19 対応で足りる）。S6b の「十五年分の年表」と一致。
5. **俺**：回想・解散の「俺」は話者名（Advice name）で、他の会話 docs と同じ扱い。

## §3 直し案（文字列のみ・どれも小さい）
- 「新春の備え」→「新年度の備え」（caption が4月なので合う）。
- 通過演出の上帯：「◆ 漫 才 の 頂 、 こ こ に 決 ま る ◆」→ 通過では出さない／「◆ 次 の 舞 台 へ ◆」。優勝演出は今のまま。
- 朱印「日本一」：THE HANA では「優勝」にする（引数で渡す）。
