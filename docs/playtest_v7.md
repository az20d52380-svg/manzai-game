## 手プレイができなかった理由
- 操作手段が無い：idb・cliclick は未インストール、osascript（System Events）は「補助アクセス不許可」で拒否、CGEvent も AXIsProcessTrusted=false、Simulator のウィンドウも画面上に無い（無人実行）。iOS Simulator の control ツール（tap）は「無人・スケジュール実行では使えない」と拒否された。＝タップが1回も送れない。
- そのため指示どおり DEBUG フックでの静止画点検に切り替えた。週ごとの記録（W1〜）は書けていない。
