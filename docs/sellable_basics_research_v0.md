# 商用育成SLGの「ゲームらしさ」調査レポート — 漫才師育成SLG改修用

## §1 ゲームの基礎（fundamentals）チェックリスト

**原則: オンボーディングは「読ませる」のではなく「遊ばせながら教える」。最初の5〜15分でゲームの価値（何が楽しいか）を体験させないと定着率・プレイ時間が低いまま固定される。初期チュートリアルは高ニーズ機能だけをシンプルに、1画面1概念。**
→ 適用案: 初回起動〜「初ライブでウケる」までを10分以内に圧縮した強制導線。練習→ネタ作り→ライブ→ウケてリザルト、を1周させてから自由行動を解放。説明テキストは各画面2行まで（just-in-time方式）。

**原則: 目標は短期／中期／長期の三層で常時明示する。行動→結果→報酬の短期ループと長期目標を両方見せることで「今何をすべきか」が迷子にならない。**
→ 適用案: 「今週やること」「次の大会（残り週＋現在値/必要値ゲージ）」「1年後の頂GP」の三層常設。※目標バナー実装済＝現在値/必要値ゲージが未。

**原則: 失敗は「予告→判断の余地→死因の明示→低い再挑戦コスト」のセットで設計する。「自分の判断ミスで死んだ」と納得できる失敗だけが「もう一回！」を生む。**
→ 適用案: 大会前に「合格見込み: 危険」を事前表示し回避手段を提示。敗退リザルトに敗因1行＋「次はこの練習が有効」ヒント。

**原則: いつでも中断可能（オートセーブ）が最低ライン。音量別スライダー、テキスト速度、演出スキップ/倍速、確認省略は商用標準装備。**
→ 適用案: オートセーブ実装済。「演出: フル/短縮/結果のみ」「倍速」を設定に追加。

**原則: リザルトは「差分」を読ませる画面。段階表示（一気に出さず順に出す）。**
→ 適用案: 実装済の段階開示を維持・数字はカウントアップ＋着地パンチへ。

**原則: 1セッションは5〜15分で必ず区切り。日常（低テンション高頻度）→山場（高テンション低頻度）の緩急を意図配置。**
→ 適用案: 日常は軽いSE・淡々、賞レースだけ専用BGM・専用演出に切り替えて落差を作る。

## §2 「見てるだけ問題」の解決パターン

**原則（ウマ娘型）: 観戦が面白いのは「事前の自分の全選択が、本番中に可視化されて発露する」から。スキル発動カットイン＝育成の答え合わせの表示装置。実況・BGM同期・表情・カメラで「晴れ舞台を見守る」感情を作る。倍速・結果のみスキップで反復苦を消す。**
→ 適用案: 本番中「仕込んだボケがハマった！」カットイン（ネタ構成＝スキル相当）、ウケメーターのリアルタイム推移（危機と逆転）、優勝時だけ特別演出。2周目以降は倍速/結果のみ必須。

**原則（オートバトラー型）: 意思決定を準備フェーズに全て圧縮し、バトルは「ビルドの答え合わせ」として観る。観戦が成立する条件＝①結果を事前選択に帰属できる②途中経過に起伏③短い（数十秒〜1分）。**
→ 適用案: ライブ前の「ネタ構成」（ボケの並び・緩急・つかみとオチ）を意思決定の本体に。ライブは60〜90秒の答え合わせ。

**原則（栄冠ナイン型）: 基本は見守り、要所だけ采配カードで部分介入。「ここぞの一手」に緊張感が凝縮。**
→ 適用案: 本番中1〜2回だけ「客が冷めてきた→アドリブ？ネタ通り？」の数秒2〜3択。

**原則（Slay the Spire型）: 快感の核は「コツコツ積んだシナジーの爆発」。組み合わせが噛み合った瞬間を派手に見せる。**
→ 適用案: ネタスキルのコンボ（天丼＝同じボケ2回目で倍率）成立時に専用カットイン＋ウケ急伸。

## §3 意思決定の緊張感（最適解の自明さを壊す5手法）

1. **リソースの相互排他**（時間・体力は同時に2つに使えない）→ 週1行動＋体力制は実装済。体力ゼロ付近の失敗率は実装済（injury）。
2. **リスク/リターン**（期待値高いが分散大の選択肢を常に混ぜる）→ ネタ選択を「安定ネタ（固定）vs 攻めネタ（客層次第で20〜120）」に。格が上がるほど安定では勝てない調整。
3. **時限機会**（今しか取れない）→ 「今週だけTV出演可（練習1週を失う）」等の期間限定。※0022 稽古ロックが同型実装済。
4. **シナジー（ビルド）**（組み合わせ評価）→ 芸風タグ×スキル相性・相方相性でスキル効果変動。
5. **隠れ情報**（当日まで分からない）→ 審査員の好み・客層は「噂」レベル、偵察行動（1週消費）で開示＝情報を買うか時間を賭けるか。

## §4 ジュース/ゲームフィールの商用最低ライン

**原則: 「ジュース＝少ない入力に対する大量のカスケード的フィードバック」。商用最低ライン＝全タップに音＋視覚反応が約100ms以内。無音・無反応のボタンが1つでもあると素人臭。基本技術＝easing必須（線形禁止）、squash&stretch、パーティクル、ヒットストップ、画面シェイク（強い瞬間のみ）。**
→ 適用案: 全ボタンにタップSE＋押下スケール（実装済）。ウケ＝笑い声SE＋数字ポップ＋メーターバウンド、大爆笑のみ軽シェイク＋紙吹雪。

**原則: 数字は「カウントアップ＋着地パンチ」。上昇は緑/暖色＋上矢印、変化項目だけハイライト。自己ベストは専用バッジ＋専用SE。**

**原則: 画面遷移は演出で伝える（フェード/ワイプ・パート転換ジングル）。日常→本番は照明・音・UIトーンを全部変える。BGMは場面の終わりと同期（ウマ娘はゴールと同時に曲が終わる）。**
→ 適用案: 本番開始＝暗転→スポットライト→出囃子ジングル。ネタ終了と同時にBGMが締まり拍手にクロスフェード。

## §5 少人数開発で「市販レベルに見える」投資優先順位

**原則: 投資対効果の順 ①音 ②フォント/UI統一 ③動き（tween） ④イラストの選択と集中。「音は体験の半分」＝最も安く商品感が買える。観客SE（クスッ/どっ/大爆笑）は漫才ゲームの生命線＝複数バリエーションに投資。**

**原則: システム標準フォントを使った瞬間に素人に見える。商用可ゲームフォント1書体＋数字用1書体に統一。ほぼ1日で一段変わる。**

**原則: アニメは絵の枚数でなく動き（easing・拡縮・タイミング）。イラストは点数を広げず「看板1〜2枚」に品質集中（立ち絵＋キービジュアル）。**

**原則: 機能を増やすより1ループを磨く。中途半端な機能5個より完成度の高いコアループ1本が「商品」に見える。未完成サブ機能は隠す。**
