# キュー60（同じネタは飽きられる）×キュー62（知名度）の案と実測（2026-10-15）

全て【仮】。実測は `tools/exp_neta_stale.py`・`exp_fame62.py`・`exp_q60_62.py`（n=1000・ネタ込み＝アプリと同じ式）。
帯の目安：ネタ無しの基準 ローテ 0.8%／31.8%・やり込み 3.0%／42.3%（優勝／決勝到達）。今のアプリ（ネタ込み）はローテ 2.8%／44.8%・やり込み 9.0%／63.6%＝ネタが効きすぎ。

## 0. 要点3行
- 飽きは「年の初めに客の反応を下げる」だけではほぼ効かない（反応を0にしても やり込み 9→5.7%）。ライブで反応がすぐ戻るため。
- 効く形は **案D：大会で使った年の数だけ点が下がる（1年目は無傷・2年目から−1・3年目以降−2で止まる）・寝かせても戻らない・新しく書いたネタは0から**。帯がネタ無しの基準とほぼ同じに戻る。
- 知名度は **案G：決勝に出ないままだと80手前で頭打ち・決勝に出ると一気に＋30（上がるほど鈍る）・優勝は＋10（鈍らない）**＝2回優勝で100。帯は基準のまま。

## 1. ネタの飽き（キュー60）
| 案 | 中身 | ローテ | やり込み |
|---|---|---|---|
| 今 | 飽きなし | 2.8%／44.8% | 9.0%／63.6% |
| A | 前の年に使ったネタは年初に反応−D（D=10〜100） | ほぼ不変 | 8.3〜5.7%（n=300） |
| B | 使った年の数×P点（上限なし） | 書き替えない人は決勝0%まで落ちる＝厳しすぎ | |
| C | Bに上限・1年寝かせると1段戻る | 2本を1年おきに回すと逃げられる＝やり込み 9%のまま | |
| **D（推奨）** | 使った年の数×1点・上限2点・寝かせても戻らない | **1.2%／32.7%** | **4.1%／49.5%** |
| D（新ネタを書く人） | 同上・飽きたネタを書き替えるボット | 0.5%／29.2% | 2.7%／45.5% |

- 推奨Dの理由：毎年同じネタだと確実に効く（オーナーの言葉どおり）／新ネタを書けば0から＝「ネタを書く」行動に意味が出る／帯がネタ無しの基準に戻る。
- Eは設計（ネタの「再演＝数年寝かせたネタ」）と合うが、やり込みが少し上に出る。再演を残したいならE（3年寝かせ）。
