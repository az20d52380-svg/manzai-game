# 審査員コメントの「文法」v0・2026-10-15

目的：ゲームの講評（決勝の口頭＋予選の紙）をオーナーが「全部ダメダメ」と判断したため、実例の「文の組み立て」から書き直す材料。
範囲：M-1 2020/2024/2025、キングオブコント(KOC)2025を主に。THE SECOND・NHK新人・ABCは審査員コメント本文がWebで取れず（THE SECONDは一般審査員100人方式で講評なし）。
限界：全文書き起こしはほぼ無く、要約記事経由（文字化けで読めない記事も多数）。以下の文数・順番は「要約記事＋書き起こしnoteから読み取れた傾向」で、厳密な計測ではない。実在の人名は本書の中だけ（ゲームに出さない）。逐語引用は短い断片のみ。
既存調査(r6/r6b)の頻度表・テンプレ8型とは重複させず、「文の組み立て」に絞る。

## 0. 要点3行
- 良い講評は「①短い結論（点の理由）→②ネタ内の具体物を1つ名指し→③条件付きの惜しさ1つ」の2〜3文。抽象の褒め言葉だけの講評は実例に無い。
- 具体物は「暗転の使い方」「拾って食べる所」「前半の振り」「後半の歌」「トップバッターという順番」など、見ていないと書けない固有物。
- 審査員ごとに「長さ・口調・見る所」が固定している（短く感覚的／長く論理的／代案を出す）。同じ型を全員に使うと嘘っぽくなる。

## 1. 長さと順番の型（3〜5種）
長さ感：放送上の1人あたり約10〜25秒、1〜3文（2文が最頻）。長い人でも4文程度。M-1は各組後に審査員が数人だけ話す（全員は喋らない＝「コメントなし」の人がいる）。
型A「結論→具体→惜しさ」（最頻）：点の理由を先に言い、触れた箇所を1つ挙げ、「あれがあれば」で締める。例：KOC2025でロングコートダディの1本目に、時間の使い方の完璧さを褒めつつ主人公の人間味と整合性を惜しむ（飯塚型）。
型B「具体だけ・褒め止め」：1文。「これぞ〜」「完璧」+ 理由を一言。M-1 2025でヤーレンズに「完璧なトップバッター」と言い、本人の実体験に寄せたゴール作りを挙げる（塙型）。
型C「前置き（不利な条件）→覆した→点」：トップバッターの不利を先に述べ、「点数入れざるを得なかった」。M-1 2024の石田型（出典 realsound）。
型D「分析長文」（山内・じろう）：伏線・回収・時間配分に触れ、代案を示す（「〜の方が気持ちよかった」）。3文以上になる。
型E「体感一言」（秋山・礼二）：「ずっと笑った」「めっちゃおもろかった」+ 表情・ビジュアル1点。1文。
出典：https://ge-sp.com/20251226-2/ （M-1 2025要約）／ https://tmbi-joho.com/2025/10/11/koc2025/ （KOC2025要約）／ https://note.com/shinypinkchina/n/ncb636b49fbd8 ／ https://realsound.jp/book/2024/12/post-1888525.html/amp

## 2. 第一声
- 多くは感嘆語で始めず、いきなり「評価語」か「点の理由」から入る。KOCでは飯塚が「時間の使い方が完璧」と名詞止めで直入。M-1 2025の礼二は「完璧」、ともこは「これぞ〜」。
- 体感から入る型：「笑ってしまう」「笑いが止まらなかった」（哲夫のエバース評・M-1 2020の上沼）。感嘆の「いやー」等は実例要約からは確認できず（映像では多いと思われるが記事に残らない＝要確認）。
- 条件・状況から入る型：「トップバッターで〜」「ハードルが上がった中で」(大吉)。
- 先に好みの断りを入れる：「好みの問題ですが」（山内がファイヤーサンダーに）。点を抑える時の前置き。
- 出典：https://gendai.media/articles/-/78657 （M-1 2020コメント要約）

## 3. ネタの具体箇所への触れ方
- 名指しの単位は「分」ではなく **場面・小道具・設定・順序・構造**。「何分目」はほぼ出ない。
- 実例の種類：冒頭の処理（暗転の使い方）／特定の動作（床の物を拾って食べる）／小道具の細かさ／ツッコミの一言（立て直し）／前半 vs 後半（前半の振りが薄い・後半の歌で笑いが止まる）／オチ（後半の大爆笑のオチ）／設定の年齢ずれ／映像パート。
- 言い方：「〜のところ」「〜の部分」より、名詞で直接言う（「暗転」「あの歌」「あの一言」）。「前半」「後半」「冒頭」「最後」は頻出。
- 一組に必ず具体物が1つ以上。全員が具体を言うとは限らず、「コメントなし」「具体的でない一言」もある（M-1 2025の要約では約半数が短い）。

## 4. 点数・順位の理由づけ
- 他組との比較は「直前の組」「順番（トップバッター／後半）」「前年の同じ組」「同じ手法の別の組」の形が多い。例：前年の令和ロマンとの比較（ともこ）、「エバースとヤーレンズは約1点差」（礼二）、おいでやすこが後だとアキナが物足りない（上沼）。
- 惜しさは「もう少し〜だったら（もっと入れた）」「〜があれば」の**条件付き**。小峠「後半の盛り上がりが手前にあれば」、哲夫「アホさが欲しかった」、塙「前半から掛け合いでも取れた」。惜しさは1つに絞る。
- 点を割り引く時は理由を言う（柴田「前半の振りを厚く」）。点が高くて理由が短い時は「完璧」「ほぼ完璧」で済ます。
- 順位への言及は少ない。「ここで優勝」「文句なしの優勝」は最終投票の時。

## 5. 語彙
**褒め（実例中心・約18）**：完璧／ほぼ完璧／これぞ〜／文句なし／素晴らしい／面白かった（おもろかった）／笑いが止まらなかった／ずっと笑った／絵が浮かぶ／説得力／テンポ／構成／間／緻密／丁寧／行き切っていた／新しいものを見た／奥深い／染みた／破壊力／芸術（古い回）。
**注文・惜しさ（約18）**：もったいない／もう少し／〜があれば／欲しかった／見たかった／引いてしまった／一辺倒／もたつき／力技／粗い／整合性（が取れていない）／回収／振りが足りない／笑いが止まった／冷めた／ブレた／ワクワク（が足りない）／好みの問題／既視感／長すぎ（時間が）。
**口調**：大吉・塙・山内・哲夫・柴田・後藤は標準語の丁寧語（「〜ですね」「〜と思います」）。礼二・ともこ・駒場・巨人は関西弁混じり（「おもろかった」「ほんまに」系）。秋山はくだけた短文。飯塚は淡々とした言い切り。じろうは「〜と感じた」「〜ような気がした」の控えめ推量。上沼は強め断定（古い回）。
注意：語彙は要約記事の言い換え混じり。上の言葉が逐語かどうかは確認していない＝ゲームには「言い回しの型」として使い、そのままコピーしない。

## 6. 立場による違い
- コント師（KOC）：構成・整合性・時間配分・伏線回収に寄る（飯塚・小峠・山内）。役者目線で表情・演技にも触れる（じろう・秋山）。
- 漫才師（M-1）：テンポ・間・つかみ・ツッコミの技術・「漫才としての型」。現役中堅は具体的、大御所（巨人・上沼・松本）は体感や好き嫌い・理屈の説明（巨人は「ツッコミは客の代弁」と理屈を重ねる）。
- 若手寄りの審査員は本人の経験から語る（若林「自分がM-1に救われた」）。先輩は「次を超えるのは難しい」と**将来の言及**を足す。
- 大御所は短く断定、中堅は理由が具体的、若い審査員は気を遣って前置きが長い、という傾向（推定）。

## 7. 紙の講評（予選の講評シート・ネタ見せのダメ出し）
Web検索15回の範囲で **実例は取れなかった**。一般則（私の整理・実例なし）：
- 口頭より事務的：箇条書き、体言止め、1〜3行。
- 「良かった点→改善点」の2点構成。改善は「何が起きたか＋どうすれば」。「つまらない」とは書かない。
- 構造語を使う：ツカミ・フリ・オチ・ボケ数・間・声量・入りの速さ。
- ゲームで使うなら、これは **推定として** 扱い、オーナーに確認する（実例が無い）。

## 8. よくない例（ゲームの嘘っぽい講評）と実例との違い
| よくない例（ありがち） | 何がダメか | 実例の作り |
|---|---|---|
| 「素晴らしい漫才でした！会場が沸きました」 | 抽象・誰にでも言える | 場面を1つ名指し：「暗転の使い方」 |
| 「テンポ、構成、間、全てが良かった」 | 観点の羅列（実在審査員は1〜2観点に絞る） | 観点は1つ＋理由1つ |
| 「このボケのこういう意図が〜」と説明する | 説明口調。審査員は解説しない | 好き嫌い・体感として短く言い切る |
| 全員が同じ長さ・同じ丁寧語・同じ褒め方 | 声が一種類 | 長さも口調も人ごとに固定（短い／長い／代案型） |
| 「〜でした。〜でした。〜でした。」と全文を同じ語尾で並べる | 書き言葉 | 名詞止め、「〜ですね」「〜かな」混在 |
| 惜しさが「もっと頑張りましょう」 | 人格・努力論 | 「前半の振りがあれば」と条件付き |
| 全員が長文でコメントする | 実際は一部が「なし」・一言 | 全員は喋らない。1文の人を混ぜる |
| 現実に無い数字（「全体の87%が〜」） | 嘘っぽい | 点数と順番だけ |

## 9. 規則10行（案・要オーナー確認）
1. 決勝の口頭講評は1〜3文、2文を中心に。1文の人・コメントなしの人を混ぜる。
2. 順番は「結論（点の理由か体感）→具体物1つ→条件付きの惜しさ1つ」。惜しさは省いてよい。
3. 具体物（場面・小道具・前半/後半・冒頭・オチ・順番）を必ず1つ入れる。抽象の褒め言葉だけの講評は禁止。
4. 観点は1〜2個。全部を褒めない（羅列禁止）。
5. 第一声は感嘆語で始めない。評価語の名詞止めか、状況（順番・不利）か、体感から。
6. 惜しさは「〜があれば／もう少し〜」の条件付き。「頑張れ」「努力」「才能」は使わない。
7. 他組比較は「前の組／順番／同じ手法」で、1回だけ。審査員が複数いる時は全員が比較しない。
8. 審査員ごとに声を固定：短く感覚的／論理的に長め／代案を出す／関西弁／丁寧な標準語。
9. 説明口調（「〜という意図で」）、％や数値の根拠、キャラの定型句の連発は使わない。
10. 紙の講評は事務的な2点構成（良かった点→直す点）で1〜3行、体言止め。実例が無いのでオーナー確認までは仮。
