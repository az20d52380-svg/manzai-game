# コード点検 2026-10-25c（警告が隠れる型）

対象：WeekHint.swift 全体、WeekMainView.swift の goalBanner／weekHintText／maybeShow 系／presentRent。コード変更なし・ビルドなし。

## §1 確度 高

### 1-1 WeekHint.swift:37 — 借金中は「体力が少ない／倒れるぞ」が一言から消える
- 何が隠れるか：`money < 0` が最初に return するので、体力の警告（:49-50）が出ない。
- 起きる手順：借金の週に体力が30以下（または injuryThreshold 未満）→一言は「所持金はマイナス」だけ。借金を返そうとバイトを選ぶと、体力が低いバイトで体調ダウンが起き（療養中はバイト代が入らない）、借金がさらに深くなる。借金の週は体力の警告がいちばん要る週。
- 直し案：money<0 の文に体力が低い時の続きを足す（例「…。体力も少ない、休むか軽いバイトを」）。または体力の行を借金の行より先に置く。
- 確度：高（コード上の順序で確定）。

### 1-2 GameSession.swift:1146-1155 と WeekMainView.swift:1433 — 借金の段の知らせが「一生に1回」で、再び借金になっても出ない
- 何が隠れるか：`debtWarnTier` は上がる一方で、`money >= 0` に戻っても下がらない。1度でも借金（100万まで残り20万の段など）を経験すると、次に借金に落ちた時の「借金が50万／80万を越えた。あと○万で終わり」のモーダルが二度と出ない。
- 起きる手順：1回目に −85万（段3）まで落ちて立て直す→後の年で生活費が払えず再び −60万→段2のモーダルは出ない（`tier > debtWarnTier` が偽）。一言は「所持金はマイナス」だけで、終了ラインまでの距離が分からないまま −100万で芸人を続けられなくなる。
- 直し案：money が 0 以上に戻った時に `debtWarnTier` を 0 に戻す（週送り後に1行）。または一言（WeekHint）に段に応じた距離を足す。
- 確度：高（リセット箇所が grep で無い）。ただし「1回きりの意図」なら設計判断になるので、オーナー確認の余地あり。

## §2 確度 中

### 2-1 WeekHint.swift:47 — ネタ0本の間は「今週末に生活費。足りない」が隠れる
- 何が隠れるか：`netaCount == 0` の行が生活費の行（:48）より前。今回直した撮影の週と同じ型。
- 起きる手順：ネタが無いまま最初の生活費の週（week = livingInterval）を迎え、所持金が足りない→一言は「まだネタが無い」。
- 直し案：生活費の不足の行を netaCount==0 より前に置く（撮影の週の枝と同じ扱い）。
- 確度：中（序盤にネタ0本のまま家賃週に着き、かつ足りない状況が現実に起きるかは未実測）。

### 2-2 WeekHint.swift:43-46 — 撮影の週は体力の警告が隠れる
- 何が隠れるか：preoccupied の枝は「生活費不足」以外は固定文を返し、体力（:49-50）を見ない。
- 起きる手順：撮影の週に体力が低い→「稽古には出られない」だけ。バイト等の他の行動で体調ダウンの危険は続く。
- 直し案：生活費不足の次に、体力が低い時の行を挟む。
- 確度：中（撮影の週に選べる行動と体調ダウン判定の詳細は未確認。体力を減らす行動が無いなら実害なし）。

### 2-3 WeekHint.swift:14-17,34 — `stageWeeksLeft`／`netaFitsStage`／`stageNearWeeks` が line() で使われていない
- 何が隠れるか：「大会が近いのにネタの尺が舞台に合わない」型の警告。入力は組み立て（WeekMainView.swift:500-501）て渡しているのに、判定に一切使っていない。
- 起きる手順：選んだネタが舞台の尺に合わないまま大会の週に入る→週の一言は何も言わない（別の場所で警告が出ているかは、WeekMainView 内に「尺」の文字列が無いので少なくとも週メインには無い）。
- 直し案：今も要るなら、体力・生活費の次に「大会まで○週。選んだネタは尺が合わない」を足す。要らない（％・見込み禁止で意図的に削った）なら Input から消して紛らわしさを無くす。
- 確度：中〜低（意図的な削除の可能性。ネタ選びの画面側で警告があるかは未確認）。

## §3 見たが問題なかった所
- goalBanner（WeekMainView.swift:444-）：「経験点が残ってる」の朱の帯（weeksLeft<=2）と lullLine（weeksLeft>=6）は排他だが、片方が重要警告を隠す関係ではない。大会「今週！」の表示は帯の上段で常に出る。
- `expBannerShown`（:496）：帯の条件と同じ `nextMilestone()`／`unspentBeforeStage` から計算していて、帯が出ている時だけ一言を引っ込める。帯が出ていないのに一言も出ない食い違いは無い（年末の bannerMilestone は帯専用で unspent 判定に影響しない）。
- maybeShowDebtNotice（:1420-）：体調ダウン→コンビ→借金の順で return するが、各通知は「出してから mark」で、条件が揃う次の呼び出し（週送り2秒後／burstHold解除／イベント解除／onAppear）で拾われる。生活費の支払い画面（presentRent）は burstHold の defer より前に終わるので、借金の知らせはその後の呼び出しで出る。最悪でも1週遅れで、段の境界を1週で飛び越える額ではない。
- 体調ダウンの知らせ：週メイン（:1421）と大会入口（StageViews.swift:234）の両方に出し口があり、大会入口に重なっても隠れない。
- maybeShowFirstHints：他の知らせがある間は出さないだけの一回きりの説明で、重要警告を隠す側ではない。
- 生活費の予告（再来週、WeekHint.swift:51）：体力の警告より後ろだが、当週の不足行（:48）は前にあるので実害のある隠れ方ではない。
- オファーの期限の表示は WeekMainView.swift に見当たらず（grep で該当なし）、この型の対象外。

## 扱い（10/25 深夜の自走）
- §1 の借金の段（debtWarnTier が下がらない）：オーナー決定 10/15 A-10「初めてのマイナス・−50万・−80万で**一度ずつ**知らせ」のとおり＝不具合ではない。返済後にまた借金した時にもう一度知らせるかはオーナー判断（キュー123 に並べる）。
- §1 の借金の週に体力の一言が出ない・§2 のネタ0本／撮影の週に他の警告が隠れる：週の一言は1行だけ出す作りで、どれを先に出すかは表示の設計判断（既存テスト WeekHintTests.testPriorityOrder が「ネタ無し＞生活費不足」を固定している）。体力は帯の数値・色でも見えるので、今は直さずキュー123 に並べる。家賃不足が撮影の週に隠れる1件だけは 10/25b §2-1 で直した。
- §2 の stageWeeksLeft・netaFitsStage が line() で使われていない：入力に残っているだけで害なし（触らない）。
