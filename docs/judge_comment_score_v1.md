## §5 全体の傾向（3行）
1. 規則・ゲートは通っている。崩れは「語彙表の言い回し×固定文」の組合せ側（同語反復・「所」「最後」「最初」「一言」の重なり・助詞連鎖）。
2. 語彙表が「場所」「物」「連体修飾つき長句」を混ぜているので、助詞や後続名詞のつくテンプレ（〜から前を／〜の一か所／〜の運び）で合わない型が出る。語彙を助詞中立の名詞止めにそろえるか、テンプレの後ろを助詞なしの言い切りにするのが効く。
3. 声の長さの超過（花園・白波・神楽坂・音羽の3文行）と、一般帯での相性主題の先食い（花園 340・348）が残る。
