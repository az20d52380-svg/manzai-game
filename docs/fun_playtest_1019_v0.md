## §2 退屈・手応えなしの所見（重さ順）

### 1. 能力アップ：経験点が山ほどあるのにランクが上がらない・押しても何も起きない（最重）
- 場所：能力アップ画面とメイン画面への戻り。
- 起きたこと：20週で経験点が 閃68／語26／間33 まで余った。それでも全5能力が「G」のまま。表の灰色（足りない）は 胆・存在感 の経験点（「胆 あと26／存在感 あと16」）。確定を押すと数字が+1〜2動くだけで、メイン画面に黙って戻る。ランクが上がる瞬間も演出も無い。メイン画面の「振れる経験点あり」の赤札は、振っても消えず出続ける。
- なぜ退屈か：稽古で貯めた物が使えず、貯めるほど「無駄にしている」感じになる。能力アップはこのゲームの一番の手応えの場所のはずが、表計算を触るだけ。ランクG→Fという最初の節目に20週かかり、その間ずっと進んでいる実感が無い。

### 2. 大会：負けた結果と講評を自分の目で見られない・負けても「何がだめだったか」が残らない
- 場所：大会の本番（客席の反応→結果発表→講評）。
- 起きたこと：「次の声へ」ボタンが毎回同じ位置で、連打すると結果発表・講評を飛ばして負けた次の週のイベントに入った（2回とも）。客のアンケートの声（「今日の三時のおやつは本調子じゃなかった」）は良い。しかし結果発表の画面を見ていないので勝敗の確信が後から「賞金0」で分かるだけ。体力0で出場できてしまう（警告の赤字だけ）。
- なぜ退屈か：大会は唯一の山場なのに、結果の演出を見る前に流れる。負けの理由（体力0・ネタ72・実力13）が一覧で出ない。

### 3. 稽古を押す度にイベント（約8タップ）が先に入り、押した稽古は選び直しになる
- 場所：メイン画面の「稽古」「ネタ」「能力アップ」のタップ直後。
- 起きたこと：20週のうち約11週で、行動ボタンを押すとイベント（地の文＋台詞を1行ずつ送る・7〜10タップ）が先に始まり、終わると行動の選び直し。体感はイベント約90タップ、行動約45タップ。イベント自体は良い（「まだ敬語の頃」「棚卸しの夜」「夏祭りの営業」は選択の結果が効果札で見える）が、「稽古を選んだつもりが別の話が始まる」。
- なぜ退屈か：イベントの頻度が高く、1つの中身は薄い（会話を送るだけ）。選択肢が実質「付き合う／断る」の2つで、毎回似た形（先輩の誘いが2回）。

### 4. お金に追われて選べない週が多い（お金・体力で行動が消える）
- 場所：月末の支払い（4週ごと-14万）と稽古の有料メニュー。
- 起きたこと：5・10週で稽古9種のうち有料は「お金が足りない」で消え、無料2種だけ。12週の大会（新幹線3.2万＋交通費）と月末が重なり借金-11万。13〜14週はバイトと営業で借金返済。16週は体力0でバイトか休むのみ。
- なぜ退屈か：数値側の「強制週」の通りで、4週に3週は「やることが決まっている」。お金を稼ぐ週の中身が薄い（バイトは数行の台詞＋札だけ）。

### 5. 営業・ロケのオファー：+28万・+22万が「数字の札」だけで終わる
- 場所：メイン画面の「オファー」札と受けた後。
- 起きたこと：札を2回押す（1回目は確認文に変わる・不親切）と、画面の上に「所持金+220,000」の札が出るだけ。場面も相手の台詞も無い。体力消費も無く、借金返済の特効薬になってしまう。
- なぜ退屈か：一番お金になる行動なのに演出が最も薄い。選択ではなく「出たら受ける」だけ。

### 6. 空白期の目標が見えにくい（良い所もあるが弱い）

### 7. 同じ文・同じ画面の繰り返し
- 場所：メイン画面の吹き出し・上の一行。

- なぜ退屈か：選択の違いが文面に出ない。

### 8. 説明ポップアップが多い（最初の11週で5回）
- 場所：はじめに／生活費／能力アップ（2種）／大会エントリー。

## §3 「おっ」と思った所（良い所）
- **イベントの選択結果の札**：選ぶと「発想↑ 表現↑ 体力↓」の札が出て、選択の意味が目に見える（「目が冴えた夜」）。
- **イベント自体の温度**：「まだ敬語の頃」「棚卸しの夜」「夏祭りの営業」「ライブ帰りの駅」は台詞が自然で、相方・先輩・バイト先の人物が立っている。バイト先の人（矢島）が出るのも良い。
- **客のアンケート**：大会の客席の声（「本調子じゃなかった」「嫌いじゃない。むしろ好き」）は具体的で、負けても読ませる。
- **大会前夜・負けた次の週のイベント**：山場の前後に物語が入る。「負けた次の週」は遅くまで稽古する／帰るの選択があり、メンタル／体力が動く。
- **年間香盤**：1年の大会・稽古・バイトが月の表になっていて、見通しが立つ。
- **月末の支払い明細**：家賃・食費・光熱・交通の内訳が出て、お金が減る理由が分かる。
- **行動メニューの札**：稽古・休む・バイトは「+14 / 体力-20 / -8万」が一覧で比べられ、迷う材料がある。

## 追記（試作ブランチ claude/fun-1019-proto・F3 見送りの理由）
- F3「イベントを行動の後に出す」は**表示順だけでは実装できない**ため見送り。
- 選択イベントは週頭（.freeAction 確定直後・GameSession.evaluateChoiceEventFire）に発火判定され、選択の効果（体力・相性・所持金など）は `applyEventChoice` → `runner.applyEventEffects` で**その週の state に先に適用**されてから、押した行動（`choose`→`resolveAction`）が解決される。
- 行動の後に回すと、(a) 効果が行動の解決（体力ゲート・稽古の伸び）より後になり週の結果そのものが変わる、(b) 発火条件（体力>=15・justLost/justPassed・大会までの週数）と選択肢の gate が行動後の state で評価し直しになり、(c) 発火判定で引く uiEventRng の消費位置が1週ずれて以後の抽選列が変わる。いずれも「式・効果・乱数順は変えない」の範囲を超える。
- 代替（表示側・効果順は不変）：週頭に既にイベントが立っているのに「行動ボタンを押して初めて出る」体感になっている箇所があれば、そこを週頭の自動提示に統一する（WeekMainView.syncEventPresentation）／台詞の2〜3行まとめ表示（所見3 案2）。要オーナー判断。
