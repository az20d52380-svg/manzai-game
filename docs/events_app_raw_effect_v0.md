# 実測機のイベント効果をアプリと同じ「素の加減算」に（10/19 自走・gamecore_review_1019 F2）

## 何を直したか（道具の修理・アプリ／GameCore／golden は不変）
- アプリ（GameCore ChoiceEventEffect.swift applyEventEffect）はイベントの効果を「素の加減算＋上限で止める」だけで適用する（成長の鈍り・年の予算・知名度の鈍化・相性の凍結を通さない＝コメントに「別枠の付与」と明記）。
- 実測機（tools/sim_career.py）の EVENTS_APP=True の経路は、それを B.add（鈍り・予算・知名度の鈍化つき）で測っていた＝アプリより弱いイベントを測っていた。
- `_ev_add` を足し、EVENTS_APP=True の時だけアプリと同じ素の加減算にした。EVENTS_APP=False（実測機独自のイベント模型）は従来どおり。check_golden_sync は 50行＋12週一致。

## 結論（オーナー判断の材料・決めるのはオーナー）
1. **今のアプリは、これまでの実測（EVENTS_APP=True）より甘い**：やり込みの10年通しの優勝が約13%、決勝到達が約87%。目安（やり込み初回優勝 3〜5% 等）より上に出ている可能性。
2. 原因はイベントの効果が成長の鈍りを通らないこと（能力が高いほど差が開く）。
3. 選択肢（どれも規律Aの判断）：(a) アプリのイベント効果も鈍りを通す（体感でイベントの効きが弱くなる）(b) イベントの数値を下げる (c) 今の甘さを受け入れて他で締める (d) そのまま。EVENTS_APP を既定にするか（判断待ち中）と一緒に決めるのがよい。
4. 過去の EVENTS_APP=True の実測（events_app_parity_v0 等）は、この直しの前の値＝低めに出ている。
