## §93 経験点の配り方（間合いが余らない）
スクリプト `tools/exp_exp_rebalance_v0.py`（生の結果 `docs/measure_raw/q93_*.txt`）。オーナー決定：交換は使わず、配り方で直す。詰まり＝「週末に経験点が5以上あるのに、どの能力も＋が押せない」。hand＝人の手配り近似、auto＝おまかせ。
試した案：S＝練習でもらえる経験点の付け替え（語彙を増やし間合いを減らす）／R＝能力が使う経験点の付け替え（間合いを使う能力を増やす）／R2＝能力が使う割合を、もらえる割合（閃.23 語.08 間.31 存.09 胆.28）に合わせる／M＝間合いのもらえる量だけ減らす（ネタ見せ会 6→4・ネタ合わせ 3→2）。「@x」は全体の量を x 倍。

| 案（hand・n=300）| 1〜3年の詰まり週（のんびり/ローテ/バランス）| 3年末に使われずに残った間合い | ローテの決勝（hand）|
|---|---|---|---|
| 今 | 93 / 82 / 93% | 99〜100% | 36% |
| S | 92 / 92 / 94%（存在感が余る側に移るだけ）| 71〜77% | 27% |
| R | 81 / 71 / 77% | 74〜78% | 40% |
| R2 | 83 / 78 / 86% | 55〜64% | 55% |
| **R2M** | 63 / 64 / 65% | 41〜53% | 55% |
| R2M@0.9 | 59 / 59 / 60% | 42〜52% | 43% |

**分かったこと**
- 能力1つに経験点を何種類も使う作り（全部そろわないと押せない）なので、どれか1種類でも足りないと全部の＋が止まる。もらえる割合と使う割合をどれだけ合わせても、遊び方（どの練習を多く選ぶか）で余る種類が変わるので、**配り方だけでは「ほぼ0」にならない**（一番良い R2M で6割前後）。
- 「ほぼ0」にするには、余った1種類だけで使える受け皿が要る＝**特技（パワプロの特殊能力）**。オーナーの「特技は後」の時に入れると完成する。それまでは R2M で「使われずに捨てる経験点」を半分にできる。
- R2M は伸びが増える（使われる経験点が増えるため）＝ローテの決勝 36→55%。全体の量を 0.8〜0.9倍にして戻す（n=1000 で測定中）。
- 賢い型（調整型）は R2 系で解散が 7→28%に増える（センスが上がってネタ合わせを選ばなくなる＝ボットの選び方の副作用・前回の実測と同じ）。§94 の「二人の週はすれ違いがたまらない」を入れると小さくなる見込み。

**n=1000 の確認（docs/measure_raw/q93_r2m_n1000.txt）**

**推奨：R2M@0.8（※10/18 夜：別のボットの組では帯が上がり解散が0になる＝docs/combined_bands_v0.md 追記。2組で測り直すまで保留）**（能力が使う割合：センス 閃.35/間.40/胆.25・発想 閃.60/語.25/間.15・表現 語.20/間.60/胆.20・華 存.50/閃.20/間.30・メンタル 存.20/胆.80／ネタ見せ会 間6→4・ネタ合わせ 間3→2／全体の量 0.48→0.384）。
- 1年目の「上げられない週」が 5〜8割 → 1割前後。1〜3年でも半分になる。ローテの帯（決勝36%・優勝2.5%）は今と同じ。
- 代わりに：のんびり型の決勝が 12.7→4.9%（稽古の少ない人は今より伸びない）。賢い型の解散が 5→28%（ボットの選び方の副作用・§94 の「二人の週」と一緒に入れて測り直す）。

## §97 体調ダウン（パワプロの怪我）
スクリプト `tools/exp_injury_v1.py`。
- **今起きない理由**：ダウンの抽選は「体力20未満で練習」だが、体力20未満はそもそも練習を選べない（谷口が止める）＝同じ線。キツいバイトでしか起きず、どのボットも 0回。

- 表示：％は出さない。体力が50を切ったら練習ボタンの横に「無理すると倒れるかも」の一言（谷口）を出す案。

## §94 予選で落ちたら相性↓＋二人でやる週はすれ違いがたまらない

- 注意：相性は本番の点に直結。L1 以上は帯が大きく下がる（決勝 −11〜−15pt）。
