# 借金警告の効果 実測 v0（2026-10-16・n=1000・コード/式は変更なし）
スクリプト: `tools/exp_debt_warning_v0.py`。基準＝人間らしい（無料稽古3週:バイト1週＋喫茶店）。反応型は所持金が線を割ったら発動、0以上に戻ったら基準へ復帰。
夜逃げ＝生活費の週に所持金が −100万 未満。①＝ネタ作り/ネタ合わせ/バイト/バイトの巡回（週2）②＝お店やめ・稽古1:バイト2 ③＝バイト専念（標準バイト・体力20未満で休む・オファー受諾）。

## 結論
1. **「バイトを増やす」程度（①週2・②週1→2/3）では防げない（夜逃げ99.7%のまま）。** 気づいた後の「バイト専念」まで振り切れば、−80万の知らせでも夜逃げ0%で立て直せる。
2. **間に合う段：−80万まで（0／−30／−50／−60／−80万はどれも0%）。−90万では手遅れ（11%が夜逃げ）。** −80万〜−100万の間は約5〜10週しかなく、1回の生活費・出費で飛び越える人がいる。知らせは −80万が実質の最終線で、それより遅らせない。
3. 立て直しても稼ぎが稽古に回らず**優勝0%・決勝2〜6%**（10年目所持金は800〜1100万＝生き延びるが育たない）。早く気づくほど決勝率は上がる（@0=5.6% > @−80万=2.1%）。線の調整案＝**−30万を足して 0／−30万／−60万（／−80万は最終）**が妥当。−50万 → −60万 に動かしても差は小さい（立て直し率はどちらも100%）ので、「早め（−30万）」を1段足すのが決勝率の面で効く。

## 注意
- 喫茶店は所持金が（費用＋30万）以上でしか買わない設計のため、②の「店をやめる」は実質差がない（借金中は元々買わない）。②の弱さの主因はバイト比率不足。
- ①②が効かないのは「週2バイトでも生活費・稽古費を賄えず下り続ける」ため。反応の強さが問題で、知らせの段の問題ではない。
- 反応型は「知らせに気づいた人」の理想形。実際の人がバイト専念まで切り替えるかは別（警告文面で「バイトに専念」と誘導する必要）。
