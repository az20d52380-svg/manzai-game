# お金の使い道の釣り合い v1（キュー61・2026-10-15・数値は全て【仮】・決定はオーナー）

## §0 要点
- 保存先：`tools/exp_money_balance_v1.py`（既定値・golden は不変＝gen_golden 後に差分なし）。
- 今（お金の使い道 全部あり・回数上限なし）は、バイトが**週の4%しか選ばれず**、10年目の所持金が 1900〜3100万も余る。「バイトか練習か」の釣り合いが成り立っていない。
- 効く道具は**生活費を上げる**（＋バイト収入を少し下げる）。値段上げ単独は所持金は減るがバイトの割合は動かない。有料効果を下げると帯が落ちすぎる。
- 推奨【仮】：**バイト収入×0.8・生活費×1.4（14万/4週）＋新アイテム（支出のみ）**。バイト13〜17%・10年目の所持金 240〜890万。帯はローテ 1.8%／32.8%（基準 0.8／31.8）・やり込み 6.3%／69.5%。

## §1 立て方
- 前提：NETA_ON/NETA_V2（飽きD: PEN1.0・CAP2）・知名度案G（FAME_V62 …）・OFFER_RATES 案G・EVENTS_ON・canon_v2.apply()。ボットは exp_money_all_v1 の「全部あり」（PCasual2＋喫茶店＋有料休み／PRotate 同／PNeedV3＋有料休み）。回数上限なし。
- 指標：優勝＝初回優勝％／決勝＝決勝到達％／10年目＝10年目まで残った人の年末所持金中央値／バイト＝バイト（オファー除く）の週÷行動週（バイト・稽古・休み・オファー）／有料＝有料の行動（場所・教室・サウナ・温泉・ネタ見せ会等）の週の割合。
- バイトの割合はボットの規則（残高が減ったら働く）の産物。人間の感覚の代理指標として読む。
- 基準（ネタ無し・n=1000）：ローテ 0.8%／31.8%・やり込み 3.0%／42.3%。やり込みは「全部あり」だと必ず上に出る（お金で自分で場所を選ぶ分。neta_bonus_remeasure §4・§7 と同傾向）。

## §5 選択肢（決めない）
- 案1【推奨】：L（バイト×0.8・生活費×1.4）＋§4 から数個。理由：バイト13〜17%・所持金が尽きない程度に減り、帯がほぼ基準内。
- 案2：C 生活費だけ×1.5（バイト9〜12%）＋アイテム。理由：変えるのが1箇所で分かりやすい。帯はローテ決勝 38.7%と少し高め。
- 案3：G（バイト×0.75・生活費×1.5）。バイト19〜32%と釣り合いは最も明確だが、のんびり層は所持金 364万・ローテ決勝 28.7%で基準を下回る。
- 避ける：D（有料効果を下げる）・C2（生活費×2）。
- 注意：ネタ込みの前提でも、ローテの決勝は 28〜33%（基準 31.8%）に収まるのは L・G 系だけ。やり込みは全案で基準を上回る（お金で自分に必要な練習を選べる分）。やり込みを下げるのは別問題（お金の判断とは分けて扱う）。

- 読み：やり込みが目安に入るのは ②（効果×0.5：3.9%／53.5%）だけ。ただしローテの決勝が 9.4%まで落ちる（基準 31.8%）＝やり込みだけを下げる手が無く、有料の効果を下げるとローテ・のんびりの方が先に潰れる（練習の場所・休みが彼らの帯を支えているため）。①は両方とも半端（やり込み決勝 66.7%・ローテ 25.3%）。③は逆に上がる。④は①と同じ。

- 結論：バイト割合と所持金は L で足りる。やり込みの帯の上振れは「お金の強さ」ではなく、やり込みボットが自分で有料の行動を選べる構造（人間もそうなる）に由来する。効果を下げて帯に合わせるとローテが壊れる＝推奨は L のまま（やり込みの上振れは容認するか、お金とは別の手で扱うかをオーナー判断）。
