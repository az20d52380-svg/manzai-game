# お金とアイテムの使い方 v1（2026-10-13 深夜・オーナー原則の反映・中身は案）

## オーナー決定（2026-10-12 23:58）
> 「パワプロのアイテムもお金で能力あがらないよね？だから体力回復とか、喫茶店でネタ作る（家で作るよりいい）、カラオケでネタ合わせ（家でやるよりいい）。そういう意味で金使ったら能力アップだけど、アイテム買ったら能力アップとかはダメ」
1. **アイテムを買っても能力は上がらない**（パワプロと同じ）。
2. **お金で能力が伸びるのは「お金を払って、良い場所・良いやり方で練習した週」だけ**（1回ごとに払う）。
3. 体力の回復・体調・移動など、能力以外にお金を使うのは自由。

## §0 要点
- 練習ごとに「無料の基本」と「お金を払う良い場所」を並べる（家で書く／喫茶店で書く、公園で合わせる／カラオケで合わせる）。
- お店の品は能力に効かない物だけにする。今の「勉強会・ボイトレ・稽古場の年契約・ICレコーダー」は練習の場所へ移すか外す。
- 伸びの総量は成長の器（年ごとの上限）で頭打ちになるので、お金持ちでも帯が壊れにくい。値は実測してから決める。

## §1 練習の場所（お金を払うほど伸びる・1回ごと）【値は全て仮】
> **オーナー確定（2026-10-13 0時）**：「ネタを書くが家で書くとか喫茶店で書くとか、そういうふうに選んだらってこと」。
> → **ネタを書く を押した一覧＝場所**（家で書く／喫茶店で書く／ファミレスで朝まで）。磨くのは勝負ネタ（一覧の上に「書くネタ：「〇〇」」＋切り替え・「新しく書く＋題名」）。作ってよい。
| 行動 | 無料の基本 | お金を払う良い場所 | 何が増えるか |
|---|---|---|---|
| ネタを書く | 家で書く | **喫茶店で書く**（¥1万）／ファミレスで朝まで（¥5千・体力の減り多め） | 閃き・語彙と、ネタの完成度が多め |
| 相方と合わせる | 公園で | **カラオケで**（¥1.5万）／貸しスタジオで（¥4万） | 間合いが多め・カラオケは相性も少し |
| 舞台に立つ | フリーライブ | お金を払って出るライブ（¥3万・ノルマ） | 存在感・知名度が多め |
| ネタ見せ会・話し方教室 | — | 今のまま（¥8万） | 今のまま |
- 画面：ネタの一覧と練習の一覧の上に「場所」を選ぶ切り替え（家｜喫茶店｜ファミレス）を置く。押す回数は増やさない（場所を選んだまま、ネタを押す＝実行）。
- 仕組み：GameCore の練習に「場所」を足す（費用・伸びの倍率・体力）。規律A（Python→Swift→golden→テスト）。今の無料の基本は数値を変えない＝golden 不変の見込み。

## §2 お金を払う休み（オーナー案）
| 休み | 費用 | 効果 |
|---|---|---|
| 家で寝る（今） | 無料 | 回復 大・メンタル少し |
| サウナ | ¥1万 | 回復 もっと大 |
| 温泉に一泊 | ¥6万 | ほぼ全回復・相方と行くと相性少し |
| 整体 | ¥1.5万 | 回復 中・しばらく体調を崩しにくい |
※相性も実力に入るので、温泉の相性は「無しにする」案もある（§5 の質問2）。

## §3 お店（能力に効かない物だけ）
| 品 | 扱い |
|---|---|
| 栄養ドリンク・銭湯の回数券・新幹線回数券 | 残す（体力・休み・移動） |
| **ネタ作家の勉強会・ボイトレ短期集中** | お店から外し、練習の「お金を払うやり方」へ移す（1週使う行動にする） |
| **稽古場の年契約** | 外す（貸しスタジオ＝§1 の1回ごとの場所に置き換え） |
| **中古のICレコーダー** | 外す。または「持てるネタが1本増える」に変える（強さに直結しない） |
| 新：お守り | しばらく体調を崩しにくい |
| 新：いい枕 | 家で寝た時の回復が少し増える（ずっと） |
| 新：勝負服 | 大会の見た目が変わる（効果なし） |

## §4 持ち物（パワプロ式）
- 買った物は「持ち物」に入り、好きな週に使う（大会の前に栄養ドリンク等）。使っても1週は進まない。
- 今は買った瞬間に効く。持ち物にするのは GameCore（状態に持ち物の数を足す）＝乱数は使わない。
