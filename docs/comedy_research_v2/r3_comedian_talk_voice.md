## 2. ゲームの会話はなぜ寒くないか（＋芸人の実際の話し方・参考）

### 2-1 結論（6つの理由）

ゲームのキャラ会話が同じくらいベタでも寒くならないのは、**文が「上手いこと」を目指していない**から。担っている仕事が小説と違う。

1. **キャラは「記号」で立つことが許されている**。語尾・一人称・口癖・執着話題の組み合わせで「誰が喋っているか」が1行で分かればよい（パワポケの「やんす」は話者が一目で分かるよう語尾に変化をつけた＝メインライター西川直樹氏の説明）。記号が先に立っているので、台詞は内容が軽くてもキャラの味になる。
2. **演出が感情を受け持つ**。表情差分・動き・BGM・効果音が感情を出すので、文章は感情を描写しなくてよい（元電撃文庫編集長・三木一馬氏「ゲームは声・BGM・背景に演出を任せられる」趣旨の発言）。→ 現行は**表情も絵もないのに感情を物に背負わせる**という、小説の手法を小説より不利な媒体で使っている。
3. **1吹き出し＝1呼吸**。ドラクエは物語を「セリフ」で進める（堀井雄二×橋野桂対談の見出し）。地の文はほぼ無く、あっても1行の状況説明。
4. **主人公は喋らないか、喋っても短い**。ドラクエの主人公はプレイヤーそのものなので喋らない（堀井氏・2019年映画イベント）。主人公が格言を言うと、プレイヤーが言わされる。
5. **ユーモアはキャラ同士の軽口で、型が記号化されている**（ボケ役が素っ頓狂なことを言う→ツッコミ役が短く受ける→汗マークや「……」で流す）。型が見えているので「ウケを狙っている作者」が透けない。ネタ本文（舞台の漫才）とは別物。
6. **真剣さと軽さの落差で効かせる**。Undertale の作者 Toby Fox は、手本の MOTHER について「面白くて変なだけでなく、誠実で感情的」な点を挙げている。パワポケも軽いギャグと不穏な本筋を同居させた。**普段が軽いから、たまの真面目が刺さる**。現行は普段から真面目なので、山場が平地に埋もれる。

### 2-4 芸人の実際の話し方（参考・オーナー指示で縮小）

楽屋やラジオでの芸人同士の会話は、相手の発言を即いじる・自分の本音は照れ隠しで茶化す・褒め言葉はボケに包む、が基本と言われる【一般的な観察・出典未確認】。ただし**そのまま文字に起こすと内輪の空気が伝わらず寒くなる**（オーナー判断 2026-10-10）。持ち込むのは「本音を言いかけて茶化す」「いじられた側がツッコミで返す」という**関係の型だけ**で、口調はゲームのキャラ会話の記号に寄せる。関西弁は谷口の記号として使い、俺は若者の口語の標準語（「いや」「まあ」「〜じゃん」程度）にする。

## 5. 新しい書き方ルール案（manzai-drama-voice 置き換えの骨格）

> 仮称 `manzai-chara-talk`。現行 Skill を消さずに「正典v2移行」バナーで上書きする想定（CLAUDE.md 規律C-6）。置き換えは**オーナー判断**。

### 5-1 基調（3行）

1. **ゲームのキャラ会話で書く**。小説・純文学の文体は使わない。会話が主、地の文はト書き1行。
2. **二人は仲のいいコンビ**。普段は軽口（谷口がズレる→俺がツッコむ）、山場だけ真面目。軽口8割・真面目2割。
3. **ネタ本文は書かない**（舞台の漫才のボケ・ツッコミ・オチの台詞）。楽屋・稽古場・帰り道の**日常の軽口は書く**。

### 5-2 話者ごとの声

| 話者 | 役割 | 口調の記号 | 言うこと | 言わないこと |
|---|---|---|---|---|
| **俺**（主人公・ツッコミ） | ツッコミ・心配・決定 | 若者の口語の標準語（「いや」「まあ」「〜じゃん」「〜だろ」）。語尾の癖は作らない | 相手へのツッコミ／相槌／金と段取りの心配／決定（「行くか」「やめとこう」） | 格言・教訓・比喩・まとめ・「それでいい」級の締め |
| **谷口**（相方・ボケ） | 楽観・大食い・ムードメーカー。たまに核心 | 関西弁・柔らかいタメ口。日常型口癖（「なんとかなるやろ」系）を差し色で | 生活のズレた発言（食べ物・バイト・寝る）／楽観／たまの一言の本音→すぐ茶化す | 詩的な比喩・小道具の回収・舞台のボケの本文 |
| **第三者**（先輩・店長・マネージャー等） | 状況を持ち込む人 | 人物帳（slots.md §5）の記号を維持。1人1記号 | 用件を短く。いじり役に回ってよい | 説教の長台詞・説明台詞 |
| **ト書き**（地の文） | 場所と時刻 | 体言止め可・1行 | 「稽古場。深夜二時。」「楽屋。出番終わり。」 | 描写・心情・比喩・余韻 |
| **心の声**（週頭の独白） | プレイヤーへの小さな一言 | 俺の口語 | 今週の心配・やること・小さいボヤき（1文） | 余韻・格言・業務日誌の羅列 |

### 5-3 長さ（ハード上限【仮】）

| 項目 | 上限 |
|---|---|
| 1吹き出し | 2文・40字以内 |
| ト書き | 1場面1行・30字以内（選択後の分岐には置かない） |
| 1イベントの setup | 4〜6吹き出し（ト書き1＋台詞3〜5） |
| 選択後 afterChoice | 2〜3吹き出し |
| 週頭の掛け合い | 2〜3吹き出し（現行どおり） |
| 長尺の解禁 | 決勝敗退・優勝・年次リザルトのみ（現行どおり）。それでも1吹き出し2文は守る |

### 5-4 禁止事項

- ネタ本文（舞台のボケ・フリ・オチ・ツッコミの台詞）。**楽屋の軽口は対象外**（現行 VB§1-1「相方の軽口も対象」を削除）。
- 俺の格言・教訓・比喩・余韻の締め（「〜それでいい」「〜同じだ」「〜安い」で終わる型）。
- 小道具の詩的な回収（地の文の物を台詞で意味づけし直す）。
- 意味を言わない謎かけ（読者が解く材料のない所作）。**意味は台詞で言ってよい**。
- 地の文での心情・比喩・描写。
- 数値・システム名の復唱、「笑」の字（現行の恒久規約を維持）、実在の芸人・番組・大会名、％表示。
- 削除する現行条項：感情語の禁止（A2）／固有物の置換テスト（VB§2）／「〜た。」で止める（VB§2-4）／乾いた一滴5〜6本に1本（VB§3）／勘定に逃がす（VB§4）。

### 5-5 採点ゲート（減点表16項目→6問）

1本書くごとに Yes/No で答え、1つでも No なら書き直す。**採点は声に出して読んでから**。

1. **ト書きを除いて、会話だけで場面が分かるか**（地の文を消しても成立するか）
2. **名前を隠しても誰の台詞か分かるか**（俺／谷口／第三者）—現行 V1 を維持
3. **どの吹き出しも2文以内か**
4. **軽口（ズレ→ツッコミ）が1つ入っているか**（山場スロットは「入れない」が正解のことがある＝その場合は理由を一言）
5. **俺の台詞が「ツッコミ・相槌・心配・決定」のどれかか**（格言・比喩・まとめなら No）
6. **ネタ本文になっていないか**（観客の前でやる漫才の台詞に見えたら No）—現行 A1 を維持

加えて、バッチごとに**作者以外（オーナー・別セッション）が読んで「寒い」と言った行は理由を問わず没**（Toby Fox の友人テスト）。

### 5-6 現行から残すもの

- ネタ本文禁止（A1）・名前隠しテスト（V1）・口癖三類型と天丼3回目でひねる（CV§1）・数値復唱禁止・「笑」不使用・固有名架空・方言ロック（谷口＝関西弁、他は人物帳どおり）・長尺はE軸のみ。
- 谷口の「腹減ったな」は切り札型のまま（年2回）。ただし**大食いという執着話題は日常型として解禁**し、文言を毎回変えて出す（CV§1 の「執着話題型は乱発耐性が高い」に合致）。
