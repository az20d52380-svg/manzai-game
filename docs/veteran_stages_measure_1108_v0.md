# ベテラン向けの大会・仕事 V1〜V4 の実測（2026-11-08 v0）
結論1：4本全部（V1〜V4）で優勝 9.5→11.2%・決勝進出 64.2→67.6%・解散率はほぼ不変（3.3→3.3%）＝GP を壊さず少し押し上げる。15年走り切った組の最終所持金の中央は 2,866万→3,644万（+27%）。
結論2：判定のない2本だけ（V2+V4）は優勝 8.1%（基準より約 -1.4pt＝稽古の週が潰れる分）・決勝 64.4%・所持金 3,147万（+10%）。**12年目の空白週はほとんど減らない**（9.6→9.4→8.9）＝V2/V4 は空白でなく稽古の週に入るため、「週が空く問題」の解決にはならない。
結論3：V1・V3 は判定つき（ライン32・36）で通過すれば知名度と賞金が入るので、4本全部の方が優勝・決勝とも V2+V4 より高い。

## 測り方
- 道具 `tools/measure_veteran_stages_1108.py`（既存の tools/*.py・GameCore・golden は無変更。実行時の差し替えだけ）。土台は exp_late_events_tuning_1108_v0.py と同じ：EVENTS_APP=True・NETA_ON/NETA_V2=True・4ボット（のんびり PCasual2／ローテ／必要充足／やり込み改）・15年・`Pool(maxtasksperchild=1)`＋`chunksize=1`・シードは BASE_SEED+i。終盤イベント候補（枠・40本）は入れない（本体の既定）。
- 優勝＝15年内の初優勝。15年目の所持金＝初優勝・解散・夜逃げをせず15年を走り切ったキャリアの最終所持金の中央値（ボット別の中央値を4ボットで平均）。全員の終了時所持金の中央は 2,850万／3,117万／3,606万（同じ向き）。
- 12年目の空白週＝12年目の `do_rest`（休み・体調ダウンの療養・稽古ゲートで止められた休み）の回数。12年目を無事に終えたキャリアだけの平均。
- V1（18週・6年目以降・ライン32・賞金30万・知名度+5）と V3（33週・11年目以降・ライン36・賞金60万・知名度+10）は `tournament_of` を差し替えて通常の大会として足した（エントリー費・ネタ補正・経験点・イベント結果の扱いは既存の大会と同じ）。
- V2（23週・知名度30以上かつ体力40以上・出演料12万・知名度+1）と V4（36週・8年目以降・ネタ2本以上・売上 10万+15万×知名度/100・知名度+2）は、その週の `pol.choose` を横取りして効果を足し、何もしない週として返す。

## 限界
- V4 の「ネタ3本以上」は sim のボットが最大2本までしか持たないため届かず、**2本以上に近似**した（3本のままだと V4 は一度も発火しない）。アプリの実プレイでは発火が減る可能性がある。
- V2/V4 は体力消費・ネタの鮮度変化・疲労を入れていない（稽古の代わりに週が埋まるだけ）。V4 の「観客動員の結果で報酬変動」は知名度比例の決定式で近似（乱数なし）。
- 空白週は休みの回数で数えた。V2/V4 が稽古の週を置き換えるため値がほぼ動かない。「稽古も休みもない空き週」はそもそも存在しないので、doc 本文の「空白4か所が埋まる」は sim 上は「稽古週が4か所置き換わる」になる。
- V1/V3 の最終ライン・賞金・資格は late_game_content_v0 §3 の案をそのまま使った（調整していない）。V2+V4 の優勝 -1.4pt は n=1000×4 の誤差（約 ±0.5pt）より大きく、稽古の週が減る効果と見るが、別シードでの再確認はしていない。
