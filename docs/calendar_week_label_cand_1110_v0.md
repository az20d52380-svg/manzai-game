# カレンダー：通算週を「◯月 第◯週」に揃える（候補・論点①の推奨形）

候補ブランチ claude/calendar-week-label-cand。表示だけ（GameCore・週の数え方は不変）。変更は ManzaiGame/Sources/CalendarView.swift のみ。
換算は表と同じ（行＝(w-1)/4 の月・列＝(w-1)%4+1）。暦の始まりは本体どおり第1週＝4月。

| 場所 | 前 | 後 |
|---|---|---|
| 見出し | 1年目　第14週 | 1年目　6月 第4週 |
| 凡例の頂GP決勝 | 第47週が決勝 | 3月 第3週が決勝 |
| 長押しトースト | 第◯週 稽古。 | ◯月 第◯週 稽古。 |

撮影：docs/shots_1110/cal_before.png / cal_after.png（MZ_UI=calendar・iPhone 17）。見出しと凡例が表の行列（月×第1〜4週）と同じ言い方になり、通算週との混在は消えた。長押しトーストは目視していない（コード確認のみ）。
範囲外（触っていない）：週メイン等の他画面の通算週。
