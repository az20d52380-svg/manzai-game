## §3 接続しなかった物と理由
- **接続しなかった本はない。** N17〜N20 の優勝経験者向け条件は新しい保存項目なしで判定できたため接続した（`GameSession.yearHistory` を使う）：N17＝前年が優勝で前々年は優勝でない／N18＝前年は優勝でなく前々年が優勝／N19＝前年も前々年も優勝／N20＝優勝経験があり前年・前々年とも優勝でない。「直近の大会が優勝直後の年」「王座を失った翌年」「連覇中」「優勝後も続けている年」を、年の記録（champion）だけで言い換えた（解釈。オーナーの意図と違えば直す）。
- sim（実測機）に載せなかった物：N17〜N20（上記）。
- 抽選に入れた物の年条件は GameCore（`weeklyFireable(year:)`）。優勝条件だけ GameSession の追加ゲート（yearHistory が GameSession にしか無いため）。

## §4 入れる時の注意
1. **優勝率の再設計が先**：変更前から帯を外れているので、この枠＋40本をそのまま入れると優勝 20%前後になる。選択肢は①40本の効果を弱める（能力+1を外す・メンタルや体力に寄せる）②イベントの能力アップを年の成長上限に数える（AUTOPILOT 115 の1問）③枠を 15+1×(年−5)〜 2 に下げる、のどれか。規律A（cap・乱数・式に触れる）として再測してから。
2. お金が増える選択肢（E9・E11・E16・E18・N2・N3・N8・N15 ほか）は late_game_content §4 の「4分の1まで」の目安に対し、E で4本・N で4本（E3 は減る側）。実測はお金寄りにしない前提で再測。
3. **セーブ互換**：ChoiceEventKind は Codable。新しい case が入ったセーブを古いビルドで読むと失敗する（ロールバックの時だけ）。古いセーブを新ビルドで読むのは問題なし。
4. 目視：lateN07（一番長い物）を iPhone 17 で1枚確認＝ト書き・吹き出し3つ・二択ボタンが崩れず収まる（`SIMCTL_CHILD_MZ_UI=event SIMCTL_CHILD_MZ_EV=lateN07 SIMCTL_CHILD_MZ_EVSTEP=99`。MZ_EV は kind の rawValue で40本どれでも開ける）。実機で全文を読む確認と、setup の吹き出し数（規約4〜6に対し3つの本が多い）は判断待ちのまま。
5. 検査の通し：GameCore swift test 456 件 green／`check_golden_sync.py` 全一致／`check_config_sync.py` 68/68／xcodebuild test 356 件 green／アプリのビルド error なし。
6. 取り込み時：`ChoiceEvent.swift` の enum・switch と `GameSession.applyEventChoice` の switch に40件の case が並ぶ（他の候補が kind を足すと同じ場所で衝突する）。テストは新規ファイルだけ。
