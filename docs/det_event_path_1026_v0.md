## 読み方
- 決勝への効き目が大きいのは **能力**（−4〜10pt）と **相性**（−5〜13pt）。7種の効果を全部外すと −10〜17pt。メンタル・知名度・体力は誤差〜−3pt。
- お金（谷口のバイト話の +15万）は決勝に −1〜3pt 効くが、10年目の所持金はほぼ変わらない（早い年の下支え＝稽古に回せる週が増える経路）。10年目所持金を下げているのは相性（−50〜155万）。
- 能力を上げているのは：負けた後（弱い所+2）・3連敗の話（表現+2）・通過の休み（センス+2 か 表現+2）・前夜（表現+1）・通過の分かれ道（弱い方+1）。相性は：結成初期（+2）・負けた後（+2）・3連敗の話（+1）・通過の休み（±1）・通過の分かれ道（+1）。
- §3 の案B（イベントの効き目を下げて元の帯に戻す）を選ぶ場合の当て先の候補（決めない）：能力+2 の3つを+1に／結成初期の相性+2を+1に。どれを下げるかで次に測る（規律A＝ChoiceEvent.swift と sim の両方・golden はイベントを回さないので不変の見込み）。
