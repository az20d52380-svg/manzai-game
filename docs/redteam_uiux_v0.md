# UI/UXレッドチームレビュー v0（2026-08-08）

オーナー指摘「見たけど全くパワプロっぽくもないしゲームっぽくない」への対応。ソシャゲ/スマホゲーの
UI/UXデザインプロを想定した4視点（視覚的階層／パワプロ実機との一致度／ゲームフィール・演出／初見の
分かりやすさ）で独立にレッドチームレビューを実施。**難易度・優勝率などのバランス調整は対象外**
（オーナー指示により別便）。対象スクショ: weekmain / allocation（のばす）/ cards（稽古カード）/
notebook（ネタ帳）/ calendar / grown（能力マックス状態）。

## 0. 総評（4視点に共通して出た核心）

個々のデータ構造（能力値・経験点・相性など）自体は実装されているが、**「立体感」「キャラの生きた表情」
「情報の重み付け」「記号の意味の説明」の4つが全画面で欠けている**ため、結果として「経験値管理シート」
「設定アプリ」に見える、という診断で4エージェントが一致した。個別のパーツ（等級バッジの色分けなど）には
パワプロっぽさの萌芽があるが、それが「同格に並んでいるだけ」で強弱が付いていない。

## 1. 最優先（複数視点で重複・最重度）

1. **キャラが無表情の色シルエット**（weekmain中央）。青/赤の丸頭ブロックが直立するだけで、表情・ポーズ差分・
   成長時の見た目変化が一切ない。4視点全員が「ゲームっぽくない」の最大要因としてここを挙げた。
2. **画面中央（weekmainの主役スペース）が死んでいる**。査定ランクや実力値などの「今週いちばん見せたい数字」
   が置かれておらず、木目調ステージの空白がそのまま残っている。
3. **体力・やる気（テンション）ゲージが常時表示されていない**。消費コスト表示（-20等）はあるが、現在値の
   ゲージ／顔アイコンがどこにもなく、育成ゲーの生命線が欠落している。
4. **単漢字の色付きバッジ（関/語/闇/存/胆）が凡例なしで登場**。稽古カードと「のばす」画面の両方に出るが、
   初見では暗号。閃き/語彙/間合い/存在感/胆力の略だと推測できる人はまずいない。
5. **等級バッジ（G/F/E/D/C/B/A/S）が単色フラットで、ランクが上がっても質感が変わらない**。実機は銅→銀→金→
   虹のような格上がり演出があるが、今は色が違うだけの同じ形。「成り上がり感」という一番の快感演出を潰している。

## 2. severe（画面ごとの作り込み不足）

- **「のばす」画面の経験点5×5テーブルが罫線もない数字の羅列**（Excelそのものと4視点中3視点が指摘）。ゲージ化
  や濃淡での表現が要る。
- **ボタン（「注ぐ」等）が押せそうに見えない**。影・ハイライト・ベベルがなく、無効/有効の区別も色の濃淡だけ。
- **稽古カードが「To-Doアプリのリスト」に見える**。効果の大小・体力消費の重さが視覚的に区別できない（全カード
  同じ白背景・同じ枠線）。
- **カレンダーが表計算グリッド**。イベントアイコンや大会マスの演出がなく、凡例も画面下に小さく孤立している。
- **ネタ帳のレーダーチャートが枠に対して値が小さすぎ、成長の説得力がない**。「成長の器」も空リングのみで
  何が満ちるゲージか説明がない。
- **通貨/評価アイコンの記号が画面ごとに不統一**（weekmainは丸コイン+文字、allocationは角丸バッジ+文字）。
- **weekmain右上の優勝/無双バッジが浮遊していて機能かただの装飾か不明**。
- **同じ丸コインアイコンが「評価ランク」にも使われており、画面下部の実際のお金（¥表示）と混同しやすい**。

## 3. 中度・軽微

- 全体の配色がクリーム×細ボーダー×薄影で「ヘルスケア/Duolingo系ウェルネスアプリ」寄り。実機は原色＋黒縁+
  ベベルの「スポーツゲームのステータスシート」感が強い。
- ネタ帳のヘッダーに顔グラ/マスコットがなく、コンビへの愛着を作る視覚アンカーが無い。
- ストーリー演出画面（rt_grown.pngで実際に写っていたのは成長後メインではなく物語演出画面だった）が発話者
  不明の地の文のみで、メニュー画面と区別がつきにくい。
- 経験点テーブルの「＝」記号が未説明（変化なし、の意だが説明なし）。
- 下部バーの緑ゲージ「100」に単位・ラベルがない。
- 「谷口評」バッジが誰の評価で何のランクなのか文脈が無い。

## 4. 良かった点（そのまま活かす）

- 「春新人賞A あと8週」のリボン風フラッグピルは実機のトーナメント告知バナーに近く、素直に良い評価。
- 経験点テーブルの行=能力／列=通貨という構造自体は実機に忠実（バッジ処理だけ弱い）。

## 5. 次アクション（提案・未着手）

このドキュメントは調査結果の記録のみ。実装するかどうか・どこから着手するかはオーナー判断待ち。バランス
（難易度・優勝率）はスコープ外のまま。想定される着手順（提案）:
1. キャラ表情/ポーズ差分の追加（③イラスト外注や簡易差分でも効果大・複数視点で最重度）
2. weekmain中央への「主役情報」設置＋体力/テンションゲージの常時表示
3. 単漢字バッジへの凡例orツールチップ追加（実装コスト低・即効性あり）
4. 等級バッジの格上がり演出（色だけでなく質感/エフェクト）
5. ボタンの立体感（影・ハイライト）底上げ
