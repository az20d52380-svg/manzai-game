## B. 止まらない（絶対）
- 作業を止めるのはオーナーの「止めて」だけ。「キューが空」「判断待ちだけ」「分からない」は止める理由にならない＝AUTOPILOT §常設の作業（リサーチ・実測・目視・テスト・採点・材料づくり）から足して続ける。
- 返事（チャットの文）を書くと止まる。区切ってよいのは C の「待つ」の時だけ。その時も**必ず背景の sleep を入れてから**1行返す。
- 嘘の進行形を書かない。「進めます」と書くなら、動いている物（背景の sleep・サブエージェント・定期タスク）を名指しする。

## C. 使用量の線と自動再開（絶対に忘れない）
**【2026-10-16 オーナー改定】60%・70%の線は廃止。使用量を理由に自分から止めない。止まるのは本当の上限（100%）で作業できなくなった時だけ＝その時に下の手順（中断中→コミット→リセット＋5分まで背景 sleep→自動再開）。下の表の60%/70%は「100%」と読み替える。**
| 状態 | やること |
|---|---|
| 5時間枠 < 60%（週は100%まで可） | 作業を続ける。作業1件ごとに get_usage。 |
| 5時間枠 ≥ 60% | ①未コミットの変更があれば §中断中 に書いてコミット・push ②`get_usage` の5時間枠 resetsAt＋5分までの秒数を `date` で計算し、Bash `run_in_background: true` で `sleep <秒>; echo 再開` ③定期タスクが enabled か確かめる ④1行だけ返す。タイマーが切れたら A-3 から再開。 |
| 週 ≥ 70% | **【2026-10-15 オーナー改定】週の線では止めない。100%に届いたらオーナーが無料リセットする＝続ける。** 100%で作業できなくなった時だけ、同じ手順で、週の resetsAt＋5分まで sleep。**PushNotification でオーナーに「週の上限に届いた・無料リセットがあれば押してね」と通知**（押されたら次の回で使用量が戻っているので再開）。 |
- sleep の秒数の出し方：`now=$(date -u +%s); t=$(date -u -j -f "%Y-%m-%dT%H:%M:%S" "<resetsAtの秒まで>" +%s); echo $((t-now+300))`
- 定期タスク（1時間ごと）は控え。チャットとぶつからないよう、対話中はこまめにコミットする（定期の回は30分以内のコミットがあれば見送る）。
