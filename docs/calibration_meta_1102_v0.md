## §2 探索で分かったこと（n=300・ネタ込・`calib_meta_1102_explore_v0.txt`）
- **型1 だけでは優勝が上がらない**ことを再確認した（点38 で 2.3%）。解散は点8で 17%、点38で 23%（必要充足 52〜63%）。
- **累計予算の上乗せ J0 はよく効く**。線形 0.5/点で点8 9.6%・点20 31%。ただし J0≈30 を超えると予算が効かなくなり、上限が出る（点38 で 65%・1年目は0）。予算以外で止まっているため。
- **年の成長上限の持ち上げ（cb）**も効き、ボットごとの差が小さい。ただし線形 ×点だと点30で 97% と急になるので、点^0.3 にした。1年目の上限は +cb·点 しか増えないため、**cb だけでは1年目の優勝は出ない**。
- **演技系の上限＋逓減 D を 120+点**（`trophy_design_v1` の D=120+pt の形）は効かない。かえって下がる（点38 で 1.5〜1.7%）。今の能力は 120 に届かず、逓減もほぼ効かないため。
- **1年目の壁**：点38で予算を足しても、1年目の実力は約43で頭打ちになる（経験点の量で決まる）。準決勝 78 に対して得点は 55〜60。1年目の優勝を出すには、**予算（J0≈36〜38）＋初期経験点 約450＋相性 +14 が全部要った**。相性だけ（+9.5）でも経験点だけ（480）でも 0〜0.3% にとどまる。
- **解散**：すれ違いは「相性が上限より低い週」にたまる。型1 の初期経験点で間（ネタ合わせの通貨）が足りてしまうと、必要充足は相性が上がるネタ合わせを選ばなくなる。所持金が40万を超えると有料の稽古（ネタ見せ会）でも間を取る。原因側の案「型1 の配分から間を外す」（sm=0）は、点20〜38 では解散を 22〜23% から 8〜3% に下げた。しかし点8では 24% で、足りなかった。**初期の相性を前寄せ（+2.27·√点）にすると、点8から解散が点0以下に下がる**。しかも相性だけなら優勝はほぼ動かない（点38 で 3.4%）。

## §3 推奨と次点
- **推奨 案2（年の上限型）**：
  - 2周目の幅（点6〜11）で 9.1〜13.1%。目標 10〜15% にほぼ入る（点6 だけ 9.1%）。
  - **ボットごとの差が一番小さい**（点20 で 20.0〜28.1%、案1 は 10.9〜32.7%）。のんびり・やり込みの両方が上がる。
  - 「伸びしろの天井が上がる」を、正典にすでにある才能解放（`canon_v2.TROPHY_LIFT_PER_PT`＝上限カーブの持ち上げ）の形で表せる。説明もしやすい（周回するほど毎年伸びる幅が広がる）。
  - 点20→30 の上がりも案1 より緩い（22→73%）。
- **次点 案1（予算型）**：J0 の1本の式で書けて、1年目の優勝・15連覇は案2より多い（11.3／1.3%）。ただし必要充足が遅れ（点20 で 10.9%）、点30 で 82% と早く飽和する。
- どちらも、相性の前寄せで解散が周回で減る（7.5→3%前後→0）。頂点の束（^8）は点30 までほとんど効かず、点34〜38 で一気に効く。

## §4 所見（5行）
1. 【設計上の懸念・オーナー判断待ち】1年目の優勝と15連覇を0でなくすると、点34以上では15年内の優勝がほぼ100%・平均12回優勝・3連覇以上100%になる（1年目に決勝ラインへ届く実力は、2年目以降は余る）。「集めきったら勝ち続ける」でよいか、王者ライン等で連覇を抑えるか（`dynasty_v2_research_v0.md` §8 (C)）を一緒に決める必要がある。
2. 点30→38 の段差が大きい（73→100%）。頂点の束を ^8 より緩くすると、点30 が 99% に跳ねた（^4 で測定）。点30〜34 の中間を滑らかにするなら、束の量（36／300／14）を少し下げて、点38 の 15連覇が0にならない境を詰める余地がある。
3. 点38 の1年目の優勝はネタ込でのんびり/ローテに寄る（13.9/12.3% に対して、やり込み 2.0%）。ネタ無では 4ボット 7〜9% で揃う。「やり込み系なら」とは逆向きで、原因は未調査（ネタの使い方の差と見込み）。
4. 解散は、相性の前寄せで原因側から消える。点8 で残る 3.6% は必要充足の 11.7%（点0 は 3.7%）。原因側の案（型1 の配分から間を外す）は中盤以降にしか効かなかった。
5. 必要充足は点30 で 49%（他は 66〜91%）で、ボットの中で一番遅い。1101 §4-3 と同じく、準決勝・決勝のライン上げが大会の経験点に頼らない伸び方に効くため。
