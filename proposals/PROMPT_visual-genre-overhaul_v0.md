## 2. やってほしいこと（一気に、ただし順番は守る）
1. **リサーチ**：育成SLG／シミュレーションの代表作（例：パワプロのサクセス、ウマ娘、ダビスタ、カイロソフト作品、プリメ、ときメモ、Reigns 等。選定は任せる）を、**画面の作り**の観点で比べる。
   - 見る観点：画面ごとの明るさと色の使い方／文字の大きさと書体／会話・イベント画面の作り（立ち絵・名前札・吹き出し・送りの合図）／結果・優勝の演出（光・紙吹雪・数字の出し方・音）／週送りのテンポ／「育てている実感」の見せ方。
   - 他社タイトル名は調査ドキュメントの中だけ。**ゲーム内には持ち込まない**。
2. **診断**：本作の全画面を simulator で実際に通して（イントロ→週メイン→イベント→大会→決勝/優勝→年末）、上の観点で「どこがジャンル水準に届いていないか」を画面ごとに言い切る。スクショ付き。
3. **設計**：画面ごとの直し方を1枚の doc（`docs/visual_genre_overhaul_v0.md`）にまとめ、必要ならモック HTML も作る。**数値・ルール・GameCore には触れない案から先に**並べる（規律B-5：体感は演出で直す）。
4. **オーナー承認を取ってから実装**。実装は1目的1コミット、1画面ずつ。各画面は simulator で目視（規律D-10）。

## 3. 絶対制約
- 固有名は全て架空。ネタ本文を一文字も書かない。新しいゲーム内テキストは `.claude/skills/manzai-drama-voice/` を通す。
- GameCore の数式・乱数消費順・GameConfig 既定値を変えない（変えるなら規律A＝golden全再測と明記してオーナーに聞く）。`cd GameCore && swift test` は常に green。
- 新規 Swift ファイルを足したら `cd ManzaiGame && xcodegen generate`。
- 質問は1論点ずつ・推奨理由つき。長い成果物はファイル＋短いカバー（保存先／要点3行／節マップ）。オーナーのペースに触れない。

## 4. 作業上の注意（前チャットで踏んだもの）
- simulator：**iPhone 17 Pro はオーナー試遊用**。自分の確認は別端末（iPhone 17 Pro Max 等）で行い、**オーナーが触っている端末には触らない**（前チャットで同じ端末を同時に操作して試遊を壊した）。どの端末がパネルに出ているか、最初にオーナーに確認する。
- tap と screenshot は別ターン（アニメより先に撮れてタップが1つずれる）。週送り直後はイベントが遅れて出るので、もう一度撮ってから次をタップ。
- 旧セーブを消すには `xcrun simctl uninstall` → install が確実（plist 直接編集は cfprefsd のキャッシュで効かない）。
- `~/Desktop` はサンドボックスで読めない。オーナーのスクショはチャットに貼ってもらう。
- DEBUG ビルドの右上「🏆優勝／💪無双」ボタンはリリースに出ない（目視の妨げにはなる）。
